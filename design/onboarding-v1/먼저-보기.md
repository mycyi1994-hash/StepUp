# StepUp 시작·로그인·첫 사용

Google 로그인 → 한 장 안내 → 첫 러닝으로 연결했습니다. 러닝 패스의 짙은 남색·흰색 버튼과 기존 강변 이미지를 사용했습니다.

## 전달 구성

- 새 장면 20개: 시작·로그인·오류·첫 안내·홈 연결·권한 분기
- 비교 보드 10개, 각 화면의 PNG와 편집 SVG
- 분리 부품 12개: Google 버튼 2종, 주·보조 버튼, 약관 링크, 오류 안내, 첫 안내·권한 시트, 안내 행
- 기존 러닝 연결 참고 SVG 4개: 새 화면 수에 포함하지 않음
- Claude 구현 지시서, 화면 전환표, 권한 상태표, 색상·간격 수치, 원본 이미지·폰트

## Claude 전달

[복사해서 보낼 문장](Claude에게-보낼말.txt)과 [구현 지시서](Claude-구현지시서.md)를 함께 전달하세요. [화면 목록](screen-index.json), [전환표](flow-map.json), [권한 상태표](permission-matrix.json)에 행동별 연결이 있습니다.

첫 안내는 한 장입니다. 홈을 둘러보는 동안 권한을 요청하지 않으며, 권한이 이미 있는 사용자는 해당 단계를 건너뜁니다. 실제 Google 계정 선택창과 OS 권한창은 자체 디자인으로 대체하지 않습니다.

## 편집과 재사용

SVG의 문구·도형은 편집할 수 있고 버튼과 모달은 03-components에 분리했습니다. 텍스트를 수정하려면 assets의 Pretendard 폰트를 설치하세요. 사진·로고는 포함된 비트맵 자산입니다. Figma Auto Layout·Variant·프로토타입 연결을 생성한 파일은 아닙니다.

04-reused는 이전 러닝 패키지의 원본 SVG입니다. 기존 실행 중 화면까지 이번 시안으로 교체하라는 의미가 아니며 상태와 연결을 참고하는 자료입니다. [재사용 출처](reused-index.json), [이미지 출처](asset-provenance.json)를 함께 제공합니다.

이 자료는 디자인 전달본입니다. Android 코드 변경, 실제 로그인·권한·서버 테스트, 온라인 Figma 반영은 수행하지 않았습니다. [파일 검수 결과](검수결과.json)를 확인할 수 있습니다.
