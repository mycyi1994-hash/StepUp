현재 STepup 앱에 이 패키지의 디자인과 에셋을 적용하세요. 기존 프로젝트를 실제로 수정하고 기존 동작을 보존하세요. 계획만 제출하지 마세요.

목표 화면 전체를 한 장의 배경으로 붙이고 투명 버튼을 올리는 방식은 금지합니다. 캐릭터는 이미지, 텍스트·버튼·카드·탭·기록·지도는 실제 동작하는 컴포넌트로 분리하세요. 이미지의 휴대폰 테두리, 시안 제목, 시간·배터리 상태바, 하단 설명문은 앱에 복제하지 마세요.

## 변경할 구조

하단 탭은 러닝 / 꾸미기 / 커뮤니티 / 내 정보 네 개입니다. 선택 표시와 화면 이동을 구현하세요. 기존의 3개 탭 참조가 남아 있다면 이번 패키지를 우선합니다.

- 러닝: 오늘 획득 포인트, 캐릭터, 오늘 거리·시간, 목표, 러닝 시작. 소식·챌린지는 작은 보조 진입점.
- 꾸미기: 남녀 기본 캐릭터, 의상/신발, 보유·미리보기·장착, 마켓 진입.
- 커뮤니티: 러닝 기록과 짧은 글 중심의 간단한 피드.
- 내 정보: 포인트 잔액·적립 내역·주간 거리·최근 기록·설정.
- 마켓은 꾸미기 하위, 소식·챌린지는 러닝 하위.

한 화면의 큰 주 행동은 하나로 정하세요. 시세·달러 환산·능력치·내구도·강화 UI는 새 디자인에 추가하지 마세요. 기존 데이터·보상 정책·보유 자산을 임의 삭제하거나 수정하지 마세요.

## 캐릭터 적용

남녀 기본 캐릭터는 고정 외형이며 NFT가 아닙니다. 의상·신발만 NFT 대상입니다. 얼굴·귀·손·팔·다리의 노출 피부는 모두 같은 짙은 블랙·네이비입니다. 살구색 피부를 다시 도입하지 마세요.

캐릭터 파일은 프로젝트의 정적 이미지 경로에 복사하고 실제 화면에서 불러오세요. contain으로 비율을 유지하며 얼굴·신발을 자르지 마세요. 일반적인 이미지 최적화는 가능하지만 저해상도 썸네일로 대체하지 마세요. 투명 여부는 파일을 검사하여 판단하세요. 불투명 배경이 있으면 임의의 전역 색상 필터 대신 정밀한 배경 제거 또는 에셋 수정 필요 상태로 처리하세요.

이 패키지는 모든 포즈와 모든 아이템 조합의 완성 에셋 세트가 아닙니다. 남자 달리기·여자 서 있기 두 에셋이 준비되어 있습니다. 남자 서 있기·여자 달리기·축하 포즈와 옷/신발 교체 조합이 필요한 위치는 추가 에셋 필요 목록에 기록하세요. 같은 에셋 재사용은 가능하나 다른 성별·다른 아이템을 착용한 것처럼 속여 표시하지 마세요.

실시간 3D 모델이 필요하다고 가정하지 마세요. 고품질 정적 에셋으로 우선 화면 품질을 맞추고, 지원되는 조합을 명시적으로 매핑하세요. 아이템 카드만 바뀌고 캐릭터는 다른 신발을 신고 있는 상태를 '장착 완료'로 보고하지 마세요. 지원되지 않는 미리보기는 해당 상태를 분명히 표시하세요.

## 홈 구현 수치 — 시작 기준

390x844 CSS px 콘텐츠 기준, 좌우 여백20px, 헤더48px, 획득 숫자48~56px, SUP24~28px, 캐릭터 무대260~300px, 무대 내 캐릭터 높이85~92%, 지표영역56~64px, 목표52~60px, 바로가기40~44px, 주요 버튼56~60px, 하단탭64px+안전영역. 수치는 캡처를 보며 보정하고 작은 기기에서는 자연스러운 스크롤을 허용하세요.

배경 #040C1B, 카드 #0B1D35, 경계 #1A3B61, 파랑 #147BFF, 시안 #24D8FF, 본문 #F4F8FF, 보조글 #A8BDD9. 카드 반경16~20px, 얇은1px 경계. 빛 번짐은 주요 버튼·포인트·캐릭터 윤곽에 제한하세요. 모든 카드에 두꺼운 외곽 그림자를 넣지 마세요.

캐릭터 뒤에 CSS 방사형 블루 조명, 바닥에 타원형 무대와 부드러운 접지 그림자를 배치할 수 있습니다. 이 효과는 캐릭터 자체를 도형으로 재제작하라는 뜻이 아닙니다. 별도 도시 배경은 제공되지 않았으므로 저작권 불명확한 도시 사진을 가져오지 말고 단순한 저대비 실루엣이나 그라데이션으로 처리하세요.

## 데이터와 동작

이미지의 수치·경로·이벤트·가격은 예시입니다. 기존 앱 데이터를 사용하고 데모는 운영 데이터와 분리하세요. 실제0SUP를 시안처럼120SUP로 조작하지 마세요. 지도 시안은 GPS 지도 데이터가 아니므로 실제 경로 이미지로 사용하지 마세요.

러닝 상태, GPS 권한, 일시정지/재개, 종료 확인, 기록 저장을 기존 로직과 연결하세요. 예상 포인트와 확정 적립을 구분하고 화면 재진입·연타로 중복 적립되지 않게 하세요. 지갑·보상·계정·보유 아이템 코드는 보존하세요. 신규 서버 접속·배포·운영DB 변경·실제 NFT 거래는 하지 마세요.
