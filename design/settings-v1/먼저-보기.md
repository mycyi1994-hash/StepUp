## 전달 파일

- `01-screens`: 화면·상태·모달 28개, 각각 PNG/SVG.
- `02-boards`: 두 장면을 나란히 보여주는 비교 보드 14개, 각각 PNG/SVG.
- `03-components`: 목록 행, 스위치, 선택 행, 권한 행, 안내, 버튼, 토스트, 모달 등 13개, 각각 PNG/SVG.
- `assets`: Pretendard Regular/Semibold와 라이선스.
- `Claude-구현지시서.md`: 화면 연결, 실제 앱 데이터와의 대응, 저장·오류 처리, 확인 항목.
- `Claude에게-보낼말.txt`: 패키지와 함께 전달할 요청문.
- `FAQ-문구.md`: 도움말 답변안과 기존 정책의 구분.
- `design-tokens.json`, `screen-index.json`, `flow-map.json`: 디자인 값, 장면 목록, 주요 화면 연결.
- `검수결과.json`: 파일 개수·크기·SVG 형식 확인 결과.

## 편집과 구현

개별 화면은 390 × 844, PNG는 3배 크기입니다. SVG의 UI 글자는 Pretendard 텍스트로 남겼습니다. Figma에서 가져온 뒤 레이어·폰트를 확인하고 Auto Layout과 인터랙션을 설정하면 됩니다. 중국어·일본어 언어 이름은 해당 언어를 지원하는 시스템 폰트가 필요합니다.

SVG는 편집 원본이며 완성된 Figma 컴포넌트 라이브러리나 실행형 프로토타입은 아닙니다. 버튼·스위치·모달은 별도 파일로 분리했습니다. 화면에 보이는 값과 권한은 예시이며 실제 사용자 상태로 대체합니다.

현재 앱의 외부 계정 연결은 준비 상태를 유지합니다. 설정 저장은 휴대폰 저장, 서버 반영, OS 권한을 구분합니다. 계정 삭제는 실제 결과가 확인됐을 때만 완료로 처리합니다.
