## 가이드에서 떼어 낸 그림

`avatar_male_idle.webp` 는 RUNO 가이드의 3/4 전신을 잘라 바탕을 지운 것이다
(`tools/cutout_character.py`). 가이드 바탕이 불투명한 회청색이라 색으로 바탕을
채워 지우고, 흰 밑창이 바닥 그늘과 같은 색이라 파이는 곳은 신발마다 볼록 껍질로
원래 픽셀을 되살렸다. 원본 크기가 309×573 이라 2배로 키웠다 — 큰 화면에서는
다른 두 장보다 흐리다. 같은 자세의 고해상도 투명 렌더가 오면 같은 이름으로 바꾼다.
