## 들어 있는 것

- `01-screens`: 새 지갑 시안 16개, 각각 PNG/SVG.
- `02-boards`: 두 장면씩 비교하는 보드 8개.
- `03-components`: 잔액 카드와 글자 없는 카드 배경, 연결 행, 필터, 적립·사용 행, 버튼, 모달 3종. 총 10개를 분리.
- `04-reused-connection`: 이전 신발 뽑기 전달본의 연결 화면 6개와 분리 모달 5개를 재사용 자료로 포함. 신규 장면 수에 포함하지 않음.
- `assets`: Pretendard Regular/Semibold와 라이선스.
- `Claude-구현지시서.md`, `Claude에게-보낼말.txt`: 바로 전달할 작업 지시.
- `sample-ledger.json`: 금액이 서로 맞는 예시 원장. 실제 보상량이나 가격 정책이 아님.
- `design-tokens.json`, `screen-index.json`, `flow-map.json`: 디자인 값, 장면 목록, 주요 연결표.

## 기존 앱과의 연결

확인한 앱 소스의 지갑은 앱에 기록된 SUP와 이용 내역을 보여주며, WEB3 지갑 연결은 아직 준비 상태입니다. **현재 기능에 적용하는 화면은 12번**입니다. 연결 전·후·재연결 시안은 실제 연결 기능이 준비된 뒤 해당 상태에 맞춰 사용합니다.

신발 뽑기는 사용자가 정한 무료 정책을 유지합니다. 연결 선물·러닝으로 받는 상급 뽑기 기회를 SUP 적립이나 사용으로 만들지 않습니다. 사용 내역 예시의 신발 강화는 기존 데이터 유형을 보존하기 위한 과거 기록이며, 새 강화 기능이나 가격을 제안한 것이 아닙니다.

## 편집 방법

개별 화면은 390 × 844 기준이고 PNG는 3배 크기입니다. SVG의 UI 글자는 Pretendard 텍스트로 편집할 수 있습니다. Figma에 가져온 뒤 폰트와 레이어를 확인하고 필요한 Auto Layout과 연결을 설정합니다. 자동으로 동작하는 Figma 프로토타입이나 실제 앱은 아닙니다.

숫자·이름·내역은 모두 예시입니다. 카드 오른쪽의 선은 러닝 패스 톤을 잇는 장식이며 지도나 거래 차트가 아닙니다.
