# StepUp S2 이미지 자산

원본 17종 / 여백 정리 8종 / Figma 개별 IMAGE 렌더 13종. 세 수치는 원본과 파생본이 중복된 수치다.

기획 시작점: [docs/redesign/s2](../../docs/redesign/s2/README.md). 화면 출처: [Figma S2](https://www.figma.com/design/BxZ1zZo74Ym7Rb8mM8cDJn/?node-id=5-2).

## 사용할 파일

| 폴더 | 용도 |
|---|---|
| originals/backgrounds/ | 배경 7종, 780×1200. 원본을 알맞게 자르고 그라데이션/아치 마스크는 실제 UI로 구성 |
| originals/shoes/ | 신발 5종, 640×640. 상품 매핑을 확인하고 원본 해상도 안에서 사용 |
| originals/brand/ | 흰 StepUp·컬러 StepUp·Google 로고. 원래 비율 보존 |
| originals/reference/maps/ | 지도 2종. 디자인 참고 전용, 실제 운동 지도나 타일 대체 금지 |
| cutouts/ | 신발/로고의 기존 알파 채널 여백 정리본. 8px 투명 패딩. 색 변경/확대/새 배경 제거 없음 |
| layer-exports/ | 개별 이미지 레이어의 Figma 렌더. 부모 프레임의 아치·그라데이션 등은 미포함 |

`manifest.json`에 각 원본의 SHA-256, Figma imageHash(파일 SHA-1), 해상도, 알파 여부, 사용 노드, 크롭 좌표가 있다. `figma-screen-index.json`에는 45개 화면 ID와 이미지 사용 위치가 있다. 만료되는 다운로드 URL이나 로그인 정보는 포함하지 않는다.

`home-sea.jpeg`는 초기 파일명이며 실제 이미지는 도시 야경이다. 광안리 기본은 `gwangalli.jpeg`. 낮·노을·밤·비 배경은 풍경 자산이며 실시간 날씨 연동의 증거가 아니다.

## 확보하지 못한 4개 합성물

사용자는 Figma의 내보내기 제한(`not allow`)을 확인한 뒤 현재 파일만으로 진행하도록 지시했다. 원본 추출을 다시 요구하거나 이 때문에 모든 구현을 멈추지 않는다.

| 미확보 항목 | 노드 | 기획의 대체안 |
|---|---|---|
| S2 뽑기 상자 | 5:1072 | 기존 `app/src/main/res/drawable-nodpi/mystery_box_closed.webp`를 S2 구도에 배치. 그림이 다른 점 명시 |
| SUP 도트 코인 | 5:593 | 우선 SUP 글자/기존 상태 아이콘 사용. 원본 코인을 추출했다고 보고하지 않음 |
| 시작 카드 합성본 | 5:771 | 확보 로고+카드 면+문구+경로 그래픽을 실제 UI로 조합 |
| 아치형 배경 합성본 | 5:47 | 확보한 풍경 원본+아치 마스크+그라데이션으로 조합 |

`manifest.json`의 pending은 추출 당시 미확보 목록이지 개발의 중단 조건이 아니다. 모든 대체안이 이미 앱에 구현되었다는 뜻도 아니다.

## 해상도와 진실성

- 작은 비교 PNG와 전체 보드 썸네일을 확대해 제품 자산으로 사용하지 않는다.
- 글자·버튼·수치·탭·그래프는 원본 이미지에 합성하지 않고 네이티브 UI로 구현한다.
- 시안의 예시 수치/모임/소유를 실제 데이터처럼 넣지 않는다.
- 5개 신발 파일로 기존 전체 상품을 일괄 대체하지 않는다. 모델과 그림이 맞지 않으면 기존 자산을 유지한다.
- 앱 글꼴은 기존 `app/src/main/res/font/`와 라이선스 정보를 사용한다. 이 폴더에 글꼴을 중복 보관하지 않았다.
