# StepUp 신발 뽑기 전체 시안

무료 뽑기와 상급 뽑기를 한 화면의 두 칸으로 배치한 최신 디자인이다. 종전 두 탭 시안을 대체한다.

## 먼저 열 파일

1. `02-boards/01-two-compartments.png` — 지갑 연결 전·후의 메인 화면.
2. `02-boards/02-free-draw-flow.png` — 뽑기 시작부터 결과, 보유 신발 복귀까지.
3. `02-boards/03-wallet-flow.png` — 지갑 연결 안내, 연결 중, 완료, 실패.
4. `04-motion/free-draw-flow-60fps.mp4` — 메인 → 뽑기 → 결과 → 내 신발, 9초 재생 영상.

## 들어 있는 것

| 폴더 | 내용 |
| --- | --- |

PNG는 외형을 확인하는 기준 이미지다. SVG는 텍스트와 도형·이미지를 분리한 원본이다. Pretendard 폰트를 사용할 수 있는 환경에서 Figma로 개별 SVG를 가져와 작업할 수 있다. SVG 가져오기 자체가 Figma의 Auto Layout이나 클릭 프로토타입을 생성하지는 않는다. 버튼 연결은 동봉한 연결표를 따른다.

현재 산출물은 디자인과 모션 전달본이다. 실제 앱의 소스, 회원 횟수, 지갑 상태는 변경하지 않았다. 특정 외부 지갑 앱의 선택·서명 화면은 해당 앱 또는 연결 SDK 화면을 사용한다.

가입 당일은 가입 10회 + 당일 3회 = 13회로 예시를 잡았다. 0.6km 러닝 진행과 시티 스프린트 결과는 화면 설명용 예시다. 실제 신발 지급 목록이나 확률을 뜻하지 않는다.
