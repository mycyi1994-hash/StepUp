# StepUp · 프로필 수정

선택한 러닝 패스 스타일을 이어가는 프로필 수정 디자인 전달본입니다. 사진과 닉네임을 수정하는 화면, 사진 선택 메뉴, 저장·실패·나가기 상태를 담았습니다. **디자인 시안이며 실제 앱 적용본이 아닙니다.**

## 전달 파일

- `01-screens`: 12개 장면. 각 장면의 PNG와 편집용 SVG.
- `02-boards`: 흐름을 두 화면씩 묶은 비교판 6개.
- `03-components`: 사진 대체 이미지, 입력 필드, 버튼 2종, 오류 안내, 사진 메뉴, 기본 이미지 선택, 나가기 확인. 8개 요소를 각각 PNG/SVG로 분리.
- `assets`: 기존 러닝 패스 카드 배경.
- `Claude-구현지시서.md`: 기존 Android 앱에 적용할 때의 화면·저장 규칙·오류 처리·검수 기준.
- `Claude에게-보낼말.txt`: 전달 시 붙여 넣을 요청문.
- `screen-index.json`: 장면 목록.
- `design-tokens.json`: 색상·크기·간격.

## 유지한 동작

사진·기본 이미지는 고르면 바로 저장합니다. 닉네임은 아래 `저장`을 눌러야 반영합니다. 그래서 나가기 확인은 **저장하지 않은 닉네임만** 대상으로 하며, 이미 바꾼 사진은 유지된다고 안내합니다.

닉네임은 기존 코드의 최대 16자 기준을 유지하고, 비워두는 것도 허용합니다. 앨범 선택 화면은 운영체제의 사진 선택기를 사용합니다. 기존 기본 이미지 16개는 보조 메뉴에 남깁니다.

## 편집 안내

개별 화면은 390 × 844 기준이며 PNG는 3배 크기입니다. SVG의 일반 UI 글자는 Pretendard 텍스트로 남아 있습니다. Figma 등에 가져온 뒤 폰트와 레이어를 확인하세요. SVG는 편집용 그래픽 원본이며 **Auto Layout, 프로토타입 연결, 실제 입력 기능이 설정된 Figma 파일은 아닙니다.**

기본 이미지 선택에 사용한 기호는 기존 앱의 `AvatarEmojis` 16개를 같은 순서로 표시한 것입니다. 시안 렌더러에서는 단색으로 보이며 실제 Android 이모지 모양은 기기 글꼴에 따라 달라집니다. 새 배지·등급·캐릭터 체계를 제안한 것이 아닙니다.

큰 사람 아이콘은 사진 자리를 보여주는 대체 이미지입니다. 기존 사용자 사진이나 선택한 아바타가 있으면 그대로 표시합니다. 이름·거리·횟수·잔액도 예시입니다.
