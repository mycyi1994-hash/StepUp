# StepUp 러닝 기록 — 목록부터 지난 기록 상세까지

2026-09-28. 남은 리디자인 목록의 1번 ‘내 러닝 기록’과, 바로 이어지는 2번 ‘지난 러닝 상세’를 한 흐름으로 만든 검토용 시안입니다. 사용자가 고른 내 정보의 ‘러닝 패스’ 색상과 경로 그래픽을 이어받았습니다.

## 먼저 볼 이미지

1. `02-boards/01-list-and-statistics.png` — 기본 목록과 주간 통계
2. `02-boards/02-period-and-month.png` — 기간 선택과 월간 통계
3. `02-boards/03-detail-and-map.png` — 지난 기록 상세와 경로 확대

나머지 비교판에는 처음 사용하는 경우, 기록 없는 기간, 불러오기·삭제 실패, GPS가 없는 기록, 통계에서 날짜를 선택한 상태가 있습니다.

## 전달 파일

- `01-screens`: 16개 장면의 PNG와 편집용 SVG. PNG 1170 × 2532, 기준 화면 390 × 844.
- `02-boards`: 두 화면씩 묶은 비교판 8개.
- `03-components`: 기록 요약, 목록 행, 주간/월간 선택, 흰색 버튼, 경로 썸네일, 예시 지도, 빈 상태 그림, 기간 선택 시트, 삭제 확인 시트의 9개 분리 요소. 각 PNG와 SVG.
- `assets`: 이전 커뮤니티 시안의 지도 참고 이미지와 러닝 패스 카드 배경. 실제 지리 서비스나 사용자 경로 데이터가 아닙니다.
- `Claude-구현지시서.md`: 화면별 연결, 집계 방식, 기존 앱 연결 시 주의할 점.
- `screen-index.json`: 장면 이름과 개별 파일 위치.
- `sample-data.json`: 합계와 그래프가 맞도록 정리한 예시 기록 8개.

텍스트는 Pretendard를 사용합니다. SVG를 편집하는 환경에는 해당 글꼴이 필요합니다. PNG는 글꼴 설치 없이 동일한 모양으로 볼 수 있습니다. SVG에는 실제 텍스트가 있으며, Figma 가져오기만으로 Auto Layout이나 프로토타입이 만들어지는 것은 아닙니다.

## 디자인 결정

- 기록 목록을 기본 진입으로 두고, 우상단 `통계`를 눌러 주간/월간 통계로 이동합니다.
- 메인 기록 카드는 러닝 패스 표현을 유지하되 작게 줄여 목록 세 개가 첫 화면에 보이도록 했습니다.
- 각 기록은 큰 박스 대신 경로 썸네일, 날짜, 거리, 시간·페이스와 얇은 구분선으로 정리했습니다.
- 기간 변경은 하단 시트 하나로 처리합니다. 월 또는 전체 기간을 선택하고 `적용`을 누릅니다.
- 기록 상세는 숫자 → 시간·페이스 → 지도 순서입니다. 장소명을 임의로 만들어 표시하지 않습니다.

## 확인 범위

화면과 구성 요소를 이미지로 렌더링해 검토했습니다. 월 합계 34.2km/8회/14,144초와 선택한 주 합계 15.2km/4회/6,214초, 표시 페이스 및 그래프 합계를 대조했습니다. 지도 확대에서도 동일한 경로 형태를 유지하며, 썸네일 그래픽은 모서리 안에 잘립니다.

이번 결과는 디자인과 구현 지시서입니다. 실제 앱 코드, 기록 데이터, 지도 서비스 또는 삭제 기능을 변경하지 않았습니다. `13-no-gps-detail`은 시간만 남아 있는 별도 예외 상태로, 위 8개 예시 기록 집계에는 포함되지 않습니다.
