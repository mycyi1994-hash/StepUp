# StepUp 알림·공지 · 디자인 전달본

개인 소식은 ‘내 알림’, 앱 안내는 ‘공지’에서 봅니다. 짙은 남색·밝은 글자·파란 강조를 이어가며 큰 카드 대신 제목·시간 중심의 목록을 사용합니다.

이번 자료는 **시안과 구현 지시서**입니다. 실제 앱 적용, 공지 게시, 초대 수락이나 보상 지급을 수행한 결과가 아닙니다.

## 파일 구성

- `01-screens`: 23개 장면, 각각 PNG/SVG.
- `02-boards`: 비교 보드 12개, 각각 PNG/SVG.
- `03-components`: 알림 행·공지 행·탭·버튼·토스트·모달 등 12개 분리본.
- `assets`: Pretendard Regular/Semibold와 라이선스.
- `Claude-구현지시서.md`, `Claude에게-보낼말.txt`: 구현 요청과 세부 기준.
- `design-tokens.json`, `screen-index.json`, `flow-map.json`: 디자인 값, 장면과 연결표.
- `sample-content.json`: 디자인용 문구와 데이터. 운영 데이터가 아님.
- `검수결과.json`: 파일 형식·크기·참조 및 시각 검토 결과.

화면은 390 × 844, PNG는 3배 해상도입니다. SVG는 글자·도형 편집 원본입니다. Figma 가져오기 후 레이어·폰트를 확인하고 Auto Layout·컴포넌트·상태 연결을 구성합니다. 완성된 Figma 네이티브 라이브러리나 동작하는 앱은 아닙니다.

기존 ‘러닝 뉴스’는 외부 대회/기사를 보여주는 별도 기능입니다. 이 공지 시안으로 덮어쓰지 않습니다. 앱 공지의 목록·상세 데이터 연결은 새로 필요한 부분이며, 예시 공지를 실제 게시물로 자동 등록하지 않습니다.

읽음/안 읽음을 유지하려면 기존 ‘알림함 진입 즉시 모두 읽음’ 동작을 바꿔야 합니다. 변경 범위와 기존 초대·보상 동작 보존 기준을 지시서에 적었습니다. 강제로 크루를 만들거나 가입시키는 흐름은 추가하지 않았습니다.
