# 홈페이지 리디자인 핸드오프 (2026-09-26)

사용자가 준 `StepUp 홈페이지 UI` 핸드오프에서 기준 문서만 옮겨 둔 것. 구현은 `web/index.html` · `web/styles.css` · `web/site.js`.
에셋은 레포의 S2 원본과 같아서 복사하지 않았고, `web/assets/img/` 에 WebP 로 줄여 넣었다. 프로토타입 런타임(`support.js`)은 이식하지 않았다.

README 와 다르게 한 것:
- 두 단 카드가 한 단으로 떨어지는 폭(≤740px)부터 세로 두 줄 비율을 쓴다(README 는 ≤680px, 681–740px 에서 겹침).
- 폭 ≤680px 에서 01 신발을 스탯과 제목 사이로 올린다(CTA 옆 iPhone 안내를 가리지 않게).
- 폰 목업 안 글자는 폰 크기(cqw)에 맞춰 줄어든다(모바일에서 타이머 잘림 방지).
- 버튼·링크에 포커스가 있을 때 Space 는 페이지를 넘기지 않는다. Tab 으로 다른 화면에 닿으면 그 화면으로 넘어간다.
- 떠난 화면의 CSS 애니메이션은 멈추고, 01 스톱워치 rAF 도 01 에서만 돈다(시간은 이어서 계산).
