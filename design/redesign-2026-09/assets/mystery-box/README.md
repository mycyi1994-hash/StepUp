# Mystery box artwork

`closed.png` is the unedited transparent PNG generated with built-in ImageGen for the new draw screen. Prompt direction: an isolated deep-navy dimensional mystery chest with cyan glowing seams and silver trim, transparent background, no text, brand mark, buttons or interface. The app and web use separately resized WebP exports; all labels and actions remain native controls.

The box is decorative art, not evidence that an on-chain draw has run.
