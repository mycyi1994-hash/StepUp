## 조립 규칙

- `ProfileCharacterStage.kt`가 1536 × 1536 기준 틀을 화면의 폭·높이 중 작은 값으로 균등 축소한다.
- 벤치: (0, 440), 크기 1536 × 1024. 루노는 앉은 접점에 맞춰 y=480.
- 캐릭터: (256, 0), 크기 1024 × 1536. 벤치 앞에 표시하며 비율을 유지한다.
- 별도 접지 그림자는 Compose Canvas. 앉은 장면에는 서기용 발광 링을 표시하지 않는다.
- 벤치에 앞쪽 팔걸이가 없어 이 구도의 모든 벤치 면은 캐릭터 뒤에 놓인다. 향후 팔걸이 등 앞에서 가리는 소품이 생기면 전경 레이어를 추가해야 한다.
- 배경은 루트의 `ProfileBackgrounds`: 푸른 밤·새벽 2장. 처음 무작위 선택하고 배경 버튼으로 다른 후보를 선택한다. 재구성, 닉네임/기록 변경, 착장 변경은 배경 선택을 바꾸지 않는다.
- `AvatarArtCatalog`는 정확히 일치하는 착장에만 SIT 그림을 허용한다. 지원하지 않는 착장은 프로필에서 기존 IDLE 그림을 사용한다. 홈·러닝·옷장은 SIT 그림을 선택하지 않는다.
- 기존 전신 그림 자체가 착장 조합을 모두 표현하지 못하는 경우에는 `AvatarLookNote`가 실제 장비와 표시 한계를 안내한다.

## 확인과 남은 것

`composition-review.html`은 **앱 캡처가 아닌 독립 자산 배치 확인용**이다. 실제 RGBA를 브라우저에서 밤·새벽·흰 바탕 위에 조합해 외곽, 좌석 접점, 배경 투과를 확인했다. 출력 이미지의 RGB 미리보기에는 후광 색이 남아 보일 수 있으나 투명 채널을 적용하면 바깥 영역은 표시되지 않는다.

문법·디자인 계약·문자열·기존 자산 검사를 통과했다. 성별/착장 일치와 다른 화면의 포즈를 보호하는 단위 테스트 2개를 추가했지만 로컬 Android 도구가 없어 실행하지 않았다. Android 컴파일과 실제 기기 캡처는 대기다. 사용자 요청에 따라 APK/AAB/CI/배포를 실행하지 않았다.

기본·라벤더·올리브·기타 의상과 다른 신발의 앉은 자세, 몸·의상·신발 부위 합성은 여전히 미완료다. 이번 2개 조합의 결과를 전체 착장 완료로 집계하지 않는다.
