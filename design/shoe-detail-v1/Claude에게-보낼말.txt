첨부한 StepUp 보유 신발 상세 전달본을 기존 Android 앱에 적용해 줘. Claude-구현지시서.md를 먼저 읽고, 저장소의 AGENTS.md와 최신 사용자 결정도 함께 확인해 줘. 별도 웹사이트를 만들지 말아 줘.

기존 일러스트 신발·받침·조명과 보유 신발 목록을 유지해 줘. 신발 상세는 큰 신발 이미지, SUP 적립 보너스·에너지 절감, 능력치 자세히, 신발 정보, 이 신발 신기 버튼으로 구성해 줘. 착용 중인 경우 버튼을 강화 버튼으로 바꾸지 말고 현재 착용 상태를 보여줘.

목록에서 보는 신발과 실제 착용 신발을 반드시 구분해 줘. 같은 모델의 여러 켤레는 실제 소유 ID로 구별해 줘. 예시 데이터의 이름·번호·능력치를 실제 DB나 상품 정보로 넣지 말아 줘. 기존 신발 카탈로그와 이번 일러스트의 매핑이 확정되지 않았다면 별도 미확정 항목으로 남기고 기존 식별자를 보존해 줘.

이 신발 신기를 누르면 기존 equip 경로로 저장하고, 실제 성공한 뒤 상세의 착용 상태와 목록 체크를 함께 갱신해 줘. 처리 중 연타는 막아 줘. 실패하면 실제 기존 착용을 유지하며 재시도할 수 있게 하고, 없는 ID로 진입했다고 기존 착용을 해제하지 말아 줘. 로딩·빈 보유 목록·조회 오류·이미지 오류를 구분해 줘.

18개 장면과 분리된 버튼·모달을 참고해 네이티브 UI로 구현해 줘. 강화·판매·도감 메뉴는 이번 새 화면에 추가하지 말고, 기존 다른 경로와 데이터까지 일괄 삭제하지도 말아 줘. 유료 민팅이나 SUP 뽑기 비용을 연결하지 말아 줘. 밝은 테마는 기존 테마의 의미별 색상을 사용하고 큰 글씨·작은 화면·스크린리더도 확인해 줘.

실제 구현한 범위와 수행한 검증을 보고해 줘. 정적 시안만 보고 앱 적용이나 서버 연동이 끝났다고 표시하지 말아 줘.
