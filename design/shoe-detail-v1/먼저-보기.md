# StepUp 보유 신발 상세 · 디자인 전달본

기존 일러스트 신발과 낮은 받침·은은한 조명을 그대로 이어갑니다. 상세 화면은 **신발 → 주요 능력치 → 이 신발 신기** 순서로 읽습니다. 보유 목록을 유지하고, 전체 능력치와 신발 정보는 누른 뒤 보여줍니다.

이번 전달본은 시안입니다. 실제 앱 코드·보유 신발·착용 상태를 변경한 결과가 아닙니다.

## 구성

- `01-screens`: 18개 장면, PNG/SVG 각각 제공.
- `02-boards`: 비교 보드 9개, PNG/SVG 각각 제공.
- `03-components`: 받침·신발 전시·버튼·능력치·행·토스트·모달 등 12개 분리본.
- `assets`: 기존 신발 일러스트 3종, 로고, Pretendard Regular/Semibold와 라이선스.
- `Claude-구현지시서.md`, `Claude에게-보낼말.txt`: 실제 앱에 전달할 지시.
- `design-tokens.json`, `screen-index.json`, `flow-map.json`: 디자인 값·장면 목록·연결표.
- `sample-inventory.json`: 네 켤레의 예시 데이터. 실제 상품표나 보상 정책이 아님.
- `asset-integrity.json`, `검수결과.json`: 신발 원본 보존 및 파일 검사 결과.

화면 크기는 390 × 844, PNG는 3배 해상도입니다. SVG의 글자와 도형은 편집할 수 있으며 신발 이미지는 별도 PNG로도 제공합니다. Figma에 가져온 뒤 폰트·레이어를 확인하고 Auto Layout·컴포넌트 변형·동작 연결을 구성합니다. 완성된 Figma 네이티브 라이브러리나 실행형 앱은 아닙니다.

선택 밑줄은 지금 보는 신발, 체크는 실제로 신고 있는 신발입니다. 같은 모델의 다른 켤레를 골라도 ‘이 신발 신기’를 누르기 전에는 착용이 바뀌지 않습니다.

예시에는 세 모델, 총 네 켤레가 있습니다. 새벽 강변은 #0002와 #0004 두 켤레입니다. 보유 수·번호·레벨·능력치·날짜는 모두 실제 데이터로 대체합니다. 일러스트 이름을 기존 앱의 특정 도감 항목에 임의로 매핑하지 않습니다.
