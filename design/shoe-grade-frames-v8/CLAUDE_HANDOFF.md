# Claude 인수인계 · StepUp 신발 등급 프레임 v8

## 요청과 이번 결과

사용자는 StepUp 러닝 앱에 맞는 신발 등급 프레임 6종을 원한다. 등급이 올라갈수록 조금씩 화려해지고, 레전더리 초과 단계는 색과 효과가 확실히 달라야 한다. 모바일 게임의 수집 보상감은 참고하되 신발과 러닝의 속도감이 중심이어야 한다.

이번 v8에서 서로 다른 요소를 하나씩 추가했다.

- **05 레드라인:** 신발 뒤꿈치 쪽에서 퍼지는 주황색 **열기 파동**. 기존 직선 속도선과 다른 곡선이다.
- **06 피니시:** 상단 우측의 민트·보라 **체커 결승 테이프**. 기존 원형 궤적과 다른 격자 패턴이다.

이 폴더의 이미지들은 **디자인 시안과 투명 레이어 자산**이다. 앱에 반영하거나 APK를 만든 결과는 아니다.

## 실제 StepUp 앱에 적용할 때

현재 확인한 앱 레포는 `C:\Users\gana0\StepUp`이다. 작업을 시작할 때 Claude가 실제 체크아웃과 Git 상태를 다시 확인하고 그 레포의 `AGENTS.md`, `PRODUCT.md`, `DESIGN.md`, `CLAUDE.md`, `docs/redesign/HANDOFF.md`, `docs/redesign/PROGRESS.md`를 먼저 읽어야 한다. `stepup-stage9`도 별도 복사본으로 있으므로 대상 레포를 섞지 않는다.

확인한 관련 코드:

- `app/src/main/java/com/stepup/android/ui/components/SneakerImage.kt` — `SneakerFrame`, `SneakerVisual`, 실제 신발 그림 리소스 선택
- `app/src/main/java/com/stepup/android/ui/components/SneakerCards.kt` — `SneakerCollectionCard`, `EquippedSneakerCard`, `Rarity.tint()`
- `app/src/main/java/com/stepup/android/ui/screens/items/ItemsScreen.kt` — 장착 카드와 컬렉션 카드 배치
- `app/src/main/java/com/stepup/android/domain/Sneaker.kt` — 현재 네 등급의 도메인 모델

제안 작업 순서:

1. 기존 `SneakerFrame`을 사용하는 실제 화면을 확인하고 **장착 신발의 큰 카드**에 01–04 레이어를 먼저 적용한다. 신발은 기존 `SneakerVisual`/실제 리소스를 그대로 사용한다.
2. 레이어는 동일한 440:418 내부 좌표와 비율을 유지한다. PNG를 Android `drawable-nodpi`에 두거나 SVG를 Android 친화적 자산으로 변환하되, SVG의 gradient/filter가 벡터 변환에서 깨지면 투명 PNG를 쓴다.
3. 기존 그리드 카드의 비율은 4:3이고 장착 카드는 높이 180dp다. 440:418 자산을 카드 전체 너비로 강제 늘려 찌그러뜨리지 말고, 내부 비율 고정 영역에 맞추거나 카드별 밀도를 조정한다. 신발 52종의 실루엣이 다르므로 한 신발만 맞춘 위치값을 전체에 고정하지 않는다.
4. 실제 신발의 속성색과 현재 이름·레벨·장착 상태·클릭 동작을 보존한다. 등급 테두리색이 속성색을 덮지 않게 확인한다. 문구·숫자·탭·버튼은 Compose UI로 남긴다.
5. 일반→레전더리의 차이가 작은 그리드에서도 읽히는지 확인한다. 05·06은 도메인에 연결하지 않은 별도 디자인 프리뷰로만 둔다.
6. 실제 앱 캡처를 비교판과 나란히 검토한다. 어두운 화면뿐 아니라 밝은 테마와 작은 화면에서도 신발이 중심인지 확인한다. 해당 레포의 디자인 계약/리소스 검사와 빌드 절차를 따른다.

## 시각 수용 기준

- 01–04가 색만 바뀐 같은 프레임처럼 보이지 않고 **테두리 → 바닥광 → 후광 → 스포트라이트/광점**으로 단계가 읽힌다.
- 05는 주황·적색, 직선 가속선, **곡선 열기 파동**이 함께 보인다.
- 06은 민트·보라, 원형 궤적, **체커 결승 테이프**가 함께 보인다.
- 신발의 앞코, 끈, 뒤꿈치가 이펙트에 가려지지 않는다.
- 레이어가 실제 화면에서 찌그러지거나 카드 밖으로 잘리지 않는다.
- 실제 앱 적용을 보고할 때는 목업 PNG가 아닌 **같은 빌드의 실제 캡처**를 제시한다.

## 이 시안의 한계

모바일 예시는 임의의 신발 한 종을 사용한 배치 목업이다. 실제 StepUp의 52종 신발, 다양한 화면 크기와 테마에 적용한 결과는 아직 검증하지 않았다. 프레임/효과는 정적 이미지이며 움직임은 구현되지 않았다.
