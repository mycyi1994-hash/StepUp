# StepUp 신발 등급 프레임 · 6단계 이펙트 (v8)

신발 이미지가 중심이 되도록 얇은 프레임을 유지하고, 등급별로 효과를 누적했습니다.

| 단계 | 등급 | 추가되는 효과 |
| --- | --- | --- |
| 01 | 일반 | 카본 프레임, 바닥 그림자 |
| 02 | 레어 | 푸른 바닥광, 작은 반사광 |
| 03 | 희귀 | 은은한 후광, 짧은 속도선 |
| 04 | 레전더리 | 따뜻한 스포트라이트, 미세 광점, 금속판 강조 |
| 05 | 레드라인 · REDLINE | 주황·적색 프레임, 가속 눈금, 긴 속도선, 붉은 바닥 반사, **뒤꿈치에서 퍼지는 열기 파동** |
| 06 | 피니시 · FINISH | 민트·보라 프리즘 프레임, 다중 궤적, 청록 바닥광, **체커 결승 테이프** |

`00-StepUp-6단계-등급-이펙트.png`는 전체 비교 시안입니다. `07-레전더리-모바일.png`, `08-레드라인-모바일.png`, `09-피니시-모바일.png`는 모바일 배치 예시입니다.

각 단계의 SVG와 PNG는 440 × 418 픽셀 기준으로 투명하게 내보냈습니다. 아래 순서로 겹치면 비교 시안과 같은 결과가 됩니다.

1. `back-effect-01`–`06`: 신발 뒤의 바닥광, 후광, 스포트라이트, 속도선
2. 신발 이미지
3. `front-effect-01`–`06`: 신발 앞쪽의 작은 반사광과 광점
4. `frame-01`–`06`: 등급 테두리

SVG는 확대해도 선명하고 PNG는 바로 시안을 합성할 수 있습니다.

01–04는 현재 앱에 쓰이는 신발 등급입니다. 05–06은 향후 확장 콘셉트입니다.
