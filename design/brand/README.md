# StepUp 브랜드 — 로고 · 심볼 · 태그라인

2026-09-23 에 받은 공식 로고 묶음이다. 로고나 앱 아이콘이 필요한 곳에서는
이 파일들을 **그대로** 쓴다(글꼴로 다시 짜거나 색을 바꿔 새로 만들지 않는다).
아직 앱에는 넣지 않았다 — 넣을 때 아래 규칙대로 고른다.

## 파일

| 파일 | 모양 | 바탕 | 크기 |
|---|---|---|---|
| `stepup-app-icon.webp` | 앱 아이콘 — 네이비 둥근 사각형에 "Step" 흰색 / "UP" (U 시안 · P 파랑, U 위 화살표) 두 줄 | **투명**(둥근 모서리 바깥) | 1254×1254 |
| `stepup-logo-tagline-on-navy.webp` | 가로 로고 "Step"(흰) + "UP"(파랑, 화살표) + 태그라인 | 네이비 #031737 (불투명) | 2000×667 |
| `stepup-logo-tagline-on-white.webp` | 가로 로고 "Step"(네이비) + "UP"(파랑) + 태그라인(네이비) | 흰색 (불투명) | 2000×667 |
| `stepup-logo-white-on-blue.webp` | 가로 로고 전체 흰색, 태그라인 없음 | 파랑 #0A76FD (불투명) | 2000×667 |
| `stepup-tagline-on-navy.webp` | 태그라인만 "RUN. EARN. LEVEL UP." (흰색 이탤릭, 넓은 자간) | 네이비 (불투명) | 2000×667 |

| 이름 | 값 | 쓰는 곳 |

| 브랜드 네이비 | #031531 ~ #031737 | 아이콘 바탕 · 어두운 로고 바탕 · 밝은 로고의 "Step" |
| 브랜드 시안 | #01C8FC | 앱 아이콘의 "U" |

앱 팔레트(디자인 패키지)의 파랑 #147BFF · 시안 #24D8FF · 배경 #040C1B 와
같은 계열이다. 앱의 어두운 테마 위에는 네이비 로고가 거의 이음새 없이 얹힌다.

## 어디에 무엇을 — 고르는 규칙

- **어두운 바탕**(앱 기본 다크 테마, 스플래시, 네이비 배너) → `on-navy` 가로 로고.
  공간이 좁으면(앱 머리글 등) 태그라인 없이 로고만 잘라 쓴다.
- **밝은 바탕**(라이트 테마, 흰 문서, 인쇄) → `on-white` 가로 로고.
- **파란 면**(CTA 배너, 프로모션 카드, 공유 이미지) → `white-on-blue`.
- **정사각형 자리**(런처 아이콘, 스토어 아이콘, 프로필 사진, 파비콘, 알림 큰 아이콘)
  → `stepup-app-icon`.
- **슬로건만**(온보딩 마지막 장, 러닝 완료 공유 카드 하단, 로딩 문구) →
  `stepup-tagline-on-navy`, 또는 같은 문구를 앱 글꼴로.

## 지킬 것

- 비율을 바꾸지 않는다(늘이거나 누르지 않는다). 기울임·화살표 위치는 로고의 일부다.
- 바탕과 반대 색 로고를 쓴다 — 네이비 위에 네이비 "Step" 을 두지 않는다.
- 가로 로고 네 장은 **바탕이 불투명**이다. 다른 색 위에 얹으려면 먼저 정밀하게
  배경을 떼어 낸 투명본을 만들고, 흰 테두리가 남지 않았는지 확인한다(전역 색
  필터로 지우지 않는다).
- 앱 아이콘은 이미 투명 바깥을 가진다. 런처용 적응형 아이콘으로 쓸 때는 안쪽
  글자가 안전 영역(가운데 66%) 안에 들어오도록 여백을 준다.
- 지금 앱 안의 워드마크는 `res/drawable-nodpi/logo_wordmark*.png`(예전 것)다.
  바꿀 때는 이 규칙대로 새 로고로 교체하고, 전후 캡처로 확인한다.
