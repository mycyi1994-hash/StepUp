클로드에 이미지 5장과 CLAUDE_PROMPT.md, CAP_RULES.md, equipment-catalog.json을 함께 전달하세요. 신발 세부 형상은 이전에 제공한 원본 52종을 우선하며 원본 신발 PNG는 이 ZIP에 중복 포함하지 않았습니다. IMAGE_PROMPTS.md는 내장 이미지 생성 도구에 사용한 프롬프트 기록입니다.

이 자료는 디자인 참고 시트입니다. 실제 앱 변경이나 NFT 발행은 수행하지 않았고, 투명 착용 레이어·리깅 모델은 별도 제작이 필요합니다. 생성 이미지의 미세한 문양·앞뒤 장식은 차이가 있을 수 있으므로 CAP_RULES.md의 기준으로 정리하세요. 실제 착용 자산이 아직 없음을 JSON의 null 값으로 구분했습니다.
