# 루미 의상–모자 연동 규칙

모자 형태와 UP 로고 위치는 유지하고, 색상은 의상 ID로 결정합니다. 별도 모자 슬롯은 없습니다.

| 의상 | 모자 |
|---|---|
| OUTFIT-BASE | 기본 남색, 파란 포인트 |
| LUM-CLO-001 | 남색, 코발트 챙·로고 |
| LUM-CLO-002 | 주황빨강, 검정 챙·로고 |
| LUM-CLO-003 | 흰색 전면, 로열블루 몸통·챙·로고 |
| LUM-CLO-004 | 노랑, 차콜 챙·로고 |
| LUM-CLO-005 | 흰색 전면, 민트 몸통·챙·로고 |

equippedOutfitId 하나로 의상 레이어와 모자 레이어를 함께 선택합니다. capId를 독립 저장해 서로 어긋나게 만들지 않습니다. 의상+모자 자산을 모두 불러온 뒤 동시에 적용하고 실패하면 이전 세트를 유지합니다. 기본 의상으로 해제할 때는 기본 모자도 함께 복원합니다.

포니테일은 유지하고 모자와 겹치는 부분의 가림 순서를 검수합니다. 실제 착용 자산은 몸체에서 기존 모자 영역을 분리한 뒤 합성하거나 3D 모자 재질을 교체해야 합니다. 완성된 기본 이미지 위에 새 모자를 무조건 덧붙이지 않습니다.

신발 시트의 추천 조합: 불=002, 물=003, 번개=004, 바람=005. 다른 조합도 모두 허용합니다. 예: LUM-CLO-004+WAT-004는 노랑 모자·차콜 의상·남색 신발입니다.

옷·모자 변경에도 눈은 청록, 머리카락은 검정, 노출 피부는 짙은 남색을 유지합니다. 의상 시트에 작은 앞뒤 장식 차이가 있으면 단독 상품 전면과 후면을 기준으로 일관되게 정리합니다. 특히 볼트 저지의 뒤판은 단독 후면의 단순한 디자인을 기준으로 하고, 착용 후면에 생성된 번개는 필수 장식이 아닙니다.
