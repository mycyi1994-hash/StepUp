## 클로드에 전달하기

이미지 5장, CLAUDE_PROMPT.md, equipment-catalog.json을 함께 첨부하고 프롬프트 본문을 전달하세요. 기존 신발 원본 52종도 함께 전달하면 개별 상품 디자인을 더 정확하게 연결할 수 있습니다. 원본 신발 이미지는 이 ZIP에 중복 포함하지 않았습니다.

의상과 신발은 독립 슬롯입니다. 신발 시트는 무료 기본 의상을 입은 상태이고, 신규 CLO-001은 대각선 패널이 있는 별도 디자인입니다. 의상 시트의 파란 신발은 무료 기본 신발입니다. 추천 계열과 다른 색상 조합도 허용합니다.

## 범위

이번 결과는 디자인 참고 시트와 구현 프롬프트입니다. 실제 앱 코드 변경, NFT 발행, 투명 착용 레이어 제작, 260개 조합의 실시간 렌더링 구현은 포함되지 않습니다. 합성용 레이어는 고정된 포즈·캔버스·가림 순서로 별도 제작해야 합니다. JSON의 runtimeAssets는 이를 구분하기 위해 null로 표시했습니다.

52개 ID와 5개 의상 표시를 확인했습니다. 생성된 착용 이미지는 원본 신발을 루노 비율에 맞춘 해석으로, 작은 문양·로고·끈·밑창은 원본과 차이가 있을 수 있습니다. 상품 세부 디자인은 기존 개별 신발 원본을 우선하세요. 물 시트의 영문 설명은 형태 설명이며 상품명은 JSON의 한국어 이름이 기준입니다.
