Figma에서 수정하기

  1. Figma 데스크톱에서 새 빈 Design 파일을 엽니다.
  2. Plugins → Development → Import plugin from manifest에서 figma-plugin/manifest.json을 선택합니다.
  3. StepUp · Editable UI Kit & 45 Screens를 실행합니다.
  4. 컴포넌트 페이지의 마스터를 수정하거나, 화면에서 인스턴스의 문구·상태를 바꿉니다.

플러그인의 전체 실행은 도구 한도로 Figma에서 검증하지 못했습니다. 로컬 구조 검증과 SVG 렌더링을 확인했습니다. 기존 온라인 파일의 6개 화면과 컴포넌트는 실제 Figma에 생성되어 있습니다.

버튼을 눌러 예시 화면을 이동할 수 있습니다. 입력·위치·시간·저장은 실제 기능이 아닌 상태 예시입니다. 이 화면 SVG 내려받기
