# StepUp 상세 화면과 버튼 연결 · v6

기존 6개 화면 + 추가 39개 상태(13개 보드). 이미지 시안이며 실제 위치 탐색, 기록 저장, 운동 추천 기능은 연결되지 않았습니다. 코스와 운동 데이터는 예시입니다.

## 보는 법

## 동작 기준

- 시작 메뉴는 자유 러닝 / 러닝 챌린지 / 추천 코스 / 다이어트 모드 네 항목으로 유지합니다. 10분 러닝은 챌린지 안에만 둡니다.
- 자유 러닝의 바로 시작에는 별도 설정이 없습니다. 3초 카운트다운을 공통으로 사용합니다.
- 운동 중 뒤로가기나 화면 이탈은 종료 확인으로 연결합니다. 지도 확대의 닫기는 운동 화면으로 돌아옵니다.
- 공통 일시정지·종료 모달은 현재 모드의 제목과 측정값을 그대로 사용합니다. 확인 모달 동안은 운동을 일시정지하고, 계속 달리기를 눌렀을 때만 재개합니다.
- 기록 저장 성공을 확인한 뒤에만 저장 완료 문구를 표시합니다. 실패해도 측정값을 유지하고 재시도할 수 있어야 합니다. 오류 유형과 관계없이 실패를 성공처럼 표시하지 않습니다.
- 기록 삭제와 저장 없이 종료를 구분합니다. 각각 R06과 R07의 확인을 사용합니다. 모달 바깥 탭이나 닫기는 취소이며, 파괴적인 행동으로 연결하지 않습니다.
- 위치 권한 요청과 앱 설정 화면은 운영체제 기본 UI입니다. L01은 그 전에 보여주는 앱 안내 화면입니다.
- 위치가 없을 때 자유 러닝은 시간만 기록합니다. 미측정 거리와 페이스는 0이 아니라 ‘— / 위치 필요’로 표시합니다. 위치가 필요한 거리 챌린지는 권한·신호 확인 후 시작합니다.
- 코스는 현재 위치에서 출발하고 돌아오는 예시입니다. 실제 구현에서는 보행 가능한 경로인지 확인한 데이터로만 추천해야 합니다. 출발점 길찾기는 없습니다.
- 신체 입력은 숫자·단위·필수값을 확인하고 오류를 해당 입력칸 아래에 보여줍니다. 키·몸무게는 기록용이고 러닝 경험은 추천 구성의 참고값입니다. 이미지의 빈 칸은 실제 저장값이 아닙니다.
- 러닝 경험은 한 개만 선택하며 선택 상태는 D06의 체크 표현을 사용합니다. U05의 화살표는 다음 화면 이동이 아니라 이 체크 상태로 구현합니다.
- 다이어트 구간의 ‘다음’은 눌러 건너뛰는 버튼이 아니라 다음 구간 안내입니다. 구간 전환은 시간이 끝나면 자동으로 일어납니다.
- 15분 예시 루틴은 준비 걷기 3분 + (러닝 1분 + 걷기 2분) × 3회 + 마무리 걷기 3분입니다. 러닝은 총 3분, 걷기는 총 12분입니다. 운동 예시는 확정된 개인별 처방이나 추천 알고리즘을 의미하지 않습니다.
- 그래픽 안의 예시 수치·문구보다 이 연결표의 동작 정의를 구현 기준으로 사용합니다. 모든 폰트는 실제 제작 때 편집 가능한 텍스트로 다시 구성합니다.
