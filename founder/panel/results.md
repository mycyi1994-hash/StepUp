## What would flip a no

- If it pulled my runs straight from Garmin Connect and worked on iPhone, so my whole Saturday crew could be on it without changing how we record.
- If my running crew all moved onto it for the shared crew runs, I'd install it to join them, not for the points.
- If SUP could be exchanged for something real, like gift cards or race entry discounts, and my crew leader moved the crew onto it first.
- If it pulled my runs straight from Strava or my watch so I didn't need to record twice, and my crew leader picked it for our group runs with an iPhone version available.
- If our crew leader set it up and everyone in the Saturday group, including the iPhone people, was actually on it, I'd install it so I'm not left out.
- If it were just a clean run tracker that properly records treadmill runs, with the sneaker and point game removed or fully optional and hidden, plus a real crew I already run with asking me to join.
- An iPhone version so my whole crew could join the same room and start together.
- An iPhone version, plus importing runs from Strava or Garmin so my crew wouldn't have to switch trackers.
- If people from my own running crew were already using it for crew runs, and it had been running for a year or more without the shoe/point economy being reset or turned into crypto.
- If my whole crew, iPhone people included, agreed to use it for our weekly meetups, and it counted my treadmill runs too.
- An iPhone app so my whole crew can join the same run room.
- If my running crew all moved to it for the crew runs and I could switch off the sneaker and points part entirely, so it's just a GPS and crew-run app.
