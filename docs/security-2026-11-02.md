## 2층 — 입구 (코드, 끝남)

- **이메일 규칙**(서버 0082 `economy.waitlist_email_ok` = 홈페이지 `validEmail`): 영문 · 숫자 · `._%+-`, 시험용 도메인 거절.
- **같은 곳 횟수**(0082): IP 소금 해시로 10분 6 · 하루 30(`waitlist_ip_per_10min` · `waitlist_ip_per_day`). 틀림 · 잦음은 `{ok:false, message}`.
- **사람 확인 Turnstile**(0083 · 워커 `/v1/waitlist/register` · 홈페이지 `TURNSTILE_SITE_KEY`) — 키를 넣기 전에는 꺼져 있다. 켜는 순서:
  1. Cloudflare › Turnstile › Add widget — 이름 StepUp waitlist, 도메인 `stepupcrew.com`, 모드 Managed.
  2. **사이트 키**(공개) → `web/waitlist.js` 의 `TURNSTILE_SITE_KEY` (Claude 에게 주면 넣는다).
  3. **비밀 키** → Cloudflare › Workers › stepup-attester › Settings › Variables and Secrets › `TURNSTILE_SECRET`(Secret). 저장소 · 채팅에 붙여 넣지 않는다.
  4. 홈페이지가 새 키로 배포된 것을 본 뒤 SQL Editor: `select admin_economy_set('waitlist_require_turnstile', 'true');` — 이제 Supabase 로 바로 오는 등록은 받지 않는다.
- **CSP**(web/_headers — 홈페이지 · 초대 · 약관): 스크립트는 이 사이트 것 + 인라인 해시 + Turnstile 만, 연결은 Supabase · 워커만, `object-src 'none'` · `frame-ancestors 'none'`.
  인라인 `<script>` 를 고치면 해시를 다시 넣는다(`web/test/csp.test.js` 가 잡는다).
- 그밖의 공개 입구: 공유 링크 제출은 영수증(64자) 없이는 못 하고 영수증마다 6개뿐, 지갑 연결 요청은 워커 IP 제한(분당 20) + 계정 제한, 접속 코드는 계정마다 1시간 10번.
