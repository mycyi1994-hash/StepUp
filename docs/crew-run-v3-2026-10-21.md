## 사용자 결정

- "크루 시작할 때 신발의 모든 능력치를 합산하고 n빵" — 크루 체력은 출발 전에 고른 신발로 만든다.
- "크루 자체의 체력도 따로 · 하루에 내 자유러닝 + 크루러닝이 가능" — 크루 러닝은 개인 에너지 · 개인 신발 내구도를 쓰지 않는다.
- "크루 내구도는 00:00(UTC+9) · 수리는 안 해도 됨" · "시작 전에 신발을 골라 그 신발만".
- 보상은 내 신발 능력치(평균 내지 않는다) × (1 + 인원 보너스 + 레벨 보너스) — "겹치지 않게"(더한다).
- 인원 보너스: 2명 5% · 3명 10% · 4명 15% · 5명 20% · 6명 50% · 7 ~ 19명 50% + 한 명마다 2% · 20명 150%. 방은 20명까지.
- 인원은 "500m 안에서 크루 들어와서 달리기에서 스타트한 사람 · 크루원 수"(출발 2분 뒤 확인은 그대로).
- 크루 보상 하루 상한은 "일단 무제한". 크루 체력 0 이면 적립만 멈추고 기록은 계속(5번 추천).
- 크루 레벨 1 ~ 20, 레벨마다 크루 체력 +6% · 보상 +1%(더하기).
- 하루 한 번(추천) — 일시정지는 괜찮고, 끝내면 그날 크루 러닝은 끝. 혼자 남으면 끝. 크루원이면 누구나 방을 연다.
- 번호 인증(여러 폰 어뷰징 막기)은 이번에 뺐다 — 나중에 Twilio + Supabase 전화 인증으로.

## 규칙(서버)

| 항목 | 값 |
|---|---|
| 크루 러닝 | 크루 방에서 출발 · 출발 2분 뒤에도 서로 500m 안으로 이어진 무리에 지금 크루원 2명 이상(나 포함) · 그날 첫 크루 러닝 |
| 크루 체력(무리) | 무리 크루원이 출발 때 고른 신발 최대 내구도 합 × (1 + 0.06 × (레벨 − 1)) — 출발 때 레벨(`parties.crew_level`) |
| 쓰는 양 | 한 사람이 달린 1분마다 5(12초에 1). 몫은 똑같이 — 한 사람 시간 = 크루 체력 ÷ 인원 × 12초 |
| 다 쓰면 | 그 뒤 걸음은 적립하지 않는다(까닭 "크루 체력을 다 썼습니다") |
| 혼자 남음 | 나와 무리의 곁 기록이 마지막으로 적힌 때 + 60초 뒤로는 적립하지 않는다(까닭 "혼자 남아 크루 러닝이 끝났습니다") |
| 보상 | 적립 걸음 × 0.01 × (1 + 고른 신발 효율) × (1 + 인원 보너스 + 레벨 보너스) × 부스터 |
| 개인 쪽 | 개인 에너지 · 신발 내구도 안 씀(신발에 거리만), 하루 금액 · 경로 없는 · 올린 날 · 걸음 상한 안 걸고 개인 상한 합에서도 뺀다 |
| 하루 한 번 | `economy.crew_run_days`(사람 · 한국 날짜) — 두 번째는 보통 러닝(인원 보너스 없음, 까닭 "오늘 크루 러닝을 이미 했습니다") |
| 크루 방 | 곁 500m(번개 200m 그대로) · 대기실 20명(꽉 차면 새 방) · 이미 들어간 방을 먼저 · 오늘 한 사람은 준비 불가(`crew_run_done_today`) |
| 크루 방에서 크루 러닝이 아니면 | 예전 함께 달리기 보너스도 없다(겹치지 않게) |
| 레벨 | 20 · 50 · 100 · 180 · 300 · 450 · 650 · 900 · 1,200 · 1,600 · 2,100 · 2,700 · 3,400 · 4,200 · 5,100 · 6,100 · 7,200 · 8,500 · 10,000km |

새 함수: `party_pick_shoe`(대기실 신발) · `crew_run_today` · `crew_run_room` · `crew_run_result` · `crew_level`(20단계, stamina · reward).
`party_start` 는 사람마다 신발 · 최대 내구도(`party_runs.sneaker_id` · `shoe_dur_max`)와 크루 레벨을 적어 둔다.

## 앱 화면

- 크루 홈: "오늘 크루 러닝" — 할 수 있어요 / 마쳤어요(인원 · 쓴 체력) · 다시 열리는 때 · 오늘 달린 사람 · 레벨 보너스. 누르면 규칙 · 인원 보너스 표 · 크루 레벨로.
- 레벨 화면: 지금 보너스(체력 · 보상 %) · 레벨마다 오르는 폭 · 1 ~ 20 레벨 표(지금 레벨 강조).
- 크루 러닝 입구: 오늘 했으면 한 줄.
- 대기실: 크루 러닝 신발(고르기 시트 — 서버 신발 · 팔지 않는 것) · 크루 체력(한 사람 약 N분) · 보너스(인원 · 레벨) 미리보기 ·
  오늘 했으면 붉은 안내 + 준비 막음 · 체력 0 안내 · 규칙 시트(규칙 · 인원 보너스 표) · 출발 확인에 "하루 한 번" 한 줄.
- 달리는 중: 크루 체력 막대(내 몫 남은 시간 · 20% 아래 주황 · 0 이면 띠) · 함께 인원 · 보너스 · 2분 확인 중 ·
  혼자 남음 띠(위치를 보이는 크루원이 모두 500m 밖일 때만) · 러닝 정보(E03)의 예상은 크루 몫 · 보너스로 · 종료 확인에 "하루 한 번".
- 잠금화면(홀드화면) 알림: 크루 러닝이면 상태 줄이 "크루 체력 12:34 남음" · 다 쓰면 "크루 체력을 다 썼어요 · 기록은 계속돼요"
  (`WalkSessionState.crewShareSec` — 러닝 화면이 방 미리보기에서 읽어 `WalkSessionService.setCrewShare` 로 알린다). 크루 러닝은 개인 신발이 닳지 않아
  "신발 내구도 다 씀" 안내를 끈다.
- 결과: 보상 설명 시트에 쓴 크루 체력 · 인원 · 레벨 보너스 · 다 씀 / 혼자 남음 · 레벨에 보탠 거리, 레벨이 오르면 크루 줄 아래 "크루 레벨 N 달성!".
  크루 러닝으로 세지 않았으면 그렇다고 한 줄.
