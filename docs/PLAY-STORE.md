# Play 스토어 출시 준비

Play Console 에 앱을 등록할 때 채우는 칸을 이 앱의 실제 동작에 맞춰 적어 둔다.
앱이 바뀌면(특히 모으는 정보가 바뀌면) 이 문서와 `web/privacy.html` · `web/terms.html` 을 같이 고친다.

마지막 대조: 2026-10-26(함께 뛰기 탭 · 휴대폰 인증 없음 · 화면 글자 정리 · 앱 안 확률 표 · 언어 네 개만). 서버로 나가는 정보는 코드에서 하나씩 찾아 맞췄다(사진 · 지갑 · 위치 · 코칭).

### 2026-10-26 출시 최적화에서 바꾼 것

- **앱 안 뽑기 확률 표** — 뽑기 › 기회 받는 방법 시트에 등급별 확률(서버 0077 `draw_odds`, 뽑기가 쓰는 표 그대로). 아래 "콘텐츠 등급"의 무작위 아이템 항목.
- **언어 네 개만 담기** — `androidResources.localeFilters = ko · en · ja · zh`. 라이브러리의 다른 언어 글자를 빼서 `resources.arsc` 3.7MB → 1.4MB(압축 안 되는 칸이라 설치 크기가 그만큼 준다).
- **개발자 말투 · 데모 · 준비 중 정리** — 스토어 판에서 보이는 화면 글자에 서버 · 데모 · 디버그 · 테스트 · 준비 중이 없다(`scripts/check-copy.py`, Build APK).
  데모 모드는 새로 켤 수 없고, 건강 앱 연결 · 주간 포인트 같은 준비 중 자리는 숨긴다.
- **휴대폰 번호를 쓰지 않는다**(0075) — 크루 보너스의 휴대폰 인증을 뺐다. 데이터 보안의 "수집하지 않음"에 전화번호가 그대로 맞다.

## 출시 전에 사용자가 정할 것 (코드로 못 정함)

| 위치기반서비스사업 신고 | 위치를 서버에 저장한다(아래 0절) |

## 스토어 판에 없는 것 — 블록체인 기능 (2026-10-20)

Google Play 는 2026-01-28 부터 **한국에서 암호화폐 거래소 · 소프트웨어 지갑 앱**에 금융정보분석원(FIU) **가상자산사업자 신고 수리** 증빙을
요구한다(없으면 한국에서 새 설치 · 업데이트가 막힌다). 지갑 연결 · SUP 출금이 들어간 앱이 여기에 묶이지 않게, 스토어 판(release)은 블록체인 기능을 빼고 낸다.

- 빌드 스위치 `BuildConfig.WEB3` — release 만 `false`(웹 지갑 주소 `WALLET_URL` 도 비운다). debug · 테스트 APK(qa)는 `true` 로 그대로 시험한다.
- 스토어 판에서 숨는 것: 지갑 고르기 창, 지갑 화면의 WEB3 지갑 · 체인 줄(SUP 잔액 · 내역은 그대로), 연결된 계정의 지갑 줄,
  뽑기의 상급 뽑기(지갑 연결 혜택) · 규칙의 상급 줄 · "상급 뽑기 보기", 설정 › 앱 정보의 "GIWA 체인", 소식의 체인 거래 예고, 뽑기 안내의 지갑 문장.
- 모든 판: "메인넷 때 1:1 로 넘어가요" 같은 쓰지 않던 출금 문구는 지웠고, "NFT 마켓 · NFT 도감"은 "신발 마켓 · 신발 도감"이다(신발은 NFT 가 아니다).
- 남는 것: SUP 포인트(현금 교환 없음) · 무료 뽑기 · 이용자 간 신발 거래소(SUP 로만). 거래소도 법률 검토 대상이다.
- 같은 계정은 웹 지갑 페이지(stepupcrew.com)에서 따로 지갑을 연결할 수 있다 — 앱 밖이다.

## 스토어 판을 폰에서 미리 보기 (2026-10-27)

### 권한 선언
- **포그라운드 서비스(위치·건강)** — "사용자가 시작한 러닝을 화면이 꺼져도 기록하기 위해. 러닝 중에는 알림이 계속 보이고, 끝나면 멈춘다."
  시연 영상: 러닝 시작 → 화면 끄기 → 알림 표시 → 러닝 종료
- 백그라운드 위치 권한: **요청하지 않음** (러닝 탭을 보는 동안 위치를 미리 잡지만 화면에 있을 때만, 기기 안에만 둔다)
- 잠금 화면: 러닝 중에만 러닝 화면을 잠금 위에 띄운다(`setShowWhenLocked`) · 안드로이드 16 실시간 알림(`POST_PROMOTED_NOTIFICATIONS`)
- 스토어 빌드에는 테스트 APK 의 스스로 업데이트 권한(`REQUEST_INSTALL_PACKAGES` · `UPDATE_PACKAGES_WITHOUT_USER_ACTION`)이 **없다**(`src/debug` 매니페스트에만)
- 신체 활동: 걸음 수 집계

### 금융 기능 · 블록체인
- Play Console › 앱 콘텐츠 › **금융 기능** 신고: 스토어 판은 지갑 · 출금이 없으므로 **"금융 기능 없음"**. SUP 는 현금으로 바꿀 수 없는 앱 포인트, 거래소는 SUP 로만 신발을 주고받는다.
- Play 정책 센터의 "블록체인 기반 콘텐츠" 정책: 토큰 보상 · 디지털 자산을 숨기지 않고 설명에 적고,
  수익 · 투자 가치를 내세우지 않는다. 신발은 지금 NFT 가 아니다(체인 발행 멈춤, `shoe_chain_enabled=false`).
- 위 법률 검토 결과에 따라 이 절을 다시 쓴다.

### 계정 삭제
- 앱 안: 내 정보 › 설정 › 연결된 계정 › 계정 삭제 (`account_delete`, 0021)
- 웹: https://stepupcrew.com/delete-account

## 4. 릴리스

1. GitHub › Actions › **Release AAB** 실행 → 서명된 `app-release.aab` 아티팩트
2. Play Console › 테스트 › **내부 테스트** 트랙에 올리고 테스터 이메일 추가
3. 새 개인 개발자 계정은 **비공개 테스트(테스터 12명 이상, 14일)** 를 거쳐야 프로덕션 신청이 열린다
4. 문제 없으면 프로덕션 → 국가: 대한민국부터
