# Play 스토어 출시 준비

Play Console 에 앱을 등록할 때 채우는 칸을 이 앱의 실제 동작에 맞춰 적어 둔다.
앱이 바뀌면(특히 모으는 정보가 바뀌면) 이 문서와 `web/privacy.html` 을 같이 고친다.

## 0. 먼저 해 둘 것

| 할 일 | 어디서 | 비고 |
|---|---|---|
| Play 개발자 계정 | play.google.com/console | $25 한 번. 본인 인증에 며칠 걸린다 |
| 업로드 키 + GitHub Secrets 4개 | [RELEASE-SIGNING.md](RELEASE-SIGNING.md) | 없으면 CI 가 서명하지 않은 AAB 만 만든다 |
| 서버 지역 | Supabase › Settings › General | 싱가포르(ap-southeast-1) — 개인정보처리방침 국외 이전 항목에 반영됨 |
| `support@stepupcrew.com` 받기 | Cloudflare › stepupcrew.com › Email › Email Routing | 개인 메일로 전달. 개인정보처리방침·계정 삭제 페이지·스토어 연락처가 이 주소를 쓴다 |
| 위치기반서비스사업 신고 | 방송통신위원회(위치정보 사업 신고) | 위치를 서버에 저장하므로 국내 출시 전 확인 |
| Play App Signing 인증서 SHA-256 | Play Console › 설정 › 앱 무결성 | `web/.well-known/assetlinks.json` 의 `sha256_cert_fingerprints` 에 **추가**(디버그 값은 남긴다). 그래야 스토어 판에서도 초대 링크가 앱으로 바로 열린다 |

## 2. 스토어 등록정보

**짧은 설명 (80자)**

> 크루와 함께 달리고, 코스 기록을 겨루고, 동네를 크루 색으로 칠하는 러닝 앱

**전체 설명**

> StepUp 은 혼자보다 같이 달리는 사람을 위한 러닝 앱입니다.
>
> • 러닝 기록 — GPS 경로, 거리, 페이스를 기록하고 결과 카드를 인스타 스토리로 공유하세요.
> • 크루 — 크루를 만들고 초대 링크로 친구를 부르세요. 크루 게시판과 번개러닝으로 모이세요.
> • 파티런 — 크루원과 로비에 모여 같은 시각에 함께 출발합니다.
> • 코스 기록 순위 — 동네 코스를 골라 완주하면 서버가 경로를 확인해 순위에 올립니다.
> • 땅따먹기 — 크루원이 달린 길이 크루 색으로 칠해집니다. 최근 14일 동안 가장 많이 달린 크루가 칸의 주인!
> • 기록 지도 — 지금까지 달린 길을 한 지도에 겹쳐 봅니다.
> • 챌린지와 SUP — 달린 만큼 SUP 포인트가 쌓이고 러너 꾸미기에 씁니다(현금으로 바꿀 수 없는 앱 내 포인트).
>
> 부정 적립(가짜 GPS·흔들기·자전거)은 서버가 경로로 다시 확인합니다.

- 그래픽: 앱 아이콘 512×512 — `design/brand/`(app-icon), 그래픽 이미지 1024×500, 휴대전화 스크린샷 2~8장
  (QA 캡처 `qa-review.zip` 에서 고르면 된다. 데모 화면은 쓰지 않는다)

## 3. 앱 콘텐츠

### 광고
- 광고 포함: **아니요**

### 앱 액세스 권한
- 일부 기능은 로그인 필요 → 심사용 안내: "구글 계정으로 로그인하면 모든 기능을 쓸 수 있습니다. 별도 테스트 계정은 필요하지 않습니다."

### 콘텐츠 등급 (설문)
- 사용자 간 상호작용: **예**(글·댓글·크루) · 위치 공유: **예**(번개 모임 장소, 파티런 방 안) · 디지털 구매: **아니요**
- 사용자 생성 콘텐츠 신고·차단: **있음**(글·댓글·크루 신고, 사용자 차단, 신고 5건이면 숨김)

### 타겟층
- 만 14세 이상(13–15 포함 안 함 권장) — 위치 공유와 사용자 간 소통이 있다

### 데이터 보안 (Data safety)

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | 수집: 예 / 제3자와 **공유**: 아니요(처리 위탁은 공유가 아님) |
| 전송 중 암호화 | 예 |
| 삭제 요청 방법 제공 | 예 — 앱 안 + https://stepupcrew.com/delete-account |

수집 항목(모두 "앱 기능", 선택 아님 / 이용 통계만 "분석"):

| 분류 | 항목 | 목적 |
|---|---|---|
| 위치 | 정확한 위치 | 앱 기능(러닝 경로, 모임 장소, 파티런) |
| 개인 정보 | 이름, 이메일 주소, 사용자 ID | 앱 기능, 계정 관리 |
| 건강 및 피트니스 | 피트니스 정보(걸음·러닝) | 앱 기능 |
| 메시지 | 기타 인앱 메시지(글·댓글) | 앱 기능 |
| 앱 활동 | 앱 상호작용, 기타 사용자 생성 콘텐츠(코스) | 분석, 앱 기능 |
| 기기 또는 기타 ID | 기기 ID(푸시 토큰, Firebase 인스턴스 ID) | 앱 기능(알림), 분석 |

수집하지 않음: 금융 정보, 연락처, 사진·동영상, 오디오, 파일, 캘린더, 웹 기록, 광고 ID.

### 권한 선언
- **포그라운드 서비스(위치·건강)** — "사용자가 시작한 러닝을 화면이 꺼져도 기록하기 위해. 러닝 중에는 알림이 계속 보이고, 끝나면 멈춘다."
  시연 영상: 러닝 시작 → 화면 끄기 → 알림 표시 → 러닝 종료
- 백그라운드 위치 권한: **요청하지 않음**
- 신체 활동: 걸음 수 집계

### 계정 삭제
- 앱 안: 내 정보 › 설정 › 연결된 계정 › 계정 삭제 (`account_delete`, 0021)
- 웹: https://stepupcrew.com/delete-account

## 4. 릴리스

1. GitHub › Actions › **Release AAB** 실행 → 서명된 `app-release.aab` 아티팩트
2. Play Console › 테스트 › **내부 테스트** 트랙에 올리고 테스터 이메일 추가
3. 새 개인 개발자 계정은 **비공개 테스트(테스터 12명 이상, 14일)** 를 거쳐야 프로덕션 신청이 열린다
4. 문제 없으면 프로덕션 → 국가: 대한민국부터
