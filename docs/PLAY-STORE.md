# Play 스토어 출시 준비

Play Console 에 앱을 등록할 때 채우는 칸을 이 앱의 실제 동작에 맞춰 적어 둔다.
앱이 바뀌면(특히 모으는 정보가 바뀌면) 이 문서와 `web/privacy.html` · `web/terms.html` 을 같이 고친다.

마지막 대조: 2026-10-20(main 32d4cb3 + 목표 API 36). 서버로 나가는 정보는 코드에서 하나씩 찾아 맞췄다(사진 · 지갑 · 위치 · 코칭).

## 출시 전에 사용자가 정할 것 (코드로 못 정함)

| 할 일 | 왜 |
|---|---|
| **SUP · 지갑 · 출금 · 거래소 법률 검토** | 달린 만큼 받는 SUP 를 지갑으로 꺼낼 수 있다(지금은 웹 지갑 페이지에서 GIWA **테스트넷**만). 앱의 지갑 화면은 "온체인 정산은 메인넷 출시와 함께 열려요. 그때 잔액이 1:1로 그대로 넘어가요"라고 적는다 — 미래의 가치 전환을 약속하는 글로 읽힐 수 있다. 메인넷 출금 · 이용자 간 거래소가 국내 가상자산 법규에 걸리는지 변호사 확인 전에는 출시 판에서 지갑 · 출금 문구를 그대로 둘지 정하지 않는다 |
| 위치기반서비스사업 신고 | 위치를 서버에 저장한다(아래 0절) |
| Play 개발자 계정 · 업로드 키 | 아래 0절 |

| Play App Signing 인증서 SHA-256 | Play Console › 설정 › 앱 무결성 | `web/.well-known/assetlinks.json` 의 `sha256_cert_fingerprints` 에 **추가**(디버그 값은 남긴다). 그래야 스토어 판에서도 초대 링크가 앱으로 바로 열린다 |

## 2. 스토어 등록정보

**짧은 설명 (80자)**

> 크루와 함께 달리고, 코스 기록을 겨루고, 동네를 크루 색으로 칠하는 러닝 앱

**전체 설명**

> StepUp 은 혼자보다 같이 달리는 사람을 위한 러닝 앱입니다.
>
> • 러닝 기록 — GPS 경로, 거리, 페이스, 랩을 기록하고 결과 카드를 공유하세요. 화면을 꺼도 알림과 잠금 화면에서 기록이 이어집니다.
> • 크루 — 크루를 만들고 초대 링크로 친구를 부르세요. 크루 채팅과 번개러닝으로 모이세요.
> • 크루 달리기 — 대기실에 모여 같은 시각에 함께 출발하고, 달리는 동안 서로의 위치를 지도에서 봅니다.
> • 이번 주 순위 — 크루 전체 거리와 개인 거리로 겨룹니다. 코스를 완주하면 서버가 경로를 확인해 코스 순위에 올립니다.
> • 땅따먹기 — 크루원이 달린 길이 크루 색으로 칠해집니다.
> • 신발 — 무료 뽑기로 받은 러닝화를 신고 달리면 SUP 포인트가 쌓입니다. 신발은 달린 만큼 닳고, SUP 로 수리 · 강화합니다.
>
> 부정 적립(가짜 GPS · 흔들기 · 차량 이동)은 서버가 경로로 다시 확인하고, 너무 빠르면 러닝이 멈춥니다.

- 그래픽: 앱 아이콘 512×512 — `design/brand/`(app-icon), 그래픽 이미지 1024×500, 휴대전화 스크린샷 2~8장
  (QA 캡처 `qa-review.zip` 에서 고르면 된다. 데모 화면은 쓰지 않는다)

## 3. 앱 콘텐츠

### 광고
- 광고 포함: **아니요**

### 앱 액세스 권한
- 일부 기능은 로그인 필요 → 심사용 안내: "구글 계정으로 로그인하면 모든 기능을 쓸 수 있습니다. 별도 테스트 계정은 필요하지 않습니다."

### 콘텐츠 등급 (설문)
- 사용자 간 상호작용: **예**(글 · 댓글 · 크루 채팅) · 위치 공유: **예**(번개 모임 장소, 크루 달리기 방 안) · 디지털 구매: **아니요**(유료 결제 · 유료 뽑기 없음 — 뽑기는 모두 무료)
- 무작위 아이템: **예** — 무료 뽑기. 확률은 이용약관(`web/terms.html` 3-2)에 공개. 앱 안 뽑기 화면에는 아직 확률 표가 없다
- 사용자 생성 콘텐츠 신고·차단: **있음**(글·댓글·크루 신고, 사용자 차단, 신고 5건이면 숨김)

### 타겟층
- 만 14세 이상(13–15 포함 안 함 권장) — 위치 공유와 사용자 간 소통이 있다

### 데이터 보안 (Data safety)

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | 수집: 예 / 제3자와 **공유**: 아니요(처리 위탁은 공유가 아님 — Supabase · Google · MapTiler · OpenStreetMap · Open-Meteo · Cloudflare) |
| 전송 중 암호화 | 예 |
| 삭제 요청 방법 제공 | 예 — 앱 안 + https://stepupcrew.com/delete-account |

수집 항목(모두 "앱 기능", 선택 아님 / 이용 통계만 "분석"):

| 분류 | 항목 | 목적 |
|---|---|---|
| 위치 | 정확한 위치 | 앱 기능(러닝 경로, 크루 달리기 중 위치, 모임 장소 · 장소 이야기 · 크루 활동 지역) |
| 개인 정보 | 이름, 이메일 주소, 사용자 ID | 앱 기능, 계정 관리 |
| 금융 정보 | 기타 금융 정보(연결한 지갑의 공개 주소, 출금 요청 주소 · 수량, SUP · 신발 거래 내역) | 앱 기능, 사기 방지 |
| 건강 및 피트니스 | 피트니스 정보(걸음 · 러닝) | 앱 기능 |
| 메시지 | 기타 인앱 메시지(글 · 댓글 · 크루 채팅) | 앱 기능 |
| 사진 및 동영상 | 사진(직접 보낸 크루 대표 이미지 · 크루 채팅 사진만. 프로필 사진은 기기에만) | 앱 기능 |
| 앱 활동 | 앱 상호작용, 기타 사용자 생성 콘텐츠(코스 · 장소 이야기) | 분석, 앱 기능 |
| 기기 또는 기타 ID | 기기 ID(푸시 토큰, Firebase 인스턴스 ID) | 앱 기능(알림), 분석 |

수집하지 않음: 연락처, 동영상, 오디오, 파일, 캘린더, 웹 기록, 심박 등 건강 측정값, 광고 ID.
AI 코칭은 지금 꺼져 있다(`coaching_enabled=false`). 켜서 외부 AI 로 보내기 전에 이 표 · 개인정보처리방침 · 동의 문구를 먼저 고친다.

### 권한 선언
- **포그라운드 서비스(위치·건강)** — "사용자가 시작한 러닝을 화면이 꺼져도 기록하기 위해. 러닝 중에는 알림이 계속 보이고, 끝나면 멈춘다."
  시연 영상: 러닝 시작 → 화면 끄기 → 알림 표시 → 러닝 종료
- 백그라운드 위치 권한: **요청하지 않음** (러닝 탭을 보는 동안 위치를 미리 잡지만 화면에 있을 때만, 기기 안에만 둔다)
- 잠금 화면: 러닝 중에만 러닝 화면을 잠금 위에 띄운다(`setShowWhenLocked`) · 안드로이드 16 실시간 알림(`POST_PROMOTED_NOTIFICATIONS`)
- 스토어 빌드에는 테스트 APK 의 스스로 업데이트 권한(`REQUEST_INSTALL_PACKAGES` · `UPDATE_PACKAGES_WITHOUT_USER_ACTION`)이 **없다**(`src/debug` 매니페스트에만)
- 신체 활동: 걸음 수 집계

### 금융 기능 · 블록체인
- Play Console › 앱 콘텐츠 › **금융 기능** 신고: 암호화폐 지갑 연결 · 출금(테스트넷)을 그대로 적는다. 거래소는 이용자 간 신발 거래(SUP).
- Play 정책 센터의 "블록체인 기반 콘텐츠" 정책: 토큰 보상 · 디지털 자산을 숨기지 않고 설명에 적고,
  수익 · 투자 가치를 내세우지 않는다. 신발은 지금 NFT 가 아니다(체인 발행 멈춤, `shoe_chain_enabled=false`).
- 위 법률 검토 결과에 따라 이 절을 다시 쓴다.

### 계정 삭제
- 앱 안: 내 정보 › 설정 › 연결된 계정 › 계정 삭제 (`account_delete`, 0021)
- 웹: https://stepupcrew.com/delete-account

## 4. 릴리스

1. GitHub › Actions › **Release AAB** 실행 → 서명된 `app-release.aab` 아티팩트
2. Play Console › 테스트 › **내부 테스트** 트랙에 올리고 테스터 이메일 추가
3. 새 개인 개발자 계정은 **비공개 테스트(테스터 12명 이상, 14일)** 를 거쳐야 프로덕션 신청이 열린다
4. 문제 없으면 프로덕션 → 국가: 대한민국부터
