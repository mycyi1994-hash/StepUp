## 통합 검사 진행 기록

- 첫 통합 CI `35711700623`은 위치 접근의 `MissingPermission` 오류 2건으로 중단되었습니다. Android 화면 검사는 실행되지 않았습니다.
- 마지막 위치 조회와 갱신 요청에 권한 취소 예외 처리를 명시했습니다. 로컬 `lintDebug` 통과를 확인했습니다.
- 홈/러닝 추가 배치 수정 후 앱과 Android 검사 코드 컴파일이 통과했습니다. 새 CI에서 전체 검사와 실제 화면 캡처를 다시 확인합니다.
- 두 번째 CI `35714344061`은 단위 검사·lint·릴리스 컴파일을 통과했고, 화면 검사 1건이 실패했습니다. 프로필 화면 안의 "Profile" 세부 탭과 하단 탭이 함께 잡힌 검사 코드 문제로, 하단 탭 줄에 `bottom-nav` testTag를 달고 검사가 그 안의 탭만 고르게 했습니다.
- Claude 브랜치의 테마 대비 수정(`3c5db8e`: 가이드 딤막·`Scrim`·`Overlay`·`VoltText`·`PaletteContrastTest`)을 합쳤습니다. `slate` 충돌은 밝은 테마 `#687796`, 어두운 테마 `#A7B5CA`로 정리했습니다.

## 검증 방식

기본 화면은 28개 × 4개 언어 × 2개 테마 × 2개 글씨 크기입니다.
한국어 큰 글씨는 화면 아래쪽도 추가로 스크롤하며 캡처합니다.
캡처와 함께 Android가 실제 계산한 텍스트 overflow와 텍스트 영역 교차를
`layout-audit.jsonl`에 기록합니다. 말줄임과 실제 잘림은 별도로 검토하며,
검사 보고서 생성 자체를 통과로 간주하지 않습니다.

서버 로그인은 생산 코드의 인증을 유지합니다. 탐색 UI 검사는 앱의 내부
Scaffold를 직접 렌더링하며, 이것을 실제 로그인 성공의 근거로 사용하지 않습니다.
