## 검토

- 캡처의 날짜 · 걸음 수를 보고 승인 · 거절. 걸음 수가 캡처와 다르면 칸을 고쳐 승인한다(합계에는 고친 값).
- "같은 곳(IP)에서 다른 이메일 N개" 표시는 다중 계정 확인용(같은 와이파이일 수도 있다).
- 승인한 것도 "대기로"로 되돌릴 수 있다. 같은 날을 다시 내면 승인 전까지는 새것으로 바뀐다.
- 검토 키: 첫 키(이름 '대표')는 해시만 0090 에 있다. 더 만들기 · 막기(SQL Editor):

```sql
select economy.walkingday_reviewer_new('담당자 이름');   -- 한 번만 보이는 키
update economy.walkingday_reviewers set revoked_at = now() where label = '대표';
```

## 응모권(명단 탭 · CSV)

- 사전 등록 1
- 11,111걸음 이상 승인된 날이 하루라도 있으면 +3
- 11/11 당일 11,111걸음 이상 승인 +3
- 친구 초대: 내 링크(`?ref=` — 사전 등록 뒤 받는 링크)로 등록한 친구가 11,111걸음 승인을 받으면 친구 한 명마다 나 +2, 그 친구도 +2
- 명단은 초대한 친구 수 → 응모권 순. 초대 순위 경품(1 · 2 ~ 4 · 5 ~ 11위)은 위에서부터. 추첨 · 1인 1경품 · 다중 계정 제외는 사람이 한다.
- 기준 걸음은 설정 `walkingday_goal_steps`(11111). 1,111보 구간을 더하기로 하면 `economy.walkingday_tickets()` 와 페이지 문구를 함께 고친다.

## SNS 게시물 링크 제출 (2026-11-07, 서버 0093)

- 해시태그 검색만으로는 인스타 게시물을 놓치고 계정과 이메일을 이을 수 없어서, 참가자가 `/11events/proof#sns` 에서 이메일 + 게시물 링크(X · 인스타 · 스레드)를 낸다. 인스타 · `x.com/i/status` 링크는 계정 아이디 칸이 열린다.
- 서버 `walkingday_sns_submit`: 기간 · 동의 · 이메일(사전 등록 안 해도 받음) · 링크 형식 · 같은 게시물 한 번 · 한 이메일 하루 3개 · 전체 15개(거절은 안 셈). 같은 곳(IP) 제한은 걸음 인증과 함께 센다.
- 검토 페이지 탭 SNS 대기 · 승인 · 거절: 링크를 열어 해시태그 4개 · 전체 공개 · 11/7 이후 게시를 확인하고 승인. 계정 아이디를 고칠 수 있다.
- SNS 명단(추첨기) 탭: 승인된 게시물을 이메일 · 채널 · 계정마다 묶어 추첨기 `SNS_명단_양식.csv` 와 같은 머리줄로 내려받는다.
- 메인 공유 창에 「올렸으면 게시물 링크 제출하기」. GA4: `assets/config.js` 의 `ga` 에 측정 ID 를 넣으면 `ga.js` 가 켜진다(CSP 열어 둠). 이벤트 `walkingday_proof_submit` · `walkingday_sns_submit`, utm 은 GA4 가 주소에서 읽는다.

## 내 초대 링크 · 11,111걸음 이상 안내 (2026-11-07, 서버 0094)

- 인증 페이지 「친구 초대」 탭(`/11events/proof#invite`): 사전 등록한 이메일 → `walkingday_invite_link` 가 내 코드 · 내 링크로 등록한 친구 수 · 11,111걸음 승인된 친구 수를 돌려준다. 링크는 `/11events/?ref=코드&utm_source=invite…`.
- 메인 응모권 칸에 「내 친구 초대 링크 받기」. 이벤트 기간에 주 버튼이 「걸음 인증하기」로 바뀔 때 ?ref= 로 온 사람은 사전 등록 버튼을 그대로 둔다(전에는 인증 페이지로 가며 ref 가 빠져 초대가 안 셌다).
- 「11,111걸음 이상」을 첫 화면 · 응모권 칸 · 인증 페이지에 밝히고, 11,111걸음보다 적게 적으면 바로 알림(응모권 없음, 합계에는 더해짐).
