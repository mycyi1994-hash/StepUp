## 게임

- 3D 장애물 달리기 세 판 — 예선 「스타트 대시」(20명 중 12명 통과) → 준결승 「흔들 다리」(12명 중 6명) → 결승 「정상 질주」(완주, 120초 안).
  - 예선: 도는 막대 둘 · 틈 뛰기 · 밀어내는 벽 셋 · 거꾸로 도는 벨트와 턱 · 점프대.
  - 준결승: 좁은 다리와 흔들 망치 셋 · 좌우로 움직이는 발판 넷 · 도는 원판 둘(위에 도는 막대) · 밟으면 떨어지는 타일.
  - 결승: 굴러 내려오는 공 비탈 · 도는 막대 둘 · 오르는 디딤돌 · 벨트 위 밀어내는 벽 · 왕관 결승선.
- 경쟁자는 고스트(반투명, 부딪히지 않음). 판마다 완주 시각을 미리 정한다 — `ROUNDS[].cut` = 통과 마지막 자리 고스트가 들어오는 초.
  자동 조종 깨끗한 기록 예선 23.5 · 준결승 19.3 · 결승 23.7초에 맞춰 cut 36 · 31 · (결승 고스트 27 ~ 44초). 어렵게 · 쉽게는 이 값만 바꾼다.
- 떨어지면 마지막 체크포인트에서 다시(시간은 흐른다). 맞으면 튕겨 나가고 0.35초 무적.
- 조작: PC 는 WASD · 화살표 · Space, 폰은 왼쪽을 끌어 이동(조이스틱) · 오른쪽 노란 버튼 점프. 소리는 짧은 합성음(오른쪽 위에서 끄기).
- 캐릭터 · 코스 · 이름은 StepUp 것으로 새로 만들었다(머리 · 몸 · 머리띠 · 큰 운동화). 다른 게임의 캐릭터 · 맵을 흉내 내지 않는다.

## 순위표 (서버 0103)

- `race_start()` → 서버 시각을 적은 번호(같은 곳 10분 40번). `race_finish(번호, 기기 토큰, 이름, 합계 ms, 판별 ms)`:
  서버가 본 시간(지금 − 시작)보다 짧은 기록 · 판별 하한(설정 `race_min_split_ms` = 15 · 12 · 15초)보다 짧은 판 · 합이 안 맞는 기록은 받지 않는다. 번호는 한 번만.
- `race_board(기기 토큰, 50)` → 사람(기기)마다 최고 기록 하나로 줄 세움 + 내 자리. 기기 토큰은 브라우저가 만든 무작위 32자(서버엔 해시만), 이메일 · 계정과 잇지 않는다.
- 게임이 브라우저에서 돌아 완벽한 부정 방지는 아니다 — 꾸민 기록도 실제로 그만큼 기다려야 하고 하한 아래는 막는다.
- 운영(SQL Editor):

```sql
select name, ms / 1000.0 as sec, splits, created_at from economy.race_scores order by ms limit 50;  -- 기록 보기
delete from economy.race_scores where name = '부적절한이름';                                          -- 지우기
update public.economy_settings set value = 'false'::jsonb where key = 'race_open';                    -- 순위 올리기 멈춤
```
