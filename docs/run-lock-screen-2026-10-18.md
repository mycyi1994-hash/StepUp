# 러닝 중 잠금화면 알림 — 우리 모양 · 안드로이드 16 실시간 알림 (2026-10-18)

사용자: "백그라운드에서 재생할 때 잠금화면에 우리 거 나오게 못 해?" → 제안 ①우리 모양 알림 ②안드로이드 16 실시간 알림 → "진행해서 모두 반영".

| 폰 | 모양 |
|---|---|
| 안드로이드 16(API 36) 이상 | 표준 알림 + 실시간 알림 요청(`android.requestPromotedOngoing`, 권한 `POST_PROMOTED_NOTIFICATIONS`) — 상태 표시줄 칩(거리)과 잠금화면 맨 위 고정. 제목 "러닝 중", 흐르는 시계, 거리 · 페이스 · 걸음. 실시간 알림은 직접 그린 모양 · 색 입힌 알림을 받지 않아 표준 모양이다 |
| 그 아래 | 남색 바탕(전경 서비스 색 입힘)에 우리 모양 — 접힘: 로고 · 상태 · 시간 · 거리, 펼침: 로고 · 큰 시간 · 거리 \| 페이스 (`res/layout/notification_run*.xml`) |

- 둘 다 잠금화면에서 내용을 보인다(PUBLIC). 소리 · 진동 없이 '조용한 알림'보다 높은 새 채널 `run_live` 로 옮겼다(예전 `walk_session` 은 지운다).
- 버튼은 일시정지 / 다시 달리기 하나. 마치기는 앱에서만 — 잠금화면 · 주머니에서 실수로 끝내지 않게.
- 시간은 알림의 시계 칸이 스스로 흐른다. 거리 · 페이스 · 걸음은 3초에 한 번까지만 다시 쓴다(멈춤 · 일시정지는 바로).
- 거리는 GPS 거리, 페이스는 50m 부터(`domain/RunNotificationText.kt`, `RunNotificationTextTest`).
- 실제 기기(안드로이드 16 · 그 아래)에서 잠금화면을 보지 못했다. 안드로이드 16 실시간 알림은 사용자가 설정에서 끌 수 있다.
- 잠금 상태에서 앱 화면(지도) 자체를 띄우는 것은 하지 않았다 — 잠금을 풀지 않은 채 앱이 열리면 다른 화면으로 가는 길을 막아야 하고,
  화면을 켤 때 앱을 띄우는 길(전체 화면 알림)은 안드로이드 14부터 알람 · 전화 앱에만 허용된다.
- 2026-10-19 더함(사용자 "홀드화면일때 우리 트랙 나오고 그런거 안되는데?"): 달리는 동안 **러닝 화면에 있었으면** 잠금 화면 위에 그 화면이
  그대로 뜬다(`setShowWhenLocked`, `WalkScreen`). 러닝이 끝나거나 다른 화면으로 가면 바로 꺼서 잠금이 다시 덮는다 — 다른 화면은 잠금을
  풀어야 열린다. 화면을 저절로 켜지 않고(전체 화면 알림을 쓰지 않는다), 다른 앱을 보다 잠갔으면 위 알림이 보인다.
  [mechanics-audit-2026-10-19](mechanics-audit-2026-10-19.md).

## 2026-10-26 — 잠금 화면 가운데 러닝 현황

사용자(솔라나 시커): "잠금화면에서 시계 밑에 '러닝 중'이라고만 뜸 … 내가 원하는 건 홀드화면(잠금화면) 중앙에 현재 현황이 딱 뜨는 그런 거".
10-19 의 방식은 **러닝 화면에 있을 때만** 켜져서, 다른 탭 · 화면에서 잠그면 알림 한 줄만 보였다. 이것으로 바꾼다.

- 달리는 동안에는 어느 화면에서 잠가도 잠금 화면 가운데에 러닝 현황(`ui/screens/walk/LockRunPanel.kt` — `LockRunHost` 가 `MainActivity` 맨 위 겹).
  검정 바탕 · 로고 · "러닝 중 / 일시정지 중" · 큰 시간 · 거리 km · 페이스 · 상태 한 줄(알림과 같은 글 `RunNotification.status`) ·
  주 버튼 일시정지 / 다시 달리기 · "잠금 해제하고 앱 열기"(지문 · 비밀번호 화면). 마치기는 여전히 앱에서만.
- 덮개가 있는 동안 앱 화면은 누를 수도, 화면 읽기로 읽을 수도 없다 — 잠금을 풀어야 지갑 · 설정 같은 화면을 연다. 뒤로 가기는 잠금 화면으로.
- 화면이 꺼지는 순간 덮어 둔다(켜는 순간 앱 화면이 비치지 않게). 앱이 앞에 있는 동안 0.5초마다 잠금 상태를 읽어 지문으로 풀면 바로 걷힌다.
- 러닝 화면만 켜던 `setShowWhenLocked` 는 지웠다(`WalkScreen`) — 이제 `LockRunHost` 가 달리는 동안 켜고 러닝이 끝나면 끈다.
- 다른 앱을 보다 잠갔으면 안드로이드가 우리 화면을 스스로 올리지 못한다(뒤에 있는 앱의 화면 열기 제한, 전체 화면 알림은 알람 · 전화 앱만).
  그때는 잠금 화면의 러닝 알림을 누르면 잠금을 풀지 않고 같은 현황이 뜬다(`LockRunActivity` — 매니페스트 `showWhenLocked` 는 이 화면에만,
  잠겨 있지 않거나 러닝이 아니면 바로 앱을 연다).
- 실제 솔라나 시커에서 아직 보지 못했다.
