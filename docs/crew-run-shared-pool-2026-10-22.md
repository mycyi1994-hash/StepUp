## 확정 규칙(R01 ~ R13)과 서버

| 규칙 | 서버(0071) |
|---|---|
| R01 크루 · 한국 날짜에 공용 체력 하나. 실제 출발 때 고른 신발 최대 내구도 × (1 + 6% × (Lv − 1))를 더한다. 0/0 은 새 하루, 0/816 은 다 씀 — 어느 쪽도 출발을 막지 않는다. 방이 달라도 같은 풀 | `economy.crew_day_pools`(crew_id, day) — `party_start` 가 참가자마다 `contribution` 을 더한다(같은 트랜잭션) |

| R07 보너스 인원 = 같은 크루 · 출발 무렵과 2분 뒤 500m 안 · 휴대폰 인증. 미인증자도 참여 · 기여 · 자기 보상 | `economy.crew_run_bonus_eval` — `party_near` 곁 기록이 출발 + 90초 안에 시작해 출발 + 120초 뒤까지 이어진 무리. 인증은 `auth.users.phone_confirmed_at`(`economy.phone_verified`) |
| R08 인원 표(구간 하나) | `economy.crew_headcount_bonus` 그대로 |

## 핸드오프 열린 결정(D01 ~ D13) — 이번에 고른 것

모두 "확정 전 · 바꿀 수 있음"이다. 사용자가 다르게 정하면 서버 함수 한 곳씩만 바꾸면 된다.

| | 고른 것 | 까닭 |
|---|---|---|
| D01 첫 2분 · 조기 종료 | 확정된 인원 보너스는 러닝 전체에 적용. 2분 전에 끝내면 `UNAVAILABLE`(보너스 없음) | 구간을 나누면 같은 러닝의 보상이 두 갈래로 보여 설명이 어렵다 |
| D02 확정 뒤 인원 변화 | 2분 판정 인원으로 고정 | 보너스 인원과 아직 달리는 사람 수는 따로 보인다 |
| D03 500m 기준 | 참가자끼리 거리(기존 `party_near` 곁 기록), 반경 500m 그대로 | 기존 위치 검증을 그대로 쓴다. 위치가 없으면 `NO_LOCATION`(확인 불가) |
| D04 러닝 중 레벨 업 | 출발 때 레벨로 체력 · 보상. 새 레벨은 다음 출발부터 | 진행 중 숫자가 바뀌지 않는다 |
| D05 자정을 넘는 러닝 | 출발한 날의 풀 · 참여권에 묶는다 | 하루 원장이 갈리지 않는다 |
| D06 0 뒤 새 기여 | 새 기여로 양수가 되면 모두 다시 적립. 0 이던 구간은 소급하지 않는다 | 빈 구간을 시각으로 적어 둔다 |
| D07 무효 러닝 | XP 없음. 이미 쓴 공용 체력 · 다른 사람 보상은 고치지 않는다. 참여권도 돌려주지 않는다 | 한 사람의 무효로 남의 원장을 다시 쓰지 않는다 |
| D08 소수 | 초 단위 비례 · 정밀도 그대로(numeric), 보상은 4자리, 화면은 소수 한 자리 버림 | |
| D09 끊김 | 30초 넘게 소식이 없으면 그동안 쓰지 않는 것으로만 본다(끝낸 것으로 치지 않는다) | 잠깐 끊긴 것을 종료로 만들지 않는다 |
| D10 방 · 진행자 | 기존 그대로(진행자가 끝내면 방이 닫히고, 남은 사람은 자기 러닝을 이어 간다). 중도 합류 없음. 크루 방은 준비한 사람 2명 이상이어야 출발(`crew_run_need_two`) | |
| D11 진행 중 신발 변경 | 출발 때 신발 · 효율 · 최대 내구도를 스냅샷 | |

## 앱

- 달리는 동안 5초마다(일시정지 · 다시 달리기는 바로) `crew_run_beat` 를 보낸다(`CrewRunRepository.startBeats`, 앱이 살아 있는 동안 한 번 건다).
  방 번호는 출발 시각과 함께 `crew_run_beats` 설정에 적어 앱을 다시 켜도 이어 간다. 러닝이 끝나면 "끝냄"을 몇 번 다시 보낸다.
  서버가 나를 끝냈으면(마지막 한 사람) 러닝을 멈추고 결과 위에 "함께 달리던 모두가 러닝을 마쳤어요"를 한 번 띄운다.
- 크루 홈: 남색 "오늘 크루 체력 612 / 816" 카드 — 막대 · "함께 쓰는 내구도 · 매일 00:00 초기화" · 0/0(새 하루)과 다 씀을 다르게 ·
  오늘 참가 N명 · 내 오늘 크루 러닝(할 수 있음 · 달리는 중 · 마침 · 다른 크루에서 마침) · 레벨 보너스 · 인증 전 안내. 레벨 업은 한 번 시트.
- 대기실: 오늘 공용 체력(남은 / 총량 · 내가 더할 체력) · 예상 보너스(준비한 크루원 중 인증된 사람으로 센 미리보기) · 다 썼어도 출발 가능 안내 ·
  인증 전 안내 · 다른 크루에서 이미 했으면 그 크루 이름 · 2명 미만이면 출발 버튼이 꺼진다. 신발 고르기 시트는 "효율 · 크루 체력에 +N".
- 달리는 중: 공용 체력 "612 / 816"(받은 값에서 지금 쓰는 사람 수만큼 부드럽게 줄인다) · 인원 보너스 확인 중(남은 시간) / 확정 / 없음 ·
  일시정지 중 · 지금 쓰는 사람 · 인증 전. 2분 판정 · 20% 아래는 한 번씩 남색 시트. 0 이면 띠.
  예상 보상 = 고른 신발 기준 × (1 + 확정된 인원 + 레벨), 0 이던 동안의 걸음은 뺀다. 잠금화면 알림은 "크루 체력 612 / 816".
- 결과(보상 설명 시트): 내 신발 기준 · 인원 · 레벨 · 합 식 · 내가 더한 / 쓴 체력 · 오늘 공용 체력 · 개인 내구도 안 씀 · 다 씀 / 자동 종료 ·
  레벨에 보탠 거리(무효면 더하지 않음) · 개인 상한과 따로. 서버가 정산하기 전에는 "서버가 정산한 뒤에 보여요".
- 크루 러닝 화면에 쓰는 남색 부품은 `ui/screens/walk/CrewNavyKit.kt`(핸드오프 design-tokens). 앱 전체 테마는 바꾸지 않았다.

## 하지 않은 것 · 남은 것

- 휴대폰 인증 화면(R12 — 범위 밖). 인증한 사람이 없으면 인원 보너스는 0 이다.
- 방 이름을 붙여 만드는 화면(서버에 방 이름이 없다), 출발 전 "아직 500m 밖" 확인(대기실에서 거리를 재는 API 가 없다), 레벨 업 · 모집 푸시, 지난 크루 러닝 상세 화면.
- 대기실 · 달리는 중 · 결과 화면 전체를 시안 그대로 남색 화면으로 바꾸지는 않았다 — 기존 크루 달리기 화면(앱 테마를 따른다)에 새 값 · 카드 · 시트를 넣었다.
- 실제 기기에서 여러 사람이 함께 달려 보지는 않았다(서버 검사 · 단위 검사 · 컴파일만).
