# 새 Claude 세션에 전달할 요청문

아래 문구는 인계 자료를 읽게 하는 요청이다. 앱 구현을 시작하는 지시와 구분한다.

> StepUp의 새 리디자인 기준은 Figma S2 무대입니다. 먼저 `docs/redesign/s2/README.md`부터 읽고, 안내된 기획·결정 기록·화면 대응표·자산 목록·진행 상태를 확인해주세요. 기존 캐릭터/옷장 방향의 문서와 혼동하지 마세요. 확보한 이미지로 진행하기로 했으므로 Figma 내보내기를 다시 요구하지 마세요. 비교 HTML은 구성 참고이며 실제 APK나 최종 승인 시안이 아닙니다. 원본 자산과 현재 기능을 기준으로 이어가야 합니다. 먼저 확정 사항, 제안 사항, 미정 사항, 현재 코드 상태, 첫 구현 범위를 짧게 정리해주세요. 구현·커밋·푸시·배포는 이 인계 요청만으로 시작하지 말고 해당 세션에서 사용자가 요청한 범위를 따르세요.

사용자가 별도로 구현을 요청하면 `STATUS.md`의 순서와 `PLAN-KO.md`의 완료 기준을 따른다. 이미 그 세션에서 받은 구현 허가를 반복해서 요청하지 않는다.
