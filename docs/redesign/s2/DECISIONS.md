# S2 결정 기록

작성: 2026-09-26. 문서와 시안의 존재를 사용자 승인이나 구현 완료로 확대 해석하지 않는다.

## 사용자가 명시한 내용

- 기존 StepUp APK 앱 전체를 S2 시안에 최대한 동일하게 리디자인하려 한다.
- 시안에는 기존 기능이 사라지거나 설명 없는 새 기능이 생긴 부분이 있으므로 이를 살펴보고 정리한다.
- 이미지부터 추출해 준비한다.
- 미확보 항목의 내보내기에서 `not allow`가 표시되어 현재 확보한 이미지로 진행한다.
- 기획서를 작성하고, 기존 화면과 변경 예상판을 비교한다.
- 비교 이미지 화질이 좋지 않다는 의견이 있었다. 축소 캡처와 실제 자산 품질을 구분해야 한다.
- 현재 요청은 Claude가 작업을 이어갈 수 있도록 레포 안의 내용을 정리하는 것이다.

캐릭터 없는 앱 방향은 기존 최신 인계에도 기록되어 있다. S2에 없는 옛 캐릭터/의상 화면을 복원하지 않는다.

## Codex가 제안한 기본안 — 세부 승인과 구현 전

| 항목 | 제안 |
|---|---|
| 메뉴 | 러닝 / 신발 / 같이 뛰기 / 내 정보. 가운데 뽑기는 신발 안으로 이동 |
| 누락 기능 | 코스·랭킹·영역 지도·게시판·도감·강화·판매·상세 설정을 하위 화면으로 보존 |
| 부족한 그림 | 아치와 시작 카드는 원본 이미지+실제 UI로 조합. 상자는 기존 자산, 코인은 우선 SUP 글자 |
| 미정 신기능 | 모드·체중 온보딩·실시간 날씨·새 초대/뽑기 보상 정책은 우선 보류 |
| 구현 순서 | 공통 부품과 홈/신발/러닝 대표 화면부터 실제 앱으로 비교 |

사용자는 비교판을 요청했지만 그 결과 전체를 최종 승인했다고 말하지 않았다. `미리보기와 완전히 똑같이 구현`을 사용자 지시로 만들어내지 않는다. S2 원본의 구조를 우선하고 현재 데이터로 연결한다.

## 임의로 정하지 않을 서비스 정책

- 라이프/러너 모드의 정의, 전환 자격, 운동 측정/보상 차이.
- 신체 정보의 수집 목적·저장·선택 입력과 목표 체중 예측.
- 시안의 편안/내구 등 기존 모델과 다른 신발 능력치.
- 뽑기 비용·확률·횟수와 초대 보상. 시안의 10 SUP/5 SUP 같은 예시는 실제 설정이 아니다.
- 다른 참가자의 실시간 위치 공유와 동의 범위.
- 실시간 날씨 공급원과 배경 자동 전환 정책.
- 확보 신발 5종과 기존 전체 상품/보유 모델의 정확한 대응.

이 항목에 의존하지 않는 화면 작업은 진행할 수 있다. 실제 기능을 추가해야 할 시점에 필요한 결정만 묻는다.

## 비교 시안에서 알려진 차이

- 실제 APK 변경 결과가 아니라 웹으로 만든 구성 미리보기다.
- 원본 S2 상자와 도트 코인은 미확보다. 상자는 기존 앱 이미지, SUP는 글자로 표현했다.
- Figma 지도 이미지와 기존 캡처의 실제 지도/경로는 다르다.
- 원본 신발 일부는 시각 예시로 배치했다. 실제 카탈로그 ID에 매핑한 것이 아니다.
- 테스트 기록이 없는 프로필은 원본 시안의 가짜 연속 일수 대신 빈 기록 메시지로 표현했다.
- 시안에 없는 정책·스탯을 만들지 않도록 문구와 일부 보조 정보가 다르다.
- 모든 화면의 정확한 글꼴 크기/색상/도형 좌표를 Figma에서 확보한 것은 아니다.
