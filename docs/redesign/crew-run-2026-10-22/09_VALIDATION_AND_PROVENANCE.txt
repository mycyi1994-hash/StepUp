패키지 검증과 자료 출처
작성일: 2026-10-22

실제로 수행한 작업
승인된 크루 러닝 시안을 구현 지시서·화면 명세·규칙표·서버 및 Android 핸드오프와 함께 정리했다. 실제 앱이나 Supabase 운영 환경을 수정·배포하지 않았다.

1. 기존 시안 검증 기록
qa/qa-report.json: 기본 390×844 리뷰 프레임의 39개 상태 검토. 프레임 밖 요소·주요 충돌·스크립트 오류 없음.
qa/narrow-report.json: 뷰포트 390px와 320px에서 39개 상태씩 검토. 갤러리 여백을 제외한 휴대폰 프레임 폭은 각각 358px와 288px다. 가로 넘침·프레임 밖 요소 없음.
qa/interaction-report.json: 신발 선택, 2분 확인, 일시정지·종료, 미인증 참여, 진행자/참가자 역할, 20명 명단, 일부 인원 제외, 풀 0, 20단계 레벨표, 전체 인원 보너스 표의 데모 흐름 검증.
위 파일은 웹 시안 제작 시의 결과다. 실제 Android·DB 테스트 결과가 아니다.

2. 이번 오프라인 내보내기 검증
qa/offline-export-report.json: 네트워크를 끈 Chromium에서 독립 실행용 reference.html을 열어 39개 상태를 전환했다.
결과: 화면 39개 로드, 본문 넘침 없음, 이미지·아이콘 정상, 원격 요청 0건, 스크립트 오류 0건.
신발 최대 내구도 150 선택→Lv7 기여량 204 반영도 확인했다.
qa/offline-export-preview.png: 내보낸 파일에서 실제 캡처한 화면.
화면별 PNG는 780×1688이며 리뷰 크기 390×844의 2배다.

3. 최종 패키지 검증
qa/package-validation.json에 파일 존재·화면 ID·규칙 수치·이미지 크기·문서 항목 검사를 기록한다.
manifest.sha256은 패키지 파일의 SHA-256 목록이다. manifest 자체는 계산 대상에서 제외한다.
ZIP 생성 후 내부 파일 읽기 검사와 manifest 해시 대조를 수행한다.

4. 실제 구현에서 아직 수행하지 않은 검증
Kotlin/Compose 빌드, Android 실제 기기 실행, GPS·백그라운드 기록, 실계정 동시 출발, DB migration 적용, RPC·권한·동시성·보상 원장 테스트는 수행하지 않았다.
06_ACCEPTANCE_TESTS.txt의 T01~T64는 구현 후 수행할 검증 목록이다. 이 패키지가 그 테스트를 통과했다는 뜻이 아니다.
이번에 최신 저장소·DB 상태를 직접 확인하지 않았다. 구현자는 실제 작업 시점의 AGENTS.md·CLAUDE.md·마이그레이션 이력·코드를 먼저 확인해야 한다.

5. 자료 출처와 사용 범위
제품 규칙: 사용자의 2026-10-21 작업 정의서, 이후 문자 발송 제외 지시, 현재 핸드오프 요청.
화면 기준: 승인된 남색 크루 홈과 그 톤을 이어 만든 크루 러닝 전체 시안. reference-fragment.html은 자산을 포함한 해당 시안 원본이다.
기존 앱 참고: 작업 공간에 보관된 CrewRunKit·CrewRunLive·CrewBlueKit·CrewHomeParts·CrewStaminaParts 및 기존 화면 자료. 현재 저장소 최신 버전이라고 보장하지 않는다.
assets/crew-identity.png와 assets/shoe_1201.webp: 기존 StepUp 작업의 앱 자산 사본. 다른 신발 ID에 같은 그림을 쓴 데모는 실제 자산으로 교체한다.
assets/map-fixture.json: 기존 테스트 경로의 예시 데이터. 실측·검증된 러닝 코스가 아니다.
지도 배경: OpenStreetMap 기반 자료. 원본 출처 표기를 유지하고 실제 앱에서는 지도 공급자 정책을 따른다. https://www.openstreetmap.org/copyright
서체: 미리보기에 Pretendard 웹용 부분 글꼴이 포함되어 있다. Android에는 기존 저장소의 정식 전체 글꼴 리소스와 해당 라이선스를 사용한다.
아이콘: 오프라인 내보내기에 로컬 Lucide 1.8.0을 포함했다. ISC 라이선스는 licenses/lucide-ISC.txt에 있다. 39개 상태의 아이콘 로드를 확인했다.

6. 파일 간 차이
reference.html: 오프라인 실행용 갤러리. 외부 아이콘 로더를 로컬 코드로 포함하고 사용하지 않는 원격 보조 스크립트를 제거했다.
reference-fragment.html: 승인 시안 원본 보존용. 단독 실행용 파일은 reference.html이다.
prototype-source/: 검토용 HTML/CSS/JavaScript 템플릿. 앱 구현체가 아니며 자산 삽입 자리표시자가 있다. 자산을 포함한 전체 버전은 reference-fragment.html이다.
