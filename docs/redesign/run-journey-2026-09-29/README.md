- 필터 칩(보관함 · 도감 · 거래소의 "등급" 고르기)은 고르는 단추라 칩 모양 그대로 둔다.

## 3. 러닝 중 — 시안 01

| 시안 | 앱 |
|---|---|
| 가운데 이름 "자유러닝" | 계획 이름(자유 러닝 · 10분 러닝 · 다이어트 러닝). 오른쪽 작은 ⋯ = 러닝 정보(예상 적립 · 코스 · 까닭) |
| 노란 띠 "속도 측정 오류 · 확인 중" | 이 러닝에 사람 속도를 넘어 버려진 구간이 있으면. 누르면 까닭. 모의 위치면 빨간 띠 "세션 무효 · 기록되지 않아요" |
| 위 판: 러닝 시간 24:18 │ 달린 거리 3.24 km | 같은 값. 거리는 결과와 같은 기준(GPS 거리, 없으면 걸음 거리) |
| 지도 화면 가득 · 형광 경로 | 실제 지도 위 경로 — 지금 자리는 위 판과 아래 판 사이 가운데에 |
| 아래 판 한 줄: 현재 속도 ⚠ — km/h │ 내구도 92/100 막대 | 현재 속도 = 최근 20초 경로 점으로 잰 값. 방금 읽은 속도가 버려졌으면 "—"와 노란 경고, 멈춰 있으면 0.0. 내구도 = 신고 있는 신발 |
| 일시정지 (파랑) · ■ 종료 | 일시정지 ↔ 다시 달리기, 종료는 먼저 멈추고 묻는다(예전과 같은 확인 창) |

- 평균 페이스 · 예상 보상(상자 표) · 신발 그림은 러닝 중 화면에서 뺐다(지시서). 예상 적립은 ⋯ 러닝 정보에 남는다.
- 계획별 위 판: 목표 러닝은 판 아래 진행 막대와 "목표까지 0.48 km", 다이어트는 왼쪽 "달리기 · 1회 / 3회 · 남은 구간 시간" │ 오른쪽 "전체 운동"과
  이번 구간 안내 · 다음 구간. 가끔만 보이는 것(GPS 찾는 중 · 위치 꺼짐 · 대략적인 위치 · 신호 약함 · 같이 뛰는 순위 · 챌린지 진행 · 코스 녹화)은
  위 판 아래 작은 판으로.
- 달리는 동안 머리에 뒤로 가기는 없다 — 시스템 뒤로 가기가 종료를 묻는다(예전 동작 그대로).
- 저장 중 · 저장 실패 · 다이어트 루틴 완료는 버튼 자리에 그 행동 하나(예전 그대로).

## 4. 러닝 완료 — 시안 03

| 시안 | 앱 |
|---|---|
| 가운데 "러닝 완료" · ✕ | ✕ = 완료와 같다. 목표를 못 채웠으면 "중간 종료 결과", 다이어트는 "저장 완료" |
| 카드: STEPUP 로고 · 날짜 | 공식 워드마크(카드 역할) · 러닝을 시작한 때 |
| 3.24 km · 지도 | 결과 거리(GPS 거리, 없으면 걸음 거리) · 달린 경로(없으면 "기록된 GPS 경로가 없어요") — 지도는 남는 높이를 채운다 |
| 러닝 시간 · 평균 페이스 · 평균 속도 | 같은 셈(50m 넘게 달렸을 때만 페이스 · 속도, 아니면 "—") |
| 신발 · 이름 + 레어 배지 · 내구도 92 / 100 막대 | 신고 있는 신발 |
| 상자 표 · 예상 보상 +2.4 SUP · ⏱ 정산 대기 | **서버 확인 전**: 이 폰이 셈한 값을 "예상 보상 · 정산 대기"로만. 서버가 확인하고 금액을 읽었을 때만 "보상 +x SUP · 적립 완료". 무효 · 거절 · 적립 없음은 "0 SUP"와 "무효" / "지급 안 됨" + 까닭 한 줄 |
| 이미지 저장 · 공유하기 · 완료 | 이미지 저장 = 공유와 같은 그림을 사진(Pictures/StepUp)에(Android 9 이하는 저장 권한을 묻는다). 공유하기 = 예전 기록 공유. 완료 = 러닝 홈(목표를 못 채웠으면 "챌린지로 돌아가기") |

- "자유러닝" 글은 로고 아래에서 뺐다(지시서). 목표 · 다이어트 러닝은 거리 아래 한 줄로 결과(달성 · 도전 · 러닝 + 걷기).
- 로그인이 풀려 올리지 못한 러닝은 보상 줄 아래 안내와 "다시 로그인"(예전 그대로). 다이어트는 "같은 방법 다시 하기"도 그대로.
- 예전 결과의 문장 제목 · 체크 · 오늘의 기록 상자 · 보유 SUP 줄은 시안에 없어 뺐다(보유는 지갑 · 머리의 SUP).

## 5. 다르게 한 것 · 남은 것

- 시안의 예시 수(24:18 · 3.24km · +2.4 SUP · 92/100)는 검사 캡처에만 있다 — 앱은 기록 · 서버 값만 보인다.
- 현재 속도는 서비스가 따로 재지 않아 화면이 경로 점으로 잰다(버려진 구간의 때를 서비스 상태에 표시용으로 더했다 — `lastFlaggedAt`, 저장본에 남기지 않음).
- 러닝 중 ⋯(러닝 정보)는 시안에 없다 — 예상 적립 · 코스 · 버려진 구간 설명으로 가는 길이라 작게 남겼다.
- 이미지 저장은 시안의 버튼대로 새로 넣었다 — 저장하는 그림은 공유하기가 보내는 기록 그림과 같다(Android 9 이하에서만 저장 권한을 묻는다).
