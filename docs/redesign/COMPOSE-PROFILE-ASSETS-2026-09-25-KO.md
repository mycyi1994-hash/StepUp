# 글쓰기·내 정보 디자인 자산 정리 — 2026-09-25

사용자 지시: 화면을 최대한 단순하게 만들고, 두 영역에 필요한 자산을 빠짐없이 준비한다. 의상·신발별 새 캐릭터 포즈는 기존 합의대로 후속 단계다. 이 문서는 화면을 통째로 이미지로 저장하지 않고 실제 조립에 쓰는 자산 단위를 기록한다.

| 화면 | 독립 자산/부품 | 현재 연결 |
|---|---|---|
| 글쓰기 공통 | 차분한 공통 배경 `CommerceBackdrop` | `Routes.POST_COMPOSE`에 연결 |
| 글쓰기 자유·팁·번개 | `FocusHeader`, `PillChip`, `FormField`, `PrimaryCta` | 동일한 네이티브 부품 사용, 자유글 기본값 |
| 글쓰기 번개 추가 입력 | 장소·거리·출발 시간·정원 필드, 위치/오류 안내문 | 번개 선택 시에만 표시 |
| 내 정보 풍경 | `scene_home_blue_night.png`, `scene_home_dawn.png` | 루트가 선택·교체, 캐릭터와 독립 |
| 내 정보 앉은 장면 | `prop_profile_bench_v2.png`, `avatar_runo_sit_studio_pink_v2.png`, `avatar_lumi_sit_studio_pink_v2.png` | 정확히 맞는 핑크/WND-010 착장에 연결, 접지 그림자는 Compose Canvas |
| 내 정보 조작 | 배경·설정·편집 아이콘, 기록 숫자, `QuietListRow` | 이미지에 굽지 않고 Compose로 표시/클릭 |

이 범위에 필요한 **새 래스터 이미지는 0개**다. 풍경 2개, 벤치 1개, 앉은 캐릭터 2개는 기존 원본과 앱 리소스를 그대로 재사용한다. 아이콘·글자·버튼·입력칸은 공통 Compose 자산이며 배경 이미지에 포함하지 않는다. 따라서 배경을 교체해도 글쓰기·메뉴 조작은 영향을 받지 않는다.

남은 검증: 이 소스의 Android 컴파일과 실제 기기 화면 캡처, 작은 화면/큰 글자/키보드, 밝은 테마, 프로필의 앉기·서기 전환. 지원하지 않는 착장은 기존 IDLE 전신으로 표시되므로, 이 문서가 모든 의상·신발의 앉은 포즈 완료를 뜻하지 않는다. APK나 출시 디자인 완료로 표시하지 않는다.
