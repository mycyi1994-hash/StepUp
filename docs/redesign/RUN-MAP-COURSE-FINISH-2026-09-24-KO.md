# 러닝·지도·코스 디자인 마감 기록

2026-09-24. 이전 로컬 디자인 변경에 이어 적용했다. APK/AAB, 원격 빌드, 배포, 새 이미지 생성은 실행하지 않았다.

## 반영 범위

기존 86개 작업표 중 아래 **12개 항목**에 소스 마감을 추가했다. 새로운 페이지 12개나 실제 기기 검수가 끝난 12개를 뜻하지 않는다.

| 작업표 ID | 소스 반영 내용 |
|---|---|
| screen-01 | 러닝 준비: 캐릭터와 기록 영역 스크롤, 아래에 유지되는 시작 버튼, 읽기 쉬운 GPS 상태 |
| screen-34 | 진행·일시정지: 폭에 맞는 전체 시간 표시, 작은 화면/큰 글자에서 기록 세로 배치, 조작 버튼 분리 |
| screen-35 | 결과: 실제 확정·거절·대기 분기 유지, 보상 숫자/단위 분리, 거리·시간·페이스의 세로 정렬 |
| screen-07 | 코스 선택: 실제 경로 미리보기 확대, 전체 이름·거리·보상, 48dp 선택/좋아요, 별도 전체 폭 행동 |
| extra-courses-create | 코스 만들기: 녹화 절차 본문 확대, 공통 이름·지역 입력, 실제 트랙과 공유 스위치 유지 |
| extra-courses-board | 코스 게시판: 공통 검색 입력·지우기 버튼, 업로드 목록/순위 팝업 가독성 개선 |
| screen-30 | 지도 내 주변: 긴 모임/코스 이름과 안내 정리, 상세 패널 높이 제한 및 스크롤 |
| extra-map-territory | 영역 탭: 안내를 지도 밖 하단 패널로 이동, 영역 순위의 이름과 수치 분리 |
| extra-map-territory-sign-in | 실제 로그인 필요 상태를 하단 안내로 표시 |
| extra-map-territory-zoom-in | 실제 확대 필요 상태를 하단 안내로 표시 |
| extra-map-territory-empty | 실제 빈 영역 상태 안내와 지도 데이터 구분 |

관련 공통 팝업 호출 **5곳**도 적용했다: 러닝 종료 확인, 러닝 목표 설정, 기록한 코스 저장, 코스 선택/해제 확인, 코스 기록 순위. 추가 페이지 수에는 넣지 않았다. 준비/진행 화면의 권한 안내와 저장 실패/재시도도 같은 배치 변경을 공유한다.

## 모듈과 데이터

- `AdaptiveNumber`: 시스템 글자 크기를 반영해 시간·금액을 측정하고, 전체 숫자가 한 줄 폭을 넘을 때만 맞춘다. 러닝 타이머·보상·잔액·기록 숫자에서 재사용한다.
- `DialogPanel`, `FormField`, `VoltButton`, `GhostButton`, `DarkIconButton`, `StatePanel`을 재사용한다. 입력·확인·취소·선택은 모두 네이티브 UI다.
- 러닝 캐릭터는 기존 성별·착장 해석을 사용한다. 독립 배경과 루트 헤더/하단 탭 구조를 유지했다. 이번에 장비 그림을 생성하거나 교체하지 않았다.
- 지도는 기존 실제 타일, 좌표, 핀 선택, 영역 데이터, 이동/확대 처리를 유지한다. 하단 상세는 화면 높이의 최대 42% 안에서 스크롤한다. 상태 문구가 지도와 저작권 표기를 덮지 않는다.
- 코스 미리보기는 기록된 좌표의 실제 경로 형태다. 안내·보상·외부 지도 버튼을 경로 바깥에 배치했다. 임의 도로나 소유 영역을 그리지 않는다.
- 시작/일시정지/재개/종료/저장 재시도, 코스 생성/선택/공유/삭제, 기록 공유 콜백과 기존 입력 조건을 유지했다. 실제 잔액·보상 확정·장비 소유를 바꾸지 않았다.
- 좋아요 접근성 문구 두 개를 한국어·영어·일본어·중국어에 추가했다.

## 근거와 확인 상태

기존 일시정지·지도 시안을 참고해 캐릭터 중심 화면과 실제 2D 지도 방향을 유지했다. 변경된 Kotlin 50개 파일(이전 마감 변경 포함)의 문법 파싱, 디자인 계약, 4개 언어 문자열, 기존 자산, 공백 검사를 통과했다. 화면 목록은 33개 경로·34개 screen 함수·20개 overlay 선언이다.

소스 검사와 문법 파싱은 타입 검사나 Android 컴파일이 아니다. 로컬 Android 도구가 없어 컴파일·실행·같은 소스의 기기 캡처는 미실시다. 통합 확인에서는 작은 화면/큰 글자, 긴 시간·숫자, 키보드와 저장창, 러닝 제어와 저장 재시도, 지도 이동/확대와 상태 전환을 확인해야 한다. 이번 기록은 출시 완료나 디자인 전체 완료 판정이 아니다.

다음 디자인 마감 대상은 홈/더보기·시작 로딩, 옷장/보관함·도감·마켓 목록, 소식 목록에 남아 있다. 전체 캐릭터 착장별 원본과 부위 합성 문제는 별도 자산 과제로 남는다.
