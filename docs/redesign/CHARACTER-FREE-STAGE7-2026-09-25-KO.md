| 대상 | 반영 |
|---|---|
| 글쓰기, 모임 만들기 | `FormPage` 하나로 머리글·스크롤 입력 영역·키보드 위 고정 제출 버튼을 공유. 글 본문 최소 높이를 144dp로 정리하고 번개러닝 숫자 입력을 개별 스크롤 항목으로 분리. 입력란 제목은 칸 위의 별도 텍스트로 표시 |
| 번개러닝 상세 | 이전 빈 배경 구성 요소를 기존 노을 풍경의 독립 100dp 배너로 교체. 장소는 전체 폭, 시간은 별도 행. 거리 항목은 큰 글씨/좁은 폭에서 세로 배치. 장소 터치 영역 최소 48dp. 채팅 머리글은 줄바꿈 허용 |
| 설정 공통 행 | 아이콘·제목·스위치/선택 표시 아래에 설명을 전체 폭으로 분리. 알림, 소리·진동, 테마, 언어 화면에 공통 적용 |
