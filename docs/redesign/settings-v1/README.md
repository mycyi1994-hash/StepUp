# 설정 v1 (2026-09-28 전달본)

사용자 전달본 "StepUp 설정 디자인"(`design/settings-v1/` — 구현 지시서 · FAQ 답변안 · 토큰 · 장면 목록, 시안 28장면)을 앱에 적용했다.
러닝 패스의 짙은 남색 · 밝은 글자 · 파란 강조를 이어 쓰고, 설정 첫 화면은 큰 카드 없이 세 그룹의 짧은 목록이다.
기존 설정 값 · 기본값 · 언어 코드 · 테마 값 · 권한 · 계정의 뜻은 그대로다(시안의 선택값은 예시).

## 첫 화면(01) — `Routes.SETTINGS`(새 경로, 부모는 내 정보)

| 그룹 | 줄 | 들어가면 |
|---|---|---|
| 러닝과 알림 | 하루 걸음 목표(현재 값) · 알림 · 개인정보·앱 권한 | 목표 시트(24) · 02 · 06 |
| 앱 사용 | 언어(현재) · 화면 테마(현재) · 소리·진동·동작 | 18 · 16 · 20 |
| 계정과 도움말 | 연결된 계정 · 도움말·문의 | 11 · 21 |
| 더 보기 | 알림함 · 업적 · 친구 초대 · 신체 정보 · 모드 | 기존 화면 그대로 |
| 앱 정보 | 데모 모드 · 버전 · (테스트 빌드 업데이트) · 네트워크 | — |

- 예전에는 내 정보 안의 두 번째 탭(18줄 목록)이었다. 이제 내 정보 첫 화면의 "설정"이 이 경로를 연다(상세 머리 · 뒤로, 아래 탭은 내 정보).
- 프로필 수정과 지갑은 러닝 패스에 그대로 있어 여기 다시 두지 않았다. 내 신발은 신발 탭, 랭킹은 커뮤니티에 있다.
- **지우지 않은 것**: 시안의 세 그룹에 없던 알림함 · 업적 · 친구 초대 · 신체 정보 · 모드와 데모 모드 · 버전은 "더 보기" · "앱 정보"로 옮겼다
  (덜 쓰는 기능은 안쪽으로). 앱 가이드는 도움말 · 문의의 "앱 사용 안내"다.

## 화면별

| 장면 | 화면 | 동작 |

| 02–05 · 25 · 26 | 알림 | 기존 네 가지(푸시 · 목표 · 러닝 초대 · 이벤트). 바꾸면 바로 휴대폰에 저장 → "이 휴대폰에 저장했어요" → 기존 PushRegistrar 로 서버 반영. 반영을 확인하지 못하면 "휴대폰에는 저장했어요 · 다시 반영하기"(04, 서버 성공으로 보이지 않는다). 휴대폰에 저장하지 못하면 스위치는 저장된 값 그대로 두고 알린다(05). 휴대폰(OS)이 알림을 막으면 앱 스위치를 대신 끄지 않고 안내 + 휴대폰 설정 열기(03), 돌아오면 다시 읽는다. 읽기 전에는 자리만(25), 못 읽으면 다시 불러오기(26). 저장 중 다시 누를 수 없다 |
| 06–10 · 27 | 개인정보·앱 권한 | 신체 활동 · 위치(정확 / 대략 / 안 됨) · 알림의 실제 상태를 글자로(앱 안 스위치가 아니다), 바꾸는 길은 "휴대폰 설정 열기" 하나. 저장하는 정보(08)는 짧은 보관 안내 + 기존 상세 안내. 알림 기록 지우기는 기존 그대로 이 휴대폰의 일반 알림만(답하지 않은 초대 · 미확인 보상 알림은 남는다) — 확인(09) → 지우는 중(다시 누를 수 없음) → 실제로 지운 뒤에만 "지웠어요"(10), 못 지우면 다시 지우기 · 취소(27) |
| 11–15 | 연결된 계정 | 로그인은 이 휴대폰의 실제 로그인 상태(확인 중 · 로그인됨 · 연결 안 됨). WEB3 지갑은 서버가 아는 실제 연결(draw_status) — 연결 전이면 "연결하기"로 뽑기 화면과 같은 웹 지갑 페이지. Health Connect 는 "준비 중". 계정 삭제는 로그인이 확인된 사람에게만 — 확인(13) → 처리 중(14, 닫기 · 중복 요청 막음) → 서버가 지웠다고 답한 뒤에만 기존 정리(로그아웃 · 사본 지우기 · 로그인 화면). 인터넷이 없거나 서버가 거절하면 "서버가 삭제하지 않았어요"(다시 시도 가능), 보냈는데 응답을 못 받았으면(끊김 · 5xx) **결과 미확인**(15) — 자동으로 다시 보내지 않고 문의 방법 · 닫기(닫으면 계정 상태를 다시 읽는다) |
| 16 · 17 | 화면 테마 | 기기 설정 따르기 · 어둡게 · 밝게(저장 값 SYSTEM · DARK · LIGHT 그대로). 즉시 바뀌고 액티비티를 다시 만들지 않는다. 저장 실패면 직전 테마로 되돌리고 알린다. 미리보기의 거리는 **이 계정의 실제 누적 러닝 거리**(시안의 34.2 는 예시라 쓰지 않았다) |
