이 내용은 사용자가 대화에 붙여 넣은 CAPTURE-NOTES-FOR-REVIEW.md의 검토 조건을 정리한 것이다. 대상은 GitHub Actions Experience QA 실행37068564191, 커밋eaf9f52, StepUp-experience-qa/screen-gallery의 과거 캡처다. 이 ZIP 작성 과정에서 해당 원격 실행이나 캡처를 새로 받아 재검증하지 않았다. 이 문서를 추가한 것이 실행 QA 통과를 뜻하지 않는다.

## 해당 과거 캡처에서 결함으로 보지 않을 조건

1. R01/E07/L03/K01/K02/K17/K18/U04/D04/D05는 일시적 상태 또는 서버 제약 때문에 부품 단위로 촬영했다. K17/K18에 코스 허브 탭·검색 줄이 없고 허브 전체는K11이다.
2. CI는 로그인 전이다. K11/K12의 로그인 필요와K16의 올릴 내 코스 없음은 맞는 상태다.
3. R01/CR08 카운트다운은 타일 로드 전에 캡처되어 남색 바탕만 보인다.
4. R02_TIME/E07/L03은 위치를 모르므로 지도 없음/빈 틀이 맞다. 시안 지도 예시를 복사해 채우지 않는다.
5. 숫자는 예시와 달라도 된다. 보상 확인 전E10은 예상·확인 중, 적립 완료는E11에서만 표시한다.
6. CR02/CR16은 보기 전용 방 조회API가 없어 당시 미구현이다. 그 캡처가 없는 것은 이미지 비교 결함이 아니며 기능 연동은 별도 미완료로 기록한다.
7. 대기실 일정·목표거리·모임 장소 줄은 서버 방 정보에 값이 없으면 없다. 가짜 값을 채우지 않는다.
8. 의도된 차이: 코스·대기실·크루 달리기는 하단 탭 없음; 기록·통계H01~H10/H15는 탭 유지. L02 주 버튼은 설정에서 위치 켜기. P01은X 없이 뒤로 닫기. 다이어트 경험 설명, K15 저장 안 함, 통계 추가 줄은 유지. 신발 바탕은 남색.
9. 상태바의 시각·배터리·아이콘은 에뮬레이터 값이다.

## 해당 러닝 캡처에서 보고할 결함

글자 잘림·겹침, 버튼이 화면 밖으로 나감, 한 화면에 큰 주 버튼 둘 이상, HOME/U01 외 러닝 화면에 전역SUP 잔액 알약, E05/CR21 경로 포함OFF인데 실제 공유 그림에 지도·길이 남음, E10의 적립 완료 표시, 승인된 남색·전기파랑 팔레트에서 큰 이탈, 화면ID와 상태 불일치.

SUP 조건은 여기 지정한 러닝 캡처 범위다. 신발/내 정보 등 다른 루트의 별도 승인 헤더를 삭제하는 근거로 확대하지 않는다. 새 구현에서는 실제 데이터와 현재 경로 정책을 다시 확인한다.

## 보고 형식

화면번호 | 캡처 파일 | 맞음/결함/확인 불가 | 위치와 사유

위 예외에 해당하면 맞음과 항목 번호를 기록한다. 캡처를 확보하지 못한 경우 실제로 봤다고 하지 말고 확인 불가로 적는다.
