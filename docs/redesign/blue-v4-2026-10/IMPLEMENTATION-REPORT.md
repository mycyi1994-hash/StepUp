[통합 지시서](Claude-통합-구현지시서.md)대로 기존 Android 앱에 적용한 결과다. 화면마다의 실제 route · 바꾼 파일 · 검사 · 남은 사유는
[implementation-tracker.csv](implementation-tracker.csv)(566줄, 기능별 원본은 [tracker/](tracker/))에 있다. PNG 는 용량 때문에 레포에 넣지 않았다.

## 공통

- 러닝 리메이크의 남색 · 전기 파랑 부품(`ui/components/RunStyle.kt` — runTone · RunButton · RunSheet · RunBackdrop …)을 모든 기능이 함께 쓴다.
  기능별 보조 부품: 뽑기 `gacha/DrawBlueParts.kt` · 신발 관리 `items/ShoeCareParts.kt` · 크루 `community/crew/CrewUi.kt` ·
  크루 채팅 · 홈 `community/chat/CrewBlueKit.kt` · 내 정보 · 설정 `components/BlueSettingsParts.kt` · 시작 `onboarding/BluePlainParts.kt` ·
  알림 `notifications/BlueNotifParts.kt`.
- 새 글자는 기능별 파일(`res/values{,-ko,-ja,-zh}/*_blue.xml`)에 4개 언어로. 밝은 테마는 runTone 의 밝은 값으로 유지.
- 하단 탭 다섯(러닝 · 신발 · 뽑기 · 커뮤니티 · 내 정보), 고른 탭은 모두 파란 면 · 흰 아이콘. 기존 route · 기능은 지우지 않았다.
- 바탕: 커뮤니티 · 이야기 · 내 정보 · 프로필 수정 · 설정이 러닝과 같은 남색 바닥(`StepUpRoot.kt`).

## 지시서와 서버 · 현재 코드가 다른 곳 (현행 유지)

- **강화**: 지시서는 하위 등급 재료 3개 · 최대 Lv20 · 기본 확률 100−3L · 실패 시 재료 소각. 서버 `sneaker_upgrade(p_id)` 는 SUP 를 받고 항상 한 단계
  올리며 등급별 상한(10/15/20/30)이 있다. 앱은 현행 서버 계약 그대로 — 재료 고르기 · 확률 · 실패 · 소각 화면(UP02 · 03 · 07~12 · 17)은 만들지 않았다.
- **수리**: `sneaker_repair` 는 견적 · 최대 금액 확인 · 요청 키가 없다. 확인과 실행 사이 서버 값이 바뀌어도 잡을 수 없고(RP10), 응답을 잃으면
  "결과 확인"은 다시 읽기만 한다(RP08). 진행 중 수리 · 강화는 앱을 다시 켜면 이어지지 않는다(SD18 · SD19).
- **뽑기**: 지갑 연결의 실시간 진행 · 실패 이벤트(DRAW07 · 09)와 "연결됨 · 첫 선물 대기" 상태(DRAW25 · 27)가 서버에 없다 — 타이머 · 추정으로
  만들지 않았다. 새 흰색/코발트 상자 분리 그림이 없어 기존 상자 그림으로 연다(DRAW11).
- **커뮤니티 지도**: 공용 지도(`StepUpMap`)가 타일 실패 · 로딩 상태를 알리지 않아 CM36 · CM41 은 미연결. 지도 핀 묶기(클러스터)는 없다.
- **크루**: CP68 레벨 확인 필요 표시는 상태가 없어 미연결. 임시 저장 실패(CP38) · 삭제 실패(CP78)는 기존 저장 코드가 실패를 알리지 않는다.
- **첫 설정 모드(ONB23 · 25)**: Lite/Runner 저장은 되지만 홈(HomeScreen)이 모드에 따라 바뀌지 않는다.
- **알림 NOT03**: 금액 줄은 비서버 모드 예시. 서버 모드에서는 showsAmount · messageFor 규칙대로 NOT25(금액 없는 기록)로 보인다.
- **프로필**: 지갑 잔액은 기존 `formatSupDown`(소수 없음), 고객센터 메일은 현재 리소스 값, 기본 아바타 16개는 기존 이모지.

## 동작이 바뀐 곳 (지시서가 요구)

- 뽑기: 무료/상급 글자 탭 → 한 화면 두 패널. 모르는 횟수는 "—" / "확인 중"(0 으로 바꾸지 않음).
- 신발 상세: 레벨 · 효율 · 착화감 · 내구도 네 줄, 수리는 시트, 강화는 독립 화면. 예전 "능력치 자세히" 시트와 관리 메뉴의 강화 줄은 본문으로 옮겼다.
  수리 가능 조건은 서버 규칙(판매 중 아님 · 체인 아님)을 따른다.
- 커뮤니티: 장소 검색 결과 한 번 눌러 고르기(지도에서 점을 찍을 때만 확인), 지도 핀으로 목록 바로 거르기, 로그인 만료 시 초안 저장 후 로그인.
- 첫 설정: "다음"은 저장이 끝난 뒤 넘어가고 실패하면 그 단계에 머문다. 모드 건너뛰기는 모드를 덮어쓰지 않는다.
- 크루 채팅: "크루에서 내보내기"를 큰 아래 버튼에서 빨간 줄로(동작 같음).
