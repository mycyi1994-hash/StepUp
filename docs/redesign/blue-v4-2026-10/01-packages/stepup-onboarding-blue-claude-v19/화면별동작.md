# 시작·로그인·첫 설정의 상태와 동작

시안17개는 상태 표본이다. 실제 권한창·계정 선택창은 OS가 표시한다. 현재 코드와 추가 구현이 필요한 부분은 지시서를 함께 읽는다.

| ID | 상태 | 버튼·다음 동작 | 유지 조건 |
|---|---|---|---|
| ONB01 | Google 로그인 | Google→OS 계정 선택→ONB05; 법적 링크→외부 브라우저. | 취소는 원래 안내로 복귀. Picking 중 중복 요청 금지. |
| ONB02 | 첫 사용 안내 | 러닝 시작→U01; 둘러보기/X/뒤로/바깥/드래그→홈. | 사람이 닫거나 선택했을 때만 guideSeen 저장. 강제 종료는 미확인 유지. |
| ONB03 | 앱 준비 중 | 실제 초기화 성공→현재 세션에 맞는 다음 진입; 실패→ONB04. | 가짜 시간·퍼센트·보상 없음. 기존14초 타임아웃 유지. |
| ONB04 | 앱 준비 실패 | 다시 시도→ONB03 초기화 재실행. | 성공 확인 전 홈 진입 금지. |
| ONB05 | 로그인 중 | 실제 서버 성공→필요한 첫 설정 또는 메인; 오류→해당 안내. | 계정 선택 이후 서버 확인. 버튼 비활성·스피너 하나. |
| ONB06 | 연결 실패 | Google→계정 선택부터 재시도. | 통신 실패를 계정 만료로 단정하지 않음. |
| ONB07 | 로그인 실패 | Google→로그인 재시도. | 기존 세션 규칙과 finally Idle 복원 유지. |
| ONB08 | Google 계정 없음 | 기기에 계정을 추가한 뒤 Google 다시 선택. | 앱에서 계정 생성·비밀번호 입력 UI를 만들지 않음. |
| ONB09 | 다시 로그인 | 동일 Google 계정으로 다시 로그인. | 실제 signInAgain 사유가 있는 경우만. 복귀 사용자의 데이터를 초기화하지 않음. |
| ONB10 | 안내 링크 열기 실패 | 법적 링크 재탭→외부 브라우저; Google 로그인도 계속 가능. | 외부 열기 자체 실패에만4초 안내. 페이지 내부 로딩 결과 추측 금지. |
| ONB11 | 첫 러닝 홈 | 러닝 시작→U01; 기록 보기→H01; 코스 찾기→기존 코스 허브. | 활동권한없음·러닝수0·누적걸음0·오늘활동없음. 조회중을0으로 보지 않음. |
| ONB20 | 앱 사용 안내 다시 보기 | 뒤로→도움말; 러닝 홈으로→HOME. | guideSeen을 초기화하지 않음. 설명3행은 클릭 버튼이 아님. |
| ONB21 | 첫 설정 몸 정보 | ±조절; 다음→몸 정보 저장 후 목표; 건너뛰기→모드. | 건너뛴 몸 정보 기본값은 저장하지 않음. 키1cm/몸무게0.5kg 단위. |
| ONB22 | 첫 설정 목표 | 목표±/8·12·16주; 다음→목표 저장 후 모드; 건너뛰기→모드. | 예시58kg를 자동 권장 목표로 쓰지 않음. 이전 몸 정보는 유지. |
| ONB23 | 라이트 모드 선택 | 카드→선택 변경; 계속→선택 모드 저장; 건너뛰기→기존 모드 유지. | 최초 기본 라이트. 종료 시 setupSeen 저장. |
| ONB24 | 목표 주의 상태 | 목표/기간 재조절; 다음 또는 건너뛰기. | 기존 조건의 안내이며 현재 다음을 막는 별도 승인 모달이 아님. |
| ONB25 | 러너 모드 선택 | 카드→선택 변경; 계속→러너 저장; 건너뛰기→기존 모드 유지. | 홈과 실제 모드 바인딩은 조사 시점에 미연결. 실행 검증 필요. |
