# StepUp 시작·로그인·첫 설정 17장 · 파란 톤 후속 전달

[Claude 지시서](Claude-시작로그인-파란톤-지시서.md) → [화면별 동작](화면별동작.md) → [화면 목록](screen-index.json) 순서로 읽는다. [붙여넣을 문장](00-클로드에게-붙여넣기.txt)도 포함했다.

- ONB01~11: Google 로그인과 시작/오류/첫 안내/첫 러닝 홈11개.
- ONB20: 앱 사용 안내 다시 보기1개. 잘못된 프로필 아이콘을 고친 r2다.
- ONB21~25: 처음 몸 정보/목표/모드 설정과 주의/선택 상태5개.

기존 후보12개와 새로 확인한 첫 설정5개를 합친17개 상태다. `01-screens`에는 개별 검수를 마친 최신17장만 있다. 동봉한 reference10장은 기존 러닝v18 연결 참고이므로 신규 장수에 더하지 않는다. 생성은 built-in imagegen을 사용했고 최종 프롬프트는 prompts에 보관했다. 앱 코드는 수정하지 않았다.

이전 StepUp-Claude-통합전달-2026-10-03-v2.zip에 추가할 후속본이다. 통합 ZIP은 그대로 보존했다. 434후보 중395개 검수,39개 미제작(알림·공지23/지갑16)이 현재 v19 집계다. 러닝v18의109개 상태는 별도다. 새 후보5개 때문에 이전429개와 분모가 다르다. 104경로 및 추가 상태 감사가 남아 있어 전체 앱 리디자인 완료본은 아니다.

그림 검수는 앱 실행 검증이 아니다. [추가 점검 목록](audit/onboarding-additional-states.json)에 첫 설정 조회/저장 실패·모드 홈 연결·설정 재진입 등의 후속 범위를 기록했다. 기록표의 '미확인'은 기존 구현이 없다는 뜻이 아니라 이 전달에서 실행 상태를 검증하지 않았다는 뜻이다.

원본 로고·강변 이미지·Google G와 글꼴/라이선스를 assets에 넣었다. PNG를 통째로 앱 화면에 붙이지 말고 글자·버튼·진행 표시·시트는 실제 UI로 만든다. 생성된 새 아트의 분리 레이어나 Figma 편집 파일은 제공되지 않았다. 출처 JSON의 로컬 절대 경로는 생성 이력이고 다른 컴퓨터에서는 이 ZIP의 상대 경로를 사용한다.
