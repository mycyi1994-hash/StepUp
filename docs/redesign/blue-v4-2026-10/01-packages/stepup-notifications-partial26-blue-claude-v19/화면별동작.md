# 알림·공지26개 상태와 동작

NOT01~26 정적 검수 완료. NOT27~46은 미제작이다. 기존 코드 분기를 보존한다.

| ID | 상태 | 동작 | 유지 조건 |
|---|---|---|---|
| NOT01 | 내 알림 | 행→종류별 내용/목적지; 모두 읽음→저장 후NOT02; 설정→알림 설정. | 진입만으로 읽음 처리 안 함. 날짜별 그룹·탭별 스크롤 유지. |
| NOT02 | 모두 읽음 | 읽은 행도 계속 열 수 있음; 완료 토스트 후 원래 목록 유지. | 행 삭제·초대 응답·보상 지급과 별개. 처리 중 새로 온 알림은 미읽음. |
| NOT03 | 적립 알림 내용 | 지갑 보기→전체 지갑; X/뒤로→목록. | showsAmount=true일 때만 금액 표시. 서버 경제의 이전 로컬 기록은 NOT25처럼 금액 없이 표시. 현재 잔액·지급 확정으로 바꾸지 않음. |
| NOT04 | 신발 알림 내용 | 보유 신발 보기→신발 탭. | 모델명으로 소유 한 켤레를 추정하거나 지급/착용하지 않음. |
| NOT05 | 크루 초대 | 크루 보기→현재 크루 상세; 수락→서버 요청; 거절→NOT21. | 보기/닫기만으로 수락 안 함. Joined와 Requested 구분. |
| NOT06 | 가입 신청 완료 | 크루 보기→크루 상세. | 승인 대기이며 가입 완료가 아님. |
| NOT07 | 초대 응답 실패 | 다시 수락→요청 재시도; 거절→NOT21. | 처리 안 됨이 확인된 실패. 결과 미확인은 추가NOT29/30. |
| NOT08 | 함께 뛰기 초대 | 대기실 보기→보기만; 수락하고 보기→로컬 응답 저장 뒤 이동. | 실제 참가/출발은 대기실의 서버 확인. 대상 ID 필요. |
| NOT09 | 지급 미확인 보상 | 챌린지 보기→현재 Routes.EVENTS. | 지급 여부 불명. 알림에서 보상 지급/수령하지 않음. |
| NOT10 | 빈 알림함 | 알림 설정 보기→알림 설정. | 로드 완료 후 참 빈 데이터만. OS 푸시와 내부 목록 별개. |
| NOT11 | 알림 조회 중 | 데이터 성공→NOT01 또는NOT10; 실패→NOT12. | 빈 목록/수치0으로 미리 표현하지 않음. |
| NOT12 | 알림 조회 실패 | 다시 불러오기→NOT11. | 기존 읽음/응답 데이터를 초기화하지 않음. |
| NOT13 | 읽음 저장 실패 | 모두 읽음 다시 탭→저장 재시도. | 행과 미읽음 상태 유지. 개별 읽음 실패는 추가NOT40. |
| NOT14 | 연결된 글을 열 수 없음 | 커뮤니티 보기→커뮤니티; X/돌아가기→알림. | 서버에서 삭제/접근불가 확인 시만. 네트워크 실패로 단정 금지. |
| NOT15 | 공지 목록 | 행→NOT16; 내 알림 탭→보존한 알림 목록. | 실제 운영자 데이터, 임의 중요 배지 없음. |
| NOT16 | 공지 상세 | 정의된 action으로 이동; 예시 신발 뽑기 보기→뽑기 탭. | 이동만 하며 뽑기/지갑연결/보상 실행하지 않음. |
| NOT17 | 빈 공지 목록 | 뒤로/탭 전환/설정 가능. | 새 CTA를 만들지 않음. 빈 사본 갱신 실패는 추가NOT44. |
| NOT18 | 공지 조회 실패 | 다시 불러오기→NOT20. | 사본 없는 초기 실패. 사본 있으면NOT23. |
| NOT19 | 볼 수 없는 공지 | 공지 목록으로→목록 복귀. | 서버가 내림/비공개 확인. 단순 연결 실패와 구분. |
| NOT20 | 공지 조회 중 | 조회 성공→NOT15/17; 실패→NOT18. | 공지 목록 구조의 스켈레톤, 제목/날짜 예시 표시 없음. |
| NOT21 | 초대 거절 확인 | 취소→초대 시트; 초대 거절→그 알림 삭제. | 현재 크루/대기실 상태 불변. 거절 처리 중/실패/완료 추가 제작. |
| NOT22 | 로그인 필요 | 로그인→기존 로그인; 나중에/X→닫기. | 초대 보존, 로그인 복귀 후 재표시만. 자동수락 금지. |
| NOT23 | 공지 갱신 실패 | 저장된 공지 열기 유지; 다시→갱신. | 전체 목록을 오류로 덮지 않음. 재시도 중 중복 버튼 잠금. |
| NOT24 | 일반 알림 내용 | 확인/X/뒤로→목록. 다른 목적지 버튼 없음. | 알림의 실제 저장 문구·시간 표시. 배경 금액 예시는 showsAmount에 따라 대체. |
| NOT25 | 금액 없는 기록 알림 | 지갑 보기→Routes.WALLET; X/뒤로→목록. | 서버 경제에서 이전 로컬 러닝 기록의 금액을 숨김. 현재 적립 완료로 표시하지 않음. |
| NOT26 | 크루 가입 완료 | 크루 보기→CrewRoutes.detail(crewId); X/뒤로→목록. ID 없으면 확인. | 실제 서버 Joined 확인 후만 표시. Requested는 NOT06, 응답 불명은 미제작 NOT29/30. |
