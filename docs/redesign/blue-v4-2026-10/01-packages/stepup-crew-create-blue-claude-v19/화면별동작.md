# 화면별 진입·행동·복귀

19개 정적 상태. 다른 기기에서는 내용 길이에 맞춰 스크롤하며, 예시 ID나 수치를 고정하지 않는다.

## CP25 · 모집할 크루 선택

[단일 화면](01-screens/CP25.png)

- 진입: 모집 진입에서 운영 크루 선택이 필요한 경우
- 행동: 운영 크루 행→기존 모집 설정 CP43; 새 크루 만들기→초안 있으면 CP39, 없으면 CP26; 내 크루 관리→CP40.
- 조건: 실제 소유 크루 목록. 목록에서 생성으로 바로 가는 기존 진입은 불필요하게 CP25를 거치게 하지 않는다.

## CP26 · 크루 만들기 1 · 소개

[단일 화면](01-screens/CP26.png)

- 진입: 새 초안 또는 저장한 소개 단계 복원
- 행동: 대표 이미지→CP27; 이름·한 줄 소개·크루장 한마디 입력; 다음→CP31; 첫 단계에서 변경 후 뒤로→CP38.
- 조건: 이름1~40자. CP26은 입력된 예시이며 신규 초안은 빈 값으로 시작한다. 이름이 유효하기 전 다음 비활성. 다른 선택 입력을 필수로 만들지 않는다.

## CP27 · 대표 이미지 선택 방법

[단일 화면](01-screens/CP27.png)

- 진입: 대표 이미지 선택 행
- 행동: 사진에서 가져오기→OS 선택기→CP28; 기본 이미지→CP30; 닫기→CP26 유지.
- 조건: 현재 이름형 이미지이므로 삭제 행 없음. 사진을 사용 중이면 기존 사진 삭제 행동을 제공하고 이름형 대체 이미지로 돌아간다. 사진 선택 취소 시 이전 이미지를 유지.

## CP28 · 대표 이미지 맞추기

[단일 화면](01-screens/CP28.png)

- 진입: OS에서 사진을 골라 읽기 성공
- 행동: 이동·확대하여 정사각형 자르기; 이 이미지 사용→처리→성공 시 CP26에 반영; 뒤로→기존 이미지 유지.
- 조건: 시안 사진은 별도 선택 분기 예시. 이동/확대 좌표로 실제 원본을 크롭한다. 원본 밖 빈 영역 금지. 저장 중 중복 적용 방지. 처리 실패 CP29.

## CP29 · 이미지 처리 실패

[단일 화면](01-screens/CP29.png)

- 진입: 선택한 이미지 읽기·변환 실패
- 행동: 다른 사진 선택→OS 선택기; 기본 이미지로 시작하기→CP30; 닫기→기존 초안.
- 조건: 접근 불가 CP69와 구분. 이름·소개·지역 등 유지. 실패한 이미지로 기존 대표 이미지를 먼저 덮지 않는다.

## CP30 · 기본 대표 이미지

[단일 화면](01-screens/CP30.png)

- 진입: 이름형 기본 이미지 선택
- 행동: 4개 중 하나 선택; 이 이미지 사용→초안에 반영 후 CP26; 뒤로→원래 이미지.
- 조건: 현재 입력한 실제 크루명으로 그린다. 공덕 한바퀴를 고정 자산처럼 사용하지 않는다. 선택은 체크와 테두리로 함께 표시.

## CP31 · 크루 만들기 2 · 러닝

[단일 화면](01-screens/CP31.png)

- 진입: 소개 다음 · 만들기2단계
- 행동: 활동 지역→공유 CP03; 정기 일정→CP32; 거리·분위기 버튼; 다음→CP33; 뒤로→CP26.
- 조건: 실제 검색 결과의 지역/좌표를 받는다. 거리 단일 선택·해제, 분위기는 현재 toggleMood의 개별 토글을 유지한다. 화면의 한 선택 예시를 강제 배타 규칙으로 해석하지 않는다.

## CP32 · 정기 일정 선택

[단일 화면](01-screens/CP32.png)

- 진입: 정기 일정 행
- 행동: 요일 복수 선택; 시간→OS 시간 선택기; 정기 일정 없음→요일과 시간 비움; 이 일정으로 선택→CP31 초안에 반영; 닫기→기존 값.
- 조건: 요일 없이 시간만 저장하지 않는다. 요일이 없으면 시간을 비운다. 새 문구 정기 일정 없음은 실제 전체 해제 행동을 설명하는 변경이다.

## CP33 · 크루 만들기 3 · 모집

[단일 화면](01-screens/CP33.png)

- 진입: 만들기3단계
- 행동: 정원 입력; 50/100km 선택 또는 직접 입력→CP88; 목표 나중에 설정; 모집 중/잠시 쉬기; 미리보기→CP34; 뒤로→CP31.
- 조건: 정원20은 예시. 현재1~9999 범위를 따르며 러닝 세션30명과 혼동하지 않는다. 가입은 현행 생성 정책인 승인형. 기존 openJoin 크루를 변경하지 않는다.

## CP34 · 만들기 전 미리보기

[단일 화면](01-screens/CP34.png)

- 진입: 입력된 초안의 미리보기
- 행동: 뒤로→CP33; 크루 만들고 모집 시작→한 번 생성 요청; 성공 CP35; 확정 실패 CP37 또는 해당 필드 오류 단계.
- 조건: 모집 휴식으로 만들면 버튼은 크루 만들기. 새 크루1/정원은 미리보기 값이며 생성 완료 증거가 아니다. clientKey 유지. 레벨·보상 임의 생성 금지.

## CP35 · 크루 생성 완료

[단일 화면](01-screens/CP35.png)

- 진입: 생성 API 성공과 생성된 crewId 확인
- 행동: 내 크루 관리→CP77; 크루 채팅 열기→해당 새 크루의 기존 채팅.
- 조건: 전송 버튼 탭만으로 진입하지 않는다. 실제 소유권·인원을 반영한다. 혼자 있는 채팅방을 기존 흐름으로 열고 예시 멤버를 넣지 않는다.

## CP36 · 입력값 오류

[단일 화면](01-screens/CP36.png)

- 진입: 이름을 비워둔 입력 오류
- 행동: 이름 수정→유효하면 오류 해제/다음 활성; 다른 칸과 대표 이미지 선택은 유지.
- 조건: 실제 nameOk 규칙에 맞춘 빈 이름 예시다. 구형 시안의 이름 중복 검증은 현행 계약에 없으므로 추가하지 않는다. 이름이 빈 기본 이미지에는 중립 대체 표식.

## CP37 · 만들기·저장 실패

[단일 화면](01-screens/CP37.png)

- 진입: 미리보기에서 일반 생성 저장 실패
- 행동: 다시 저장→같은 초안·clientKey로 재시도; 뒤로→입력 단계.
- 조건: 입력과 이미지 보존. 필드별 서버 오류는 그 필드가 있는 단계로 이동해 표시. 결과 불명 타임아웃을 무조건 새 생성 요청으로 처리하지 않고 기존 계약의 요청 결과 확인을 유지.

## CP38 · 작성 중 나가기

[단일 화면](01-screens/CP38.png)

- 진입: 변경한 첫 단계에서 이탈
- 행동: 저장 후 나가기→초안 보관이 끝난 뒤 호출자로; 계속 작성/닫기/뒤로→같은 단계 유지.
- 조건: 여기에는 초안 삭제 버튼 없음. 2·3단계 뒤로는 직전 단계다. 임시저장 실패 시 입력을 버리거나 성공처럼 나가지 않도록 구현 후 검증.

## CP39 · 초안 이어 쓰기

[단일 화면](01-screens/CP39.png)

- 진입: 생성 재진입 시 저장된 초안 있음
- 행동: 이어서 만들기→저장한 단계·값 복원; 새로 만들기→CP78; 닫기→호출자.
- 조건: 초안은 아직 실제 크루가 아니므로 레벨·멤버·모집 성공을 붙이지 않는다. 시안은 CP01에서 연 예시이며 실제 CP25 호출자는 그 화면을 배경으로 유지.

## CP69 · 사진 접근 불가

[단일 화면](01-screens/CP69.png)

- 진입: 사진 접근 불가 또는 시스템 선택기를 열 수 없음
- 행동: 설정으로 이동→기존 앱 설정 경로; 기본 이미지로 시작하기→CP30; 닫기→초안 유지.
- 조건: 기본 이미지로 계속할 수 있다. Android Photo Picker를 사용하며 모든 사용자에게 광범위 사진 권한을 선요청하지 않는다. 실제 접근 오류가 있을 때만 안내.

## CP77 · 새 크루 관리

[단일 화면](01-screens/CP77.png)

- 진입: 생성 직후 크루장 관리
- 행동: 가입 신청→CP48/빈 상태 CP54; 소개→CP41; 모임 정보→CP42; 모집 설정→CP43; 주간 목표→CP46; 크루 채팅→기존 채팅; 크루 목록 보기→CP01.
- 조건: 신규 예시는1/20명·신청0건. 현행 created=true 변형의6행을 유지한다. 일반 관리 CP40의 멤버 관리·운영 설정을 삭제하라는 뜻은 아니다.

## CP78 · 초안 삭제 확인

[단일 화면](01-screens/CP78.png)

- 진입: CP39에서 새로 만들기 선택
- 행동: 지우고 새로 만들기→저장된 생성 초안 삭제 성공 후 빈 CP26; 취소/닫기→CP39.
- 조건: 이미 생성된 크루 해산과 구분. 확인 전에는 초안을 지우지 않는다. 삭제 실패 시 보관된 초안을 유지하고 재시도 상태를 제공해야 한다.

## CP88 · 만드는 크루의 목표 입력

[단일 화면](01-screens/CP88.png)

- 진입: 생성3단계에서 주간 목표 직접 입력
- 행동: 숫자 입력; 이 목표로 선택→CP33 초안 목표에 반영; 닫기→기존 목표.
- 조건: 현재1~99999km·숫자5자리. 빈 값/0/범위 밖이면 적용 비활성+필드 안내. 기존 크루 목표 편집 CP46과 분리하여 여기서는 서버 크루를 수정하지 않는다.
