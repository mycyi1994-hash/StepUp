# 검수 범위

38장 모두 개별로 확인했다. 문구·역할·주 버튼·시트·크루 동일성·인원과 목표의 분기를 검토했다. CP55와CP90은 이전 결과의 비율/배치를 보완한r2다. 크기 분포는 {'887x1774': 36, '886x1774': 1, '887x1773': 1}이며 원본 이미지를 늘리거나 재편집하지 않았다.

PNG CRC/SHA256, 최신 검수 리비전, 각 파일과 문서 링크, ZIP CRC와 압축 내부 해시를 확인한다. 재사용 참고9장은 새38장에 포함하지 않는다. 검토 중 읽은 앱 파일의 패키징 전후 해시를 비교한다.

실제 API·권한 변경 전파·로컬 자료 정리·앱 터치·접근성·기기 안전 영역은 미검증이다. PNG의 시스템 표시줄 유무·미세한 두께/글자 차이는 구현 시 OS와 공통 컴포넌트로 통일한다. 추가 코드 상태는 additional-state-audit.json을 따른다. 전체 목표는 미완료다.
