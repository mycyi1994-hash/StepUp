# 화면별 진입·버튼·복귀

38개 정적 상태. 데이터 예시는 고정 정책이 아니며 번호는 별도 경로 수가 아니다.

## CP40 · 크루 관리 홈

[단일 화면](01-screens/CP40.png)

- 진입: 크루장 상세의 크루 관리
- 행동: 가입 신청→CP48/54; 멤버 관리→CP55; 소개→CP41; 모임→CP42; 모집→CP43; 주간 목표→CP46; 운영 설정→CP74/90.
- 조건: 현재 소유한 크루만 관리. 생성 직후6행 관리 CP77과 구별한다.

## CP41 · 크루 소개 수정

[단일 화면](01-screens/CP41.png)

- 진입: 소개 수정
- 행동: 대표 이미지→공유 CP27~30/69; 이름·소개·한마디 수정; 저장 성공→호출 관리 화면; 뒤로→변경 시 공유 초안 이탈 확인.
- 조건: 원본 소개는 가볍게, 시안 수정안은 편하게. 변경이 있어 저장 활성. 이름1~40,소개120,한마디300자.

## CP42 · 모임 정보 수정

[단일 화면](01-screens/CP42.png)

- 진입: 모임 정보 수정
- 행동: 지역→CP03/71/72; 일정→CP32; 거리 단일 선택; 분위기 독립 토글; 저장 성공→호출 관리 화면.
- 조건: 기존3~5km에서1~3km로 바꾼 입력 예시. 요일이 없으면 시간도 비운다. 다른 입력과 대표 이미지 보존.

## CP43 · 모집 설정

[단일 화면](01-screens/CP43.png)

- 진입: 모집 설정 수정 또는 정원 충돌 CP81
- 행동: 정원·목표·모집 상태 변경; 직접 목표→기존 크루 CP46; 설정 저장 성공→호출자.
- 조건: 현재24명/정원30. 정원은 현행1~9999 범위와 현재 인원 조건을 따른다. 목표100km는 별도 수정 초안이며 CP46의200km 분기와 연속 상태가 아니다.

## CP44 · 모집 잠시 멈추기

[단일 화면](01-screens/CP44.png)

- 진입: 모집 중 운영 설정에서 모집 잠시 멈추기
- 행동: 모집 멈추기→요청→성공 후 CP89; 취소/닫기→CP74.
- 조건: 기존 멤버·레벨·기록을 유지한다. 요청 중 중복 탭/닫기 제한, 실패는 시트 안 오류.

## CP45 · 모집 다시 시작

[단일 화면](01-screens/CP45.png)

- 진입: 모집 쉼 운영 설정에서 모집 다시 시작
- 행동: 모집 시작→요청→성공 후 CP76; 취소/닫기→CP90.
- 조건: 24/30이라6자리인 예시. 만원·정원 미설정일 때는 현행 별도 설명을 사용하고 숫자를 임의 계산하지 않는다.

## CP46 · 주간 목표 수정

[단일 화면](01-screens/CP46.png)

- 진입: 관리의 주간 목표 또는 기존 크루 직접 목표 입력
- 행동: 100/160/200km 또는 숫자 입력; 목표 변경→CP47; 뒤로→호출자.
- 조건: 현재160,초안200,누적126. 유효 범위1~99999. 바뀌지 않은 값·빈 값·0·범위 밖이면 저장하지 않는다.

## CP47 · 주간 목표 변경 확인

[단일 화면](01-screens/CP47.png)

- 진입: 유효하고 변경된200km 목표 적용 직전
- 행동: 목표 적용→서버 성공 CP83; 취소/닫기→CP46 초안 보존.
- 조건: 누적126km를 초기화하지 않는다. 전송 중 잠금, 실패는 오류와 같은 초안 유지.

## CP48 · 가입 신청 목록

[단일 화면](01-screens/CP48.png)

- 진입: 가입 신청2건이 있는 목록
- 행동: 도윤/지연 행→해당 applicationId의 CP49; 뒤로→CP40.
- 조건: 24/30은 이 분기의 예시. 로딩·조회 실패를 신청0건과 구분한다.

## CP49 · 가입 신청 검토

[단일 화면](01-screens/CP49.png)

- 진입: 대기 중인 가입 신청 열기
- 행동: 공개 프로필→CP85; 가입 승인→CP50; 승인하지 않기→CP52.
- 조건: 도윤 신청 예시. 승인 전24명, 승인 성공 시25명. 이미 처리된 신청은 두 행동 비활성화하고 현재 결과 안내.

## CP50 · 가입 승인 확인

[단일 화면](01-screens/CP50.png)

- 진입: 가입 승인 확인
- 행동: 가입 승인→성공 CP51; 정원 충돌 CP81; 다른 실패 CP80; 취소→CP49.
- 조건: 승인 성공 응답 전에는 멤버를 추가하지 않는다. 현재 정원과 권한을 서버에서 재확인.

## CP51 · 가입 승인 완료

[단일 화면](01-screens/CP51.png)

- 진입: 승인 성공 응답
- 행동: 남은 신청 보기→CP79, 실제0건이면 CP54.
- 조건: 도윤 승인 후25/30,남은1건. 인원·정원·남은 신청 수는 결정 응답값을 사용한다.

## CP52 · 미승인 확인

[단일 화면](01-screens/CP52.png)

- 진입: 승인하지 않기 확인
- 행동: 승인하지 않기→성공 CP53; 실패 CP80; 취소→CP49.
- 조건: 승인과 다른 분기. 가입시키지 않으며 확인 전 신청을 목록에서 제거하지 않는다.

## CP53 · 미승인 처리 완료

[단일 화면](01-screens/CP53.png)

- 진입: 승인 거절 처리 성공
- 행동: 남은 신청 보기→최신 신청 목록,없으면 CP54.
- 조건: 멤버24명 그대로. 승인 결과 CP51의25명으로 바꾸지 않는다.

## CP54 · 가입 신청 없음

[단일 화면](01-screens/CP54.png)

- 진입: 신청 조회 성공·결과0건
- 행동: 크루 관리로→기존 관리 화면.
- 조건: 로드 중·권한 오류·네트워크 오류를 빈 목록으로 처리하지 않는다.

## CP55 · 멤버 관리

[단일 화면](01-screens/CP55.png)

- 진입: 크루장 멤버 관리
- 행동: 크루장 넘기기→CP58; 크루장 행→CP10; 일반 멤버→CP84.
- 조건: 전체24명 중 첫5행 예시이며 목록 스크롤. 실제 userId로 연결, 보이는 이름으로 대상 식별 금지.

## CP56 · 멤버 공개 프로필

[단일 화면](01-screens/CP56.png)

- 진입: 일반 사용자가 보는 멤버 공개 프로필
- 행동: 함께하는 크루→해당 상세; 뒤로→명단.
- 조건: 가입일·주간 거리 등 공개된 실제 데이터만. 크루장 전용 더보기 없음.0거리면 현행 활동 없음 문구.

## CP57 · 멤버 내보내기 확인

[단일 화면](01-screens/CP57.png)

- 진입: 크루장 멤버 메뉴의 내보내기
- 행동: 내보내기→서버 성공 후 명단 재조회·호출 명단으로 복귀; 취소→CP84.
- 조건: 일반 멤버 대상만. 요청 중 닫기·중복 차단, 실패는 같은 시트 안 오류.24명에서23명으로 그리는 것은 성공 확인 후.

## CP58 · 새 크루장 선택

[단일 화면](01-screens/CP58.png)

- 진입: 운영 설정·명단에서 크루장 넘기기
- 행동: 현재 일반 멤버 행→CP59; 뒤로→호출자.
- 조건: 현재 크루장과 가입 대기자는 후보가 아니다. 후보0명/조회 실패/로딩은 별도 상태.

## CP59 · 크루장 변경 확인

[단일 화면](01-screens/CP59.png)

- 진입: 민수 선택 또는 CP75의 민수에게 지정
- 행동: 크루장 변경→서버 성공 CP86; 취소→CP58 또는 실제 호출 흐름.
- 조건: 현재 소유자는 일반 멤버로 남는다. 자동 탈퇴하지 않는다. 실패 시 권한과 선택 대상을 임의 변경하지 않는다.

## CP60 · 멤버용 더보기

[단일 화면](01-screens/CP60.png)

- 진입: 일반 멤버 상세의 더보기
- 행동: 크루 멤버 보기→CP12; 크루 신고→CP64; 크루 나가기→CP61; 닫기→상세.
- 조건: 가입 대기/방문자의 CP73, 크루장의 운영 설정 진입과 구분한다.

## CP61 · 크루 나가기 확인

[단일 화면](01-screens/CP61.png)

- 진입: 일반 멤버가 크루 나가기 선택
- 행동: 크루 나가기→서버 성공 후 멤버 권한 해제·상세 갱신; 취소→기존 상세.
- 조건: 퇴근런 승인제 예시라 재가입 신청 안내. 자유가입 크루의 실제 정책에 맞게 문구 분기. 계정/다른 크루를 지우지 않는다.

## CP62 · 크루장 탈퇴 안내

[단일 화면](01-screens/CP62.png)

- 진입: 다른 멤버가 남아 있는 크루장의 나가기
- 행동: 새 크루장 선택→CP58; 닫기→운영 설정.
- 조건: 권한 이전과 탈퇴는 별도 작업이다. 혼자 남은 크루장은 이 시트 대신 CP63으로 이어진다.

## CP63 · 크루 해산 확인

[단일 화면](01-screens/CP63.png)

- 진입: 크루 해산 또는 혼자 남은 크루장의 나가기
- 행동: 크루 해산→서버 성공 후 크루 목록; 취소→운영 설정.
- 조건: 소속과 모집 종료 범위를 설명한다. 확인 전 삭제하지 않는다. 실패는 시트 안에 표시하고 기존 상태 유지.

## CP64 · 크루 신고 사유

[단일 화면](01-screens/CP64.png)

- 진입: 방문자/멤버 메뉴의 신고
- 행동: 사유 하나 선택; 기타면 선택 메모 입력; 신고하기→접수 성공 CP65; 닫기→상세.
- 조건: 사유 미선택 전송 비활성. 시안은광고 선택 예시. 실패 시 사유·메모 유지.기타 메모 최대500자.

## CP65 · 신고 접수 완료

[단일 화면](01-screens/CP65.png)

- 진입: 신고 접수 성공
- 행동: 확인/뒤로→신고했던 크루 상세.
- 조건: 접수 확인만 의미. 제재 완료·문제 해결·처리 시간 보장으로 해석하지 않는다.

## CP74 · 운영 설정

[단일 화면](01-screens/CP74.png)

- 진입: 모집 중인 크루장의 더보기/운영 설정
- 행동: 모집 멈춤→CP44; 넘기기→CP58; 나가기→CP62 또는 CP63; 해산→CP63; 가입 방식→기존 정책 시트.
- 조건: 가입 방식 행은 기존 기능이므로 보존. 정책 시트는 기존95개 후보 밖의 추가 제작 대상.

## CP75 · 멤버 관리 동작

[단일 화면](01-screens/CP75.png)

- 진입: 크루장이 일반 멤버 CP84의 더보기
- 행동: 크루장으로 지정→대상이 지정된 CP59; 크루에서 내보내기→CP57; 닫기→CP84.
- 조건: 본인·현재 크루장·신청자에게 보여주지 않는다. 대상 userId를 유지한다.

## CP76 · 크루 상세 · 크루장

[단일 화면](01-screens/CP76.png)

- 진입: 크루장이 보는 모집 중 상세
- 행동: 크루 관리→CP40; 더보기→CP74; 대표 이미지→CP09; 레벨→CP11; 크루장→CP10; 명단→CP12; 목표→CP13.
- 조건: 소개·멤버24·준호·126/160km·79% 유지. 화면 아래의 크루 활동 진입도 보존(CP94 참고).

## CP79 · 남은 가입 신청

[단일 화면](01-screens/CP79.png)

- 진입: 도윤 승인 후 남은 신청 목록
- 행동: 지연 신청→해당 CP49; 뒤로→관리.
- 조건: 도윤은 목록에서 빠지고 신청1건·멤버25/30. 거절 분기의 멤버 수는24이며 이 이미지 수치를 재사용하지 않는다.

## CP80 · 관리 작업 실패

[단일 화면](01-screens/CP80.png)

- 진입: 가입 처리 실패 또는 결과 재확인 필요
- 행동: 다시 확인→작업 오류 해제 후 신청·크루 상태 재조회; 닫기→신청.
- 조건: 실패를 성공으로 표시하거나 무조건 승인 재전송하지 않는다. 최신 신청 상태로 다음 행동을 결정한다.

## CP81 · 승인 직전 정원 초과

[단일 화면](01-screens/CP81.png)

- 진입: 가입 승인 중 정원 충돌
- 행동: 모집 정원 확인→CP43; 신청으로 돌아가기→현재 신청 재조회.
- 조건: 작성된 신청을 보존한다. 자동 정원 확대/자동 승인 금지. 최신 멤버 수를 우선한다.

## CP83 · 목표 변경 후 현황

[단일 화면](01-screens/CP83.png)

- 진입: 주간 목표200km 적용 성공
- 행동: 참여 멤버→CP82; 목표 수정→CP46; 뒤로→호출자.
- 조건: 누적126/200=63%,남은74km,참여9/24명. 새 목표로 누적 거리를 재설정하지 않는다.

## CP84 · 멤버 프로필 · 크루장 열람

[단일 화면](01-screens/CP84.png)

- 행동: 더보기→CP75; 함께하는 크루→상세; 뒤로→명단.
- 조건: 표시 대상은 일반 멤버 민수이고 보는 사람이 크루장이다. CP56과 공개 데이터는 동일.

## CP85 · 신청자 공개 프로필

- 진입: 가입 신청 상세에서 공개 프로필 보기
- 행동: 뒤로→해당 신청.
- 조건: 도윤은 아직 멤버 아님. 신청 날짜·선택한 문구만 사용. 멤버 가입일·주간 거리·관리 메뉴를 넣지 않는다.

## CP86 · 크루장 변경 후 상세

[단일 화면](01-screens/CP86.png)

- 진입: 크루장 넘기기 성공 후 상세
- 행동: 멤버 보기→CP12; 더보기→CP60; 새 크루장 소개→현재 민수의 프로필.
- 조건: 총24명 그대로. 새 크루장민수,이전 크루장준호는 일반 멤버. 뒤로 가도 이전 운영 권한이 남지 않아야 한다.
