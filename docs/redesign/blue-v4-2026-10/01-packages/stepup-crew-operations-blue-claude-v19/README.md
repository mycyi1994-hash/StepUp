01-screens는 최신38장이다. CP55와CP90은r2다. 02-shared-reference의9장은 이전 전달본 재사용이며 새38장에 더하지 않는다. 원본 로고와 크루 예시 그림은 assets, 생성 프롬프트는 prompts에 있다.

기존 둘러보기·가입38장, 만들기19장과 합치면 최초 크루 목록95장은 모두 리메이크했다. 다만 기존 코드의 가입 방식·로딩·오류 등 추가 상태와 다른 메뉴는 남아 있다. 전체 리메이크 완료본이 아니다.

정적 PNG와 구현 명세다. 편집 가능한 Figma나 실제 앱 구현·동작 검증을 제공한다는 뜻은 아니다.
