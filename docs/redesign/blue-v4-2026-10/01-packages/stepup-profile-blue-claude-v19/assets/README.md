# 자산 범위

STEPUP-원본로고.png를 공통 헤더에서 그대로 사용한다. Pretendard 두 굵기와 OFL을 fonts에 동봉했다. 새 화면은 개별 비트맵이며 편집 가능한 Figma 또는분리된 새 신발/도시/아이콘 자산은 없다.

신발은 실제 착용 신발의 기존 자산, 사진은 실제 사용자가 선택한 파일, 기본 이미지는 기존16개 옵션을 사용한다. 시안의 사람 윤곽은 사진 파일이 없을 때의 대체 이미지다. 선택지를 새 아바타 ID로 바꾸지 않는다. 버튼·텍스트·입력·시트는 네이티브 컴포넌트다. OS 키보드를 이미지로 재구현하지 않는다.
