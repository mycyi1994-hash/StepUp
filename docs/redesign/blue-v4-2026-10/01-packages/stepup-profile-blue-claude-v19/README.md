# 내 정보·프로필 편집 파란 톤 전달본

개별 새 시안 21장과 연결 참고 2장이다. PF01~04는 내 정보, PRO01~17은 편집·저장·입력·복귀 상태다. 실제 탐색 경로 2개와 그 안의 상태를 구분한다.

먼저 [Claude 지시서](Claude-내정보프로필-파란톤-지시서.md), [화면별 동작](화면별동작.md), [화면 목록](screen-index.json)을 읽는다. 최초 후보13장에 코드 대조로 발견한8장을 추가했다. 전체 리메이크 완료본은 아니다.

PF01·PRO04·PRO09·PRO14는 r2, 나머지는 r1 최종본이다. 이 폴더의 PNG 이름에는 편의를 위해 리비전 접미사를 생략했다. 이미지 생성 도구는 built-in imagegen이며 각 요청은 prompts에 기록했다. PRO13은 중단된 호출에서 생성 파일을 회수했고 요청문 복원 사실을 명시했다.

21장은 정적 비트맵 시안이다. 앱 실행·서버 연동·분리된 신규 신발 자산·Figma 편집 파일을 제공했다는 뜻이 아니다. 앱 소스 변경·커밋·푸시를 하지 않았다.
