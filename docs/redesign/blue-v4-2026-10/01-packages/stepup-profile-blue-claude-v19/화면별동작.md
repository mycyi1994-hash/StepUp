# 화면별 진입·동작

시안 수와 경로 수는 다르다. 뒤로 가기는 실제 호출자와 기존 스택을 보존한다.

## PF01 · 내 정보 러닝 패스

[시안](01-screens/PF01.png)

진입: 内정보 정상

동작: 사진·프로필 수정→PRO01; 기록→RECORDS/H01; 챌린지→CHALLENGE_HISTORY; 지갑→WALLET; 설정→SETTINGS; 5탭 기존 이동.

주의: 루트 공유 헤더·탭 사용. 러너 레벨과 신발 레벨, 전체 누적과 월별 기록을 구분.

## PF02 · 내 정보 기록 불러오는 중

[시안](01-screens/PF02.png)

진입: 프로필 값은 도착했지만 러닝 합계를 읽는 중

동작: 조회 결과→PF01/PF04 또는 PF03. 다른 메뉴 이동 유지.

주의: 모르는 거리·횟수에 0을 표시하지 않음. 잔액과 프로필의 독립 상태 보존.

## PF03 · 내 정보 기록 조회 실패

[시안](01-screens/PF03.png)

진입: 러닝 합계 조회 실패

동작: 보조 다시 시도→기존 retryRecords→PF02; 기록·다른 메뉴 유지.

주의: 실패를 빈 기록이나 탈퇴로 처리하지 않음.

## PF04 · 내 정보 첫 러닝 전

[시안](01-screens/PF04.png)

진입: 저장된 러닝이 실제 0건

동작: 기록→H07 참고 구조의 실제 빈 기록 화면; 다른 메뉴 유지.

주의: 걸음 기반 레벨·보상 잔액·신발 소유를 임의 초기화하지 않음.

## PRO01 · 프로필 수정

[시안](01-screens/PRO01.png)

진입: 프로필 수정 진입, 변경 없음

동작: 사진 변경→PRO03; 닉네임 터치→PRO16; X→PRO05; 뒤로→내 정보.

주의: 저장 비활성. 실제 사진·이름 유지. 최초 자동 키보드 없음.

## PRO02 · 닉네임 변경

[시안](01-screens/PRO02.png)

진입: 정규화한 닉네임이 달라짐

동작: 저장→PRO10; 뒤로→PRO09; 사진 변경→PRO03.

주의: 예시 달리는민수5/16. 최종 저장값과 비교.

## PRO03 · 사진 변경 메뉴

[시안](01-screens/PRO03.png)

진입: 사진 변경 메뉴

동작: 앨범→OS PickVisualMedia; 기본 이미지→PRO04; 닫기·외부·뒤로→편집.

주의: 앨범 취소 시 아무 변화 없음. 선택은 즉시 사진 저장이며 이름 초안 보존.

## PRO04 · 기본 이미지 선택

[시안](01-screens/PRO04.png)

진입: 기본 이미지 목록

동작: 새 이미지→PRO14; 같은 저장 ID→저장 없이 닫기; 닫기→편집.

주의: 기존16개 ID 순서 유지. 사용자 사진이면 체크 없음. 기존 기본 이미지면 그 체크만 표시.

## PRO05 · 닉네임을 비웠을 때

[시안](01-screens/PRO05.png)

진입: 저장된 민수를 지워 빈 이름 입력

동작: 저장→PRO10→기본 호칭으로 내 정보; 입력→해당 길이 상태.

주의: 빈 이름은 유효. 원래도 빈 이름이었다면 저장 비활성. X 없음.

## PRO06 · 16자 입력

[시안](01-screens/PRO06.png)

진입: 16자 이름 입력

동작: 저장→PRO10; 계속 편집·지우기 가능.

주의: 16자 자체는 오류 아님. 입력 변환·저장 규칙·카운트 일치.

## PRO07 · 사진 저장 중

[시안](01-screens/PRO07.png)

진입: 앨범 사진 저장 처리

동작: 성공→PRO17; 실패→PRO08. 이름 입력은 가능.

주의: 사진 재선택과 이름 저장 차단. 작업은 앱 범위에서 계속됨.

## PRO08 · 사진 저장 실패

[시안](01-screens/PRO08.png)

진입: 앨범 사진 저장 실패

동작: 다시 선택→OS 선택기; 사진 변경→PRO03; 이름은 독립적으로 편집.

주의: 이전 파일·ID·리비전 보존. 초안 변경 시 이름 저장은 정상 활성.

## PRO09 · 수정 중 나가기

[시안](01-screens/PRO09.png)

진입: 저장하지 않은 이름으로 뒤로 가기

동작: 계속 수정·외부·뒤로→편집 초안 유지; 닉네임 버리고 나가기→내 정보.

주의: 이미 저장된 사진은 유지. 사진 변경 없으면 사진 유지 안내 줄 생략.

## PRO10 · 닉네임 저장 중

[시안](01-screens/PRO10.png)

진입: 닉네임 저장 중

동작: 성공→PRO12; 실패→PRO11.

주의: 이름 입력·사진 변경·중복 저장 비활성. 화면 종료 후 임의 재진입 금지.

## PRO11 · 닉네임 저장 실패

[시안](01-screens/PRO11.png)

진입: 닉네임 저장 실패

동작: 다시 저장→PRO10; 편집 가능; 변경 초안으로 뒤로→PRO09.

주의: 실패 초안 재진입 복원. 다른 작업 상태를 덮지 않음.

## PRO12 · 저장 완료

[시안](01-screens/PRO12.png)

진입: 닉네임 실제 저장 성공 후 내 정보 복귀

동작: PF01과 같은 메뉴. 2.6초 안내 한 번 후 사라짐.

주의: 사진 변경 없는 독립 분기: 기본 사진 유지, 새 이름만 반영. 성공 전에 표시 금지.

## PRO13 · 프로필 초기 불러오는 중

[시안](01-screens/PRO13.png)

진입: 저장된 이름·아바타 초기 로딩

동작: 로드 완료→PRO01 또는 복원된 초안; 뒤로→호출자.

주의: 기본값을 실제 저장값으로 오인시키지 않음. 현행 읽기 실패 기본값 처리와 별개의 상태.

## PRO14 · 기본 이미지 저장 중

[시안](01-screens/PRO14.png)

진입: 새 기본 이미지 즉시 저장 중

동작: 성공→편집 사진 갱신; 실패→PRO15.

주의: 첫 셀은 pending 표시만. 이전 선택 유지. 모든 선택·닫기·외부·뒤로 차단.

## PRO15 · 기본 이미지 저장 실패

[시안](01-screens/PRO15.png)

진입: 기본 이미지 저장 실패

동작: 선택 재시도→PRO14; 닫기→편집.

주의: 이전 저장값과 초안을 유지. 새 이미지에 성공 체크 없음.

## PRO16 · 닉네임 키보드 입력

[시안](01-screens/PRO16.png)

진입: 닉네임 입력·OS 키보드 열림

동작: 저장→키보드 닫고 PRO10; 완료→키보드만 닫기; 사진 메뉴→포커스 해제 후 PRO03.

주의: 입력·안내·저장 버튼은 IME 위. 키보드는 생성 그림이 아닌 실제 OS.

## PRO17 · 사진 변경 완료

[시안](01-screens/PRO17.png)

진입: 사진만 저장 완료

동작: 사진 변경→PRO03; 뒤로→변경 사진이 반영된 내 정보; 이름 변경→PRO02형태.

주의: 이름 변화 없으므로 저장 버튼 비활성. 새 사진을 나가기 때 되돌리지 않음.
