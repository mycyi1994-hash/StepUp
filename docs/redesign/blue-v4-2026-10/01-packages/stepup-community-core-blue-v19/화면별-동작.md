# 커뮤니티 화면별 상태와 버튼 동작

CM07은 폐기된 중복 장소 목록이다. 상태 번호를 모두 개별 라우트로 구현하지 않는다. 뒤로 가기는 실제 진입 문맥을 복원한다.

| 번호 | 화면 | 진입 상태 | 행동과 다음 상태 |
|---|---|---|---|
| CM01 | 확정 목록 | 선택 지역과 목록 조회 성공 | 범위 변경→CM02; 지도→CM05; 글→CM08; 장소 썸네일→CM06; 글쓰기→CM12 또는 초안이 있으면 CM21. |
| CM02 | 범위 변경 | 목록에서 범위 변경 | 반경 임시 선택; 적용하면 해당 목록 재조회; 지역 변경→CM03; 닫으면 기존 범위 유지. |
| CM03 | 지역 검색 | 지역 변경 또는 지역 직접 선택 | 결과 선택→CM43; 내 위치로 찾기는 권한 상태에 따라 CM30/31/32; 검색 결과 없음→CM04. |
| CM04 | 지역 검색 결과 없음 | 지역 검색 성공 결과 0개 | 검색어 변경→CM03. 이전 선택 지역은 유지하고 가짜 결과를 넣지 않음. |
| CM05 | 주변 지도 | 작은 지도 또는 지도 보기 | 핀→CM06; 글→CM08; 내 위치 버튼은 실제 권한 확인; 뒤로는 진입 화면과 필터 복원. |
| CM06 | 지도에서 장소 선택 | 핀 또는 글의 공개 장소 선택 | 같은 목록을 해당 장소로 필터; 글→CM08; 전체 장소→CM05; 뒤로는 실제 진입 화면. |
| CM08 | 글 상세 | 다른 사람의 글 조회 성공 | 댓글 입력→CM09; 더보기→CM26; 장소→CM06; 좋아요 실패→CM39; 뒤로 목록 상태 복원. |
| CM09 | 댓글 입력 | 댓글 입력창에 포커스 | OS 키보드 사용; 등록 중 중복 방지; 성공→CM10; 실패→CM11; 입력 내용은 보존. |
| CM10 | 댓글 등록 완료 | 댓글 서버 등록 성공 | 실제 댓글과 개수 갱신, 입력창 초기화. 등록을 다시 누른 것으로 처리하지 않음. |
| CM11 | 댓글 등록 실패 | 댓글 등록 실패 | 입력과 개수 보존; 재시도 성공→CM10; 입력 수정 가능, 오류가 입력창을 가리지 않음. |
| CM12 | 글쓰기 시작 | 새 글쓰기, 아직 필수 입력 없음 | 코스→후속 WRITE09; 장소→CM14/후속 WRITE10; 문구·본문 입력 가능. 장소와 본문/기록이 갖춰져야 게시 활성화. |
| CM13 | 내용과 장소 입력 | 공개 장소와 본문을 입력한 일반 글 | 올리기→CM17; 장소 변경→CM14; 코스는 선택사항; 뒤로→CM20. 시안 예시에는 첨부 기록이 없음. |
| CM14 | 장소 검색 | 장소 검색 또는 선택 진입 | 검색 결과 한 번 선택→작성 화면, 내용 유지; 지도 직접 선택만 CM15; 결과 없음→CM16. 매번 확인 화면을 열지 않음. |
| CM15 | 장소 확인 | 지도에서 공개 장소 직접 지정 | 선택한 장소 확정→작성 화면; 뒤로는 장소 선택, 본문 보존. 장소 검색 결과의 필수 중간 화면이 아님. |
| CM16 | 장소 검색 결과 없음 | 장소 검색 성공 결과 0개 | 검색어 수정→CM14; 지도 선택→CM15; 취소해도 작성 내용과 이전 장소 유지. |
| CM17 | 글 올리는 중 | 게시 요청 중 | 내용·장소·첨부 유지, 중복 게시 차단; 서버 성공→CM18; 확정 실패→CM19; 결과 불명은 같은 요청 조회. |
| CM18 | 글 게시 완료 | 서버가 일반 글 게시를 확인 | 같은 목록 형식의 새 글과 짧은 완료 안내; 내 글→CM44; 실제 지역·필터 기준 개수 갱신. |
| CM19 | 글 게시 실패 | 일반 글 게시 실패 | 내용과 장소 그대로; 다시 올리기→CM17. 만료 인증이면 기존 인증 복귀 경로 사용, 자동 게시하지 않음. |
| CM20 | 작성 중 나가기 | 내용 변경 후 작성 화면 이탈 | 임시저장하고 나가기 / 계속 쓰기 / 버리고 나가기; 계정별 초안 보존, 저장 실패를 완료 처리하지 않음. |
| CM21 | 임시저장 이어쓰기 | 보관된 초안이 있는 상태에서 글쓰기 | 이어쓰기→보존된 작성 상태; 지우고 새로 쓰기→CM12; 닫으면 초안 보존. 첨부 기간 재검증. |
| CM22 | 내 글 메뉴 | 내 글 상세의 더보기 | 수정→CM23; 삭제→CM24; 닫기→같은 내 글. 다른 사람 글에 이 메뉴를 표시하지 않음. |
| CM23 | 글 수정 | 내 글 수정 | 원문·장소·첨부 유지; 성공하면 같은 ID의 CM44 갱신; 실패 시 내용 보존과 재시도; 기존 댓글·반응 유지. |
| CM24 | 글 삭제 확인 | 내 글 삭제 선택 | 명시적 삭제 확인 후 요청; 성공하면 목록에서 제거; 실패→CM25; 취소는 글 유지. |
| CM25 | 삭제 실패 | 글 삭제 확정 실패 | 원래 글과 목록 유지; 다시 시도하거나 취소; 결과 불확실은 재조회하여 중복 요청을 피함. |
| CM26 | 다른 글 메뉴 | 다른 사람 글의 더보기 | 이 글 숨기기→CM29; 신고→CM27; 닫기→같은 글. 작성자 차단과 구분. |
| CM27 | 신고 사유 | 신고 선택 | 사유 하나를 선택하고 제출; 접수 성공→CM28; 실패→CM40; 미선택 또는 처리 중 제출 비활성. |
| CM28 | 신고 접수 완료 | 신고 접수 서버 확인 | 확인으로 시트 닫기; 글 삭제나 제재 완료로 안내하지 않음. |
| CM29 | 글 숨김 완료 | 글 한 건 숨김 반영 | 해당 글만 제외하고 핀 개수 갱신; 되돌리기는 그 글 숨김만 취소. 전체 작성자 글을 차단하지 않음. |
| CM30 | 위치 사용 안내 | 주변 검색의 위치 사용 안내 | 내 위치 사용하기→OS 권한→CM32/31; 지역 직접 선택→CM03; 닫기로 동의를 강요하지 않음. |
| CM31 | 위치 권한 꺼짐 | 위치 권한 또는 위치 기능 사용 불가 확인 | 설정 열기→OS 설정, 복귀 후 재확인; 지역 직접 선택→CM03. 무한 권한 요청과 로딩 금지. |
| CM32 | 위치 확인 중 | GPS 위치 확인 중 | 성공→목록 조회 CM34; 실패→CM37; 지역 직접 선택→CM03. 지역 전에는 범위·지도 버튼 없음. |
| CM33 | 주변 글 없음 | 목록 조회 성공, 조건에 맞는 글 0개 | 첫 이야기 남기기→CM12; 범위 변경→CM02. 실패나 조회 중 상태를 0개로 표시하지 않음. |
| CM34 | 목록 불러오는 중 | 초기 목록 조회 중 | 목록 자리표시자; 성공→CM01/43 또는 CM33; 실패→CM35; 글쓰기는 조회와 별개로 이용 가능. |
| CM35 | 목록 조회 실패 | 목록 조회 실패 | 다시 불러오기→CM34; 알고 있는 지역 유지. 이전 데이터가 있으면 별도 새로고침 실패 안내와 함께 보존. |
| CM36 | 지도 조회 실패 | 주변 지도 타일만 조회 실패 | 지도 안 다시 불러오기→CM41; 이미 불러온 글은 계속 선택 가능. 목록까지 오류로 비우지 않음. |
| CM37 | 위치 찾기 실패 | 현재 위치 찾기 실패 | 지역 직접 선택→CM03; 위치 다시 찾기→CM32. 임의 지역·거리·현재 위치 점을 넣지 않음. |
| CM38 | 볼 수 없는 글 | 글 삭제 또는 접근 불가 확인 | 글 목록으로→원래 목록; 본문·작성자·댓글 조작 UI 없음. 일반 통신 실패와 구별. |
| CM39 | 좋아요 반영 실패 | 좋아요 반영 실패 | 직전 좋아요 상태와 수치 복구; 본문 내 안내, 재탭 가능; 댓글·본문·입력은 유지. |
| CM40 | 신고 접수 실패 | 신고 접수 실패 | 선택 사유 유지; 다시 접수; 닫기 가능. 접수 성공은 서버 확인 후 CM28. |
| CM41 | 지도 불러오는 중 | 지도 타일 불러오는 중 | 지도 자리만 로딩; 성공→CM05/06; 실패→CM36; 이미 조회한 글 목록은 계속 사용. |
| CM42 | 글 불러오는 중 | 글 상세 최초 조회 중 | 자리표시자와 뒤로 가기; 성공→CM08/44; 접근 불가→CM38; 일반 통신 실패는 재시도. 이전 글을 새 글처럼 노출하지 않음. |
| CM43 | 직접 선택한 지역의 글 | GPS 대신 사용자가 지역 선택 | 선택 지역 기준 거리 명시; 범위→CM02, 지도→CM05, 글→CM08, 글쓰기→CM12. GPS 위치점 금지. |
| CM44 | 내가 쓴 글 상세 | 내가 쓴 글 상세 | 더보기→CM22; 댓글·장소는 공통 상세와 동일; 예시의 댓글 0개를 모든 내 글에 강제하지 않음. |
