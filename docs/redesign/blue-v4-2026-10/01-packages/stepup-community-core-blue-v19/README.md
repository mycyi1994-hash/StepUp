- 공통 색과 부품 지침: design-tokens.json
- 로고 원본: assets/STEPUP-원본로고.png

PNG 43장은 개별 화면이다. CM07 중복 장소 목록은 포함하지 않는다. 코스 첨부·최근 기록 등 WRITE01~17, 크루 모집·채팅의 새 톤 상세 시안은 별도 작업 중이므로 이 ZIP을 커뮤니티 전체 완료본으로 해석하지 않는다.

이번 파일은 정적 시안과 구현 문서다. 앱 코드나 편집 가능한 Figma 구성, 분리된 버튼 이미지가 만들어졌다는 뜻이 아니다. 실제 지도·위치·키보드는 앱의 네이티브 기능과 연결한다. 예시 게시글·숫자·지도는 실제 서비스 데이터가 아니다.

Claude에게는 이 ZIP 전체와 현재 작업 브랜치를 함께 전달한다. 앱의 기존 상태와 기능을 보존하면서 시안과 공통 부품을 맞추고, 실제 적용 후 확인한 결과를 별도로 보고한다.
