# 설정40개 상태의 동작

모든 이미지는 정적 시안이다. 같은 경로 안의 상태를 별도 페이지로 중복 구현하지 않는다.

| ID | 상태 | 버튼·다음 동작 | 유지 조건 |
|---|---|---|---|
| SET01 | 설정 첫 화면 | 8개 설정 행→각 기존 경로; 아래로 스크롤→SET29. 뒤로→진입 화면. | 행 우측은 현재 값. 로딩 값을 임의로 만들지 않음. |
| SET02 | 알림 정상 | 4개 토글 변경→로컬 저장→서버 동기화. | 푸시는 다른 세 토글의 마스터 스위치가 아님. |
| SET03 | OS 알림 차단 | 설정 열기→OS 앱 설정. 복귀 시 권한 재조회. | 기존 앱 토글 선택을 지우지 않음. |
| SET04 | 서버 반영 대기 | 다시 시도→서버 동기화. | 이 휴대폰 저장과 서버 반영 완료를 구분. |
| SET05 | 로컬 저장 실패 | 오류 표시; 사용자가 토글을 다시 조작할 수 있음. | 이전 저장값을 유지하고 성공 토스트를 띄우지 않음. |
| SET06 | 개인정보·권한 정상 | 권한 설정→OS; 저장 정보→SET08; 알림 삭제→SET09. | 상태 행 자체는 가짜 권한 토글이 아님. |
| SET07 | 권한 제한 | 설정 열기→OS; 복귀 시 실제 상태 반영. | 대략적 위치와 거절을 구분. |
| SET08 | 저장 정보 시트 | 확인/X/뒤로→진입한 개인정보 화면. | 기존 저장 범위 설명을 임의 정책으로 바꾸지 않음. |
| SET09 | 일반 알림 삭제 확인 | 취소→닫기; 삭제→SET30. | 미응답 초대와 미확인 보상 알림 유지. |
| SET10 | 일반 알림 삭제 완료 | 완료 알림 뒤 원래 개인정보 화면. | 실제 저장소 삭제 성공 뒤만 완료. |
| SET11 | 계정·지갑 연결됨 | 계정 삭제→SET13; 뒤로→설정. | 소셜 연결은 읽기 전용; 준비 중 건강 연동을 활성 기능처럼 표시하지 않음. |
| SET12 | 로그아웃 상태 | 기존 로그인 경로 이용; 뒤로→설정. | 회원 전용 계정 삭제와 가짜 연결 버튼을 만들지 않음. |
| SET13 | 계정 삭제 확인 | 취소/X→닫기; 계정 삭제→SET14. | 삭제 범위·되돌릴 수 없음·휴대폰 기록 안내를 모두 유지. |
| SET14 | 계정 삭제 요청 중 | 서버 확정 결과로 성공 처리/SET31/SET15 분기. | 중복 요청과 닫기 방지. 타이머로 성공 처리 금지. |
| SET15 | 삭제 결과 미확인 | 문의→기존 문의 기능; 닫기→계정 상태 재조회. | 확정 실패와 다름. 자동 재삭제하지 않음. |
| SET16 | 어두운 테마 | 시스템/어둡게/밝게 중 선택 즉시 적용·저장. | 실패 시 이전 선택 복원. 별도 저장 버튼 없음. |
| SET17 | 밝은 테마 | 테마 변경/뒤로. | 의도적인 밝은 배경 예외. 밝은 테마 기능을 삭제하지 않음. |
| SET18 | 한국어 설정 | 시스템/en/ko/zh/ja 중 선택→앱 언어 변경. | 사용자 글·이름까지 자동 번역하지 않음. |
| SET19 | 영어 설정 | 같은 5개 언어·영어 앱 내비게이션. | 기존 번역 리소스를 우선하고 시안 문구를 새 정책으로 사용하지 않음. |
| SET20 | 소리·진동·동작 | 효과음/주변음/진동/동작 줄이기/날씨 배경 토글; 피드백 미리듣기. | 미리듣기는 보상을 지급하지 않음. 날씨는 기존 위치 권한과 근사 위치 처리 유지. |
| SET21 | 도움말 기본 | FAQ 5개 중 하나 펼치기; 가이드→기존 안내; 문의→SET23. | 메일이 자동 전송되지 않음. |
| SET22 | 첫 FAQ 펼침 | 같은 질문→닫기; 다른 질문→해당 하나 펼치기. | 접힌 질문의 순서와 가이드/문의 유지. |
