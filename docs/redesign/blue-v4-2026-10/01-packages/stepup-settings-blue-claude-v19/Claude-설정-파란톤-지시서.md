# StepUp 설정40장 파란 톤 구현 지시서

기존 Android 설정 화면에 승인된 남색·파랑 표현을 적용한다. SET01~40은 개별 시각 검수를 마친 상태 표본40개다. 정적 PNG와 지시서이며 앱 구현·서버 검사·Figma 레이어 완료본은 아니다. 기존 통합 ZIP의 설정 부분 전달을 이 폴더로 대체해 참고하되 다른 기능의 지시서는 유지한다.

먼저 [화면 목록](screen-index.json), [화면별 동작](화면별동작.md), [검수 범위](audit/검수범위.md)를 읽는다. SET31은 r2로 삭제 실패 안내를 보완했다. 각 PNG 파일명에는 리비전 접미사를 생략했고 실제 버전은 목록에 적었다. 과거 SET31 r1을 재사용하지 않는다.

## 구성과 스타일

현재 프로젝트 app/src/main/java/com/stepup/android/ui/screens/settings의 SettingsHomeScreen, NotificationSettingsScreen, PrivacyScreen, ConnectedAccountsScreen, ThemeScreen, LanguageScreen, ExperienceSettingsScreen, SupportScreen을 수정 대상으로 확인한다. AppChromePolicy와 values-ko/settings.xml, experience.xml의 실제 경로·문구도 읽는다. 다른 checkout으로 옮기거나 작업 중인 변경을 덮어쓰지 않는다.

현재 값이 보이는 짧은 설정 행, 묶음 안 구분선, 필요한 때만 나타나는 안내가 중심이다. 배경#031427, 면#0B2B50, 테두리#0754FF, 강조#48D9FA, 기본 글자#F5F8FF, 보조#ABC7EF. 캐릭터·신발 무대·장식 배지·이모티콘을 추가하지 않는다. 기존 글꼴/아이콘을 쓰고 동봉 폰트의 라이선스를 유지한다. 원본 로고를 바꾸지 않으며 설정에는 로고/SUP 헤더를 새로 넣지 않는다.

설정 Detail은 뒤로+제목과 공통 하단5탭을 유지한다. 시트는 아래 탭까지 덮는다. SET17 밝은 테마의 흰 배경은 의도된 예외다. 시스템 상태바·홈 표시줄은 OS가 그린다. 작은 화면이나 큰 글씨에서는 스크롤하고 안내나 버튼을 삭제하지 않는다.

## 저장·권한·삭제 동작

읽기 중, 저장 중, 실제 빈 값, 조회 실패를 구분한다. 알 수 없는 값에0/OFF/예시 숫자를 확정 값으로 넣지 않는다. 페이지의 로딩 중에도 실제로 확정된 다른 정보는 유지한다.

알림4종은 독립 선택이다. 푸시 알림은 다른3종의 마스터 스위치가 아니다. SET36은 DataStore 로컬 저장 중으로 토글4개를 잠시 막는다. 기존 saving 상태에 진행 문구 하나를 보여주는 표현 제안이며 새 서버 상태가 아니다. SET37은 로컬 저장은 끝나고 서버 전송 중이다. 이때 재시도 버튼만 비활성화하고, 로컬 저장 중이 아닌 토글은 계속 조작할 수 있다. OS 차단과 서버 미반영이 함께 있으면 기존 OS 차단 안내 우선순위를 유지한다. OS 설정에서 돌아오면 실제 권한을 다시 읽는다.

일반 알림 삭제는 미응답 초대와 미확인 보상 알림을 보존한다. 기록/신발/SUP 삭제가 아니다. 확인→처리 중→성공/실패로 구분하며 처리 중에는 중복 삭제·닫기를 막는다. 실패하면 원래 안내와 재시도 길을 유지한다.

계정 연결은 Checking/Linked/NotLinked/Unknown/SignedOut 실제 상태에 대응한다. 조회 실패를 미연결로 단정하지 않는다. 소셜 계정과 Health Connect 상태 행은 읽기 전용이며 준비 중 건강 연동을 가짜 기능으로 만들지 않는다. 로그인 확인 전에는 삭제 버튼이 없다. 지갑 미연결/조회 실패 행의 진입은 기존 웹 지갑 경로다.

계정 삭제는 확인 후에만 요청한다. Deleted는 기존 서버 성공 처리와 로그아웃·세션 종료·사본 정리를 수행한다. NotDeleted는 SET31 확정 실패로 재시도 가능하고, Unknown은 SET15 결과 미확인으로 자동 재삭제하지 않는다. SET31 r2는 삭제 범위·크루장 이전·되돌릴 수 없음·휴대폰 기록 안내를 유지한 채 오류를 추가했다. 기존 문구의 휴대폰 기록 보존 설명과 실제 로컬 정리 범위가 맞는지는 구현 검토 항목이며 이 패키지가 개인정보 정책을 새로 정한 것이 아니다.

## 테마·언어·체험·목표

테마는 고르는 즉시 적용하며 저장 실패 시 직전 선택으로 복구한다. SET38의 어두운 테마는 실패 후 복구 예시다. 미리보기128.4km는 실제 계정 합계에 바인딩하고 읽기 전에는 미확정 표시다. 언어5종은 기존 앱 언어 설정이며 사용자 글/이름까지 번역하지 않는다. 언어 저장 실패와 빠른 연속 변경의 저장 순서는 별도 실행 검사가 필요하다.

소리·진동·동작5옵션과 효과 미리듣기를 유지한다. 미리듣기는 기존 피드백만 실행하며 보상/러닝/뽑기를 시작하지 않는다. 음소거·방해금지·음악 재생과 동작 줄이기를 따른다. 날씨는 기존 위치 권한 및 약10km 근사 위치의 Open-Meteo 전달 설명을 보존한다. 실패 시 이전 값 안내를 표시하고 기존 값을 유지한다.

걸음 목표는3,000~20,000,500단위다. 변경 즉시 기존 StepRepository 저장 경로를 사용하며 닫기를 저장 버튼으로 바꾸지 않는다. 8,000걸음·6.1km·20.0SUP은 계산 예시다. 목표 보너스는 이미 지급된 보상이 아니다. 실패 시 실제 저장된 목표를 다시 보여준다. 최솟값에서 감소/최댓값에서 증가 비활성, 읽기 중 값과 보조 계산 표시, 빠른 변경·닫기 때 저장 지속 여부는 실제 검사한다.

## 도움말·추가 메뉴

FAQ는 기존5개 중 하나만 펼친다. 안내는 기존 앱 사용 안내 경로다. 문의 주소 support@stepupcrew.com은 현재 리소스이며 OS 메일 작성 화면을 연다. 위치나 계정 정보를 자동 첨부하거나 메일을 자동 발송하지 않는다. 메일 앱을 못 열면 주소 복사/닫기를 제시한다. SET40 안내는 실제 클립보드 성공 후2.5초만 표시하며 시트와 버튼은 유지한다.

SET29의 알림함/업적/친구 초대/신체 정보·목표/모드는 현재 경로로 연결한다.1.0.0은 예시이며 실제 버전 사용. 데모/테스트 업데이트 기능은 기존 빌드 조건을 보존하고 운영 회원에게 새로 노출하지 않는다. 이 연결 대상 전체가 설정40장에 포함됐다는 뜻은 아니다.

## 적용·검증

PNG 전체를 앱 화면으로 붙이지 않는다. 텍스트/토글/체크/버튼/시트/진행 표시는 실제 Compose UI다. 현재 구현 파일과 상태의 대응을 [구현 기록표](implementation-checklist.csv)에 남긴다. 오류를 성공으로 바꾸거나 비활성 버튼을 실제 요청에 연결하지 않는다.

작은 화면·큰 글씨·TalkBack·하단 안전영역, 권한 설정 복귀, 저장 실패·연타·백그라운드 복귀, 미확정 삭제 결과의 재조회와 로그인 전 메뉴를 검사한다. 화면마다 실제 캡처와 검사 결과를 남긴다. 정적40장 검수를 실제 앱 실행 통과로 표현하지 않는다. 전체 리메이크와 추가 경로/상태 감사는 계속 남아 있다.
