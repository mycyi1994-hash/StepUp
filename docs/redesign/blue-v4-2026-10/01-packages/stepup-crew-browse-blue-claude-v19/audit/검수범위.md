# 검수 범위

38장을 개별로 열어 레이아웃·예시 크루 동일성·역할·주요 문구·버튼 위치를 확인했다. 최신 수정본 CP01/10/14/15/21/67을 포함한다. PNG의 청크 CRC·파일 해시와 압축을 별도 확인했다. 36장은887×1774, CP06은887×1773, CP12는886×1774다. 원본을 재가공하지 않았다.

정적 시안에서 본 결과이며 실기기·앱 빌드·API·애니메이션·접근성 통과를 뜻하지 않는다. 생성 이미지의 막대 길이·아이콘·대표 이미지 글자 차이는 원본 자산과 실제 계산값으로 구현한다. CP04의 가까운 순 안내는 선택 지역 기준으로 문맥화한다. CP82는 전체 명단이 아닌 주간 참여 목록임을 표시한다.

생성 프롬프트/원본 경로는 제작 추적용이다. 압축을 다른 컴퓨터에 옮겨도 필요한 시안·로고·대표 이미지·지시서는 내부 파일로 접근 가능하다. 원본 프로젝트를 수정한 파일은 없다.
