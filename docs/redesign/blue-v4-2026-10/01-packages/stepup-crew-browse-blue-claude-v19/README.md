# StepUp 크루 둘러보기·가입 / 파란 톤

크루의 대표 이미지·이름·레벨·인원·크루장을 한눈에 보여주는 명함형을 유지하고, 승인된 남색·전기 파랑 톤으로 리메이크했다. **새 단일 화면 시안 38장과 클로드 구현 지시서**다.

1. `Claude-구현지시서.md`를 먼저 읽는다.
2. `화면별동작.md`에서 번호·진입 조건·버튼 동작을 확인한다.
3. `01-screens/CP01.png` 목록과 `CP08.png` 상세를 기준으로 공통 구성 요소를 만들고 나머지는 역할·상태별로 재사용한다.
4. `screen-index.json`, `flow-map.json`, `design-tokens.json`, `fixtures.json`을 함께 전달한다.

클로드에게 전달할 문장:

> 이 패키지의 Claude-구현지시서.md와 화면별동작.md를 먼저 읽고 기존 StepUp 앱의 크루 둘러보기·가입 화면을 리메이크해 주세요. 원본 로고, 실제 데이터, 역할별 권한, 기존 연결을 유지하세요. 38장은 상태 시안이며 별도 웹사이트나 38개 독립 경로를 만드는 요청이 아닙니다. 이번 미포함 화면은 기존 기능을 보존하고 연결만 유지해 주세요.

## 포함 범위

- `01-screens`: 약887×1774 PNG 38장, 화면 하나씩. CP06은887×1773, CP12는886×1774이며 원본의1px 차이를 보존했다. 수정본이 있는 번호는 최신 검수본만 포함.
- `02-shared-reference`: 이미 전달된 러닝 이야기 CM01 1장. 공통 탐색 참고이며 신규38장에 미포함.
- `assets`: 공식 STEPUP 로고와 기존 가상 크루 대표 이미지 3종의 PNG/SVG. 실제 서비스에서 사용자 이미지로 교체.
- `prompts`: 제작 이력. 구현 지시서는 아니며 재생성을 요구하지 않음.
- `audit`: 시각 검수 기록, 코드 참고 해시, 제작 범위·미제작 목록, 파일 해시.

## 진행 범위와 한계

크루 후보95상태 중38장이다. **생성·운영·관리 등57상태는 아직 리메이크 중**이며 `audit/coverage.json`에 모두 적었다. CP94/95는 아래로 스크롤한 장면이다. 앱 전체 후보와 경로 누락 감사도 계속 중이다.

이 전달본은 정적 시안과 구현 설명이다. 새 화면이 편집 가능한 Figma/Auto Layout 문서, 구현 코드, 실행 가능한 프로토타입이라는 뜻은 아니다. 대표 이미지 SVG만 기존 독립 자산으로 제공한다. 앱 코드 수정·실행 검증·서버 검증·커밋·푸시는 수행하지 않았다.
