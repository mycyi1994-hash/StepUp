# 화면별 진입·행동·검수 기준

모든 번호는 상태 예시다. 사용자·크루·초안·목록 복귀 문맥을 유지한다. 외부 연결은 flow-map.json에 별도 표기했다.

## CP01 · 확정 크루 명함 목록

[단일 화면 보기](01-screens/CP01.png)

- 진입: 커뮤니티의 크루 모집 탭, 조회 성공
- 행동: 지역→CP02; 정렬→CP04; 카드·크루 보기→해당 상세; 이미지→CP09; 레벨→CP11; 인원→CP12; 크루장→CP10; 목표→CP13; 모집하기→기존 생성 진입.
- 지킬 조건: 중첩 클릭 중복 실행 금지. 상세 복귀 시 지역·반경·정렬·목록 위치 보존. 생성 진입 CP25/26/39는 이번 시안에 미포함.

## CP02 · 지역과 거리 범위

[단일 화면 보기](01-screens/CP02.png)

- 진입: 지역·범위 버튼
- 행동: 지역 검색→CP03; 1/3/5km 중 하나 선택; 적용→호출자에 선택 지역과 반경 반영; 닫기→원래 값 유지.
- 지킬 조건: 목록 선택과 만들기 초안의 지역 선택은 호출자를 구분한다. 적용 전 서버 설정을 수정하지 않는다.

## CP03 · 지역 검색

[단일 화면 보기](01-screens/CP03.png)

- 진입: 지역 이름으로 찾기
- 행동: 검색어 입력·지우기·결과 선택; 결과 없음→CP72; 현재 위치 사용→CP71 또는 이미 허용된 위치 확인; 뒤로→호출자.
- 지킬 조건: 이름만으로 좌표를 추측하지 않는다. 선택한 실제 결과 ID/좌표를 반환하고 지역 외 입력을 보존.

## CP04 · 목록 정렬

[단일 화면 보기](01-screens/CP04.png)

- 진입: 목록 정렬 버튼
- 행동: 가까운 순/최근 순/활발한 순 단일 선택; 적용→목록 갱신; 닫기→이전 정렬.
- 지킬 조건: 가까운 순은 선택한 지역 기준. 수동 지역일 때 내 주변이라고 단정하지 않는다. 정렬 기준은 기존 서비스 계약 유지.

## CP05 · 모집 목록 없음

[단일 화면 보기](01-screens/CP05.png)

- 진입: 조회 성공, 선택 범위에 크루 없음
- 행동: 범위 넓히기→CP02; 크루 모집하기→기존 생성 진입.
- 지킬 조건: 조회 실패·로그인 필요·로딩을 이 화면으로 표시하지 않는다. 범위 확장은 재조회하며 임의 크루를 삽입하지 않는다.

## CP06 · 목록 불러오는 중

[단일 화면 보기](01-screens/CP06.png)

- 진입: 최초 크루 목록 조회 중
- 행동: 지역·정렬은 입력 가능; 크루 모집하기→기존 생성 진입; 조회 완료에 따라 목록/빈 결과/실패로 전환.
- 지킬 조건: 미확인 인원·레벨을 채우지 않는다. 스켈레톤 카드 클릭 금지. 재조회 중 기존 데이터가 있으면 유지.

## CP07 · 목록 불러오기 실패

[단일 화면 보기](01-screens/CP07.png)

- 진입: 최초 목록 조회 실패
- 행동: 다시 불러오기→같은 조건 재조회; 크루 모집하기→기존 생성 진입.
- 지킬 조건: 재시도 중 주 버튼 중복 실행 방지. 생성은 보조 버튼이며 별도의 큰 고정 모집 버튼을 중복 배치하지 않는다.

## CP08 · 크루 상세 · 방문자

[단일 화면 보기](01-screens/CP08.png)

- 진입: 방문자·승인형 모집·자리 있음
- 행동: 이미지/크루장/레벨/인원/목표→CP09/10/11/12/13; 더보기→CP73; 가입 신청하기→CP14.
- 지킬 조건: 선택 crewId 고정. 같은 템플릿으로 다른 크루 데이터도 표시. 신청 성공 전 인원 증가 금지.

## CP09 · 대표 이미지 크게 보기

[단일 화면 보기](01-screens/CP09.png)

- 진입: 선택한 크루 대표 이미지 탭
- 행동: 닫기 또는 시스템 뒤로→원래 목록/상세 위치.
- 지킬 조건: 같은 크루의 원본 대표 이미지 확대. 다른 예시 이미지로 바꾸지 않는다. 이미지가 없는 크루는 이름형 대체 이미지 사용.

## CP10 · 크루장 프로필

[단일 화면 보기](01-screens/CP10.png)

- 진입: 크루장 행 탭
- 행동: 뒤로→호출자. 공개된 크루장 소개와 크루 정보만 표시.
- 지킬 조건: 선택 leaderId 유지. 서윤을 누르면 준호가 나오는 식의 고정 예시 구현 금지. 연락처·메시지 기능을 새로 만들지 않는다.

## CP11 · 레벨 안내

[단일 화면 보기](01-screens/CP11.png)

- 진입: 저장된 레벨 배지 탭
- 행동: 확인/닫기/뒤로→호출자.
- 지킬 조건: 레벨은 저장된 값. XP·랭크·승급 공식 없음. 주간 참여·거리는 레벨 산식이 아닌 별개 현황. 미설정은 새 크루, 조회 실패는 CP68.

## CP12 · 크루 멤버 목록

[단일 화면 보기](01-screens/CP12.png)

- 진입: 멤버 수·멤버 보기 탭
- 행동: 멤버 행→기존 공개 프로필 CP56; 뒤로→호출자; 전체 목록 스크롤.
- 지킬 조건: 전체 멤버 목록. CP82의 이번 주 참여자 필터와 구분. 방문자·멤버에게 내보내기/크루장 변경 권한 금지.

## CP13 · 주간 공동 목표

[단일 화면 보기](01-screens/CP13.png)

- 진입: 주간 목표 영역 탭
- 행동: 참여 멤버→CP82; 뒤로→호출자.
- 지킬 조건: 주간 합계와 목표는 서버 값. 126/160=79%, 남은34km. 목표 없으면 진입 영역을 숨긴다. 여기서 목표를 편집하지 않는다.

## CP14 · 가입 신청 작성

[단일 화면 보기](01-screens/CP14.png)

- 진입: 승인형 가입 신청하기
- 행동: 문구 버튼 선택/해제; 선택 입력 한마디 작성; 신청→전송 중→성공 CP15, 확정 실패 CP17, 모집 변경 CP24; 뒤로→상세.
- 지킬 조건: 문구와 직접 작성 내용을 따로 보존. 한마디 빈 값 허용. 300자 제한은 현행 CrewRules.MESSAGE_MAX. 전송 전 최신 역할/모집 상태 검증.

## CP15 · 신청 완료 · 확인 대기

[단일 화면 보기](01-screens/CP15.png)

- 진입: 신청 저장 성공 또는 대기 중인 내 신청 조회
- 행동: 신청 취소→CP16; 크루 보기→CP20.
- 지킬 조건: 신청 대기는 멤버가 아니다. 크루장이 현재 읽는 중이라고 단정하지 않는다. 실제 제출 시각·신청 내용을 표시.

## CP16 · 가입 신청 취소 확인

[단일 화면 보기](01-screens/CP16.png)

- 진입: 대기 신청 취소 선택
- 행동: 유지하기/닫기→CP15; 신청 취소→동일 applicationId 취소; 성공→현재 상세 재조회.
- 지킬 조건: 실패하면 신청을 유지하고 모달에 재시도 가능 안내. 승인과 경합하면 서버 최종 상태로 계산. 먼저 취소 성공을 보여주지 않는다.

## CP17 · 신청 전송 실패

[단일 화면 보기](01-screens/CP17.png)

- 진입: 가입 신청의 확정 전송 실패
- 행동: 다시 신청하기→같은 입력으로 재시도; 문구·한마디 수정 가능; 뒤로→상세.
- 지킬 조건: 입력 손실 금지. 결과 불명 타임아웃은 먼저 같은 요청 결과를 확인하고 중복 신청을 만들지 않는다.

## CP18 · 가입 승인 결과

[단일 화면 보기](01-screens/CP18.png)

- 진입: 서버에서 가입 승인을 확인
- 행동: 크루 보기→갱신된 멤버 상세 CP87.
- 지킬 조건: 푸시 기능이나 보상을 새로 가정하지 않는다. 기존 알림 또는 앱 내 재조회로 진입. 확인 전에 승인 화면 금지.

## CP19 · 가입 미승인 결과

[단일 화면 보기](01-screens/CP19.png)

- 진입: 서버에서 미승인 결과를 확인
- 행동: 다른 크루 보기→기존 조건의 CP01; 닫기→호출자.
- 지킬 조건: 전송 실패와 구분. 크루 이름 유지. 멤버 수 증가·멤버 권한 부여 금지.

## CP20 · 크루 상세 · 가입 대기

[단일 화면 보기](01-screens/CP20.png)

- 진입: 가입 신청 대기자의 상세
- 행동: 신청 내역 보기→CP15; 공개 이미지/크루장/레벨/명단/목표와 방문자 더보기 사용.
- 지킬 조건: 가입 신청 CTA를 다시 노출하지 않는다. 멤버 전용 채팅·대기실·게시판은 아직 없음.

## CP21 · 크루 상세 · 멤버

[단일 화면 보기](01-screens/CP21.png)

- 진입: 기존 멤버의 상세
- 행동: 크루 멤버 보기→CP12; 더보기→기존 멤버 메뉴 CP60; 아래로 스크롤→CP94 구조의 크루 활동 연결.
- 지킬 조건: 예시24명 유지. CP94의25명은 승인 후 예시이며 스크롤만으로 인원이 늘지 않는다. 하단 전체 탭은 없음.

## CP22 · 크루 상세 · 모집 휴식

[단일 화면 보기](01-screens/CP22.png)

- 진입: 방문자·모집 휴식
- 행동: 공개 정보·더보기는 그대로; 모집 휴식 버튼은 비활성.
- 지킬 조건: 휴식 상태가 멤버/크루장의 관리 권한을 없애지 않는다. 방문자 예시와 크루장 상태를 혼용 금지.

## CP23 · 크루 상세 · 정원 마감

[단일 화면 보기](01-screens/CP23.png)

- 진입: 방문자·모집 정원 마감
- 행동: 공개 정보·더보기는 그대로; 정원 마감 버튼 비활성.
- 지킬 조건: 예시30/30과 멤버 행30명 일치. 정원30은 고정 정책이 아니다. 정원 없는 기존 크루는 분모를 만들지 않는다.

## CP24 · 신청 중 모집 상태 변경

[단일 화면 보기](01-screens/CP24.png)

- 진입: 신청 도중 모집 종료·정원 변경을 서버가 응답
- 행동: 현재 크루 상태 보기→같은 크루 재조회 후 CP22/23 또는 실제 상태; 닫기→입력 유지.
- 지킬 조건: 신청이 완료되지 않았음을 명확히 한다. 서버에 이미 신청이 존재하면 무조건 실패 처리하지 말고 최종 신청 상태 조회.

## CP66 · 크루 접근 불가

[단일 화면 보기](01-screens/CP66.png)

- 진입: 크루 삭제·접근 불가로 상세 표시 불가
- 행동: 목록으로→CP01; 뒤로→호출자.
- 지킬 조건: 원인을 모르면 해산으로 확정하지 않는다. 일시 네트워크 실패에 재시도 대신 이 화면을 쓰지 않는다.

## CP67 · 크루 상세 로딩

[단일 화면 보기](01-screens/CP67.png)

- 진입: 상세 최초 조회 중, 기존 데이터 없음
- 행동: 뒤로→호출자; 완료→같은 크루의 실제 역할·상태.
- 지킬 조건: 그림·인원·목표 진행률을 가짜로 채우지 않는다. 스켈레톤/주 버튼 비활성. 재조회 중 기존 값이 있으면 유지.

## CP68 · 레벨 조회 실패

[단일 화면 보기](01-screens/CP68.png)

- 진입: 공개 상세는 있으나 레벨 조회만 실패
- 행동: 다시 불러오기→레벨 재조회; 닫기→상세.
- 지킬 조건: 다른 공개 정보는 유지. 레벨0 또는 새 크루로 바꿔 표시하지 않는다. 실제 API가 이 오류를 구분할 때 적용.

## CP70 · 다른 크루 상세

- 진입: 해뜨런 상세 예시
- 행동: CP08과 같은 행동을 해당 크루와 서윤의 ID로 실행.
- 지킬 조건: 대표 이미지·Lv12·18/24·여의도·06:00·162/200=81%가 함께 바뀐다. 퇴근런의 준호/목표를 섞지 않는다.

## CP71 · 위치 사용 선택

[단일 화면 보기](01-screens/CP71.png)

- 진입: 현재 위치 사용을 사용자가 선택, 권한 안내 필요
- 행동: 위치 사용하기→필요한 OS 권한 요청/위치 확인; 지역 직접 검색→CP03; 닫기→호출자.
- 지킬 조건: 앱 설명 시트와 OS 권한 창은 별개. 권한이 이미 있으면 불필요한 안내 반복 금지. 거부 시 수동 검색 유지.

## CP72 · 지역 검색 결과 없음

[단일 화면 보기](01-screens/CP72.png)

- 진입: 지역 검색 정상 응답, 해당 검색어 결과 없음
- 행동: 검색어 수정/지우기→CP03; 현재 위치→CP71 또는 허용 위치 조회; 뒤로→호출자.
- 지킬 조건: 지역 검색 없음과 모집 크루 없음 CP05를 구분. 검색어 보존.

## CP73 · 방문자용 더보기

[단일 화면 보기](01-screens/CP73.png)

- 진입: 방문자 또는 대기자의 상세 더보기
- 행동: 멤버 보기→CP12; 신고→기존 CP64; 닫기→상세.
- 지킬 조건: 탈퇴·내보내기·운영 설정 없음. 신고 후 CP65 등 후속은 기존 기능 보존, 이번 새 시안에는 미포함.

## CP82 · 이번 주 목표 참여 멤버

- 행동: 공개 멤버 행→기존 CP56; 뒤로→CP13; 목록 스크롤.

## CP87 · 승인 후 내 크루 상세

- 행동: 크루 멤버 보기→CP12의25명; 더보기→기존 CP60; 하단 활동→CP94.

## CP91 · 크루 목록 로그인 필요

[단일 화면 보기](01-screens/CP91.png)

- 진입: 인증이 필요한 크루 목록
- 행동: 로그인→기존 인증→목록 재조회; 모집하기 보조 행동→인증 후 기존 생성 진입.
- 지킬 조건: 로그인 없이 비어 있는 크루 목록처럼 표시하지 않는다. 기록·장비·보상 및 기존 초안 보존. 로그인과 큰 모집 CTA 중복 금지.

## CP92 · 바로 가입 크루 상세

[단일 화면 보기](01-screens/CP92.png)

- 진입: 기존 openJoin 크루·방문자·모집 중·자리 있음
- 행동: 바로 가입하기→기존 가입 요청→멤버 확인 후 CP87; 실패 CP93.
- 지킬 조건: 신청 작성·대기 단계를 추가하지 않는다. 응답이 대기/미승인을 반환하면 해당 실제 상태로 이동. 인원은 서버 값.

## CP93 · 바로 가입 실패

## CP94 · 멤버 상세 하단 연결

## CP95 · 모집 목록 하단 기존 모임 연결

[단일 화면 보기](01-screens/CP95.png)

- 진입: 모집 목록 끝까지 스크롤
- 행동: 번개 모임·같이 달리기 보기→기존 모임 경로; 모집하기→기존 생성 진입; 카드 버튼은 CP01과 같음.
- 지킬 조건: 새 화면/탭이 아니다. 필터 줄은 화면처럼 상단 고정, 목록 내용만 스크롤. 마지막 카드를 고정 예시로 삽입하지 않는다.
