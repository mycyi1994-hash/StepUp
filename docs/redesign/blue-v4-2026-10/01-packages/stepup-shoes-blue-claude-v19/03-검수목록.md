# 구현 검수 목록

아래는 Claude가 구현 후 체크할 목록이다. 현재 체크되지 않은 상태이며, 앱 실행 검증을 했다는 의미가 아니다.

- [ ] 공식 원본 로고를 유지한다.
- [ ] 기존 내 신발/보관함 구조와 순서를 유지한다.
- [ ] 실제 이름·등급·레벨·번호·착용 신발을 표시한다.
- [ ] 목록 선택만으로 착용이 바뀌지 않는다.
- [ ] 같은 모델의 다른 소유ID가 섞이지 않는다.
- [ ] 효율·착화감·내구도 수치와 바 길이가 실제 함수값과 일치한다.
- [ ] 선택 테두리와 착용 체크가 구분된다.
- [ ] 정렬·필터·관리·도감·마켓·아이템이 기존 경로로 동작한다.
- [ ] 공통 다섯 하단 탭과 채운 SUP 버튼이 유지된다.
- [ ] 로딩·실패·빈 목록·그림 없음이 구분된다.
- [ ] 320~390dp 폭과 큰 글씨에서도 필요한 기능에 접근할 수 있다.
- [ ] 밝은 테마 기능을 깨뜨리지 않는다.
- [ ] 현재 저장소가 요구하는 빌드·검사와 실제 앱 캡처를 확인한다.
- [ ] 미연동 또는 미검증 상태는 완료로 표시하지 않는다.

시안 제작 방식: built-in imagegen. 이미지 자체의 글자/구성/상태를 검수했다. 실제 구현, 테스트, Figma 분리는 이 전달본에서 수행하지 않았다.
