# 신발탭 화면과 동작

| 화면/상태 | 누르는 곳 | 동작 |
|---|---|---|
| 내 신발 | 보유 목록 신발 | 해당 소유ID 선택, 착용은 유지 |
| 내 신발 | 현재 상세/관리 진입 | 선택한 신발의 기존 상세/관리 |
| 내 신발 | 신발 보관함 | 현재 보유 목록, 정렬/필터 유지 |
| 보관함 | 내 신발 | 선택 상태를 유지하며 원래 탭으로 |
| 보관함 | 정렬 | 기존 최근 획득/등급/레벨 정렬 선택 |
| 보관함 | 등급 필터 | 실제 보유 신발에서 해당 등급 필터 |
| 보관함 | 카드 | 기존 선택/상세 동작, 자동 착용 금지 |
| 보관함 | 도감/마켓/아이템 | 각각 기존 경로 |
| 공통 | SUP 잔액 | 기존 지갑 |
| 공통 | 하단 다섯 탭 | 기존 앱 탭으로 이동 |
| 조회 중 | 콘텐츠 | 미확정 수치는 — 또는 기존 로딩 처리 |
| 조회 실패 | 다시 불러오기 | 기존 조회 재시도, 빈 목록으로 취급하지 않음 |
| 실제 빈 목록 | 신발 뽑기 | 기존 뽑기 화면으로 이동, 즉시 지급하지 않음 |
| 그림만 없음 | 다시 불러오기 | 아트 재조회, 실제 이름과 능력치 유지 |

두 PNG는 기본 데이터 상태다. 로딩·실패·빈 목록 등은 현재 구현을 유지하며 동일한 색 토큰을 적용한다. 그 상태의 별도 리메이크 PNG는 이번 소규모 전달본에 포함되지 않았다.
