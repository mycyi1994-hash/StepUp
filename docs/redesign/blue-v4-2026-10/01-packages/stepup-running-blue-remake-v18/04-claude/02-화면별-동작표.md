# StepUp 화면별 진입과 동작

109개 시안이 열리는 조건과 버튼 동작을 대응시킨다. 모든 화면은 01-screens의 같은 ID PNG와 연결된다. 이 표는 구현 지침이며 현재 앱에서 각 동작이 이미 연결됐다는 뜻은 아니다.

공통 뒤로는 진입 화면과 해당 선택 상태를 복원한다. 운동 중에는 종료 확인 또는 일시정지를 거쳐 기록을 보존한다. 삭제·폐기·전송은 명시적 버튼을 눌렀을 때만 실행한다.

‘기존’으로 표시한 목적지는 현재 앱의 경로를 연결한다. 새 route 이름을 이 표의 ID로 강제하지 않는다. 각 실제 파일/route/상태는 implementation-checklist.csv에 적는다.
