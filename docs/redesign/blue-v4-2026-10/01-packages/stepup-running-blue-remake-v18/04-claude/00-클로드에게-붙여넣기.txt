StepUp의 승인된 남색·파랑 시안을 기존 앱에 적용해줘.

첨부 ZIP을 푼 폴더에서 04-claude/01-구현지시서.md를 먼저 읽고, 02-화면별-동작표.md와 03-검수목록.md를 함께 따라줘. 실제 구현 대상 저장소의 AGENTS.md와 현재 작업 상태도 확인해줘. 다른 checkout으로 옮기거나 기존 변경을 지우지 마.

러닝은 01-screens의 109개 화면·상태를 모두 대응해줘. 109개의 독립 페이지를 새로 만드는 것이 아니라, 현재 화면·공통 컴포넌트·모달·상태 분기로 구현해줘. 로고와 계정·기록·보상·위치·저장 로직은 보존해줘. 기존 헤더·하단 탭·라우팅 정책을 재사용하고 별도 웹페이지는 만들지 마.

신발탭은 04-claude/reference/shoes-blue.png의 색감과 조명만 참고해줘. 현재 신발탭의 구도·보관함·능력치·정렬·필터·선택/착용 구분은 그대로 유지해줘. 시안에서 빠졌다는 이유로 기존 기능을 삭제하지 마.

지도는 실제 앱의 지도 타일·경로·위치 데이터를 연결하고, 시안의 지도 그림과 예시 숫자를 실제 데이터로 넣지 마. 글자·숫자·버튼·입력창·탭·상태바는 네이티브 Compose로 구현해줘. PNG 한 장을 깔고 투명 버튼을 올리는 방식은 쓰지 마.

문서에 제안값으로 표시한 크기·간격은 현재 앱과 실제 기기에서 조정해줘. 기존 API가 없는 기능은 구현된 것처럼 꾸미지 말고, 연결된 기능과 남은 연동을 구분해줘. 모호하지 않은 시각 작업과 이미 승인된 기능 연결은 계속 진행해줘.

구현은 공통 스타일 → 자유 러닝 → 챌린지/코스/다이어트 → 기록/통계/권한/오류 → 크루 → 신발 색감 순으로 진행해줘. 각 구간마다 동일 소스 버전으로 빌드·검사·실제 앱 캡처를 남겨줘. 체크리스트는 실제 확인한 항목만 완료로 바꿔줘. 최종 보고에는 변경 파일, 실제 캡처, 실행한 검사, 남은 연동을 포함해줘.
