# 화면별 진입·버튼·복귀

44개 정적 상태. 번호는 새 경로 수가 아니다. 예시 수치를 서비스 정책으로 사용하지 않는다.

## CHAT01 · 커뮤니티 · 크루 채팅

[단일 화면](01-screens/CHAT01.png)

- 진입: 커뮤니티의 크루 채팅 탭·가입 방 있음
- 행동: 방 행→해당 crewId의 CHAT02/03/30; 다른 글자 탭·하단5탭은 기존 진입 유지.
- 조건: 퇴근런24명과 공덕한바퀴1명은 비교용 독립 방. 새 크루/읽지 않은 수/최근 대화는 서버 상태 사용.

## CHAT02 · 크루원 · 실시간 대화

[단일 화면](01-screens/CHAT02.png)

- 행동: 더보기→CHAT04; 공지→CHAT08; 프로필→CHAT07; 길게 누름→CHAT14/15; 사진→CHAT25.
- 조건: 도윤 본인만 오른쪽. 관리 메뉴·전역 하단 탭 없음. 기존 호출자로 뒤로 이동.

## CHAT04 · 크루원 · 채팅방 정보
