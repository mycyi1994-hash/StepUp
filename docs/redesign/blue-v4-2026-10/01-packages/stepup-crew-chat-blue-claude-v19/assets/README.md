# 자산 재사용

STEPUP-원본로고.png는 이전 전달본의 원본을 그대로 복사했다. crew-examples는 이전 크루 전달본의 예시 대표 이미지와 SVG다. 사용자가 정한 실제 대표 이미지를 우선한다. 공덕한바퀴의 개별 청록 그림은 이 패키지에 분리 원본이 없으므로 임의로 PNG에서 잘라 실제 사용자 이미지로 사용하지 않는다. 기존 실제 대표 이미지 또는 기존 기본 이미지를 사용한다.

버튼·아이콘·텍스트·말풍선·모달은 앱의 실제 컴포넌트로 구현한다. 생성 PNG는 화면 비교용이며 편집 가능한 레이어나 완성된 앱 코드가 아니다.
