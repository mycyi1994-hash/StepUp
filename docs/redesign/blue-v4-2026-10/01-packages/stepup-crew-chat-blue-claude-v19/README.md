01-screens는 새44장,02-shared-reference는 기존 크루7장 참고다. 참고7장을 새 제작 수에 더하지 않는다. 로고와 대표 이미지 예시는 assets에 있다. 사용자의 실제 크루 이미지·이름·데이터를 예시로 덮지 않는다.

CHAT02는r2,CHAT16은r3,CHAT25/27은r2,그 밖에는r1을 사용한다. 번호는 시각 상태이므로44개 경로를 새로 만들지 않는다. 크루장/크루원과 전송/실패/확인창을 같은 컴포넌트의 상태로 구현한다.

전체 앱 리메이크는 진행 중이다. 이 묶음만으로 로그인/로딩/모임 선택/캐시 갱신/기기 키보드까지 전부 완료됐다고 판단하지 않는다.
