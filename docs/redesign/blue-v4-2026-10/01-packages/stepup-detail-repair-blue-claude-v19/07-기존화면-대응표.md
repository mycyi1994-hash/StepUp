# 기존 신발 상세와 대응

최신 상세 네 행을 기준으로 오래된 화면을 대체하거나 유지한 위치다. 전체104개 앱 경로의 완료 보고가 아니다.

| 기존 화면 | 이번 연결 | 해석 |
|---|---|---|
| 01-owned-shoes-entry | SH01/SH02 | 별도 신발탭 전달본 |
| 02-shoe-detail | SD01 | 네 독립 한줄 바의 최신 상세로 대체 |
| 03-equipped-detail | SD02 | 등급·번호를 보존한 착용 상태 |
| 04-all-stats / 05-stat-explanation | SD01 | 이전 별도 능력치 시트를 본문4행으로 대체. 제거된 속성 복원 안 함 |
| 06-shoe-information | SD15/16/17 | 체인 정보를 관리의 신발 기록으로 유지 |
| 07-owned-copies / 08-another-copy | SH02 / SD01 | 현재 보관함에서 소유 ID별 상세 진입. 선택만으로 착용 변경 없음 |
| 09-equipping / 10-equipped-success | SD03/04 | 요청 중과 실제 착용 확인 분리 |
| 11-equip-error | SD05/06/07/10 | 거절·로그인·미확인·소유 없음 구분 |
| 12-inventory-after-equip | SH01/SH02 | 별도 목록이 실제 착용 ID를 갱신하는 상태 |
| 13-detail-loading / 14-detail-load-error | SD08/09 | 로딩과 실패 분리 |
| 15-shoe-not-found / 16-art-load-error | SD10/11 | 소유 없음과 아트만 실패 분리 |
| 17-first-equipment | SD12 | 첫 소유 신발도 명시적 착용 |
| 18-empty-inventory | 추가 제작 대상 | 이 전달본의 상세 오류로 빈 보관함을 대체하지 않음 |
| 현재 관리 / 강화·수리 후 상세 | SD13/14/18/19 | 기능 진입과 미확정 작업 복귀 |
| 수리 진입 시안3개 중 간편 확인 구조 | RP01~11 | 최종1개 구조를 확인·처리·완료·경계 상태로 확장 |

판매·도감·마켓·아이템과 보관함 추가 상태는 별도 범위에 남아 있다. 기존 버튼과 경로는 유지한다.
