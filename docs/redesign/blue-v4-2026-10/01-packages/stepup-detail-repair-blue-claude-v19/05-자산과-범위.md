# 자산과 전달 범위

이 폴더에는 신발 상세19장과 수리11장의 정적 PNG, 화면별 동작표, 데이터 기준, 현재 코드 차이와 검수 목록이 들어 있다. references의 내 신발과 강화 준비 화면은 색과 연결을 이해하는 보조 자료다. assets의 STEPUP 원본 로고는 상위 공통 화면에서 원본 유지 여부를 확인하는 용도다.

최종 시안은 images 안의 이름으로 사용한다. 제작 중 잘못된 배지·잘린 모달·오탈자가 있던 중간 이미지는 포함하지 않는다. prompts에는 수정 과정의 프롬프트도 보존되어 있으며 최종 파일은 screen-index.json으로 구분한다.

## 실제 구현 자산

원본 신발 아트, 등급 프레임과 배경은 기존 앱 자산을 재사용한다. 생성된 화면에서 신발을 잘라 저해상도 원본으로 대체하지 않는다. 이번 폴더에는 새 원형 받침·조명·프레임의 독립 투명 레이어가 포함되지 않는다. 필요한 표현은 기존 무대 컴포넌트에 적용하거나 별도 제작 자산으로 명시한다.

글자·숫자·진행바·버튼·모달·스크림은 네이티브 Compose 요소다. 전체 PNG를 화면으로 깔고 투명 버튼을 얹는 방법은 사용하지 않는다. 새 HTML 페이지나 웹뷰 데모도 만들지 않는다. Figma 레이어, 동작하는 앱, 새 API, 애니메이션이 이미 제공됐다고 보고하지 않는다.

## 다른 전달본과 관계

신발탭 색감 변경 전달본은 내 신발과 신발 보관함 구조를 유지하는 기준이다. 강화17장 전달본은 강화 독립 페이지·하위 등급 재료3개·실패 소각과 보정 규칙을 다룬다. 본 전달본은 그 화면으로 가는 연결을 제공한다. 이미 삭제한 확률 설명 화면을 만들지 않는다.

판매 절차·보관함의 빈 목록과 정렬·도감·마켓·아이템은 이30장에 포함되지 않는다. 전체 리메이크 작업에서는 계속 남아 있는 범위다. 여기서 기존 진입을 제거하거나 전체 신발 기능이 완료됐다고 처리하지 않는다.

이미지는 대부분853×1844px이고 SD06만853×1843px다. 한 픽셀 차이를 앱 크기 차이로 구현하지 않는다. 시스템 상태표시와 홈 표시줄은 OS 및 공통 안전 영역을 따른다.
