# StepUp 코스 글쓰기 · 파란 톤 전달본

새 시안 **WRITE01~WRITE20 20장**과 클로드 구현 지시서다. 기존 커뮤니티 기본 43장 전달본에 이어서 적용한다.
16장의 공통 화면은 `02-shared-reference/`에 연결 참고용으로 복사했다. 새로 만든 20장에 중복 집계하지 않는다.

- 시작: [Claude 구현 지시서](Claude-구현지시서.md)
- 화면별 진입·버튼·예외: [화면별 동작](화면별-동작.md)
- 시안: `01-screens/WRITE01.png` ~ `WRITE20.png`
- 연결/데이터: `flow-map.json`, `screen-index.json`, `fixtures.json`
- 공통 색·구성: `design-tokens.json`, `assets/STEPUP-원본로고.png`
- 눈으로 확인한 검수: `audit/visual-review.json`
- 생성 프롬프트: `prompts/` (내장 이미지 생성 도구 사용, 로컬 참조 경로는 제작 이력)

정적 PNG와 구현 명세다. 앱 구현 완료본, 실행 테스트 결과, 편집 가능한 Figma 구성요소, 분리된 지도/버튼 이미지가 아니다.
앱의 글자·버튼·지도는 실제 컴포넌트와 데이터로 구현한다. 시안 전체를 이미지 한 장으로 넣지 않는다.

이번 묶음 밖의 크루·채팅·내 정보 및 전체 경로 누락 감사는 계속 진행 중이다. 전체 리메이크 완료본이 아니다.
