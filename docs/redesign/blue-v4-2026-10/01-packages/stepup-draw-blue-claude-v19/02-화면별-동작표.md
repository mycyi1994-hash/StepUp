# 화면별 동작표

모든 버튼은 실제 현재 상태를 재확인한다. 시트의 닫기·뒤로는 상태를 보존한다. 조건부 장면은 서비스 근거가 있을 때만 연결한다.

| 화면 | 진입 | 주요 동작 | 보조·복귀 | 주의점 |
|---|---|---|---|---|
| [DRAW00 내 신발에서 진입](images/DRAW00.png) | 신발탭 | 하단 뽑기 → DRAW01/02 등 서버 상태에 맞는 메인 | 다른 탭은 기존 동작 | SH01 재사용. 예전 상단 뽑기 버튼을 다시 만들지 않는다. |
| [DRAW01 지갑 연결 전](images/DRAW01.png) | 뽑기 탭·미연결 최초 회원 | 무료 1회 → DRAW10 / 지갑 연결 → DRAW06 | 무료 내역 → DRAW03 / 기회 받는 방법 → DRAW05 | 미연결 10회는 받을 수 있는 선물이며 보유 수가 아니다. |
| [DRAW02 연결된 메인](images/DRAW02.png) | 뽑기 탭·횟수 있음 | 각 종류 1회 → DRAW10 | 각 내역 → DRAW03/04 / 안내 → DRAW05 | 두 패널을 동시에 표시한다. |
| [DRAW03 무료 기회 내역](images/DRAW03.png) | 무료 패널 기회 내역 | 무료 1회 → DRAW10 | 닫기·X·뒤로 → 원래 메인 / 기회 받는 방법 → DRAW05 | 가입 잔여+오늘 잔여 합계. 불가 상태에서는 뽑기 비활성. |
| [DRAW04 상급 기회 내역](images/DRAW04.png) | 상급 패널 기회 내역 또는 다음 거리 | 상급 1회 → DRAW10 | 닫기 → 원래 메인 / 안내 → DRAW05 | 연결 선물 잔여+러닝 잔여. 서버 진행 거리. |
| [DRAW05 기회 받는 방법](images/DRAW05.png) | 메인 또는 내역의 안내 | 확인 → 호출한 화면 | X·뒤로 동일 | 회원에게 해당되는 규칙만 서버 값으로 표시한다. |
| [DRAW06 지갑 연결 혜택](images/DRAW06.png) | 미연결 패널 연결 버튼 | WEB3 지갑 연결 → 기존 연결 페이지 | 나중에·닫기 → 원래 메인 | 외부 앱/페이지를 열기 전 기존 LinkWatch 기준 저장. |
| [DRAW07 지갑 연결 대기](images/DRAW07.png) | 연결 시스템에서 실제 진행 이벤트를 제공할 때 | 지갑 다시 열기 → 기존 연결 페이지 | 취소 → 시트 닫기 후 서버 상태 갱신 | 조건부 시안. 현행 DrawViewModel에는 진행 이벤트가 없다. 타이머로 꾸며내지 않는다. |
| [DRAW08 연결·선물 확인 완료](images/DRAW08.png) | 서버 연결과 선물 증가 모두 확인 | 상급 1회 → DRAW10 | 뽑기 화면으로·닫기 → DRAW02 | 첫 연결 추가량만 +N. 재연결에는 이 선물 시트를 띄우지 않는다. |
| [DRAW09 연결 실패](images/DRAW09.png) | 연결 시스템에서 명시적 실패가 확인될 때 | 다시 연결 → 기존 연결 페이지 | 나중에·닫기 → DRAW01 또는 DRAW24 | 조건부 시안. 단순 복귀·닫기·지연을 실패로 판단하지 않는다. |
| [DRAW10 뽑기 요청 결과 대기](images/DRAW10.png) | 사용 가능한 1회 버튼 | 별도 실행 버튼 없음 | 뒤로 → DRAW26, 요청 보존 | 중복 요청 차단. 확정 후 DRAW11, 거절 DRAW19/31, 불명 DRAW20. |
| [DRAW11 상자 열기](images/DRAW11.png) | 서버 신발 결과 확정 | 약 2초 후 DRAW12/13/14/33 | 건너뛰기·뒤로 → 같은 확정 결과 | 정적 키프레임. 연출 중 서버 뽑기를 다시 요청하지 않는다. |
| [DRAW12 무료 결과](images/DRAW12.png) | 무료 신발 확인, 잔여>0 | 내 신발 보기 → DRAW21 | 한 번 더 → 조건 재확인 후 DRAW10 / 뒤로 → 메인 | 받은 소유 ID로 선택만 한다. |
| [DRAW13 상급 결과](images/DRAW13.png) | 상급 신발 확인, 잔여>0 | 내 신발 보기 → DRAW21 | 한 번 더 → 조건 재확인 후 DRAW10 / 뒤로 → 메인 | 상급은 특정 등급 당첨 보장이 아니다. |
| [DRAW14 마지막 기회 결과](images/DRAW14.png) | 결과 확인, 해당 종류 잔여=0 | 내 신발 보기 → DRAW21 | 뽑기 화면으로 → 서버 상태별 메인 | 한 번 더 뽑기를 표시하지 않는다. 상급에도 같은 결과 컴포넌트. |
| [DRAW15 무료·상급 모두 소진](images/DRAW15.png) | 실제 두 잔여=0 | 무료 안내 → DRAW16 / 러닝 → DRAW17 | 각 내역·규칙·하단 탭 | 0회 안내 버튼은 누를 수 있다. |
| [DRAW16 무료 소진 안내](images/DRAW16.png) | 무료=0 안내 버튼 | 확인 → 메인 | 상급 뽑기 보기 → 메인의 상급 패널로 스크롤·포커스 | 무료/상급 글자 탭을 새로 만들지 않는다. 미제공 갱신 시간은 쓰지 않는다. |
| [DRAW17 러닝으로 상급 받기](images/DRAW17.png) | 연결됨·상급=0 | 러닝 시작 → 기존 자유 러닝 진입 | 닫기·X·뒤로 → 메인 | 여기서 거리를 쌓거나 기회를 지급하지 않는다. |
| [DRAW18 러닝 기회 반영](images/DRAW18.png) | 같은 계정에서 서버 runLeft 증가 확인 | 상급 1회 → DRAW10 | 토스트 약 3.2초 후 닫힘 | 처음 조회한 수를 신규 지급으로 알리지 않는다. |
| [DRAW19 미사용 확정 실패](images/DRAW19.png) | 서버 거절 또는 미시작 확인 | 재시도 가능한 사유일 때만 다시 뽑기 → DRAW10 | 닫기 → 메인 | 타임아웃은 이 장면이 아니라 DRAW20. |
| [DRAW20 결과 확인 지연](images/DRAW20.png) | 요청 결과 불명 | 결과 다시 확인 → 같은 pending 조회 | 뽑기 화면으로·뒤로 → DRAW26 | 조회 중 버튼 비활성. 응답 후 상태 전환. 새 draw 호출 금지. |
| [DRAW21 보유 목록에서 받은 신발](images/DRAW21.png) | 결과의 내 신발 보기 | 받은 ID 선택, 관리·상세는 기존 경로 | 보관함·다른 소유 카드·하단 탭 | 새 신발 선택이 기존 착용 ID를 바꾸지 않는다. |
| [DRAW22 횟수 로딩](images/DRAW22.png) | 상태 조회 중 | 두 뽑기 버튼 비활성 | 하단 탭은 기존 동작 | 수는 —. 내역/규칙은 데이터 확인 전 노출하지 않는다. |
| [DRAW23 횟수 로딩 실패 시트](images/DRAW23.png) | 상태 조회 실패 | 다시 불러오기 → DRAW22 | 내 신발로 → SH01 / X·뒤로 → DRAW32 | 소진과 구분. |
| [DRAW24 기존 지갑 재연결](images/DRAW24.png) | 연결 이력 있음·현재 미연결 | 지갑 다시 연결하기 → 기존 연결 페이지 | 무료·내역·규칙은 현재 상태대로 | 보유 상급 수 유지, 재연결 선물 재지급 금지. |
| [DRAW25 연결 완료·선물 확인 중 시트](images/DRAW25.png) | 연결 성공과 지급 대기를 구분하는 권위 있는 상태가 있을 때 | 지급 상태 확인 → 상태 조회 | 뽑기 화면으로·닫기 → DRAW27 | 조건부 시안. 연결됨+gift0만으로 미지급을 추정하지 않는다. |
| [DRAW26 미확인 결과가 있는 메인](images/DRAW26.png) | 진행 중 뒤로·재실행 | 두 패널 모두 결과 확인 → DRAW20 또는 확정 결과 | 다른 탭 이동 시에도 pending 보존 | 다른 종류의 새 뽑기도 막는다. |
| [DRAW27 연결 선물 확인 중 메인](images/DRAW27.png) | DRAW25 닫기·동일한 명시적 대기 상태 | 지급 상태 확인 → 상태 조회 | 무료 뽑기는 실제 가능 여부에 따라 허용 | 조건부 시안. 프런트가 10회를 임의 지급하지 않는다. |
| [DRAW28 로그인 전](images/DRAW28.png) | 인증 없음 | 로그인하고 뽑기 → 기존 로그인 | 하단 탭 기존 동작 | 서버 미설정 빌드에서는 비활성 안내. 이 폰의 기록·장비 삭제 금지. |
| [DRAW29 상급 일시 중단](images/DRAW29.png) | 서버 chainPaused | 상급 버튼 비활성, 무료는 실제 가능하면 유지 | 내역·규칙 | 기존 보유 횟수 유지. |
| [DRAW30 하루 러닝 지급 한도](images/DRAW30.png) | 서버 runCapReached | 보유 상급 기회가 있으면 1회 뽑기 | 닫기·X·뒤로 → 메인 | 오늘 추가 지급 중단이지 보유 기회 사용 중단이 아니다. |
| [DRAW31 발행 한도](images/DRAW31.png) | 서버 MintLimitReached 거절 | 확인 → 메인 | X·뒤로 동일 | 재시도 CTA 없음. 기회 미사용 확정. 안내 문구는 서버 규칙에 맞춘다. |
| [DRAW32 실패 후 메인](images/DRAW32.png) | DRAW23 닫기·조회 실패 유지 | 두 다시 불러오기 → 상태 조회 | 하단 탭 | —는 미확인이다. 실제0으로 치환하지 않는다. |
| [DRAW33 결과 확정·남은 횟수 미확인](images/DRAW33.png) | 새 신발은 받았지만 횟수 재조회 실패 | 내 신발 보기 → DRAW21 | 뽑기 화면으로 → 상태 재조회 | 신발 성공은 유지. 남은 수는 확인 중, 한 번 더는 숨김. |
