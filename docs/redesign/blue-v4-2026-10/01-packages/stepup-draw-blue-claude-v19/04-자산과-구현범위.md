# 자산과 구현 범위

## 전달된 것

- images/DRAW00.png~DRAW33.png: 상태별 정적 PNG 34장.
- assets/STEPUP-원본로고.png: 원본 로고.
- 구현 지시서, 화면별 동작, 검수목록, 코드 상태 대응표, 생성 근거와 파일 해시.
- DRAW00은 현재 신발탭 SH01 재사용이다. DRAW07/09/25/27은 조건부 서비스 상태 참고다.

## 앱에서 재사용할 것

공통 원본 로고와 아이콘, 실제 모델별 신발 원본, 실제 등급 프레임, 기존 폰트·시스템 영역·지갑 연결 경로를 사용한다. 시안에서 신발을 잘라 모델 자산을 교체하지 않는다.

현재 앱의 상자 자산은 다음 위치에 있으나, 기존 색과 새 시안은 다를 수 있다.

- res/drawable-nodpi/draw_box_closed_free.webp
- draw_box_closed_premium.webp
- draw_box_lid.webp
- draw_box_lid_premium.webp
- draw_box_body.webp
- res/raw/draw_box_open.wav

새 시안대로 상자 모양까지 교체하려면 무료/상급 닫힌 상자, 각각 뚜껑·몸통, 받침과 그림자를 같은 투시·원점·크기로 제작해 넣어야 한다. 이번 ZIP에 그 분리 파일은 들어 있지 않다. 기존 자산을 사용한 임시 화면을 최종 아트 완성으로 보고하지 않는다.

## 실제 UI로 만들 것

모든 글자·숫자·배지·탭·버튼·바·스피너·딤·선택 체크를 네이티브 UI로 만든다. 상자의 표면 로고는 원본 워드마크를 적용한다. PNG 전체를 클릭 가능한 화면처럼 붙이지 않는다.

시안에 남아 있는 경미한 글자 간격, 단위, 배지 줄바꿈, 뒤로 화살표·닫기 X의 위치 차이는 공통 컴포넌트로 통일한다. 로그인 전 숫자는 한 개의 —만 표시한다. 확인 가능한 상태에서는 공통 “기회 받는 방법” 접근을 유지한다. 시안별 장식을 별도 컴포넌트로 복제하지 않는다.

34장은 34개의 새 앱 경로를 뜻하지 않는다. 하나의 뽑기 화면과 공통 시트·결과 컴포넌트의 상태 조합이다. Figma 레이어, 최종 애니메이션 영상, 앱 코드 변경, 실제 기기 검사 결과는 포함되지 않는다.
