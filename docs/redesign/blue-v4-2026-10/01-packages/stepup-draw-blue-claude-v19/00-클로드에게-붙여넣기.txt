첨부 폴더의 01-구현지시서.md, 02-화면별-동작표.md, 03-검수목록.md, 04-자산과-구현범위.md를 읽고 기존 StepUp Android 앱의 뽑기 화면을 수정해줘.

최종 기준은 남색·전기 파랑·청록·흰색의 두 패널 디자인이야. 무료/상급 글자 탭으로 되돌리지 말고 두 뽑기 칸을 동시에 보여줘. 기존 STEPUP 원본 로고, 실제 신발 자산과 보유 데이터, 서버 뽑기·지갑·횟수·결과 확인 규칙을 유지해줘.

이미지 번호는 DRAW00~DRAW33이며 34개 상태 참고야. 그림을 배경으로 붙이지 말고 텍스트·버튼·숫자·탭·진행바를 실제 UI로 구현해줘. 숫자는 모두 예시이며 실계정에 고정하지 마.

DRAW07/09/25/27은 현재 코드가 그 상태를 직접 제공하지 않아 조건부로 분리해놨어. 타이머나 앱 복귀만으로 진행·실패·선물 지급 대기를 꾸며내지 말고 현재 연결 서비스가 확인할 수 있는 상태만 연결해줘.

새 신발을 보유 목록에서 선택해도 자동 착용하면 안 돼. 미확인 뽑기 요청이 있으면 무료·상급 모두 새 요청을 막고 기존 요청 결과만 확인해줘.

먼저 기존 변경 사항과 관련 코드를 확인하고, 공통 스타일 → 메인 두 패널 → 안내창 → 결과/상자 열기 → 오류/미확인 상태 순으로 적용해줘. 시안에 미세하게 다른 버튼 모양·글자 간격은 문서의 공통 컴포넌트 기준으로 통일해줘.

마지막에 변경 파일, 실제 앱 캡처, 수행한 검사, 아직 없는 자산이나 연결되지 않은 조건부 상태를 보고해줘. 이 전달물은 정적 시안과 구현 지시서이고 앱 구현 완료본이 아니야.
