# 강화 화면별 동작

17개 이미지가 모두 별도 경로는 아니다. 강화 한 화면의 상태들과 재료/확인/오류 시트로 구현한다.

| 시안 | 형태 | 진입 | 버튼/다음 상태 | 조건 |
|---|---|---|---|---|
| [UP01](images/UP01.png) | 독립 강화 화면 · 재료0개 | 상세의 강화하기 | + → UP10/UP02; 뒤로 → 진입한 신발 상세 | 3개 미만 실행 비활성. 선택만으로 소각하지 않음 |
| [UP02](images/UP02.png) | 재료 선택 시트 · 정상 | 빈 슬롯 + 또는 재료 변경 | 선택한3개넣기 → UP03; 1~2개넣기 → 부분선택; 닫기 → 진입전 선택 | 임시 선택과 적용된 선택을 분리. 네 번째 선택 불가 |
| [UP03](images/UP03.png) | 독립 강화 화면 · 재료3개 | 선택3개 적용과 견적 확인 | 강화하기 → UP04; X → 부분선택 | 최종 확률과 재료 상태를 확인한 뒤 활성화 |
| [UP04](images/UP04.png) | 최종 확인 시트 | UP03 강화하기 | 취소/닫기 → UP03; 강화 시작 → 검증 후 UP05 | 이 단계만 서버 변경 요청. 중복 탭 방지 |
| [UP05](images/UP05.png) | 독립 강화 화면 · 처리중 | 요청 전송 또는 접수 후 | 확정 성공 → UP06; 확정 실패 → UP07; 불확실 → UP15; 나중에 → 상세 대기 | 타이머로 성공/실패/소각을 만들어내지 않음 |
| [UP06](images/UP06.png) | 독립 강화 화면 · 성공 | 서버의 확정 성공 | 신발상세보기 → 최신 상세; 다음레벨강화 → UP01 | 재료는 비움. Lv20이면 UP13으로 |
| [UP07](images/UP07.png) | 독립 강화 화면 · 확률 실패 | 서버의 확정 확률 실패 | 재료다시선택 → UP01; 신발상세보기 → 최신 상세 | 통신/검증 오류에는 이 상태 사용 금지 |
| [UP08](images/UP08.png) | 독립 강화 화면 · 재료2개 | 선택2개 적용 | + → UP02; X → 부분선택 | 78.4% 예시. 1개 선택은 같은 컴포넌트 상태 |
| [UP09](images/UP09.png) | 재료 선택 시트 · 없음 | 정상 조회 결과 적합 재료0개 | 보유신발보기 → SH02 보관함; 닫기 → 기존 강화 | 조회실패를 빈목록으로 간주하지 않음 |
| [UP10](images/UP10.png) | 재료 선택 시트 · 로딩 | 재료 조회 시작 | 성공 → UP02/UP09; 실패 → UP11; 닫기 → 이전 | 미확정 재료를 예시 값으로 채우지 않음 |
| [UP11](images/UP11.png) | 재료 선택 시트 · 오류 | 재료 조회 실패 | 다시불러오기 → UP10; 닫기 → 이전 | 기존 적용 선택 보존 |
| [UP12](images/UP12.png) | 사전 검증 오류 시트 | 선택 재료 사용불가 확인 | 다른재료선택 → UP02; 돌아가기 → 유효한 선택 유지 | 미접수/미소각이 확인된 경우. 무효 재료만 제외 |
| [UP13](images/UP13.png) | 독립 강화 화면 · 최대 | Lv20 도달/진입 | 신발상세보기 → 상세 | 신규 강화20상한. 기존 상한 초과 자산 수치 낮추지 않음 |
| [UP14](images/UP14.png) | 전송 전 연결 오류 시트 | 요청 미전송이 확실한 연결 오류 | 돌아가기 → UP03; 연결다시확인 → 견적 재확인 | 연결 복구만으로 자동 강화하지 않음 |
| [UP15](images/UP15.png) | 독립 강화 화면 · 결과 미확인 | 접수/결과 불명 또는 앱 재진입 | 결과다시확인 → 같은 요청 조회; 나중에 → 상세 대기 | 새 요청 키 생성/재소각 금지. 미확인 재료는 사용 제한 |
| [UP17](images/UP17.png) | 독립 강화 화면 · 하위등급 없음 | 도메인상 하위 등급이 없는 대상 | 다른신발보기 → SH02 보관함 | 같은등급을 자동 허용하지 않음. 실제 대상명 표시 |
| [UP18](images/UP18.png) | 독립 강화 화면 · 대상 거절 | 대상의 소유/사용 상태 사전 거절 | 보유신발보기 → SH02 보관함 | 미소각 확정에만 안내. 결과 불명은 UP15 |

SH02는 별도 신발탭 전달본의 보관함이다. 이 폴더에 보관함이나 신발 상세의 새 시안이 포함되었다는 뜻은 아니다.

UP01/03/08의 재료 상태는 하나의 선택 집합을 공유한다. 0/1/2/3개 선택은 모두 지원하며 1개 전용 이미지만 별도로 복제하지 않았다. 키보드 화면은 필요 없다. 계산 설명 UP16은 생성하지 않았으며 버튼·경로도 없다.
