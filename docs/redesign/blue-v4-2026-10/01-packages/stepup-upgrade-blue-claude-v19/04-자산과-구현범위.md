# 전달 자산과 범위

포함: 강화17개 상태 PNG, 원본 STEPUP 로고, 구현 지시서, 버튼 동작, 밸런스 JSON, 생성 프롬프트20건(원안17 + 대비보정3), 정적 검수 기록.

포함하지 않음: Figma 원본, 레이어로 분리된 신발/무대/효과, 실제 Compose 변경, 서버 변경, 실행 캡처, 앱 테스트, 신발 상세와 수리의 새 시안. 이 제한은 이번 강화 전달본의 범위이며 전체 리메이크 범위를 줄이지 않는다.

PNG는 통째로 앱 배경에 넣지 않는다. 글자·숫자·버튼·바·시트·scrim·잠금·체크는 네이티브 요소다. 신발은 실제 원본 아트를 사용한다.

현재 저장소의 재사용 위치:

- app/src/main/res/drawable-nodpi/shoe_1302.webp: 스태빌리티 트레이너.
- 같은 폴더의 shoe_1201.webp, shoe_1108.webp, shoe_1203.webp: 예시 재료 모델.
- ui/components/SneakerImage.kt의 SneakerGradeStage 및 shoe_grade_*: 실제 등급 무대.
- design/brand/: 원본 로고의 배경별 변형. 이 2차 화면에는 별도 브랜드 헤더를 추가하지 않는다.

조명과 받침의 시각 표현은 기존 무대 컴포넌트에 적용한다. 새 독립 비트맵이 필요하면 미제공 자산으로 기록하고 시안에서 잘라 사용하지 않는다. 일반 신발 경계 상태 UP17의 이름/아트는 실제 소유 데이터로 결정하며 새로운 카탈로그 모델을 발명하지 않는다.

생성 방식은 built-in imagegen이며 원본을 보존하고 프로젝트에 복사했다. prompts의 절대 경로는 생성 당시의 출처 기록이다. Claude 구현에 필요한 현재 기준은 images와 이 지시서이며 원래 로컬 생성 환경은 필요하지 않다.
