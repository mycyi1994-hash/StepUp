# 네이티브 표시 기준

같은 상태를 이미지별로 따로 구현하지 않는다. 부모화면은 공통 뒤로가기와 신발강화 제목이며, 하단 주요5탭은 이 독립 흐름에 새로 추가하지 않는다. 시스템 상태바와 안전영역은 OS 및 공통 정책이 담당한다.

본문: 실제신발/등급무대 → 재료3슬롯 → 성공시변화3행 → 성공률 → 소각안내 → 실행버튼. 기존 신발 상세의 네 행은 이 강화 미리보기와 별개다. 강화로 바뀌지 않는 내구도를 보상처럼 추가하지 않는다.

재료는 한 소유ID당 하나. 등급 배지 오른쪽에 소유번호를 유지하고 긴 이름은 줄바꿈한다. 슬롯과 시트 목록의 체크·개수는 같은 선택 상태에서 계산한다.

예시 바의 정확한 정규화 값:

| 항목 | 전 | 후 |
|---|---:|---:|
| 레벨 | 10/20=50% | 11/20=55% |
| 효율 | 18/27.5≈65.45% | 18.5/27.5≈67.27% |
| 착화감 | 8/20=40% | 8.2/20=41% |

이 표는 개발용이며 UI에 노출하지 않는다. 실패와 결과미확인에는 증가예정 구간을 표시하지 않는다. 기존 값과 예정값을 구분할 때 끝부분을 과장해서 다음단계의 이득이 실제보다 커 보이게 만들지 않는다.

각 능력치 행은 둥근배경 한 개다. 라벨·바·수치를 한 줄로 정렬하되 글자 확대 시 값 영역 높이를 늘려 겹침을 방지한다. 이미지 픽셀을 dp로 복사하지 않는다. 최소48dp 터치영역, 주요버튼56dp부터 검토한다.

재료시트는 화면 높이와 글자크기에 따라 스크롤하고 하단버튼이 목록을 가리지 않게 한다. backdrop은 공통 검정 scrim 약0.6을 시작점으로 사용하고 접근성 초점을 시트로 이동한다. 닫기는 임시 선택을 취소하고 이전적용상태로 복귀한다.

입체감은 주버튼/신발무대/바에 집중한다. 본문글자에 광원을 덧씌우지 않는다. 원본 등급색(일반중립/레어파랑/에픽보라/레전더리금색)을 보존한다. REDLINE/FINISH는 기존시리즈 의미를 보존한다.

선택/시트/수치전환은 짧게, 반복광은 기본정지. 성공 응답 뒤 수치전환 약320ms, 동작줄이기에서는 바로갱신한다. 진행률이나 성공률에 맞춰 가짜 대기시간을 만들지 않는다.
