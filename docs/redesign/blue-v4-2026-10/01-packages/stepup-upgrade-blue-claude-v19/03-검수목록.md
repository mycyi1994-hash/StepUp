# Claude 구현 후 검수

아래는 구현자가 수행할 체크리스트다. 이 전달본은 정적 시안만 검수했으며 앱 검사를 수행하지 않았다.

- [ ] 독립 강화 화면과 한 겹의 시트로 구성한다. UP16 계산 설명창/링크가 없다.
- [ ] 대상 이름·등급·번호·레벨과 실제 원본 아트가 일치한다.
- [ ] 서로 다른 소유ID의 하위 등급 재료만 최대3개 선택한다.
- [ ] 0/1/2개는 확률이100%여도 실행 불가, 3개 견적 확인 뒤만 실행 가능하다.
- [ ] 시트 닫기/취소/적용에서 임시 선택과 적용 선택의 차이가 유지된다.
- [ ] 예시 기본70%, 재료5.6+2.8+2.0%p, 최종80.4%와 부분선택78.4%가 맞는다.
- [ ] 레벨20/기존20초과/최하위등급/비지원/거래중/소유변경 조건을 실제 계약대로 처리한다.
- [ ] 성공·확률실패 모두 재료3개 소각, 사전 거절은 미소각, 불명 결과는 조회로 처리한다.
- [ ] 중복 탭·응답 유실·앱 종료/재시작에서 새 요청이나 중복 소각이 없다.
- [ ] 성공 후 상세/보유 목록 수치가 같고, 실패 시 대상 수치가 제안된 결과 규칙과 같다.
- [ ] 기존 SUP 강화와 새 재료 소각을 중복 적용하지 않는다.
- [ ] 320~390dp와 큰 글씨에서 이름·번호·바·값·버튼이 잘리지 않는다.
- [ ] 모든 바는 표기 값으로 계산하고 색만으로 상태를 전달하지 않는다.
- [ ] 모달 배경은 눌리지 않으며 닫힌 뒤 접근성 초점이 원래 버튼으로 돌아온다.
- [ ] 동작 줄이기에서 반복광/움직임을 줄이고 결과 응답을 불필요하게 지연하지 않는다.
- [ ] 저장소 요구 검사와 변경한 선택/경제 처리 검증을 실행하고 같은 빌드의 화면을 캡처한다.
- [ ] 미연동·미검증 항목은 완료로 표시하지 않는다.
