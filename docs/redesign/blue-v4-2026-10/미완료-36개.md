# 현재 후보 목록의 미제작36개

알림·공지 NOT27~46 20개와 지갑 WAL01~16 16개다. 최신 등록 후보457개 중421개 정적 검수 완료,36개 미제작이다. 별도 러닝109개를 더한 합계530개는 재사용/별칭을 포함한 UI 상태 수이며 고유 페이지 수가 아니다.

전체104경로와 추가 상태의 대조가 남아 있어36개는 전체 앱의 최종 잔여 수가 아니다. `03-audit/source-audits`의 기능별 추가 상태 문서를 함께 확인한다. 미제작은 신규 파란 톤 PNG가 없다는 뜻이며 기존 기능이 미구현이라는 뜻이 아니다. 기존 기능을 보존하고 미확인 구현 상태는 실제 코드와 캡처로 확인한다.
