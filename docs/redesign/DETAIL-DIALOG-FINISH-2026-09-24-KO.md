# 상세 화면·팝업 마감 기록

2026-09-24. 기존 로컬 디자인 변경에 이어 적용했다. APK/AAB, 원격 빌드, 배포, 새 이미지 제작은 실행하지 않았다.

## 이번에 바꾼 범위

기존 86개 작업표 중 아래 **9개 항목**에 소스 마감을 추가했다. 독립 페이지 9개를 새로 제작하거나 실제 기기에서 확인했다는 의미는 아니다.

관련 팝업도 함께 정리했다. `DialogPanel` 적용 지점은 총 8개: 프로필 편집, 목표 설정, 초대 문구, 장비 획득 결과, 보유한 같은 신발 목록, 강화 확인, 구매 입찰, 판매 등록. 호출 지점 수이며 모든 진입 경로의 실행 확인 수가 아니다.

## 공통 구조와 기존 동작

- `DialogPanel.kt`: 공통 모서리·표면·가로 여백, 최대 560dp 폭, 화면 안전 영역과 키보드 여백, 제목과 48dp 닫기 버튼, 스크롤 본문, 분리된 하단 행동 영역.
- 본문 안쪽을 스크롤해도 확인 버튼은 별도 영역에 남는다. 뒤로 가기, 닫기, 바깥 터치는 기존 dismiss 콜백으로 연결한다.
- 닉네임·초대 문구·거래 숫자 입력은 `FormField`를 재사용한다. 닉네임/초대 길이 제한, 숫자 필터, 구매 가능 잔액·레벨 조건, 판매할 켤레 사전 선택, 강화 가능 조건을 유지했다.
- 프로필 사진의 즉시 저장과 닉네임의 확인 시 저장, 목표 슬라이더 조작 완료 시 저장도 기존과 같다.
- 상품·보상·잔액·소유·체결 값은 기존 데이터를 사용한다. 준비 중 상품을 구매 가능한 상태로 바꾸지 않았다.
- 독립 배경, 캐릭터/상품 원본, 실제 지도, 공통 헤더·하단 탭은 기존 구조를 유지한다.
- 자동 목록 도구가 공통 팝업의 호출도 인식하게 수정했다. 목록은 33개 경로·34개 screen 함수·20개 overlay 선언이며 완료 수가 아니다.

## 확인 결과와 남은 확인

디자인 계약, 문자열/리소스, 기존 자산, 변경 공백 검사가 통과했다. 현재 로컬 변경 Kotlin 46개 파일의 문법 파싱도 통과했다. 파싱은 타입 검사나 Android 컴파일이 아니다.

로컬 Android 도구가 없어 컴파일·실행을 하지 않았으며, 사용자의 APK 보류 지시를 지켰다. 같은 소스의 실제 기기에서 작은 화면·큰 글자·키보드 표시·긴 신발 목록·밝은/어두운 테마·팝업 닫기를 통합 확인해야 한다. 이번 기록으로 출시 완료나 디자인 전체 완료를 선언하지 않는다.
