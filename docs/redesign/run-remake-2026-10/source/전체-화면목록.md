# StepUp 러닝 전체 리메이크

전체 109개 화면·상태 / 새 시안 108개 + 승인 메인 1개

승인한 남색·파랑 스타일의 정적 시안입니다. 앱 코드 및 실시간 지도 구현을 뜻하지 않습니다.

## 기준

- 기존 로고, 큰 버튼, 흰색 주요 버튼과 파란 하단면, 절제한 조명을 공통으로 적용합니다.
- 모든 화면은 개별 PNG입니다. 기존 기능과 상태를 기준으로 대응합니다.
- 크루 시작 메뉴는 U01과 통합했고, 커뮤니티의 크루 관리 화면은 연결만 합니다.
- 지도와 수치는 예시입니다. 구현 시 기존 지도 SDK와 실제 데이터를 사용합니다.
