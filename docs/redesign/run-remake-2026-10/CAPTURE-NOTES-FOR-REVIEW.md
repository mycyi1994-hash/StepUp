## 2. 오해하면 안 되는 것 (결함이 아님)

1. **화면 부품만 따로 찍은 캡처**: R01 · E07 · L03 · K01 · K02 · K17 · K18 · U04 · D04 · D05 는 앱에서 아주 잠깐만 지나가거나
   서버 없이는 만들 수 없는 상태라, 같은 화면 부품을 그 상태로 그려 찍었다(`RunJourneyDesignTest#states`).
   - K17 · K18 캡처에는 코스 허브의 글자 탭 · 검색 줄이 없다. 허브 전체 모습은 K11 캡처에서 본다.
   - R01 은 앱 안에서 찍은 캡처(`forms/run-countdown.png`)도 따로 있다.
2. **로그인 전 기기**: CI 에뮬레이터는 로그인하지 않았다. 그래서 K11(코스 게시판) · K12(코스 순위)는 "로그인 필요" 상태,
   K16(공유할 코스 고르기)은 "올릴 내 코스 없음" 상태로 찍힌다. 그 상태 그대로가 맞는 화면이다.
3. **지도 타일이 아직 안 그려진 캡처**: R01 · CR08(3-2-1) 상태 캡처는 지도 타일이 그려지기 전에 찍혀 남색 바탕만 보인다.
   지도를 일부러 뺀 것이 아니다.
4. **일부러 지도를 그리지 않은 화면**: R02_TIME(위치 없이 기록) · E07(휴대폰 위치 기능 꺼짐) · L03(위치 확인 중)은
   자리를 모르기 때문에 지도를 그리지 않거나 빈 틀만 둔다. 시안의 「지도 예시」를 앱이 흉내 내지 않는 것이 규칙이다.
5. **숫자가 시안과 다름**: 캡처의 거리 · 시간 · 걸음 · SUP 는 검사가 넣은 표시용 값이나 실제 저장값이다. 시안의 예시 숫자와
   같을 필요가 없다. 서버가 확인하기 전 보상은 "예상 · 확인 중"으로만 보여야 한다(E10). "적립 완료"는 E11 에서만.
6. **만들지 않은 화면**: CR02(준비 중인 방 미리보기) · CR16(이미 출발한 방)은 서버에 보기 전용 방 조회 API 가 없어 구현하지
   않았다. 캡처가 없는 것이 맞다.
7. **크루 대기실에 일정 · 목표 거리 · 모임 장소 줄이 없음**: 서버 방 정보(party_state)에 그 값이 없어 그리지 않는다.
8. **시안과 일부러 다르게 한 것**: README 「시안과 다른 점」에 적은 것은 결함이 아니다.
   - 코스 · 대기실 · 크루 달리기 화면은 하단 탭 없음. 내 러닝 기록 · 통계(H01~H10 · H15)는 하단 탭이 보임.
   - L02 주 버튼은 "설정에서 위치 켜기", P01 은 닫기 X 없이 뒤로 가기로 닫음.
   - 다이어트 경험 줄 설명 · K15 "저장 안 함" · 통계의 추가 줄은 기존 기능이라 남김.
   - 신발 탭 바탕은 러닝과 같은 남색.
9. **상태 표시줄 · 시스템 바**: 시각 · 배터리 · 아이콘은 에뮬레이터 것이다. 시안과 달라도 된다.

## 3. 결함으로 보고할 것

- 글자가 잘리거나 겹침, 버튼이 화면 밖으로 나감, 한 화면에 큰 주 버튼이 둘 이상.
- SUP 잔액 알약이 HOME · U01 말고 다른 화면에 보임.
- 공유 미리보기(E05 · CR21)에서 "경로 포함"이 꺼져 있는데 그림에 지도 · 길이 보임.
- 서버 확인 전 화면(E10)에 "적립 완료"가 보임.
- 색이 시안의 남색 · 전기 파랑(배경 #031427 · 패널 #0B2B50 · 파랑 #0754FF · 시안 #48D9FA)에서 크게 벗어남.
- 화면 번호와 캡처의 상태가 맞지 않음(예: R03 인데 일시정지가 아님).

## 4. 보고 형식

화면 번호마다 한 줄로: `화면번호 | 캡처 파일 | 판단(맞음 / 결함 / 확인 불가) | 결함이면 무엇이 어디서 다른지`.
위 2장에 해당하는 차이는 "맞음"으로 적고, 근거가 된 항목 번호를 덧붙인다.
