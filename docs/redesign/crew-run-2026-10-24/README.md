## 추가 — 코스는 골라도 되고 안 골라도 된다 · 지도에서 직접 그리기 · 크루 관리 바로가기 (2026-10-24, 서버 0073)

사용자: "uiux 편의성과 더불어서 코스선택이 코스를 내가 선택할 수가 없네 지금 크루 달리기 기준 무조건 뭐 정해준것만 해야되던데 그건 아닌거같다"
(앞서 "크루장이 뭐 이것저것 할 수 있는 탭은 어디있어? 크루원 본다거나 크루 삭제 · 크루 이미지 바꾸기").

- **코스 없이 대기실을 연다(자유 코스)** — 러닝 만들기의 코스 칸은 "(선택)"이다. 고르지 않으면 "자유 코스 — 코스 없이 각자 원하는 길로 함께 달려요"이고,
  "대기실 열기"는 이름만 맞으면 된다. 코스를 고른 뒤에도 "코스 빼기"로 되돌린다. 열린 대기실 목록 · 대기실의 코스 칸은 지도 대신 "자유 코스 · 각자 원하는 길로".
- **지도에서 직접 그리기**(`ui/screens/walk/CrewCourseDraw.kt`) — 코스 고르기 맨 위 줄. 지도를 누를 때마다 점이 이어지고(점 사이는 곧은 줄),
  끌면 지도가 움직이고 ± · 두 손가락으로 키운다. 거리는 점 사이 거리의 합(`CrewRoomRules.pathKm`), 점 둘 이상 · 100km · 점 300개까지.
  되돌리기 · 출발점으로 잇기(한 바퀴) · 처음부터. "이 코스로 정하기"를 눌러야 고른다. 그린 코스는 방의 코스 사본으로만 간다(이름 "내가 그린 코스").
  처음 지도는 내 자리(모르면 서울 시청), 점을 찍기 시작하면 지도를 옮기지 않는다. 목록으로 돌아갔다 와도 그리던 점이 남는다.
- **진행자는 대기실에서 코스를 넣고 · 바꾸고 · 뺀다** — 코스 없는 방은 코스 칸 · ⋯ 메뉴 · 명단 시트의 "코스 정하기"가 바로 코스 고르기로,
  코스가 있으면 코스 바꾸기 시트에 "코스 빼기". 뺄 때도 판이 오르고 진행자를 뺀 준비가 풀린다(D14). 참가자에게는 "코스를 뺐어요" 시트(`party-course-removed`).
  출발은 코스가 없어도 판을 맞댄다(`PartyState.courseRev` — 코스를 넣었다 뺀 방은 그 판, 코스 없이 연 방은 판 0 이라 예전처럼 `party_start`).
- **크루 관리 바로가기** — 크루장에게만: 커뮤니티 내 크루 홈의 이름 카드 바로 아래 "크루 관리" 한 줄(`home-manage`), 러닝 탭 크루 홈의
  "크루 러닝 기록" 아래 "크루 관리" 줄(`crew-home-manage`, 기다리는 가입 신청이 있으면 "신청 N"). 둘 다 ⋯ 메뉴의 크루 관리와 같은 화면
  (`CrewRoutes.manage` — 가입 신청 · 멤버 관리 · 크루 소개 · 대표 이미지 · 모임 정보 · 모집 · 주간 목표 · 운영 설정 · 크루 해산)이다.
