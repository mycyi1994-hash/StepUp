StepUp 승인 디자인 적용 규칙

최신 지시가 최우선
터널 사진 + 움직이는 배경은 대기실에만 둔다.
크루 홈·방 개설·코스 목록·러닝 중·결과·레벨·기록에 동일 터널을 깔지 않는다.
이 문서는 시안을 재디자인한 결과물이 아니라 기존 70개 시안을 실제 앱에 적용하는 지시다.
reference/와 screenshots/는 원본 보존 자료이며 다른 화면의 터널은 구현 대상에서 제외한다.

1. 화면별 배경
LOBBY_TUNNEL: host-lobby, host-waiting, solo, full, removed-host, member-lobby, member-ready.
LOBBY_STATIC: loading. 불러오기 중 과도한 애니메이션을 추가하지 않는다.
INHERIT_PARENT_DIM_PAUSE: 대기실 위에 뜨는 신발/인원/코스/내구도/출발 확인 시트. 부모 터널이 어둡게 보이는 것은 허용하되 움직임은 멈춘다. 시트 자체는 불투명하다.
APP_EXISTING: 크루 홈, 방 목록/개설, 코스 선택, 레벨/결과/기록/예외 전체 화면. 실제 앱의 기존 색·그라데이션·표면 토큰을 읽어 사용한다. 새로운 공통 배경 사진을 만들지 않는다.
MAP_EXISTING: 달리는 중, 확인 중, 휴식, 내구도 경고/소진, 연결 끊김/복구. 실제 지도와 기존 러닝 화면 배경을 사용한다.
COUNTDOWN_EXISTING: 3→2→1→0→StepUP!은 기존 자유 러닝의 승인된 카운트다운 배경·로고를 재사용한다. 별도 터널 반복 재생을 추가하지 않는다.
ANDROID_SYSTEM: 잠금화면은 Android 실제 알림 템플릿으로 구현한다. 시안의 잠금화면 전체를 앱 화면으로 그리지 않는다.
상세 화면의 기본 바탕은 실제 앱 토큰을 우선한다. 이 문서만으로 앱 전체를 새 남색 테마로 바꾸지 않는다.

2. 대기실 프레임 — 선택한 3번 듀얼 레일
크루원 영역과 내 신발 영역은 같은 부품을 사용한다.
외곽: 5dp, 모서리 20dp.
외곽 그라데이션: 110도, #96EAFF → #56CBFA(45%) → #2E9FD5.
내부: 125도, #113A58 → #09253C(82%).
두 번째 선: 바깥에서 9dp 안쪽, 1.5dp, #82D8F9/약65%, 모서리 11dp.
바닥 음영 참고: 아래 5dp #052338, 부드러운 그림자 0/12/26 #000/약27%.
정확한 CSS 값은 design-tokens.json / prototype-source/all-scenes.css 참고.
네이티브 그림자는 동일 인지 결과를 내는 최소 레이어로 맞춘다. HTML의 mask 구현을 그대로 옮길 필요는 없다.
테두리 크기·모서리·면색을 두 카드에 각기 다르게 만들지 않는다. 테두리와 카드는 움직이지 않는다.
일반 리스트 행이나 모든 작은 버튼까지 5dp 프레임을 두르지 않는다. 핵심 그룹의 위계를 유지한다.

3. 색과 버튼
승인 대기실 바탕 #031427. 본문 #F5F8FF. 보조 글자 #B5CBE6.
액센트 #1166FF, 정보/진행 #48D9FA, 아이스 블루 #95E6FF.
준비 칩: 면 #83E5FF / 글자 #073346 / radius 6dp.
내 신발 변경: 면 #95E6FF / 글자 #07384D / radius 8dp / 높이 44dp 이상.
주 행동: 면 #F5F8FF / 글자 #071B3D / radius 14dp / 기준 높이 60dp.
비활성: 면 #24455D / 글자 #A2BDD0. 실제 disabled semantics 포함.
아이콘 액션의 터치 영역은 앱 플랫폼 기준으로 최소 48dp를 확보한다. 그림 자체를 크게 키우지 않아도 된다.
경고는 주황/노랑 계열의 기존 경고 표면을 사용하고 문구·아이콘을 함께 제공한다. 색만으로 상태를 구분하지 않는다.

4. 대기실 레이아웃
리뷰 기준 390×844. 실제 dp는 기기 인셋과 현재 앱 부품을 기준으로 맞춘다.
위에서: 앱 헤더 → 방 이름/짧은 부제 → 크루원 3열×2행 → 왼쪽 공용 내구도·크루 목표 / 오른쪽 코스 지도 → 내 신발 카드 → 주요 버튼.
좌우 여백 기준 24dp. 원본 크루원 카드 약267dp, 요약/지도154dp, 신발 카드96dp, 주 버튼60dp.
신발 카드와 주 버튼 사이에 여백을 남긴다. 아래로 밀려 화면 밖으로 나가지 않게 한다.
20명 전체를 기본 화면에 몰아넣지 않는다. 일부 아바타와 +N/전체 보기로 열고 목록에서 모두 접근한다.
내구도·목표·코스는 모든 참가자가 보는 정보다. 자기 신발 선택은 본인만 편집한다.
진행자는 'N명과 출발', 참가자는 '준비 완료', 준비한 참가자는 진행자 대기 + 준비 취소.
상세 산식과 20단계 표는 시트로 둔다. 대기실에 긴 규칙 설명을 다시 늘어놓지 않는다.

5. 서체와 자산
기존 Android의 정식 서체 리소스, 굵기, 숫자 스타일을 재사용한다. 시안의 StepUpCapture는 웹 미리보기 부분 글꼴이다.
큰 제목은 약31sp/37sp, 주요 숫자26sp/30sp, 기본 본문14sp, 보조12sp를 시각 출발점으로 삼는다. 실제 앱 접근성 설정을 반영한다.
로고는 기존 StepUp 로고 자산으로 사용한다. StepUP!을 일반 시스템 폰트로 새로 조합하지 않는다.
assets의 신발 그림은 샘플이며 실제 보유 신발 이미지·ID·능력치로 교체한다. #1201과 #1248에 같은 그림이 보이는 데모를 그대로 출시하지 않는다.
지도는 실제 앱의 지도 공급자·경로·출발점 리소스를 쓴다. 참조 이미지의 예시 경로를 실제 코스로 등록하지 않는다.

6. 대기실 모션
사진 앞쪽으로 천천히 전진하는 두 이미지 레이어를 교차시킨다. 각 주기11초, 시작 위상 약10%/60%.
scale/opacity 참고: 0%=1/0, 14%=1.03/1, 70%=1.15/1, 100%=1.23/0. 기준점 50%/43%.
측면 조명은 4.2초 ease-in-out 왕복. 왼쪽 x=+60→−30, 회전 −20→−30도; 오른쪽 반대. 빛 불투명도 약0.3→1.
중앙 빛은 같은 템포로 opacity 0.4→1. 사진과 조명만 움직이고 텍스트·프레임·버튼은 고정.
촐랑거리는 바운스, 흔들리는 카드, 반짝이 입자, 매 프레임 그림자 변화는 추가하지 않는다.
대기실이 실제 보일 때만 재생한다. 화면 전환·백그라운드·시트·출발 카운트다운에서는 정지한다.
감소된 모션 설정에서는 이동·확대·회전을 제거한다. 정지 이미지 또는 느린 조명 변화만 허용한다.
터널 자산은 전환 전에 준비하고 출발 때마다 디코딩/네트워크 로딩하지 않는다. GPS/기록 서비스의 성능을 방해하지 않는다.

7. 출발 전환
서버가 승인한 start와 출발 시각이 먼저다. 카운트다운이 일일권/풀 기여를 직접 생성하지 않는다.
사용자에게는 3→2→1→0→StepUP!→중앙 펼침으로 이어져야 한다.
원본 참고 타임라인: 숫자 약0.9초씩, 0이 나타난 뒤 약0.3초부터 원형/숫자 fade와 로고 등장 0.42~0.47초 중첩, 로고 다음 중앙 펼침 약0.73초.
시간은 실제 다인 동시 출발 동기화에 맞춰 조정한다. 승인된 전환의 연결감을 유지하는 것이 핵심이다.
새로 네트워크나 지도 첫 로딩을 시작해서 로고 뒤가 비지 않게 한다. 지도/러닝 목적 화면을 미리 준비하고 동일 상태로 전환한다.
끝의 원형 펼침 레이어와 실제 러닝 화면이 다른 지도 줌·다른 위치·다른 숫자로 튀지 않게 한다.
감소된 모션에서는 회전/확대 대신 숫자와 로고의 짧은 전환·크로스페이드로 의미를 유지한다.

8. 작은 기기와 접근성
기본 글꼴의 핵심 화면은 일반 휴대폰 한 화면에 주 행동까지 들어오게 한다.
실제 status/navigation bars, 3버튼 내비게이션, 작은 높이, 큰 글꼴, 키보드를 확인한다.
큰 글꼴/긴 목록에서는 본문이나 시트를 스크롤해 접근 가능하게 한다. 텍스트를 무조건 축소하거나 내용/CTA를 잘라 '한 화면'을 맞추지 않는다.
전체 명단·레벨표·보너스 표는 전체 항목에 접근할 수 있어야 한다. 웹의 페이지 선택 방식을 네이티브에서 그대로 강제할 필요는 없다.
주요 버튼 하나, 정확한 라벨, 선택/비활성/로딩 상태, 닫기/Back 복귀 위치를 유지한다.
