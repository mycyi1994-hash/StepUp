자료 출처와 검증 범위 — 2026-10-24

제품 규칙은 사용자의 크루 러닝 작업 정의서와 후속 지시에서 가져왔다.
현재 선택은 3번 듀얼 레일이다. UI 선택기의 마지막 선택 기록을 새로운 사용자 승인으로 해석하지 않았다.
최신 사용자 지시는 사진/움직이는 배경을 대기실 정도에만 적용하고 시안을 다시 만들지 말라는 것이다.
이에 시안 원본을 보존하고 문서·화면별 backgroundPolicy에 실제 구현 범위를 기록했다.

기존 웹 시안 검증
qa/all-scenes-review.json: 70개 상태 × 기본/좁은 뷰포트 = 140회 레이아웃 검토. JS 오류·넘침/겹침 검사 결과 포함.
qa/all-interactions-review.json: 29개 검증. 프레임 일치, 배경 실제 변화/전경 고정, 시트 정지, 신발·코스·준비, 20명, 카운트다운, 보너스, 레벨, 종료, 감소 모션 등.
위 QA는 원본 전체 배경 시안에 대한 자료다. 새 배경 정책을 실제 Android에 적용한 결과가 아니다.
qa/offline-export-report.json: 이번 패키지의 오프라인 70개 장면/이미지/아이콘/네트워크 요청 검증 결과.
qa/package-validation.json: 파일·70개 ID·규칙표·배경 범위·ZIP 해시 대조 결과.

실행하지 않은 것
최신 앱/DB 저장소 조사, Kotlin 빌드, 실제 기기 GPS, Supabase migration/RPC 실행, 인증 연동, 보상 지급, 운영 배포는 이번 지시서 작성 범위에서 하지 않았다.
07_ACCEPTANCE_TESTS.txt는 구현 이후 Claude가 실행할 검증이다. 통과 보고가 아니다.

자산
터널 사진: 이 대화의 승인된 시안 제작 과정에서 만든 배경 자산. 대기실 전용.
로고·신발: 기존 StepUp 작업 자산의 참조 사본. 실제 앱은 정식 저장소 리소스를 우선한다.
신발 #1248에 같은 그림을 사용한 것은 데모 편의다. 실제 인벤토리 자산으로 교체한다.
지도: 기존 테스트 fixture와 OpenStreetMap 기반 배경. 검증된 실제 러닝 코스가 아니다. 앱 지도/GPS/코스 데이터로 대체한다.
OpenStreetMap 출처 표시 유지: https://www.openstreetmap.org/copyright
서체: 웹 참조에는 부분 글꼴이 포함된다. 네이티브는 기존 정식 전체 글꼴과 라이선스를 사용한다.
Lucide: 오프라인 참조를 위해 로컬 배포본을 포함. licenses/lucide-ISC.txt 참조.

앱 콘텐츠 디자인과 경제 데모 동작은 변경하지 않았다.
