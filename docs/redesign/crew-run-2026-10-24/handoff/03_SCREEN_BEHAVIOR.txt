70개 장면별 동작 명세

우선순위: 최신 사용자 배경 지시 → 확정 규칙 → 이 명세 → 원본 시안의 시각 예시.
시안의 장면 선택기는 제품 UI가 아니며 70개의 Activity를 만들라는 의미가 아니다.
모든 데이터 화면: 로딩/빈 값/오류/오래된 스냅샷/권한·서버 상태 변경을 구분한다. 오류를 0 또는 성공으로 바꾸지 않는다.
모든 변경 요청: 중복 탭 방지, 요청 키/상태 확인, 실패 시 입력 보존, 서버 성공 후 반영, 재진입 시 복구.
모든 시트: 불투명 표면, 부모 선택과 역할 유지, Back/닫기 시 원래 화면 복귀. 서버 자동 종료 등 terminal 상태는 닫아도 취소되지 않는다.
화면의 주요 행동은 하나. 보조 동작은 상세/메뉴로 분리하고 긴 명단/표는 모두 접근 가능하게 한다.
referenceParent는 갤러리의 예시 부모다. 실제 호출한 부모 화면/역할/선택을 보존하며 고정 부모로 강제 이동하지 않는다.
배경 정책 코드는 04_DESIGN_BACKGROUND.txt에 정의되어 있다. 시안의 원본 이미지가 최신 배경 범위를 덮어쓰지 않는다.
