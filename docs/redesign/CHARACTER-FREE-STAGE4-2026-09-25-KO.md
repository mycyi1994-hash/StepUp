# 캐릭터 없는 리디자인 4단계 — 실제 앱 검증

## 범위

선택한 기록 중심 방향의 주요 화면 10개와 러닝 일시정지·GPS 대기·신발 마켓·소식을 검증한다. 캐릭터/의상은 제거한 상태이고 신발 수집/착용/뽑기 진입은 유지한다. 이번 검증은 전체 앱의 출시 승인 또는 모든 화면/서버 기능의 완성을 의미하지 않는다.

## 이번에 수정한 문제

- 삭제된 캐릭터 이미지가 있어야 한다고 검사하던 단위 검사를 현재 자산 계약(신발 52개, 배너 2개, 캐릭터/의상 없음)에 맞췄다.
- 기기 검사에서 사용하던 경로 생성자와 없는 확장 함수 import를 수정했다. 프로덕션 GPS·기록 저장 구조는 바꾸지 않았다.
- 360dp 실제 캡처에서 홈의 주간 기록과 신발 목록이 아래로 밀리는 문제를 확인했다. 홈 기록/목표 간격과 배너 높이를 줄이고, 신발 미리보기는 일반 글자에서 가로 배치로 바꿨다. 큰 글자는 세로 배치와 스크롤을 유지한다.
- 후속 캡처에서 배경 전환 버튼과 문구의 겹침을 확인해 버튼을 위쪽으로 옮겼다. 낮은 화면에서는 배너 높이를 한 번 더 줄여 거리·시간 숫자의 노출 공간을 확보했다.
- 클릭 가능한 커뮤니티 카드의 접근성 정보가 합쳐지므로, 캡처 준비 검사는 원래 자식 노드까지 조회하도록 고쳤다. 실패하면 해당 화면을 Activity 종료 전에 저장하도록 했다.

## 검증 한계 / 다음 인수인계

- 에뮬레이터의 기록·경로·소유 신발·커뮤니티 게시물은 검사 전용 자료다. 실제 야외 GPS 정확도, 활동 추적 복구, 서버 적립 또는 지갑 거래의 성공 근거가 아니다.
- 기본 뽑기 배포 설정이 비어 있는 상태에서는 버튼이 비활성이다. 이는 디자인 누락이 아니며, 실제 뽑기 출시에는 계약/서버/지갑 연결 검증이 별도로 필요하다.
- 로그인 화면 캡처는 Google 인증을 실제 완료했다는 뜻이 아니다.
- 이번 14장면 외 상세/작성/설정 화면 전체, 밝은 테마, 모든 언어와 실제 단말 조합은 이 실행으로 검증하지 않았다.
