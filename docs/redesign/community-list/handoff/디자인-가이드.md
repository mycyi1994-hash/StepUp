# StepUp 목록형 커뮤니티 — 화면 설계

선택한 A 목록형을 기준으로 한 31개 화면·상태와 연결된 프로토타입입니다. 상단 지도, 장소와 거리를 담은 썸네일, 다른 사람의 글 목록, 흰색 글쓰기 버튼을 유지했습니다.

## 파일 열기

- `index.html`: 설치 없이 브라우저에서 열기. 각 장면에서 버튼을 눌러 다음 화면으로 이동할 수 있습니다.
- `00-overview.png`: 핵심 화면 6개 요약.
- `01-reading.png` ~ `05-states.png`: 흐름별 전체 보드.
- `screens/`: 31개 개별 화면. 390 × 844 기준 디자인을 2배 크기로 캡처했습니다. 저장된 개별 PNG는 780 × 1690입니다.
- `data.js`: 예시 게시글, 장소, 화면 목록, 초기 상태.
- `screens.js`: 화면·목록·버튼·모달 구성 요소.
- `interaction.js`: 화면 이동과 입력·선택 동작.
- `style.css`, `map-list.css`, `variants.css`, `scenes.css`: 기본 토큰과 목록형·세부 화면 스타일.
- `assets/`: 로고, 지도 참고 이미지, Pretendard 폰트와 라이선스.

HTML/CSS는 편집 가능한 화면 원본입니다. PNG는 비교·검토용이며 Figma의 편집 가능한 레이어 파일은 아닙니다. 개발 전 디자이너가 구조·간격·문구를 수정할 수 있게 구성과 동작을 분리했습니다.

## 구성 원칙

**목록**: 상단 지도 높이 246, 목록 시작점 229. 좌우 여백 22, 행 간격 14, 장소 썸네일 92 × 101. 목록에서 제목은 최대 2줄, 본문은 1줄, 상세에서 전체 내용 확인. 글 카드에는 별도 테두리나 배경을 반복하지 않고 구분선만 사용합니다.

**상세**: 글쓴이 → 제목과 본문 → 장소 → 반응 → 댓글 순서. 장소 카드는 70 × 63 지도 썸네일과 이름·거리를 포함합니다. 댓글 입력창은 하단에 고정합니다.

**글쓰기**: 제목·분류 입력을 추가하지 않습니다. 본문 1,000자, 댓글 200자. 본문 첫 줄은 목록의 제목, 나머지는 본문으로 보여줍니다. 장소를 바꾸고 돌아와도 입력한 내용은 유지합니다.

**장소**: 썸네일은 글쓴이가 고른 공개 장소입니다. 작성자의 실시간 위치를 표시하는 의미가 아닙니다. 거리는 보는 사람의 위치 또는 직접 선택한 지역을 기준으로 계산하는 설계입니다.

**버튼**: 주요 행동은 흰색 50px 높이 버튼. 보조 행동은 남색 배경이나 텍스트. 삭제는 확인 모달에서만 차분한 붉은색으로 구분합니다. 비활성 버튼은 짙은 남색 바탕과 낮은 밝기의 글자로 구분합니다.

**모달**: 범위·메뉴·신고·임시저장은 하단 시트. 되돌릴 수 없는 삭제는 중앙 확인창. 모달이 열리면 배경 조작을 막고, 닫기 또는 Escape로 복귀합니다. 시트 내부에 키보드 초점을 유지합니다.

**알림**: 게시·수정·임시저장·숨김·삭제는 짧은 확인 메시지. 숨김에는 되돌리기를 제공합니다. 글쓰기 버튼과 알림이 겹치지 않게 배치했습니다.

## 프로토타입 범위

각 장면의 데이터는 서로 독립적입니다. `처음 장면으로` 버튼은 해당 장면만 초기화합니다. 글·댓글·좋아요·숨기기·신고·임시저장은 현재 열린 페이지 안에서 동작하며 새로고침하면 초기화됩니다. 실제 계정·서버·신고 처리·위치 서비스에는 연결하지 않았습니다. 지도는 여의도 참고 이미지이며 확대/이동 가능한 지도 SDK가 아닙니다.

게시 중·로딩·오류는 디자이너가 확인할 수 있도록 별도 장면에서 정지 상태로 보입니다. 실제 버튼을 누르는 흐름에서는 짧은 대기 후 다음 상태로 연결됩니다. 게시 실패 장면에서 다시 올리기는 입력 내용을 유지하며 성공 상태로 전환됩니다.

운영체제의 위치 허용 대화상자와 키보드는 앱에서 새로 그리지 않는 요소입니다. 실제 앱에서는 `내 위치 사용하기` 다음에 시스템 권한 요청을 연결하고, 입력 시 시스템 키보드 높이에 맞춰 입력창과 완료 버튼을 올려야 합니다. 시안에서는 위치 허용 후 목록과 권한 없이 지역 선택하는 경로를 눌러볼 수 있습니다.

지도·장소 검색 결과·거리·글 수·글쓴이·댓글은 전부 예시 데이터입니다. 다른 지역을 선택하는 예시는 빈 목록으로 이어집니다. 앱의 다른 하단 탭(러닝·신발·내 정보)은 맥락 표시용이며 이번 목록형 커뮤니티 작업에 포함하지 않았습니다.
