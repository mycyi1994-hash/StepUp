# 01. 확정 범위와 디자인

## 확정된 방향

사용자가 마지막으로 선택한 **A 목록형**입니다. 지도와 글 목록을 한 화면에서 함께 보여줍니다. 다른 사람의 글이 처음부터 충분히 보이는 것이 핵심입니다. 지도만 큰 탐색 화면이나 글을 한 장씩 넘기는 카드형 피드로 바꾸지 않습니다.

최신 선택은 이전 크루 결성·배지 확장 논의를 대체했습니다. 강제 크루 생성, 게임형 장식, 랭킹·쇼핑 분류·큰 소개 문구를 새 목록의 앞부분에 추가하지 않습니다. 기존 앱의 크루 기능·계정·저장 데이터는 이번 UI 방향 변경과 별개로 보존합니다.

## 시각 기준

- 배경은 거의 검정에 가까운 남색, 주요 행동은 흰색 버튼, 위치·선택 상태에 파랑 사용.
- 게시글마다 큰 박스나 테두리를 두지 않고 얇은 구분선으로 나눔.
- 큰 히어로 문구, 배너, 과도한 그림자, 네온·보라 그라데이션은 추가하지 않음.
- 현재 StepUp 로고·폰트·하단 메뉴의 제품 정체성 유지. 실제 앱에서는 공통 컴포넌트와 토큰을 사용.
- 버튼은 `글쓰기`, `올리기`, `이 장소로 선택`, `이 장소 글 보기`처럼 다음 행동을 명확하게 표현.

## 기본 목록의 구성

위에서부터 지역명·로고 → 지도와 장소 핀 → 목록 제목과 펼치기 → 게시글 행 → 글쓰기 버튼 → 하단 메뉴입니다. 행 왼쪽에는 선택한 장소의 지도 썸네일·장소명·거리를, 오른쪽에는 제목·본문 한 줄·작성자·시간·좋아요·댓글 수를 놓습니다.

글 제목을 누르면 상세, 지도 썸네일을 누르면 그 글의 장소 지도로 이동합니다. 두 동작은 별도 터치 영역입니다. 목록 펼침은 같은 화면의 상태 변화이며 지도 보기로 복귀할 수 있습니다. 목록 스크롤 위치와 범위·장소 선택을 상세 왕복 시 유지합니다.

## 수치 기준

기준 아트보드는 390 × 844, 개별 PNG는 2배인 780 × 1690입니다. PNG 픽셀을 Android dp로 그대로 복사하지 말고 기준 아트보드 비율로 옮깁니다. 화면 상하단 시스템 영역은 기기별 인셋을 사용합니다.

| 요소 | 기준 |
|---|---|
| 지도 영역 / 목록 시작 | 246 / 229 |
| 목록 좌우 여백 | 22 |
| 장소 썸네일 | 92 × 101, 모서리 10 |
| 썸네일과 본문 간격 | 14 |
| 글 상세 장소 썸네일 | 70 × 63 |
| 입력 화면 좌우 여백 | 24 |
| 주요 버튼 | 높이 50, 모서리 14 |
| 글쓰기 플로팅 버튼 | 높이 44, 흰색 |
| 하단 시트 상단 모서리 | 24 |
| 목록 제목 글자 | 16 / medium, 최대 2줄 |
| 목록 본문 | 12 / regular, 1줄 말줄임 |
| 입력 본문 | 17 / regular |
| 화면의 주요 문구 | 23~26 / semibold |

색상은 `design/디자인-가이드.md`의 표와 CSS를 기준으로 합니다. Pretendard 400/500/600/700 파일과 OFL 라이선스가 포함되어 있습니다. Android의 터치 영역은 최소 48dp 수준으로 확보하되 작은 아이콘의 보이는 크기를 불필요하게 키우지 않습니다. 글자 확대 시 텍스트가 잘리지 않도록 고정 높이를 조정합니다.

390px 시안의 상태 표시줄·홈 바·9:41 시각은 기기 프레임 표현입니다. 앱 안에 중복으로 그리지 않습니다. 하단 메뉴의 명칭과 활성 표시는 현재 앱의 공유 정책에 맞추되, 이번 커뮤니티 화면의 톤과 정렬을 맞춥니다.
