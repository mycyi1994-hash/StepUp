# 전체 화면·상태별 모듈 적용표

개정: 2026-09-24. 남은 50장 이상을 개별 디자인 작업으로 관리하며, 공통 부품과 독립 자산을 먼저 정의한다.

기존 촬영 코드의 기본 37개 + 내부 탭/팝업 31개 + 시작 변형 2개 + 안내 4개 + 상세 변형 3개 = **77개 검토 항목**이다. 개별 페이지 수·신규 원본 이미지 수·완료 수를 뜻하지 않는다. 성별/배경만 다른 옷장과 단순 재방문은 중복 제외했다.

아래 T/M 매핑은 **앞으로 적용할 설계안**이다. 현재 모든 화면이 해당 공통 모듈을 쓴다는 의미가 아니다. 기존 코드에 이미 있는 부품은 재사용·확장한다. 부품군 표에는 해당 화면의 여러 상태에 쓰는 부품이 포함되며, 모두를 한 화면에 동시에 노출하라는 뜻은 아니다. 공통 기반 M01은 부모 화면의 것을 사용하며 팝업이 헤더/하단바를 하나 더 만들지 않는다.

## 완료와 비용 추적

- 각 항목에 기준 시안, 최종 실제 캡처, 앱 소스 버전, 남은 차이를 연결한다. 현재 촬영 코드의 존재는 완료 근거가 아니다.
- 기존 내 거래 촬영 실패는 미검증으로 유지한다. 미로그인 화면으로 대체 촬영한 것을 거래 내용 검증으로 보고하지 않는다.
- 옷장 일부만 부분 검증이다. 공통 부품을 바꿨다고 연결 화면 전체를 완료 처리하지 않는다.
- 원본 자산 ID를 공유하면 이미지 수는 한 번만 센다. 같은 버튼의 문구별·선택 상태별 PNG를 만들지 않는다.
- 3A: 부품 보드/분해 조합도. 3B: 작은 합성 조합·대표 화면 검증. 이후 항목별 시안→실제 적용→캡처 확인 순서다.
- 마지막 10차는 전수 비교·수정이며 남은 상세 화면의 첫 디자인을 맡기는 차수가 아니다.
