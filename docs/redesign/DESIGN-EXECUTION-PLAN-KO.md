## 1. 목표와 범위

승인된 8개 시안을 기준으로 StepUp 전체 화면을 하나의 일관된 제품 디자인으로 완성한다. 캐릭터·배경·빛·타이포그래피·버튼·여백이 같은 기준을 따르게 한다.

이번 범위는 디자인이다. 기능 확장, 저장 구조, 계정 분리, 보상 처리, 서버·GIWA 연동은 포함하지 않는다. 시안의 잔액·기록·모임은 예시이며 실제 데이터로 취급하지 않는다.

기준 자료:
- 승인 시안: `design/redesign-2026-09/concepts/01-launch-loading.png`부터 `08-profile.png`까지.
- 현재 구현 비교: b1ac925의 Android 14 캡처. 테스트용 데이터와 고정 화면 영역을 사용한 자료임을 구분한다.
- 브랜드 원본: 기존 STEPUP 워드마크와 RUNO·LUMI 캐릭터 자산.

## 2. 작업 방식

1. 전체 화면에 적용할 규격을 먼저 정한다.
2. 필요한 이미지 자산 목록을 확정한 뒤, 화면 묶음에 필요한 것만 제작한다.
3. 홈을 시각 기준으로 완성하고 다른 화면에 확장한다.
4. 한 단계의 결과를 정리한 다음 다음 단계로 이동한다. 여러 화면을 동시에 조금씩 수정하지 않는다.
5. 매 단계에서 같은 형식으로 결과를 제출한다: 기준 시안 / 작업 결과 / 달라진 점 / 남은 디자인 항목.
6. 새 디자인 방향을 여러 개 만들지 않는다. 승인 시안을 기준으로 부족한 부분을 채운다.

## 3. 단계별 실행

### 1단계 — 공통 디자인 규격 확정

작업:
- 8개 시안을 한 화면에 놓고 배경색, 강조색, 글자색, 빛의 강도를 통일한다.
- 원본 로고, SUP 표시, 뒤로 가기, 주요 버튼, 보조 버튼, 하단 탭의 모양과 크기를 정한다.
- 제목·본문·숫자·보조 문구의 글자 크기와 굵기, 화면 좌우 여백을 정한다.
- 하단 탭은 러닝 → 꾸미기 → 커뮤니티 → 내 정보 순서로 고정한다.
- 시안 사이에 서로 다른 로고 크기나 아이콘 표현이 있으면 공통 규격 하나로 정리한다.

결과물: 색상·글자·버튼·헤더·하단바를 실제 크기로 배치한 공통 디자인 보드 1장.

완료 기준: 같은 역할의 요소는 어떤 화면에서도 같은 모양과 비율을 갖는다. 이후 단계는 이 규격을 재사용한다.

### 2단계 — 캐릭터와 배경 제작 기준 확정

작업:
- RUNO·LUMI의 얼굴, 눈, 머리·몸 비율, 옷 재질, 로고 위치를 기준 이미지에 고정한다.
- 야경은 푸른 가장자리 빛, 노을은 따뜻한 역광을 사용하되 같은 캐릭터로 보이게 맞춘다.
- 화면별 필요한 포즈를 정한다: 홈의 대기, 러닝의 달리기, 꾸미기의 전신, 챌린지의 준비, 프로필의 앉기.
- 기존 자산을 재사용할 것과 새로 보완할 것을 목록으로 구분한다. 전체 착장을 한꺼번에 생성하지 않는다.
- 배경, 캐릭터, 조작 요소를 분리한다. 이미지에 버튼·숫자·문구를 구워 넣지 않는다.

결과물: 캐릭터·조명 기준 보드와 화면별 자산 목록. 포즈별 실제 제작은 해당 화면 단계에서 수행한다.

완료 기준: 어떤 그림이 어디에 필요한지 명확하고, 캐릭터가 화면마다 다른 얼굴·재질·비율로 바뀌지 않는다.

### 3단계 — 홈을 기준으로 시작 경험 완성

디자인 작업 순서: 홈 → 로딩 → 로고 플레이. 사용자에게 보여주는 화면 순서는 로딩 → 로고 플레이 → 홈이다.

| 화면 | 디자인 작업 |
|---|---|
| 03 홈 | 캐릭터와 강변이 하나의 장면이 되도록 크기·바닥 접촉·그림자·광원을 조정한다. 상단 로고와 잔액, 하단 러닝 시작 버튼이 그림과 자연스럽게 어울리도록 배치한다. |
| 01 로딩 | 짙은 남색 바탕, 중앙의 원본 로고, 하단의 얇은 로딩 막대와 짧은 문구로 정리한다. 현재 원형 표시를 시안의 선형 표현으로 바꾼다. |
| 02 로고 플레이 | 로고를 따라 흐르는 짧은 푸른 빛과 강변 배경의 등장으로 홈에 이어지게 한다. 로고 위치와 배경 전환이 갑자기 튀지 않도록 구성한다. |

결과물: 완성 화면 3장과 로딩 → 로고 → 홈의 전환을 보여주는 짧은 디자인 미리보기.

완료 기준: 홈의 캐릭터·배경·공통 조작 요소가 이후 화면의 시각 기준으로 사용할 만큼 정리되어 있다. 시작 화면 2개가 같은 제품의 도입부로 연결된다.

### 4단계 — 러닝과 꾸미기 완성

| 화면 | 디자인 작업 |
|---|---|
| 04 러닝 | 달리는 포즈와 노을 강변을 결합한다. 시간 → 거리·페이스 → 일시정지 순서로 시선을 정리한다. 준비·일시정지·완료 화면은 같은 배경과 글자 규칙의 변형으로 만든다. |
| 06 꾸미기 | 큰 전신 미리보기 아래 의상·신발 선택과 목록을 정돈한다. 썸네일의 크기·재질·조명을 맞추고 착용 상태를 명확히 표현한다. 아이템이 적을 때도 의도적인 배치가 되도록 디자인한다. |

결과물: 러닝·꾸미기 완성 화면과 필요한 상태별 디자인. 기존 버튼과 공통 규격을 재사용한다.

완료 기준: 홈과 캐릭터의 형태·재질·빛이 이어지고, 그림을 보면서도 주요 조작과 숫자를 쉽게 읽을 수 있다.

### 5단계 — 커뮤니티·챌린지·내 정보 완성

| 화면 | 디자인 작업 |
|---|---|
| 05 커뮤니티 | 함께 뛰는 장면을 크게 사용하고 모임 정보와 주요 버튼의 위계를 정리한다. 로그인 안내·모임 없음 상태도 같은 화면 구성 안에서 정돈한다. |
| 07 챌린지 | 도전 내용, 준비하는 캐릭터, 진행도, 시작 버튼 순서로 구성한다. 현재의 작은 캐릭터와 큰 카드 중심 구성을 승인 시안의 장면 중심 구성에 맞춘다. |
| 08 내 정보 | 벤치에 앉은 캐릭터와 노을 장면을 완성한다. 이름과 기록 요약을 간결하게 배치하고 기록·챌린지·지갑은 시안처럼 정돈된 목록으로 표현한다. |

결과물: 완성 화면 3장. 필요한 캐릭터 포즈와 배경은 2단계의 제작 기준을 따른다.

완료 기준: 각 화면의 목적이 분명하면서도 홈과 동일한 캐릭터 세계·색감·버튼·타이포그래피를 유지한다.

### 6단계 — 상세 화면 확장과 전체 디자인 마감

작업:
- 기록·지갑·설정·로그인·상세 페이지를 목록형, 정보형, 입력형으로 묶어 공통 레이아웃을 적용한다.
- 팝업·하단 시트·로딩·빈 상태·오류 안내의 디자인을 통일한다. 기능 구현은 이 단계에 포함하지 않는다.
- 주요 8개 화면을 한 장에 놓고 색감, 캐릭터 비율, 버튼, 글자, 여백의 차이를 조정한다.
- 작은 화면과 큰 글씨에서 구도가 무너지거나 문구가 잘리지 않는지 시각적으로 확인한다.
- 기본 남색 디자인을 먼저 마감하고 밝은 테마에도 같은 위계와 가독성을 적용한다.

결과물: 주요 8개 화면 전체 보드, 상세·상태별 디자인 묶음, 공통 규격표, 이미지 자산 목록.

완료 기준: 화면을 넘겨도 같은 앱이라는 인상이 유지되고, 미완성 디자인 항목이 구체적으로 표시되어 있다. 시안·디자인 미리보기·실제 앱 캡처는 명확히 구분한다.

## 4. 비용과 범위 관리

- 이미지 생성은 필요한 포즈와 부족한 자산에만 사용한다. 이미 승인된 화면의 대안 시안을 반복 생성하지 않는다.
- 각 단계는 결과를 모아 한 번에 검토하고 발견된 차이를 묶어서 수정한다.
- 완료율은 코드 변경량이나 테스트 수로 보고하지 않는다. 완성된 디자인 결과물을 기준으로 보고한다.
- 기능 문제를 발견하면 기록만 남긴다. 사용자가 디자인 우선순위를 바꾸기 전까지 기능 작업으로 확장하지 않는다.

## 5. 첫 제출물

첫 제출물은 **공통 디자인 보드 + 캐릭터·배경 기준 보드 + 필요한 이미지 목록**이다. 이 기준을 정리한 후 홈과 시작 화면 제작으로 들어간다.

현재는 계획서만 작성한 상태다. 다음 실행은 1단계부터 시작한다.
