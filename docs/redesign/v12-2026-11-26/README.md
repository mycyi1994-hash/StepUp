# v12 디자인 시제품 적용 (2026-11-26)

사용자가 받은 `StepUp_12차_디자인시제품.apk`(지인이 만든 클릭형 시제품)를 앱에 옮긴다.
사용자: "디자인 · 애니메이션 전면 교체" → "스댕이 키우기는 일단 그냥 두고 디자인만 대충 · 기획 줄게" ·
"web3 관련 넣어도 괜찮아" · "강화는 지금 버전 유지(역행하지 않게), 디자인만 참고".

## 시제품이 무엇인가

- 실제 앱이 아니다. 코드는 웹 화면 하나를 띄우는 3KB 짜리이고, 336장 화면 캡처(밝은 · 어두운 판 각각, 720 × 1598 JPG)를
  누를 자리(`HOT`)로 이어 붙였다. 서버 연결 · 권한이 없다.
- 지금 앱 위에서 다시 그린 것이다 — 하단 탭 다섯 · 서버 규칙 숫자(과속 25km/h · 30초, 보상 30%, 뽑기 확률표, 목표 4,000 ~ 20,000)
  · 버전 1.21.0 이 그대로다. 그래서 대부분 **기능은 그대로 두고 모습만** 옮긴다.
- 가져다 쓸 수 있는 원본은 Lottie(스댕이 7단계)뿐이다. 화면은 그림이라 코드로 다시 짠다.

## 색 · 글자

밝은 테마 값은 지금 `WhiteBlueUi` 와 같다(바닥 #F4F5F9 · 블루 #2458E9 · 카드 흰색). 어두운 테마는 시제품이 카드를 남색(#0E1728)으로,
블루를 #4B83FE 로 쓴다(지금 #101216 · #3D74FA). 신발 상세 위쪽은 남색(#0B193C) 무대.

## 따르지 않는 것 (사용자 결정 2026-11-26)

| 시제품 | 앱 | 까닭 |
|---|---|---|
| 강화: 재료 3켤레 · 성공률 80% · 실패하면 그대로 | 지금의 경험치 강화(0118 — 실패 없음) 그대로, 모습만 참고 | 사용자 "지금 버전 유지, 역행하지 않게" |
| 능력치 설명 "효율 높을수록 빨리 닳음" | 서버 규칙 묶음이 주는 글 그대로(`statMeaningRes`) | 대격변에서 바뀔 수 있다 — 글은 서버 규칙을 따른다 |
| 자유 러닝 중 지도 없음 | 지도는 그대로 둔다 | 기능을 빼지 않는다(같은 원칙) |
| 설정 › 모드의 데모 켜기 · 홈 모드 기본 / 러너 | 그대로(데모는 이미 켠 사람만, 홈 모드는 없음) | 예전 결정(2026-10-26 데모 빼기) · 새 기능 |
| 스댕이 키우기의 숫자(640 / 1,000 · 밥 1그릇 …) | 단계 이름 · 모습만, 숫자 없이 "곧 열려요" | 규칙이 아직 없다 — 예시 숫자로 꾸미지 않는다 |

WEB3(지갑 연결 · 상급 뽑기 · 체인 기록 · NFT 말)는 시제품대로 넣되 지금처럼 `BuildConfig.WEB3` · `WALLET_LINK` 로 가린다 —
스토어 판은 Play 정책(한국 가상자산 앱)이 그대로다.

## 이 판에서 한 것

- 러닝 홈(`HomeContent`): 사진 카드와 오늘 거리 / 적립 / 이번 주 줄을 빼고 "지금 신은 신발" 카드(`home/HomeShoeCard.kt`) —
  이름 ›(신발 상세) · 등급 · 비어져 나온 신발 그림 · 내구도 "남은 / 가득 분"(`durabilityText`) + 수리(신발 탭과 같은 `ShoeRepairSheet`) ·
  러닝 아이템 ›(아이템 탭 — 고른 것, 없으면 가진 수, 없으면 줄 없음). GPS 준비는 제목 오른쪽. 오늘 거리 · 적립은 걸음 칸의 오늘의 활동 시트에 그대로.
- 스댕이 키우기 미리보기(`screens/pup/PupScreen.kt`, 길 `pup`): 방 그림 7단계(시제품 캡처에서 잘라 냄, 밤 테마 따로) · 강아지 Lottie
  (`assets/pup/lv*/` — 가만히 · 누르면 쓰다듬기) · 단계 보기로 일곱 단계를 넘겨 본다. 밥 주기 · 꾸미기는 "곧 열려요".
  입구는 러닝 홈 한 줄 — **테스트 판(debug · qa)에만**(`PupFeature.SHOWN`). 기획이 오면 다시 쓴다.
- 어두운 테마의 카드 · 채움 · 선을 남색 면으로(`DarkPalette` · `DarkBlueUi` — #0F1829 · #172236 · #20283D, 예전 #101216 · #1E2128 · #292E37).
  버튼 파랑은 시제품의 #4B83FE 대신 지금 #3D74FA 그대로 — 흰 글자 대비(4:1)를 지킨다.
- 그림 저작: 시제품의 방 · 꾸미기 그림 · Lottie 는 지인 작업물이다 — 정식으로 쓰기 전에 사용 허락을 받는다(사용자 몫).
