# 시작·로그인·첫 사용 v1 (2026-09-28 전달본)

사용자 전달본 "StepUp 시작·로그인·첫 사용"(`design/onboarding-v1/` — 구현 지시서 · 먼저 보기 · 보낼말 · 흐름표 · 권한 상태표 · 토큰 ·
장면 목록 · 이미지 출처, 새 장면 20개 — 비교 보드 10장은 이 폴더의 `reference-*.webp`)을 앱에 적용했다.
Google 로그인 하나 → 한 장짜리 첫 안내 → 러닝 방법 → 자유 러닝을 고를 때만 필요한 권한 안내. 짙은 남색 바닥 · 흰 주 버튼 ·
기존 강변 사진(`home_banner_blue_night.png` — 시안의 river-night 와 같은 파일)의 아치 구도를 쓴다. 시안 PNG · SVG 를 화면에 붙이지 않았다 —
글자 · 버튼 · 시트는 모두 Compose 요소다. 계정 선택(Credential Manager)과 OS 권한 창은 시스템 UI 그대로다.

## 로그인 — 보존한 것

- 계정 선택은 `GoogleSignIn`(Credential Manager · nonce · 승인 계정 없으면 넓혀 다시 묻기) 그대로. 가짜 계정 선택창 · 비밀번호 입력 · 둘러보기 로그인 없음.
- 서버가 세션을 준 뒤(`TokenResult.Ok`)에만 로그인 표시 · 홈. `Analytics.login` · `pushRegistrar.syncInBackground` · `refreshEconomyInBackground` ·
  `SessionUploadWorker.schedule` 호출을 같은 순서로 둔다. 취소 · 실패 · 예외 모두 `finally` 에서 버튼을 푼다.
- 취소는 오류 없이 01(다시 로그인하러 왔으면 09 안내 그대로). 별도 취소 화면 없음.
- 재로그인 뒤 가이드를 이미 봤으면 첫 안내 없음(`guideSeen`), 초대 · 초대 링크 목적지는 기존 처리 그대로.
- 약관 주소 · 문구는 기존 그대로(`login_terms` · 두 링크). 문서를 요약한 동의 화면 · 마케팅 체크 없음.

## 러닝 권한 — 분기

한 번 고른 러닝 하나에 붙는다(메뉴의 `freeRunPending` · 러닝 화면의 `startPending`, 회전 · 설정 다녀오기에도 이어짐). 준비가 끝나면 **한 번만**
3-2-1(R01)로 가고, 러닝 서비스는 3-2-1 이 끝나야 켜진다. 안내를 닫거나 다른 화면으로 가면 그 의도는 끝난다(돌아와도 저절로 시작하지 않는다).
허용 여부는 앱 표시로 대신하지 않고 매번 OS 에서 읽는다. 앱이 남기는 것은 "물어봤다 · 골랐다"뿐이다 —
`run_activity_request_history`(NEVER · ASKED · BLOCKED), `run_location_chosen`, `run_notification_chosen`(모두 `strideup_prefs`).

| 권한 | 상태 | 보이는 것 | 누르면 |
|---|---|---|---|
| 신체 활동 | Android 10 미만 · 허용됨 | 없음(건너뜀) | — |
| | 아직 허용 안 됨 | 13 | 권한 허용하기 → 시스템 창 / 나중에 · X · 뒤로 · 바깥 · 끌기 → 메뉴(시작 안 함) |

| | 다시 물을 수 없음(창을 띄운 결과로 확인) | 15 | 설정 열기 → 앱 설정(열지 못하면 알림) → 돌아오면 다시 읽어 허용이면 다음, 아니면 15 |
| 위치 | 정확 · 대략이 이미 있음, 또는 전에 고름 | 없음(건너뜀) | — |

| 알림 | Android 13 미만 · 허용됨 · 전에 고름 | 없음(건너뜀) | — |
| | 처음 | 19 | 알림 허용하기 → 시스템 창(허용 · 거절 모두 다음) / 나중에 → 다음(다시 묻지 않음) / X · 뒤로 · 바깥 → 메뉴(시작 안 함) |

- 처음 창을 띄우기 전의 `shouldShowRequestPermissionRationale=false` 만으로 "다시 묻지 않음"이라 하지 않는다. 창을 띄우기 전 · 후의 설명 권유와 이력으로
  가른다(처음 창을 고르지 않고 닫으면 14). 홈의 수동 권한 줄도 같은 이력을 남긴다.
- 예전 한 장짜리 러닝 권한 안내(S2 시안 23)를 본 사람은 위치 · 알림을 이미 고른 것으로 본다 — 기존 사용자를 다시 붙잡지 않는다.
- 같은 차례를 러닝 화면(챌린지 · 다이어트 · 기록 없음 · 이벤트 · 다시 하기로 시작할 때)도 쓴다. 거기서 닫으면 러닝을 연 화면으로 돌아간다.
- 앱 안의 알림 선택(설정 › 알림)은 OS 알림 권한과 따로다 — OS 허용을 받아도 켜지 않는다.
- 추천 코스의 위치 안내(L01)는 기존 코스 흐름의 몫이다(지금은 "준비 중").

## 첫 안내 — 저장 조건

| 행동 | 결과 |
|---|---|
| 러닝 시작 | "봤음" 저장 → 러닝 방법(12). 운동 기록은 시작하지 않는다 |
| 먼저 둘러보기 · X · 뒤로 · 바깥 · 아래로 끌기 | "봤음" 저장 → 러닝 홈에 머문다. 이 화면에서 다시 열리지 않는다 |
| 앱 종료 · 강제 중단 | 저장하지 않는다 — 다음 실행에서 다시 보인다 |
| 도움말 › 앱 사용 안내 | 20 — "봤음"을 되돌리지 않는다 |

러닝 홈에 있고, 초대 링크 · 로그인 뒤 다시 열 초대 같은 목적지나 멈춘 러닝이 없을 때만 뜬다 — 목적지가 있으면 그 화면을 먼저 보이고
안내는 다음에 러닝 홈에 올 때로 미룬다. 홈을 보는 것만으로 권한을 묻지 않는다.
