# 내 정보 첫 화면 — 러닝 패스 (2026-09-27)

사용자가 기록 중심형 시안 4종(`options-all-four.webp`, 설명 `시안-4종-설명.md`) 중 **2번 러닝 패스**를 골랐다.
기준 이미지는 `reference-running-path.webp`(원본 1170 × 2532를 390px로 줄인 것), 지시는 `구현지시서.md`,
카드 배경 원본은 `running-path-card-background.svg`다.

## 구현

| 부분 | 파일 | 내용 |
|---|---|---|
| 카드 | `ui/components/RunningPathCard.kt` | 짙은 남색 면(좌하 `#0D182A` → 우상 `#182E4C`), 5dp 아래 그림자 면, 오른쪽 경로 장식. SVG 의 선을 Canvas 로 옮겼다(좌표 그대로, 1단위 = 1dp) |
| 첫 화면 | `ui/screens/profile/ProfileHome.kt` | 프로필 줄 → 카드(지금까지 달린 거리 · 큰 숫자 · km · 횟수) → 흰 "내 러닝 기록 보기" → 챌린지 · 지갑 · 설정 |
| 상태 | `ProfileViewModel.records` | 불러오는 중(`—`) · 값 · 실패(카드 안 "기록을 불러오지 못했어요." + 다시 시도). 실패를 0km 로 보이지 않는다 |

- 거리 · 횟수는 저장된 러닝 세션 합계(`StepRepository.observeRunTotals`)다. 걸음으로 어림한 거리(`lifetimeKm`)나 최근 몇 회의 합이 아니다.
- 경로 장식은 **실제 위치 · 경로가 아니다.** 지도 · 위치 권한과 무관하고, 화면 낭독에서 빠지며, 움직이지 않는다.
  카드가 좁거나 숫자가 길면 장식을 오른쪽으로 밀어 잘라 내고 글 자리를 먼저 둔다. 숫자는 72sp 에서 40sp 까지 한 칸씩 줄여 km 와 한 줄에 맞춘다.
- 공통 머리(로고 · SUP)와 아래 탭은 앱 셸의 것을 그대로 쓴다. 시안의 "내 정보" 큰 제목은 두 번째 머리가 되므로 두지 않았다(아래 탭의 "내 정보"가 선택돼 있다).
- 어두운 테마는 시안 색 그대로, 밝은 테마는 앱 토큰(흰 주 버튼 → 남색 면에 흰 글자, 앱 규칙). 기록 카드는 두 테마 모두 남색이다.

## 버튼

| 누르는 곳 | 가는 곳 |
|---|---|
| 사진 · 프로필 수정 | 기존 사진 · 닉네임 편집 창 |
| 내 러닝 기록 보기 | 기존 기록 · 통계 화면(최근 기록 · 총 시간은 여기 그대로 있다) |
| 챌린지 | 챌린지 기록(K2) — 거기서 진행 중인 챌린지로 간다(사용 피드백 7에서 정한 흐름, 지시서의 "기존 챌린지 화면"을 현재 앱에 맞춤) |
| 지갑(오른쪽 실제 SUP 잔액, 읽기 전 `—`) | 기존 지갑 |
| 설정 | 기존 설정 목록, 뒤로 가기로 내 정보 첫 화면 |

첫 화면에서 빠진 것: 가운데 큰 문장 · 보유 SUP 큰 숫자 · 거리/횟수/시간 세 칸 · 최근 러닝 3개. 모두 기록 화면과 지갑에서 볼 수 있다.
