# StepUp 내 정보 — 기록 중심형 확장 시안

기존 3번 ‘기록 중심형’을 바탕으로 시각 표현을 다르게 만든 4개 시안입니다. 앱에 적용하기 전의 디자인 비교안입니다.

공통 구조: 프로필 → 누적 러닝 거리와 횟수 → 내 러닝 기록 보기 → 챌린지 / 지갑 / 설정 → 하단 탭.

| 시안 | 디자인 방향 |
| --- | --- |
| 01 트랙 라인 | 화면에 자연스럽게 이어지는 트랙 곡선. 큰 숫자와 열린 여백으로 러닝 기록에 집중합니다. |
| 02 러닝 패스 | 짙은 남색 기록 카드에 경로 선을 더했습니다. 장식은 오른쪽에 모아 숫자의 가독성을 유지합니다. |
| 03 실버 레코드 | 차가운 은백색 카드와 얇게 겹친 남색 면으로 기록을 선명하게 보여줍니다. |
| 04 딥 네이비 | 부드러운 반사광과 깊이감 있는 남색 패널 안에 기록과 흰색 버튼을 함께 담았습니다. |

## 파일

- `01`–`04` PNG: 각각 1170 × 2532 픽셀, 기준 화면 390 × 844의 3배 크기.
- `01`–`04` SVG: 기준 화면 390 × 844. 텍스트, 아이콘, 배경 그래픽, 버튼을 편집할 수 있습니다.
- `00-compare-1-2`, `00-compare-3-4`: 두 시안씩 비교하는 이미지와 SVG.
- `00-all-four`: 네 시안을 한눈에 비교하는 이미지와 SVG.

SVG 글꼴은 Pretendard입니다. 편집 환경에 이 글꼴이 없으면 대체 글꼴이 나타날 수 있습니다. PNG는 글꼴 설치와 관계없이 시안 그대로 표시됩니다. SVG 가져오기 시 편집 도구에 따라 일부 그라데이션이나 마스크는 다르게 처리될 수 있으므로 PNG를 기준 이미지로 확인하세요.

## 공통 스타일

- 배경 `#050912`, 주 텍스트 `#F2F4FC`, 보조 텍스트 `#98A8C0`, 파란 강조색 `#A3BFFE`.
- Pretendard 사용. 기능 이름과 정보 순서는 네 시안에서 동일합니다.
- 작은 메뉴 아이콘 받침을 추가하고, 주 장식은 러닝 기록 영역에 집중했습니다.
- 버튼과 기능 연결은 시각 디자인만 표현했습니다. 이번 결과물에는 웹페이지나 앱 기능 구현이 포함되어 있지 않습니다.

## 데이터와 그래픽

러너님, 34.2km, 러닝 8회, 83.07 SUP는 시안 비교용 예시입니다. 트랙과 경로는 러닝을 표현하기 위한 장식으로, 사용자의 실제 위치·러닝 경로·활동 데이터가 아닙니다. 실제 기록 화면에서 경로를 보여줄 경우에는 실제 저장된 기록에 연결해야 합니다.
