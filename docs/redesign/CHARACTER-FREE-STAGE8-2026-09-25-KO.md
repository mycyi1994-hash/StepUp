## 이번 화면

프로필에서 열리는 러닝 기록, 기록 지도, 지갑, 업적, 알림함 다섯 경로를 같은 디자인으로 확인한다. 이번 소스 변경은 사용자가 먼저 찾을 정보의 순서다.

| 화면 | 반영 |
|---|---|
| 러닝 기록 | 주간·3개월 기록의 그래프와 요약을 지도 입구보다 먼저 배치. 원래 기록 지도 연결은 각 기간 요약 다음에 유지 |
| 지갑 | 공통 상세 화면 틀을 사용하고 잔액 → 적립·사용 요약 → 거래 내역 → 외부 지갑 안내 순서로 정리 |
| 기록 지도·업적·알림함 | 기존 실제 데이터와 빈 상태를 유지하며 소형 화면·큰 글씨에서 화면 배치를 확인 |

지갑 잔액은 기존 원장 흐름, 기록 지도는 기기에 저장된 GPS 경로, 업적은 실제 보유/운동 상태를 읽는다. 테스트에서 표시되는 걸음 수와 모임 자료는 검사 전용이다. 외부 지갑 연결, 실제 보상 지급 및 야외 GPS를 캡처만으로 승인하지 않는다.
