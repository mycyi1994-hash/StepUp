## 진행자 / 참가자 종료(소스 확인 — 다중 사용자 검증 미실시)

- 진행자가 마치면 `party_finish` 로 방이 닫힌다. 남은 사람의 휴대폰은 방 닫힘을 받고 더 묻지 않는다 — 그들의 러닝(측정)은 각자 멈출 때까지 이어진다.
  이제 남은 사람 화면은 "진행자가 함께 달리기를 마쳤어요 · 내 기록은 계속돼요" 띠를 보이고 옛 명단 · 위치를 숨긴다.
- 참가자가 마치면 `party_leave` 로 방에서 나온다. 방과 다른 사람은 그대로다.
- 마칠까요 시트: 참가자 "내 기록을 저장하고 함께 달리기에서 나가요 · 다른 참가자의 러닝은 그대로 이어져요",
  진행자 "내 기록을 저장하면 이 함께 달리기가 끝나요 · 서로의 위치 · 거리는 더 이상 보이지 않아요", 혼자 "내 기록을 저장하고 마쳐요".
  진행자 자동 승계 · 방 유지는 만들지 않았다.

## 시안과 다르게 둔 것

- "6명 함께 달리는 중" → "참여 n명": 다른 사람이 달리는지 멈췄는지 서버가 알려 주지 않는다.
- "크루원은 계속 달리고 있어요" → "내 러닝 일시정지 · 내 기록만 멈췄어요".
- "크루 전체의 러닝은 종료되지 않아요"(진행자에게는 사실이 아님) → 역할별 문구.
- 결과 메시지 "오늘 크루와 함께 3.24km 달렸어요!" → 기존 "크루 러닝 · 거리 · 시간 · 페이스"(혼자 출발한 크루 달리기에도 맞게).
- 입구의 고정 지도 · "한강 · 크루 러닝" 이름표 · 결과 지도 이름표는 두지 않았다. 지도에 다른 사람 점은 공유를 켠 사람만.
- "리더" → "진행자". 보상 줄은 "예상 +x SUP · 확인 전"(서버 확인 전 적립 완료라 쓰지 않는다).
- 덜 쓰는 "내 러닝 기록 보기" · "삭제"는 결과의 ⋯ 안으로.
