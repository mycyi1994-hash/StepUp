## 동작

- 준비(기존 초기화)와 영상이 함께 돈다. 둘 다 끝나면 넘어간다. 준비가 끝난 뒤에는 화면을 누르면 건너뛴다.
- 영상이 끝났는데 아직 준비 중이면 마지막 장면 그림 위, 영상 속 줄 자리에 진짜 로딩 줄이 돈다(실제로 기다릴 때만).
- 준비 실패(14초)는 영상이 끝난 뒤 그림 위에 까닭 · 다시 시도.
- 동작 줄이기(앱 설정 · 기기 애니메이션 끔)면 영상 없이 마지막 장면 그림.
- 소리: 설정의 효과음이 켜져 있고 기기가 막지 않을 때만(무음 · 진동 · 방해 금지 · 시스템 소리 0 · 다른 음악 재생 중이면 소리 없이).
  오디오 포커스를 받지 않아 듣던 음악을 멈추지 않는다.
- 폰 세로는 꽉 채우고(가장자리 잘림), 가로 · 태블릿처럼 넓은 화면(너비/높이 > 0.6)은 다 보이게 넣는다.
- 테마와 상관없이 늘 어두운 장면 — 상태바 아이콘은 밝게, Android 12+ 시스템 시작 화면 바닥도 `launch_ground`(#050A10).
- 화면을 돌려도 인트로를 다시 틀지 않는다. 앱이 뒤로 가면 멈추고 돌아오면 이어서. 8초 안에 끝을 못 받으면 끝난 것으로 본다.

예전 시작 화면(망원 한강공원 사진 + 워드마크가 왼쪽에서 들어옴, 2026-10-25 통합안 01)은 이것이 대신한다.
