# 그림·소리 앱 적용 기록 — 2026-09-25

[파일별 적용표](MEDIA-APPLICATION-2026-09-25.csv)는 이번 디자인 자산 묶음의 그림 89개와 오늘 제작한 소리 원본 29개, 미리듣기 6개를 **파일 하나당 한 줄**로 기록한다. `source`는 원본, `app`은 Android에 넣은 파일, `web`은 뽑기 웹에 넣은 파일이다. 표는 `python tools/audit_applied_media.py`로 재생성·확인한다. 화면 전체 시안 PNG는 실행 그림이 아닌 검토 자료로 [기존 화면 시안 검토표](ASSET-MOCKUP-REVIEW.csv)에 따로 있다.

## 적용된 그림

- 상품 그림 62개: 신발 52개와 의상 10개의 투명 PNG 원본을 640px WebP로 포장했다. 기존 상품 ID를 그대로 유지하고 카탈로그·옷장 카드의 개별 리소스에 연결했다. PNG 한 장을 통째 화면으로 깔지 않으며 버튼·가격·선택 상태는 앱 UI다.
- 분리 배경 4개: 밤/새벽 강변과 러닝 밤/노을 이미지를 기존 독립 배경 리소스에 연결했다. 배경 교체 시 버튼·캐릭터·정보 패널과 따로 바뀐다.
- 기본 착장 러닝 프레임 4개: RUNO/LUMI 두 프레임씩 러닝 중 조건부로 교체한다. 장비나 NFT 신발을 착용한 전체 조합에 적용되는 애니메이션은 아직 아니다.
- 프로필 3개: 벤치와 RUNO/LUMI 앉은 모습을 별도 리소스로 연결했다. 핑크 의상·WND-010처럼 정확히 일치하는 조합에서만 앉은 그림을 쓴다.
- 미스터리 박스 1개: 닫힌 상자 그림을 앱과 웹에 각각 연결했다. 열림·희귀도·버튼은 결과를 꾸며 보여 줄 UI이며 이 그림 자체가 당첨을 뜻하지 않는다.
- 나머지 시안/합성 시험 15개는 `REFERENCE_ONLY`다. `preview-render.png`, 초기 벤치/앉기 그림, 몸·의상·신발 분리 시험, 후면 달리기 시안으로 실제 화면에는 연결하지 않았다.

## 적용된 소리

- 짧은 효과음 26개를 Android `res/raw`에 포장했다. 공통 조작, 착용 성공, 게시·저장 성공/오류, 보상 확정, 러닝 상태, 뽑기 화면 진입 18개는 해당 앱 이벤트에 연결했다. 사용자 소리 설정·무음·방해금지·다른 미디어 재생을 존중한다.
- 뽑기 거래 8개(`draw_charge`, `draw_box_open`, 희귀도 4개, `draw_cancel`, `draw_fail`)는 Android에도 포장해 두었고 웹에는 별도 복사했다. 웹 코드는 확인된 거래 영수증과 `Drawn` 결과에만 충전·열림·공개음을 연결하고, 서명 거절/거래 실패에는 각각 취소/실패음을 연결한다. 앱의 뽑기 버튼은 계약 설정이 없으면 잠긴 상태이고 배포된 웹 실행 경로는 아직 검증되지 않았다.
- 배경 루프 3개는 밤·새벽·옷장 장면에 연결했다. 기본값은 꺼짐이며 `설정 > 경험 설정 > 배경 소리`로 켤 수 있다. 앱이 전면에서 벗어나거나 다른 음악이 재생되면 정지한다.
- `preview_*.wav/mp3` 6개는 검수용 묶음이다. 화면 조작에 재생하지 않는다.

## 아직 남은 일

1. 로컬 PC에 Android SDK/JDK/adb가 없어 이 변경 묶음의 Android 컴파일·기기 캡처는 아직 수행하지 못했다. 소스·리소스·웹 빌드 검사만 통과했다. 따라서 출시용 디자인 검수를 마쳤다고 표기하지 않는다.
2. 뽑기 8개 소리는 웹 거래 코드까지 연결했지만 실제 DApp/계약 설정과 배포, 지갑·트랜잭션 실기기 검증이 필요하다. 결과가 없는 상태에서 당첨음은 재생하지 않는다.
3. 임의의 의상·신발·모자 조합을 캐릭터의 모든 포즈와 러닝/후면 동작에 정확히 합성하는 그림은 이 묶음에 없다. 시험 시안 15개를 출시 자산으로 간주하지 않는다.

`APP_ACTIVE`는 현재 화면·카탈로그에서 참조됨, `APP_CONDITIONAL`은 특정 캐릭터·장비·상태에서만 표시됨, `APP_EVENT_ACTIVE`는 해당 소리 이벤트에 연결됨, `WEB_TRANSACTION_GATED`는 계약/배포 뒤 거래 결과에서만 재생됨, `AMBIENCE_OPT_IN`은 사용자가 켜야 재생됨을 뜻한다. 표의 상태는 디자인의 시각 검수 완료를 뜻하지 않는다.
