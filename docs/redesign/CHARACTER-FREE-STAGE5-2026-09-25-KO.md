## 원문 제안에서 바로 적용하지 않을 부분

- 하단 메뉴 계산이 `폭 / 6`이라는 설명은 소스와 다르다. `AppChromePolicy.tabs`는 4개이고 가운데 뽑기를 포함해 식의 분모는 5다. 실제 390dp 글자 폭은 여백을 빼기 전 약 78dp다. 잘못된 분모를 원인으로 고치지 않는다.
- 큰 글자 문제를 무조건 11sp까지 축소해서 해결하지 않는다. 먼저 폭/여백과 적절한 문구 줄바꿈을 검토하고 접근성을 유지한다.
- 러닝 중 2열과 완료 카드 3열은 필요한 폭이 다르다. 두 임계값을 무조건 같은 값으로 바꾸지 않고 각각 캡처로 확인한다.
- 스크롤 영역 경계에서 일부 카드가 보이지 않는 것과 텍스트 자체가 잘리는 것은 구분한다. 화면 밀도 문제라는 관찰은 수용하되, 모든 스크롤을 제거하는 기준으로 사용하지 않는다.
- 배너 화살표를 세로 중앙으로 되돌리는 제안은 채택하지 않는다. 4단계에서 해결한 문구 겹침이 재발할 수 있다.
- 커뮤니티 안내를 줄일 때 서버/로그인 상태, 실제 데이터 또는 버튼 동작은 바꾸지 않는다. 로그인된 상태, 게스트 빈 상태, 게스트+검사 자료는 후속 검증에서 구분한다.
