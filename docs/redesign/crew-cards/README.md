사용자 전달본 "StepUp · 확정 2번 크루 명함형 구현 지시서"(ZIP 107f4205, 화면 90장 · 컴포넌트 · 흐름)를 기존 앱의
커뮤니티에 넣었다. "러닝 이야기" 글자 탭은 그대로 두고, 옆에 "크루 모집" 글자 탭을 더했다. 로그인 · 서버 · 데이터 모델은
기존 것을 이어 쓴다(크루 · 멤버 · 크루 러닝 거리). 새 홍보 페이지나 비교 페이지는 만들지 않았다.

## 서버(0047)

`supabase/migrations/0047_crew_cards.sql` — 기존 크루 표에 명함 칸을 더하고 가입 신청을 신청서로 바꿨다.

- 명함 칸: 크루장 한마디 · 이름 이미지 바탕(넷 중 하나) · 대표 사진(`crew_images`, 512px 정사각형) · 정기 모임(요일 · 시각) ·
  한 번에 달리는 거리 · 분위기 · 모집 정원 · 모집 중/쉼 · 이번 주 목표(km) · 레벨.
- 가입 신청서(`crew_applications`): 고른 문구와 한마디를 따로 남긴다. 기다림 · 승인 · 미승인 · 취소, 본 적 있는지. 같은 요청 키로 다시 보내면
  같은 신청서다(전송 실패 뒤 "다시 신청 보내기"). 예전 `crew_join_requests` 는 옮기고 지웠고, 예전 앱 함수(`crew_join` 등)는 같은 이름으로 신청서를 쓴다.
- 승인은 크루를 잠근 뒤 정원을 다시 본다 — 그사이 찼으면 `crew_full`(시안 81). 정원은 지금 인원보다 작게 못 한다(`capacity_below_members`).
- 주간 목표 달성은 기존 크루 거리 규칙 그대로다: 한국 시간 월요일부터, 지금 멤버가 크루 러닝(함께 달리기로 적힌 러닝)으로 달린 거리.
  126/160 = 79%, 목표를 200 으로 바꾸면 126/200 = 63% · 74km 남음. 100% 를 넘으면 숫자는 그대로 · 바는 끝까지만. 목표가 없으면 나누지 않는다.
- 크루장 넘기기 · 멤버 내보내기 · 크루 해산 · 신고(`content_report` 'CREW').
- 서버 검사: `supabase/tests/schema_test.sql` 의 "크루 명함형(0047)" 구간(약 60개).

## 정하지 않은 것은 만들지 않았다

- **레벨**: 계산식 · 승급 기준 · 상급 등급 이름 · 보상은 정해지지 않았다. `crews.level` 칸은 있지만 어떤 서버 함수도 값을 넣지 않는다.
  값이 없으면 시안처럼 "새 크루"로 보이고, 레벨 안내 시트는 "아직 레벨이 정해지지 않은 새 크루예요"와 이번 주 활동만 말한다.
  레벨을 읽지 못한 것(시안 68)과 레벨이 없는 것은 따로 보인다.
- **이름 중복**: 기존 정책에 없어 막지 않는다(시안 36의 "이미 사용 중인 이름" 대신 실제 제약인 1~40자만 그 칸 아래에 보인다).
- **활동 지역**: 필수가 아니다(기존 정책). 지역이 없는 크루는 범위로 거를 때 빠지고, 범위를 풀면 보인다.
- **푸시**: 가입 결과를 푸시로 알리지 않는다. 목록 · 상세를 다시 읽을 때(앱 안 — 목록은 다른 화면이나 다른 앱에서 돌아올 때도, 30초에 한 번까지)
  아직 보지 않은 승인 · 미승인을 띠로 알리고, 누르면 결과 화면(18 · 19). 승인은 기존 "크루에 가입했어요" 알림도 그대로 남는다.
- 금속 배지 · 방패 · 왕관 · 게임 등급 · XP 바는 없다 — 레벨은 짙은 파랑 칩 하나, 목표는 가는 진행 바 하나.
- 스크린샷의 크루 이름 · 숫자 · 사진은 앱 코드에 없다. 기기 검사만 시안 패키지의 예시(퇴근런 · 해뜨런 사진 포함)를 가짜 서버 자료로 쓴다.

## 다르게 한 것 · 옮긴 것

- 예전 "함께 뛰기" 글자 탭(번개 모임 · 내 크루)은 지우지 않고 크루 모집 목록 끝의 "번개 모임 · 같이 달리기 보기" 줄 안쪽으로 옮겼다.
  지도 · 내 크루(예전 크루 탭: 이름 검색 · 로비 · 게시판) 아이콘도 그 안에 그대로 있다.
- 예전 "모임 만들기" 화면은 만들기 1단계로 바뀌었다. 내 크루(예전 크루 탭)의 "모임 만들기"도 크루 모집 목록과 같이, 남겨 둔 초안이 있으면
  이어 쓸지 먼저 묻는다(39 · 78). 예전 가입 방식(바로 가입 · 승인제)은 운영 설정(74 · 90)의 "가입 방식"으로 옮겼다 —
  새로 만드는 크루는 시안대로 크루장이 확인한다.
- 멤버 · 크루장은 상세에서 기존 크루 게시판 · 같이 달리기 대기실로 간다(상세 안의 줄). 초대 링크 · 크루 알림은 크루 상세를 연다.
- 모집 설정(43)의 "직접 입력"은 시안대로 주간 목표 수정(46)으로 간다(운영 중인 크루의 목표는 확인 뒤 바로 바뀐다). 모집 설정을 저장할 때는
  이 화면에서 목표를 바꾼 경우에만 목표를 보낸다 — 46에서 바꾼 값을 덮지 않는다. 만드는 크루의 "직접 입력"은 초안에만 들어간다(88).
- 신청을 보낸 뒤 응답을 잃어 "다시 신청 보내기"를 눌렀는데 그사이 그 신청이 미승인됐으면 결과(19)로 간다(가입한 것으로 보이지 않는다).
  그사이 취소됐으면 새 신청으로 보낸다. 수정할 크루를 읽지 못하면 빈 칸을 열지 않고 다시 불러오기를 보인다.
- 사진은 OS 사진 선택기로 고르고 앱 안에서 정사각형으로 맞춘다(28, 손가락으로 옮기고 4배까지 확대). 읽지 못한 사진(29) · 사진 접근 불가(69)는
  다른 사진 · 기본 이미지로 이어진다. 기본 이미지(30)는 실제 크루 이름 전체(두 줄까지)와 고른 바탕을 쓴다.
- 만들기 · 수정 중 나가면 "저장 후 나가기"(38)로 이 폰에 초안을 남긴다(계정마다 따로, 로그아웃 · 계정 데이터 지우기 때 함께 지운다).
  수정 초안을 다시 열면 "처음 값으로" 되돌릴 수 있다. 저장이 실패하면 입력 · 이미지가 그대로 남고 같은 요청 키로 다시 저장한다(37).
- 크루 이름 · 소개가 길면 두 줄에서 줄인다. 아래 고정 버튼은 본문을 가리지 않는다(본문이 버튼 위에서 끝난다). 시트는 배경을 누를 수 없고,
  닫기 · 취소는 바꾸기 전으로 돌아간다.
