# 프로필 수정 v1 (2026-09-28 전달본)

사용자 전달본 "StepUp · 프로필 수정"(`design/profile-edit-v1/` — 구현 지시서 · 먼저 보기 · 장면 목록 · 토큰, 시안 12장면 — 비교 보드 6장은
이 폴더의 `reference-*.webp`)을 앱에 적용했다. 내 정보 "러닝 패스"의 짙은 남색 · 밝은 글자 · 흰 주 버튼을 잇는다.

## 화면 — 새 `Routes.PROFILE_EDIT`(`profile/edit`, 부모 내 정보, 하단 탭 없음)

내 정보의 "프로필 수정"(또는 사진)을 누르면 예전의 작은 창 대신 **전체 높이의 편집 화면**이 열린다. 뒤로 가면 내 정보.

| 장면 | 무엇 | 어떻게 |
|---|---|---|
| 01 · 02 | 편집 | 사진 100dp · "사진 변경" · "사진은 선택하면 바로 저장돼요." · 닉네임 입력(한 줄 18sp, 길면 가로로 흐름, 지우기 48dp) · 길이 `n / 16` · 아래 "저장". 저장된 이름과 같으면(저장과 같은 정규화 — 앞뒤 공백 · 16자) 저장을 누를 수 없다 |
| 03 · 04 | 사진 메뉴 · 기본 이미지 | "앨범에서 사진 선택"(OS 사진 선택기 — 권한을 새로 묻지 않는다) · "기본 이미지 선택"(기존 16개 이모지, 순서 · 번호 그대로, 체크는 저장된 것에만). 누르면 바로 저장, 저장되면 시트를 닫는다. 지금 쓰는 것을 다시 누르면 저장하지 않는다. 닫기 · 바깥 · 뒤로는 시트만 닫고 이름 초안은 그대로 |
| 05 · 06 | 빈 이름 · 16자 | 비워도 저장된다(내 정보에는 기본 호칭 "러너님"). 16자를 넘는 입력 · 붙여넣기는 받지 않는다(이미 쓴 글자를 지우지 않는다) |
| 07 · 08 | 사진 저장 중 · 실패 | 사진 안에만 진행 표시, 그동안 사진 변경 · 이름 저장을 막는다(이름 입력은 된다). 실패하면 "사진을 저장하지 못했어요. 기존 사진을 유지했어요." · "다시 선택" |
| 09 | 수정 중 나가기 | 저장하지 않은 **이름**이 있을 때만 — "계속 수정" · "닉네임 버리고 나가기"(이름 초안만 버린다). 이번에 사진을 바꿨으면 "이미 바꾼 사진은 유지돼요." |
| 10 · 11 | 이름 저장 중 · 실패 | "저장 중…"(입력 · 사진 변경 · 다시 누르기 막음), 실패하면 입력한 이름 그대로 "다시 저장" |
| 12 | 저장 완료 | 실제로 저장된 뒤에만 내 정보로 — 새 이름과 "닉네임을 저장했어요." 한 번 |

## 저장 — 기존 규칙 그대로, 결과는 실제 저장 뒤에만

- 닉네임: `UserPrefs.setNickname`(앞뒤 공백 · 16자) 그대로. 최소 길이 · 중복 검사 · 변경 비용 · 대기 기간을 더하지 않았다.
- 사진 · 기본 이미지: 고른 즉시 저장(기존). 저장은 앱 범위(`ProfileEditor`)에서 끝까지 한다 — 편집 화면을 나가도 반쯤 저장되지 않고,
  다시 들어오면 지금 단계를 본다(저장하지 못한 이름 초안은 되살린다). 사진 작업과 이름 작업의 단계 · 실패는 서로 덮지 않는다.
- 갤러리 사진(`AvatarPhotoStore`): 긴 변 512px · JPEG 90(기존 정책) + 사진 방향을 바로 세운다. 큰 사진은 줄여 읽는다(화면 스레드가 아님).
  새 사진은 **임시 파일**에서 다시 읽어 확인한 뒤에만 기존 파일과 바꾸고, 설정(아바타 번호 · 리비전 — `UserPrefs.useCustomAvatar` 로 한 번에)을
  적지 못하면 기존 파일을 되돌린다. 실패하면 기존 사진 · 번호 · 리비전이 그대로다. 사진을 외부 서버에 올리지 않는다.

## 시안과 다르게 한 것

| 무엇 | 왜 |
|---|---|
| 입력칸 아래 "다른 러너에게 이 이름으로 보여요." → "내 정보와 러닝 화면에 이 이름으로 보여요." | 닉네임은 이 휴대폰에만 저장되고 서버로 가지 않는다 — 다른 러너에게 보이지 않는다(커뮤니티 · 랭킹 이름은 서버 계정의 것) |
| 사진을 저장한 뒤 안내 줄이 "사진을 저장했어요." | 화면 낭독이 성공을 알 수 있게(지시서 "진행 · 실패 · 성공을 알린다") |
| 사진 자리는 실제 아바타 — 기본 이미지(이모지) 또는 갤러리 사진 | 시안의 사람 모양은 대체 그림이다(지시서). 갤러리 사진을 쓰는데 파일이 없을 때만 사람 모양 |
