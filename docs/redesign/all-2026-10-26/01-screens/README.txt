StepUp 화면 시안 — BLACK / WHITE

각 테마 9장, 총 18장. PNG 1080 × 2340.

active: 자유 러닝 중. 지도 확대, 중앙 위치 표시, 거리·시간·평균 페이스·현재 속도 하단 2×2, 작은 제어 버튼.
lobby: 크루 러닝 / 진행 중인 대기실. 추천 코스 탭 제거.
create-direct-together: 직접 설정 + 같이 뛰기.
create-direct-remote: 직접 설정 + 원격 뛰기.
create-free-together: 자유 러닝 + 같이 뛰기.
create-free-remote: 자유 러닝 + 원격 뛰기.
compose: 번개 러닝 모집 글쓰기.
profile: 내 정보 / 누적 거리 프레임과 사람 없는 배경.
run: 자유 러닝 시작 / 내 소속 크루.

화면의 거리, 시간, 크루, 모집 내용은 시안용 예시입니다. 이번 결과물은 화면 이미지이며 실제 StepUp 레포에 적용한 변경 사항은 아닙니다.
배경 15종은 별도 stepup-backgrounds-15.zip에 있습니다. 대화 미리보기에서 무작위 배경 전환을 확인할 수 있습니다.
