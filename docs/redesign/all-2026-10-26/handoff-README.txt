StepUp — 전체 디자인 자료
2026-10-26

01-screens: 블랙 9장 / 화이트(light) 9장, 총 18장. PNG 1080 × 2340.
02-backgrounds-15: 사람 없는 배경 원본 15종과 생성 프롬프트.
03-overviews: 주요 변경 화면, 블랙 전체, 화이트 전체, 배경 15종 모음.
04-interactive-preview: 최신 미리보기. StepUp-latest.html을 브라우저로 열면 화면·테마·랜덤 배경을 전환할 수 있습니다.
05-earlier-version: 초기 3개 화면 미리보기와 수정 전 인물 포함 배경. 이전 작업 보관용입니다.
06-editable-source: 최신 및 초기 미리보기의 편집용 HTML 소스.
MANIFEST.json: 포함 파일 목록, 크기, SHA-256.

최신 화면: 번개 모집, 내 정보, 러닝 시작, 자유 러닝 중, 크루 대기실, 새 대기실의 코스·러닝 방식 4가지 조합.
최신 배경은 모두 사람이 없는 버전입니다. 이전 인물 포함 배경은 05-earlier-version에만 보관했습니다.

미리보기는 압축을 푼 뒤 HTML 파일을 열어 사용하세요. 글꼴을 처음 불러올 때 인터넷 연결이 필요할 수 있습니다.
이 자료는 UI 디자인 시안입니다. 화면의 기록·크루·모집 내용은 예시이며, 실제 StepUp 레포의 배포 코드가 아닙니다.
