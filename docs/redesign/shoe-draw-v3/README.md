# 신발 뽑기 디자인 26장 (2026-09-28 전달본 → 2026-09-29 앱 적용)

사용자 전달본 "신발 뽑기 디자인"(화면 26장, Drive 두 링크는 같은 디자인)을 앱에 넣었다. 비교 보드는 이 폴더의 `reference-*.webp`
(전달본 화면을 폰으로 찍은 것). v2 두 칸(`docs/redesign/shoe-draw-v2/`)의 **화면**을 대체한다 — 수 · 연결 · 결과 확인 규칙과 서버(0042)는
v2 그대로다(v2 README 의 "데이터 — 서버 값만" · 뽑기 판정 설명이 여전히 맞다. 그 문서의 장면 번호는 v2 번호).

경로는 그대로 `Routes.MYSTERY_BOX`, 하단 가운데 **뽑기 탭**(`Screen.Draw`, `Header.Main`).

## 다르게 한 것 · 두지 않은 것

- 흐름 화면(04 · 05 · 06–08 · 19)은 하단 탭만 걷는다. 로고 · 잔액 머리는 셸이 그대로 그린다 — 화면이 로고를 다시 그리지 않는 설계 규칙 때문에 05 의 "건너뛰기"는 머리의 잔액 자리가 아니라 그 아래 제목 줄 오른쪽이다.
- 안내창 틀은 설정 v1 시트(모서리 27 · 제목 21sp)를 그대로 쓴다 — 전달본(28 · 23sp)과 조금 다르다.
- 밝은 테마는 전달본에 없어 어두운 값에서 끌어냈다.
- 가격 · SUP 결제 · 확률 · 나올 수 있는 신발 목록 · 새 보상은 없다. 삭제된 고정 설명("러닝 1km마다" · "오늘 남은 기회")은 메인에 다시 두지 않았다(ⓘ 안내창 안에만).
- 모르는 수는 "—", 결과 확인 중은 "확인 중" — 0 으로 보이지 않는다.
