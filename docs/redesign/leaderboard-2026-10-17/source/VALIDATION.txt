검증 기록 — 2026-10-17

수행 완료:
- 전달 패키지의 fragment가 최신 인라인 시안과 바이트 단위로 일치.
- 패키지 안의 이동 가능한 Node 빌더 실행 성공.
- JavaScript 구문 검사 통과(new Function).
- 정적 querySelector/querySelectorAll 대상 존재 확인.
- 최신 화면 3개: 크루 순위, 개인 러닝 순위, 주간 포인트.
- 화면마다 배경 1개와 트랙 선 3개 포함. 배경 비교 스위치 포함.
- 이미지 3개 모두 포함되어 있으며 실제 로고 자산과 원본 일치.
- source/ 파일이 최신 작업 원본과 일치.
- 모션 감소, 비가시 화면/백그라운드/상세 시트 정지 코드 포함.
- motion-spec.json 및 data-contract.json 유효한 JSON.
- reference.html 독립 실행 래퍼 생성 완료.
- window.openai 사용은 widgetState/setWidgetState로 제한됨.
- 패키지 manifest 생성, ZIP CRC 및 압축 내용 일치 검증 수행.

수행하지 않은 검증:
- 브라우저 실제 렌더링과 픽셀 단위 시각 검증.
- 실제 앱 소스 반영, 앱 컴파일, API 연결 검증.
- 실제 기기의 모션 부드러움, 프레임 시간, 발열·전력 측정.
- 실제 서버의 주간 집계·동점·포인트 정정 정책 확인.

앱 및 기기 검증을 통과한 구현으로 간주하지 않는다. 클로드 구현 후 HANDOFF.txt의 완료 기준을 확인한다.
