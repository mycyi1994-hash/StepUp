StepUp 앱에 첨부한 최신 리더보드 3개 화면과 애니메이션 배경을 구현해줘.

먼저 HANDOFF.txt, motion-spec.json, data-contract.json을 읽고 reference.html과 source/preview.html을 확인해. 실제 저장소의 지침과 기술 스택, 기존 리더보드/기록/크루/포인트 API를 조사한 뒤 기존 구조에 연결해. 이 패키지에는 앱 소스가 없고, 프레임워크나 앱 파일명은 확인되지 않았다. 추측한 클래스명이나 API가 존재하는 것처럼 작업하지 마.

사용자가 선택하고 수정 요청한 방향은 다음 3개다. 이전 4개 시안이나 이전 주간 요약 레이아웃으로 돌아가지 마.

1. 크루 순위
1위는 큰 블루 영역으로 독립시키고 이름·기록·큰 숫자 1을 강조한다. 2·3위도 일반 목록과 분리해 나란히 보여준다. 이후 순위는 목록, 우리 크루 순위는 하단에 고정한다. 하단을 누르면 우리 크루의 앞뒤 순위를 보여준다.

2. 개인 러닝 순위
내 순위를 큰 이탤릭 숫자로 보여주고 지난주 대비 순위 변화를 함께 표시한다. 바로 앞 러너와 현재 거리 차이를 블루 영역에 강조한다. 내 주변 순위/상위 러너를 전환할 수 있고, 목록에서 나를 강조한다. 하단에는 내 누적 거리와 러닝 횟수, 이번 주 기록 상세 진입을 둔다.

3. 주간 포인트
이번 주 적립 포인트와 내 순위를 크게 보여준다. 전체 러너/우리 크루 순위를 전환한다. 1위 행을 강조하고, 하단에는 바로 앞 순위와의 포인트 차이 및 내 주변 순위 상세 진입을 둔다. 보유 잔액, 토큰 가치, 예상 수익을 표시하는 화면으로 바꾸지 마.

공통 디자인:
- StepUp 딥 네이비 #061B30, 블루 #1450FF, 흰 숫자와 실제 로고를 유지한다.
- 일반 글꼴로 로고를 다시 타이핑하지 말고 assets/logo.png 또는 저장소의 같은 원본 자산을 사용한다.
- 시안의 이름·순위·수치·날짜·모노그램은 샘플이다. 실제 계정, 크루, 기록, 프로필 이미지와 집계 기간에 연결한다.
- 시안의 휴대폰 프레임, 가짜 상태바, 캐러셀, Tweak, 배경 비교 스위치, window.openai 기능은 앱 UI에 넣지 않는다.

애니메이션 배경:
네이비 배경 위의 고정된 러닝 트랙 3개를 따라 푸른 빛이 천천히 흐른다. 크루 1위 영역에는 별도의 빛이 지나간다. 순위 숫자·목록·버튼은 배경과 함께 움직이면 안 된다.
motion-spec.json의 곡선, 주기, 강도, 레이어 구조를 기준으로 현재 앱 기술 스택에 맞게 구현한다. 웹 시안의 CSS를 네이티브 앱에 그대로 붙이는 작업이 아니다. 영상/GIF나 새 대형 3D 엔진을 추가하지 말고 기존 렌더링·애니메이션 도구를 우선 사용한다.
보이지 않는 화면, 앱 백그라운드, 상세 시트가 열린 상태에서는 모션을 멈춘다. 시스템 모션 감소 설정에서는 정적인 트랙 배경을 유지한다. 목록을 바꾸거나 상태가 갱신될 때 배경을 재생성해 처음부터 반복하지 마.

데이터와 정책:
시안은 크루를 참여 러너 1인당 거리, 개인을 누적 거리, 포인트를 주간 적립으로 나누었다. 이 기준은 시안 제안이며 확정된 서버 정책이라고 간주하지 마. 기존 집계·주간 시간대·동점·취소/정정 정책을 확인해 유지하고, 차이가 있으면 어댑터에서 분리해 보고해. P를 $SUP 잔액이나 원화로 임의 변환하지 마. 보상 지급·신발 소모·광고 수익·토큰 수수료 로직은 이번 UI 작업에서 바꾸지 마.
본인 순위와 앞뒤 기록은 서버 집계 결과를 사용해. 현재 받은 목록 페이지 안에서만 내 순위를 계산하지 마. 이전 주 데이터가 없으면 임의의 상승 숫자를 만들지 마.
API가 없는 부분은 명시적인 개발용 fixture와 어댑터 경계로 분리하고, 실제 데이터 연결이 안 된 상태를 완료로 보고하지 마. 가능한 UI 구현은 계속 진행하되 필요한 서버 계약과 남은 연결을 명확히 남겨줘.

실제 앱을 수정하고 관련 빌드·검증을 수행해. 작은 화면·글꼴 배율·긴 이름·빈 순위·동점·미집계·통신 실패를 처리해. 첫 진입, 탭 반복 전환, 상세 열기/닫기, 백그라운드 복귀, 모션 감소 설정을 확인하고 실제 기기에서 배경의 부드러움과 발열/부하를 점검해. 수행하지 못한 검증은 완료했다고 쓰지 마.

완료 보고:
수정 파일, 각 화면의 데이터 연결 위치, 확인한 집계 정책과 남은 정책 차이, 빌드·검증 결과, 3개 화면 캡처와 배경 모션 영상, 미연결 API 및 남은 제한을 정리해줘. 승인된 디자인을 임의로 다시 디자인하지 마.
