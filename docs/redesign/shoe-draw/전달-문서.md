# StepUp 신발 뽑기 — 무료 정책 반영 시안

이 문서와 같은 폴더의 세 화면이 최신 기준이다. 이전 SUP 결제형 뽑기 화면과 비용 확인창을 대체한다. 이 산출물은 앱에 적용하기 전 디자인이며 실제 회원 상태를 바꾸지 않는다.

## 확정 요청

- 나올 수 있는 신발 목록을 삭제한다.
- 현재 모든 뽑기는 무료다. SUP 잔액, 가격, 결제·구매·충전, 비용 확인창을 표시하지 않는다.
- 첫 가입 회원에게 무료 뽑기 10회를 제공한다.
- 매일 무료 뽑기 기회 3회를 제공한다.
- WEB3 지갑을 연결하면 상급 뽑기 10회를 추가 제공한다.
- WEB3 지갑이 연결된 회원은 러닝 1km당 상급 뽑기 1회를 얻는다.
- 무료 뽑기와 상급 뽑기의 사용 가능 횟수는 별도로 보여준다. 지갑 연결 여부가 일반 무료 뽑기 이용을 막지 않는다.

## 세 화면

### 01-free-draw

신발 탭에서 뽑기를 누르면 기본으로 여는 화면. 상단에서 `무료 뽑기`가 선택된다. 기존 StepUp 상자와 받침, 조명을 유지한다. 남은 무료 뽑기 횟수를 크게 보여주고 아래에서 첫 가입 선물과 오늘 무료 기회를 구분한다.

시안은 처음 가입한 날이며 사용 전이다. 가입 선물 10회와 당일 무료 3회를 함께 지급하는 기준으로 총 13회를 표시했다. `WEB3 지갑 연결 혜택`을 누르면 상급 탭의 지갑 연결 안내로 이동한다. 주 버튼은 `무료로 1회 뽑기`다.

### 02-premium-connect-wallet

지갑이 연결되지 않은 상태에서 상급 탭을 누르거나 연결 혜택을 누른 화면. 상급 뽑기도 무료임을 설명하고 `처음 연결 10회`, `연결 후 러닝 1km마다 +1회` 두 규칙만 보여준다. 주 버튼 `WEB3 지갑 연결하기`는 실제 앱의 지갑 연결 흐름을 연다.

지갑을 연결하라는 UI는 허가나 서명 성공을 뜻하지 않는다. 연결과 회원 보상 지급이 서비스에서 확인된 후에만 연결 완료 상태와 횟수를 갱신한다. 취소·실패 시 횟수는 늘어나지 않는다.

### 03-premium-running

연결 확인 및 처음 연결 선물 지급이 완료된 상태의 예시다. 상급 뽑기 10회가 남았고 러닝으로 추가 지급받은 횟수는 0회다. 러닝 진행 거리는 0.6km인 예시로 다음 1회를 받기까지 0.4km를 보여준다. 진행률은 60%다. 주 버튼은 `상급으로 1회 뽑기`다.

`첫 연결 선물`과 `러닝으로 받은 기회`의 숫자는 해당 출처에서 남아 있는 사용 가능 횟수로 통일한다. 최초 지급량이나 평생 누적 횟수를 잔여량과 섞어 합계가 맞지 않게 표시하지 않는다.

## 뽑기 동작

선택된 종류의 기회 1회를 사용하는 버튼이다. 무료이므로 종전의 SUP 비용 확인창은 사용하지 않는다. 탭만 바꾸거나 연결 안내를 열 때는 기회를 사용하지 않는다.

실제 뽑기 버튼을 누르면 중복 요청을 막는다. 서비스가 확정한 당첨 결과와 남은 횟수를 받아 이전에 만든 상자 열기 연출과 결과 화면으로 연결한다. 확인되지 않은 결과를 먼저 연출하거나 클라이언트에서 임의로 횟수를 지급·차감하지 않는다. 오류·재시도에서 중복 차감되지 않아야 한다.

결과 화면에서 내 보유 신발로 이동한다. 뽑은 신발을 자동으로 착용시키지 않는다. 상급이라는 이유로 금색 상자, 등급 보석, 폭죽 등 게임 장식을 추가하지 않는다.

## 이번 시안에서 정하지 않은 운영 기준

아래 사항은 화면 디자인 때문에 임의 확정하지 않는다. 기존 정책이나 후속 결정을 사용한다.

- 당일 무료 3회의 갱신 시각·시간대, 미사용분 이월·소멸 여부.
- 첫 가입일에도 매일 무료 3회를 동시에 지급하는지. 현재 그림은 동시 지급 기준이다.
- 러닝 거리 인정 기준, 여러 러닝 간 소수점 거리 누적, 연결 전 러닝의 소급 여부.
- 러닝 보상 한도와 거리 기록의 검증 기준.
- 각 종류의 신발 지급 목록·확률·중복 지급 처리.
- 기회 사용 시 가입·일일·러닝 등 지급 출처의 차감 순서.

최초 연결 선물은 이 시안에서 1회성으로 해석했다. 지갑을 반복 연결해 선물이 반복 지급되는 동작을 만들지 않는다. 서비스 정책이 다르면 해당 문구와 지급 처리를 함께 조정한다.
