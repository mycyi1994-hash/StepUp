# 신발 뽑기 — 모두 무료 (2026-09-27)

사용자가 준 "StepUp 신발 뽑기 — 무료 정책 반영 시안"(`전달-문서.md`, 시안 `reference-*.webp`)을 앱과 서버에 적용했다.
문서가 "정하지 않음"으로 둔 운영 기준은 사용자가 "알아서 기본값으로"(확률도 "일단 알아서") 맡겼다 — 아래 **기본값**이
그 결정이다. 모두 운영 값(`economy_settings`)이라 배포 없이 `admin_economy_set` 으로 바꿀 수 있다.

## 정책

| 항목 | 값 | 어디서 |
|---|---|---|
| 모든 뽑기 무료 | SUP 가격 · 결제 확인창 없음. 서버의 `draw_paid` 는 닫았다(예전 앱이 불러도 SUP 가 나가지 않는다) | 0042 |
| 첫 가입 | 무료 10회 | 0023 그대로 |
| 매일 무료 | 3회(`daily_free_draws`) | 0042 |
| 지갑 첫 연결 | 상급 10회, 첫 번은 Genesis(에픽 이상) | 0025 그대로 |
| 러닝 | 지갑 연결 뒤 러닝 1km(`premium_run_step_m` = 1000)마다 상급 1회 | 0042 |

### 기본값(문서가 정하지 않은 것)

- **매일 무료 3회**: 한국 날짜(자정)로 새로 준다. 안 쓴 것은 다음 날로 넘기지 않는다. 가입한 날에도 3회를 함께 준다(시안의 13회).
- **쓰는 순서**: 무료는 오늘 몫 → 가입 선물(오늘 몫이 자정에 사라지니까). 상급은 지갑 선물 → 러닝으로 받은 기회.
- **러닝 거리**: 서버가 인정한 경로 거리(`walk_sessions.gps_credit_m` — 경로로 잰 것만, 하루 GPS 상한 안)만 센다.
  무효(VOID) 러닝은 세지 않는다. **지갑을 연결한 뒤에 시작한** 러닝만 — 연결 전 러닝은 소급하지 않는다.
  1km 에 못 미친 거리는 다음 러닝으로 이어진다(0.6km + 0.7km → 1회, 0.3km 남음).
- **하루 한도**: 러닝으로 받는 상급은 하루 10회(`premium_run_daily_cap`). 한도를 넘은 1km 는 버리고 1km 에 못 미친 나머지만 남긴다.
- **확률**(등급 가중치 표는 기존 그대로 — 씨앗 공정성 검증이 같은 식으로 된다)

| 종류 | 일반 | 레어 | 에픽 | 레전더리 |
|---|---|---|---|---|
| 무료 뽑기(기존 표) | 55% | 28% | 13% | 4% |
| 상급 뽑기(레어 이상, `premium_min_rarity`) | — | 62.2% | 28.9% | 8.9% |
| 지갑 첫 선물의 첫 번(Genesis) | — | — | 76.5% | 23.5% |

- **상급 뽑기 신발**은 기존 보너스 뽑기처럼 체인에서 발행된다(`chain_ops` BONUS_MINT, 전체 하루 발행 한도 `bonus_mint_global_daily`).
  무료 뽑기 신발은 50km 전에는 꺼낼 수 없다(0023 그대로).

## 서버 — `supabase/migrations/0042_free_draws.sql`

- `draw_daily`(날짜마다 쓴 수) · `premium_run_progress`(모은 거리 · 오늘 준 수) — 앱은 읽지도 쓰지도 못한다.
- `draw_grants.kind` 에 `RUN`(러닝으로 받은 상급)을 더했다 — 화면이 출처마다 남은 수를 보인다.
- `walk_sessions` 에 AFTER INSERT 트리거(`economy.premium_run_credit`) — `record_session` 이 기록할 때 상급을 준다.
- `draw_free()` 오늘 몫 → 가입 선물, `premium_draw()` 새 신발 번호를 돌려준다, `draw_status()` 화면 한 장의 수(모두 남은 수).
- 검사: `supabase/tests/schema_test.sql` — 13회 순서 · 다음 날 3회 · 유료 차단 · 지갑 전 러닝 제외 · 연결 전에 시작한 러닝 제외 ·
  2.5km → 2회 + 0.5km · 이어 세기 · 하루 한도 · 선물 → 러닝 순서 · Genesis 1켤레 · 모두 레어 이상 · 권한.
