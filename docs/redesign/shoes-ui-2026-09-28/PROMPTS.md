## Shared prompt

Create ONE standalone StepUp rarity badge UI ASSET, with a TRUE TRANSPARENT ALPHA background. The only visible object is a single compact HORIZONTAL ROUND-ENDED CAPSULE with Korean label INSIDE. Output landscape 3:1, approximately 1200x400, same layout and consistent text size as the other badges. Badge centered, fills about92% width and72% height; enough transparent padding for subtle glow. No scene, no presentation board, no sheet, no other labels, no buttons stacked, no watermark, no checkerboard baked into image. This is a premium crisp 2D/2.5D MOBILE UI pill shown beside a shoe name, not a huge decorative game panel. Perfectly rounded capsule ends, dark midnight navy interior nearly opaque, delicate polished double hairline border, centered sharply legible bold Korean sans label, minimal internal highlights. No large side icons or wings or protrusions; design details confined to the capsule edges, centered label never obstructed. Refine for small mobile display: simple strong silhouette, subtle craftsmanship, controlled glow, contrast excellent. Each tier is distinguished by subtle EDGE MOTIF and MATERIAL as well as COLOR, but identical outer geometry. Only the stated Korean word in the entire asset. No English. No surrounding app UI.
