전달본 `stepup-crew-claude-package.zip`(SHA-256 `1004201cb69492ac7ead80199c18ae02c433ba724d0c02b479b365ead6e299fe`)에는
사용자가 승인한 이미지 1장, 수정 시안 4장(대기실 · 달리는 중 · 결과 · 공유), 구현 지시서가 들어 있다. 시안 축소본은 [reference/](reference/)에 있다.

- 시안의 인물 · 지도 · 숫자는 예시다. 앱은 실제 명단(이니셜) · 실제 지도 · 실제 기록만 그린다.

## 대표 네 화면

### 대기실 (CR04 · CR05 · CR06 · CR15)

- 머리는 크루 이름과 정확히 "크루 달리기" 배지다. 설명 부제는 없다.
- "출발 준비" 아래에 "4 / 6명 준비"(민트)와 준비 점(2~8명일 때)을 둔다.
  - 글 · 점 · 출발 버튼은 같은 명단에서 센다(`readyCount` · `partySize`).
- 참가자는 3 × 2 그리드로 보인다.
  - 파티 응답에 사진 주소가 없어 이니셜로 그린다. 준비하면 파란 면 + 체크, 준비 전은 흐린 면 + 시계다.
  - 이름(나는 "나")과 짧은 상태("준비 완료" · "준비 전")를 적는다. 진행자만 "진행자 · 준비 완료"처럼 역할을 앞에 붙인다.
  - 일반 참가자에게 "크루원"을 되풀이하지 않는다.
- 6명이 넘으면 다섯 사람과 "+N" 칸을 둔다. "+N"을 누르면 전체 명단 시트가 열린다.
  - 시트는 그리드와 같은 순서이고, 진행자는 대기실에서 내보낼 수 있다.
  - 진행자에게 내보낼 사람이 있으면 "전체 명단 보기" 링크도 둔다.
- 위치 공유 스위치(아이콘 · "함께 달리는 크루원에게만 보여요")는 기본 끔이고 고른 대로 기억한다(바꾸지 않았다).
- "크루에게 알리기 ›"를 둔다. 혼자면 아래 버튼이 이 일을 맡는다.
- GPS · 함께 달린 인원 기준 문단은 "함께 달린 인원 기준 ›" 시트로 옮겼다(서버 0056 `party_near`, 200m).
- 버튼 갈래는 그대로다.
  - 준비 전: "준비하기"
  - 참가자 준비 완료: "출발 대기 중" + "준비 취소"
  - 진행자: "n명과 출발" — 준비 전 인원이 있으면 CR07 에서 확인한다.
  - 혼자: "혼자 출발" + "크루에게 알리기"
  - 준비를 마친 "나"에게는 "준비하기"가 보이지 않는다. 기기 검사(CR04-many)가 이것을 확인한다.

### 달리는 중 (CR09 · CR11 · CR18)

- 위에서부터 이렇게 놓인다.
  1. 크루 이름 · "참여 n명" · 배지
  2. 밝은 실제 지도 카드(남색 덧칠 없음, `CrewBrightMap`)
  3. 같이 달리는 사람 줄
  4. 거리 | 시간 | 평균 페이스 카드
  5. 내 목표 카드("러닝 정보 ›")
  6. 일시정지(주 행동) | 종료(보조)
- 예상 보상 · 내구도 줄은 정상 화면에서 뺐다. 러닝 정보(E03)가 같은 값(예상 SUP · 내구도 · 측정 까닭)을 보인다.
- 지도 크게 보기와 위치 · 측정 문제 띠는 그대로다.
- 연결 끊김 · 방 닫힘 · 되살린 러닝 · 일시정지 띠는 지도 카드와 같은 여백의 둥근 띠다. 옛 명단 · 위치를 숨기는 규칙은 그대로다.

### 결과 (CR13)

- 머리는 "러닝 결과" · 배지 · ⋯ 이다. ⋯ 안에는 기록 보기 · 삭제가 있다.
- 크루 줄: 크루 표시(크루가 정한 머리글자) · 크루 이름 · "함께 출발 n명" 또는 "혼자 출발".
  - 인원은 출발 명단(`lastGroupSize`)이다. 지금 남은 사람 수가 아니다.
- 큰 거리 옆에 "✓ 저장됨"을 한 번만 적는다. 그 아래가 시간 | 평균 페이스다.
- 지도는 180dp 고정에서 넓혔다.
  - 폭의 72%(390dp 화면 약 252dp)이고, 보이는 높이의 42%를 넘지 않는다(160~300dp).
  - 밝은 지도에 내 경로만 그린다. 경로가 없으면 "기록된 GPS 경로가 없어요"다.
- 보상은 한 줄 카드다: 아이콘 · 이름 · 금액(예상 · 반영 완료일 때만) · 상태 알약 ›.
  - 누르면 설명 시트가 열린다.
  - 다시 로그인 · 지급 제외 까닭(자세히 보기) · 미지급 까닭 · 보상 내역은 카드 안에 그대로 둔다.
- 아래는 "크루에 기록 공유"(주 행동)와 "완료"(글자 행동)다.
- 없앤 것: 큰 완료 체크, 큰 완료 제목, "내 기록 저장 완료" 줄, 늘 붙던 보상 설명.

### 공유 (CR21)

- 위에서부터 이렇게 놓인다.
  1. "기록 공유" · 배지
  2. 받는 크루(그 러닝의 크루 · "크루 채팅으로 공유")
  3. "보낼 메시지" 미리보기 하나
  4. 경로 포함 스위치
  5. "크루 채팅에 보내기"
- 미리보기의 글은 보내는 글과 같은 값이다(`CrewShareScreen` 의 `text`).
  - 경로를 끄면 글만, 켜면 글과 실제로 만든 경로 그림이다. 그림을 만드는 동안은 빈 자리만 둔다.
- 보낼 글은 두 줄이 됐다: "크루 러닝 · 1.56 km" / "12:30 · 평균 페이스 8′01″ /km". 예전에는 "크루 러닝 · 1.56 km · 12:30 · 8′01″"였다.
- 경로가 없으면 스위치를 켤 수 없고, 같은 줄에 "기록된 GPS 경로가 없어요"를 적는다.
- 큰 공유 권유 제목 · 기록 요약 카드 · 취소 버튼을 없앴다. 취소는 뒤로 가기가 맡는다.
- 보내는 동안에는 뒤로 · 시스템 뒤로를 막는다. 예전에는 닫으면 보내기가 끊겨 같은 요청 키로 다시 보낼 수 없었다.
- 보내는 중 · 보냄(크루 채팅 보기) · 실패(같은 요청 키로 다시) · 복원 상태 처리는 그대로다.

## 연결 화면

- 진입(CR03): 큰 제목 · 설명 문단을 없앴다.
  - 크루 카드(표시 · 이름 · 한 줄 소개 · 인원 · 지역 · "다른 크루 선택 ›")와 한 줄 안내, "대기실 들어가기"만 둔다.
  - 한 줄 안내는 "누르기 전에는 대기실을 만들거나 참여하지 않아요."다.
- 크루 없음(CR14): 한 줄 안내와 크루 찾아보기 · 크루 만들기 · 자유 러닝으로 시작.
- 동시 출발(CR08): "같은 순간에 함께 출발" 장식 줄과 설명 줄을 뺐다. 서버 출발 시각 3-2-1 은 그대로다.
- CR07 · CR10 · CR12 · CR17 · CR19 · CR20 은 구조를 그대로 두었다. 이미 같은 부품 · 같은 톤이다.

## 시안과 다르게 둔 것

- 사진 대신 이니셜이다. 파티 응답에 사진 주소가 없다.
- 배지는 오른쪽 위다.
  - 승인 이미지는 배지를 이름 아래, ⋯ 을 오른쪽 위에 두었다. 수정 시안 넷은 모두 배지를 오른쪽 위에 두어 그것을 따랐다.
  - 대기실에는 ⋯ 이 할 일이 없어 두지 않았다.
- 승인 이미지는 "나"가 준비 완료인데 "준비하기"가 보인다. 지시서대로 상태와 버튼을 맞췄다.
- 결과 시안의 "함께 출발" 옆 사진 줄은 두지 않았다. 러닝에는 출발 인원 수만 남는다(이름 · 사진은 저장하지 않는다).
- 결과 지도의 "시작" · "도착" 글자 대신 기존 경로 핀(시작 · 끝 점)을 쓴다.
- 기록 카드의 단위는 숫자 옆이다(시안은 아래). 기존 숫자 부품(`FitNumber`)이 칸 폭에 맞춰 줄인다.
- 달리는 중 시안의 뒤로 단추는 두지 않았다. 달리는 중 뒤로는 기존 앱 흐름이 맡는다(러닝은 이어진다).
- 시안의 "러닝 상세"는 앱의 "러닝 정보"(E03 이름)로 적었다.

## 바뀐 사용자 동작

- 공유 화면에 취소 버튼이 없다(뒤로 가기). 보내는 동안에는 뒤로 가기가 듣지 않는다.
- 크루 채팅에 보내는 기록 글이 두 줄이 됐다(평균 페이스 이름 · 단위).
- 달리는 중 예상 보상 · 내구도는 러닝 정보를 열어야 보인다.
- 결과의 보상 설명은 보상 줄을 눌러야 보인다. 문제를 푸는 행동은 그대로 카드 안에 있다.
- 대기실의 GPS 기준 문단은 시트로 옮겼고, 공유 안내 둘째 줄은 없앴다. 진행자의 내보내기는 전체 명단 시트 안에 있다.
- 진입의 "다른 크루 선택"이 큰 보조 버튼에서 카드 안 글자 행동으로 바뀌었다.
