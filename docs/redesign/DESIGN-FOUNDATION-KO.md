# 1차 디자인 교체 기준

2026-09-24. 사용자가 첨부한 옷장을 실제 UI 교체의 첫 대상으로 삼는다. 전체 리디자인 완료를 뜻하지 않는다.

## 이번 교체

- 상단 원본 로고·SUP, 하단 네 탭은 기존 공통 컴포넌트와 규격을 유지한다.
- 옷장은 큰 전신 미리보기 → 의상/신발 탭 → 이미지 중심 3열 목록으로 정리한다.
- 선택 테두리, 착용 체크, `착용 중` 또는 `체험`만 목록에 남긴다. 의상 이름은 접근성 설명으로 제공한다.
- 큰 글자 설정에서는 2열로 바뀐다. 목록은 독립적으로 스크롤한다.
- 뒤로 가기는 러닝 홈으로 돌아간다. 배경 버튼은 현재 배경을 제외한 호환 배경을 무작위로 고른다. 더보기에는 기존 캐릭터 선택·마켓·보관함·신발 상세가 있다.
- 현재 실제 소유 의상은 기본 의상 한 벌이다. 여섯 칸을 채우기 위해 소유권이나 상품을 추가하지 않는다. 데모 모드의 의상은 계속 `체험`으로 표시한다.
- 사용자 참고 이미지의 분홍·보라·올리브 착장은 아직 별도 제작 대상이다. 기존 착장 그림의 품질 차이도 후속 자산 단계에서 맞춘다.

## 공통 규격

`StepUpDesign`과 공통 컴포넌트가 기준이다. 화면별 별도 헤더를 만들지 않는다.

| 요소 | 기준 |
|---|---|
| 좌우 여백 | 20 dp |
| 로고 | 원본 자산, 헤더 높이 26 dp |
| 상단 영역 | 최소 64 dp + 시스템 안전 영역 |
| 아이콘 버튼 | 48 dp 터치 영역, 24 dp 아이콘 |
| SUP | 최소 높이 48 dp, 금액 16 sp, 단위 12 sp |
| 기본 큰 버튼 | 최소 높이 60 dp, 글자 18 sp |
| 하단 탭 | 러닝 → 꾸미기 → 커뮤니티 → 내 정보, 24 dp 아이콘, 13 sp 라벨 |
| 옷장 목록 | 기본 3열, 간격 10 dp, 모서리 12 dp |
| 옷장 미리보기 | 헤더와 하단 탭을 제외한 영역의 56% |

## 교체 가능한 배경

화면 합성 순서: **배경 이미지 → 공통 접지 그림자/무대 → 투명 캐릭터 → 버튼·탭·목록**.

- 원본 배경에는 로고, 캐릭터, 의상, 버튼, 글자를 넣지 않는다.
- `RunnerScene`은 배경과 가독성 마스크를, `CharacterStage`는 캐릭터와 접지를, 루트 화면은 공통 헤더와 하단 탭을 담당한다.
- `WardrobeBackgrounds`에 현재 강변 테라스·야경·노을을 한 목록으로 모았다. 교체는 장면에만 적용하며 착장·장비·목록 위치를 바꾸지 않는다.
- 새 배경은 가운데 발 위치가 빈 지면 위에 놓이는지, 난간이나 물 위에 서지 않는지, 캐릭터의 푸른 가장자리 빛과 충돌하지 않는지 확인한 뒤 목록에 추가한다. 목록 등록만으로 자동 호환이 보장되지는 않는다.
- 앉은 프로필 캐릭터는 벤치가 포함된 별도 전경과 호환 배경 목록이 필요하다. 현재 서 있는 옷장 목록과 섞지 않는다.
- 밝은 배경에서도 목록은 짙은 남색 면을 유지한다. 헤더 가독성 마스크 역시 이미지 파일과 별도다.
- 이번 단계는 기존 3종의 버튼 교체까지다. 서버에서 배경을 공급하거나 일정 시간마다 자동 교체하는 정책·다운로드·캐시는 후속 범위다. 옷장 배경은 화면 상태 복원 범위에서 유지된다.

## 실제 지도에 맞춘 후속 시안

확인한 현재 구현: `MapTiles.kt`, `RouteMapLive.kt`.

- 현재 지도는 MapTiler/OSM **2D 래스터 타일**이다. 기존 합성 시안의 입체 도시·임의 도로·빛나는 3D 지형을 현재 앱 화면처럼 취급하지 않는다.
- 다음 지도 디자인은 실제 앱 지도 캡처를 바탕으로 만든다. 지도 위 경로선·마커·선택 표시·조작 버튼·하단 정보창을 디자인 대상으로 삼는다.
- 지명·도로 모양은 타일 안에 포함돼 있다. 화면 디자인만 바꿔 글꼴이나 특정 지명을 따로 수정할 수 없다. 전체 지도 색조 조정은 가능하지만 도로와 지명이 읽혀야 한다.
- 현 구현의 확대/축소 범위는 3–18, 256 px 타일, 한 번에 최대 24장이다. 회전·기울임·3D 건물은 구현된 동작으로 약속하지 않는다.
- 공급자 출처는 지도 위에 계속 보여야 한다. 하단 시트나 버튼으로 가리지 않는다.
- 로딩·오프라인·타일 실패·경로 없음 상태의 표시 영역을 남겨둔다. 장식 배경의 랜덤 교체는 실제 지도 타일·좌표·경로에 적용하지 않는다.

## 검증

공통 디자인 규칙, 문자열 및 자산 검사를 통과했다. 실제 빌드·같은 소스의 Android 캡처 결과는 `PROGRESS.md`에 이어 기록한다. 캡처에서 기본 보유 상태와 데모 목록을 구분한다.
