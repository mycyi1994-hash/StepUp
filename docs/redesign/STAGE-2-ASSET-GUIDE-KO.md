# 2차 — 옷장 자산과 합성 기준

2026-09-24. 1차 옷장 구조를 유지하며 사용자가 지정한 부드러운 색상의 의상을 실제 자산으로 연결한다.

총 9개. `app/src/main/res/drawable-nodpi/avatar_{lumi,runo}_idle_studio_*.png`, `outfit_studio_*.png`에 저장한다. 기존 캐릭터의 검은 얼굴, 파란 눈, 머리 모양, 신체 비율과 시작 신발을 기준으로 제작했다. RUNO와 LUMI의 재단 차이는 유지한다.

제작 방식은 내장 이미지 생성 도구의 참조 이미지 편집이다. 원본과 생성 프롬프트는 `design/redesign-2026-09/stage2/prompts-pink.json`, `prompts-variants.json`에 기록했다. 자산별 크기·투명도·발 아래 여백은 같은 폴더의 `manifest.json`에 보관한다.

## 실제 앱에 연결하는 기준

- 기존 데모 모드에서 체험 의상으로 선택하고 적용한다. 소유 의상·NFT 상품 목록에는 추가하지 않는다.
- 체험 모드를 끄면 실제 보유 착장으로 돌아가는 기존 동작을 따른다.
- 목록의 첫 여섯 칸은 남색·흰색·분홍 / 파랑·라벤더·올리브 순서다. 기존 추가 의상은 스크롤하면 볼 수 있다.
- 캐릭터 그림은 시작 신발 WND-010을 신고 있다. 다른 신발을 선택한 경우 실제 선택 정보와 미리보기 차이를 화면에 안내한다.
- 그림은 배경과 분리된 PNG다. UI 문구, 선택 테두리, 착용·체험 표시, 버튼은 앱이 그린다.

확인 경로: **내 정보 → 설정 → 데모 모드 켜기 → 꾸미기 → 의상 선택 → 장착하기**.

## 캐릭터·배경 규격

1. 전신은 세로 2:3 캔버스를 기본으로 한다. 머리·모자·포니테일·신발 끝을 자르지 않는다.
2. 불투명한 직사각형 배경을 넣지 않는다. 투명도와 실제 발바닥 아래 여백을 원본에서 측정한다.
3. 앱의 `CharacterStage`가 발 아래 여백을 보정해 공통 접지 위치에 맞춘다. 색상별 임의 위치 조절을 추가하지 않는다.
4. 원본 조명은 세 색상이 같은 방향을 유지한다. 캐릭터 둘레의 약한 빛은 알파에 포함되며, 새 배경에서는 실제 합성 결과로 확인한다.
5. 옷장 배경은 기존 강변 테라스·강변 노을 2종을 재사용한다. 야경은 실제 합성에서 발 아래가 물로 보여 옷장 교체 목록에서 제외했다. 랜덤 배경 목록과 캐릭터 목록은 독립적이다. 추가 배경도 바닥이 맞는지 검토한 뒤 이 구조에 등록한다.
6. 새 배경의 바닥은 캐릭터 발 위치에 빈 지면을 제공해야 한다. 수평선·난간·광원의 위치가 맞지 않으면 같은 목록에 섞지 않는다.
7. 벤치에 앉은 프로필은 벤치와 캐릭터가 맞는 별도 조합이 필요하다. 서 있는 옷장 그림을 잘라 앉은 그림처럼 쓰지 않는다.
