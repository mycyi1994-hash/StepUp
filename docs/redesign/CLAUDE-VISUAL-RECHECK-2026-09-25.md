- **근거 (`ref-390-large-00-home.png`):** 하단 탭의 러닝 / 신발 / 뽑기 / 커뮤니티 / 내 정보가 모두 한 줄로 보이고 읽을 수 있습니다.
- "커뮤니티"는 줄바꿈 없이 한 덩어리로 표시되어 마지막 음절만 다음 줄로 넘어가는 문제가 없습니다.
- "내 정보"도 화면 오른쪽 끝에 붙어 있지만 잘리지 않았습니다.
- 글꼴은 줄이지 않은 큰 글꼴 상태 그대로입니다.
- **남은 차단 요소:** 없음.

### 2. 좁은 화면의 러닝 화면 — **해결됨**
- **진행 중 화면 (`ref-360-normal-03-run_active.png`):**
  - 24:18 타이머 아래에 거리 3.20 km와 평균 페이스 7'35"가 2열로 놓여 있습니다.
  - 지도의 네 모서리가 모두 보입니다.
  - "© MapTiler © OpenStreetMap contributors" 표기가 지도 안 왼쪽 아래에 있고, 고정된 "일시정지" 버튼보다 위에 있어 가려지지 않습니다.
- **완료 화면 (`ref-360-normal-04-run_finish.png`):**
  - 거리 / 운동 시간 / 평균 페이스가 3열의 작은 카드 하나에 들어가 있어 화면의 대부분을 차지하지 않습니다.
  - 그 아래 지도 전체와 출처 표기가 보입니다.
  - "서버 확인 중" 카드 아래쪽이 고정된 "완료" 버튼 뒤로 잘려 있지만, 스크롤 영역이 잘린 것일 뿐 레이아웃이 깨진 것으로 보지 않습니다.
