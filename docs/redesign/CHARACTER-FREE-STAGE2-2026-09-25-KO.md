# 캐릭터 없는 화면 적용 — 2단계

2026-09-25 · `codex/stepup-cohesive-redesign` · 시작 기준 `7d4ff2f`(main 병합 완료)

2단계는 새 시안 10장의 구성을 실제 Compose 화면에 반영하는 작업이다. 아래는 **소스 적용 상태**이며, 기기 캡처 비교를 통과했다는 뜻이 아니다. APK·푸시·배포는 하지 않았다.

## 화면별 적용

| 시안 | 실제 화면 | 이번 적용 |
|---|---|---|
| 01 홈 | HomeScreen | 큰 걸음 수, 목표 막대, 독립 배경 위 네이티브 문구, 일별 수치가 있는 7일 그래프, 거리·시간, 고정 러닝 시작 버튼. 권한 안내도 본문에서 확인 가능. |
| 02 신발 | CustomizeScreen | 기존 보관함 재사용을 전용 신발 선택 화면으로 교체. 선택 미리보기, 실제 보유 사본 2열 목록, 사용 중 표시, 저장 중 중복 탭 방지, 상세·도감·보관함·마켓 연결. 큰 글자는 1열. |
| 03 뽑기 | MysteryBoxScreen | 실제 상자 그림, 도감·지갑 링크, 이용 안내, 고정 뽑기 버튼. 내용은 스크롤. 배포 설정이 없을 때 준비 안내와 비활성 버튼 유지. |
| 04 러닝 중 | RunScreen | 큰 타이머, 거리·페이스 아래 실제 GPS 경로 지도 복원. 경로 수신 전에는 기다림 안내. 기존 시작·일시정지·종료·저장 재시도 유지. |
| 05 러닝 결과 | FinishCard | 기록 3종 → 저장된 경로 → 실제 보상 확인 상태 순서. GPS 경로가 없는 기록은 안내문. 완료·공유 유지. |
| 06 커뮤니티 | TogetherTab | 실제 공개·미래·참가 가능한 모임 최대 3개, 실제 가입 크루 최대 2개, 각각 기존 상세/크루 화면 연결. 샘플 모임을 넣지 않음. |
| 07 내 정보 | ProfileScreen | 실제 프로필 사진/이모지와 편집, 누적 거리 강조, 횟수·시간, 실제 최근 러닝 3개, 기존 기록·지갑·설정 진입 유지. 최근 기록은 미확정 보상 대신 소요 시간 표시. |
| 08 챌린지 | EventsScreen | 독립 풍경 배너, 실제 일일·주간·야간 목표의 기존 선택/진행률/보상 상태 유지. 시안의 예시 10km 이벤트를 새로 만들지 않음. |
| 09 로그인 | LoginContent | 원본 워드마크 → 네이티브 제목 → 독립 풍경 → Google 로그인·약관 순서. 큰 글자에서도 전체 스크롤로 접근. main의 미전송 러닝 업로드 예약 코드 유지. |
| 10 첫 안내 | GuideOverlay | 실제 화면 위 3단계 안내, 진행 막대와 공통 주 버튼. 러닝 시작·신발 탭·내 정보 탭을 실제 대상으로 사용. |

## 모듈·데이터 기준

- 배경 그림, 신발 그림, 상자 그림은 독립 리소스. 화면 전체 시안 PNG를 UI로 넣지 않는다.
- 버튼·문구·숫자·그래프·선택 상태는 네이티브 요소. 공통 PrimaryCta, GlowCard, Header, Navigation을 재사용한다.
- 홈 배경 2종 교체 구조 유지. 신규 생성/삭제 이미지 없음.
- 기존 저장소/사용자/보유 신발/백엔드 변경 없음. 마켓·도감·상세·고급 보관함 진입을 유지한다.
- 뽑기는 기존 배포 설정 조건에 따른다. 이번 디자인 적용은 계약 배포나 거래 성공을 뜻하지 않는다.

## 확인과 다음 단계

통과: 디자인 계약(34개 라우트), 4개 언어 문자열, 패키지 이미지/소리/폰트 검사, diff 공백 검사.

로컬 Java/Android SDK가 없어 Android 컴파일·기기 실행은 이번 단계에서 수행하지 못했다. 따라서 화면 잘림, 다크/라이트, 큰 글자, GPS 지도 표시, 신발 변경 실제 반영은 기기에서 확인이 필요하다. 실제 앱 캡처로 시안과 같다고 판정하지 않았다.

3단계: ExperienceUiTest / DesignReferenceTest의 캐릭터·의상·이전 배치 기대값을 새 화면에 맞게 변경한다.
4단계: 같은 리비전에서 컴파일·기기 상호작용·캡처 비교를 수행한다. 기존 70여 상태 전체의 출시 검수 완료로 확대 해석하지 않는다.
