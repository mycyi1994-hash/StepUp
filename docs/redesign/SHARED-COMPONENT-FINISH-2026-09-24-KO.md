# 공통 화면 부품 디자인 마감 기록

2026-09-24. 기존 로컬 변경 위에 공통 부품을 보완했다. APK/AAB, CI 빌드, 푸시, 배포, 새 이미지 생성은 하지 않았다.

## 반영 내용

| 공통 부품 | 변경 내용 |
|---|---|
| PageHero | 고정된 어두운 막을 테마에 맞는 카드 바탕으로 교체. 제목과 설명 뒤의 바탕을 진하게 유지하고, 그림 쪽은 장면이 보이도록 구성. 설명 14sp/21sp, 가용 폭에 따른 그림 크기, 큰 글자·매우 좁은 폭에서는 본문 우선 |
| PrimaryCta / VoltButton / TwoWaySwitch / CircleControl | 공통 파란 버튼 면을 장식용 밝은 색과 분리. 흰 글자가 밝은 끝에서도 읽히도록 두 색으로 구성. 주 버튼의 움직이는 빛 강도를 0.18에서 0.08로 낮춤 |
| GhostButton / PillChip | 불투명한 공통 바탕 위에 색을 얹어 배경 교체의 영향을 줄임. 밝은 테마와 어두운 테마의 선택 글자 색을 각각 조정 |
| TwoWaySwitch | 아이콘이 차지하는 폭을 제외한 공간에서 긴 분류명이 줄바꿈하도록 배치 |
| ShortcutButton | 최소 높이 48dp, 긴 제목·설명의 줄 제한 제거, 설명 14sp/20sp |
| SmallBadge | 상태 글자 14sp/20sp, 줄바꿈 허용, 독립된 불투명 바탕, 밝은 테마에서도 읽히는 시안·보라 글자 |
| PillChip의 개수 배지 | 16dp 고정 원과 9sp 숫자 대신, 실제 개수 길이와 글자 크기에 따라 커지는 알약형 표시. 숫자 14sp, 아이콘 20dp |
| AdaptiveNumber | 비례 축소 한 번 대신 실제 글자 폭을 측정해 크기를 결정. 큰 글자 설정에서도 측정 결과에 맞게 전체 숫자를 표시. 폭이 부족할 때만 최대 8회 탐색하고 결과를 기억 |

배경 이미지, 캐릭터 이미지, 버튼 면, 라벨, 숫자, 선택 상태는 각각 독립된 요소다. 로고 크기·메인 헤더·탭 소유 구조, 잔액 값, 거래·저장·선택 콜백은 변경하지 않았다. 가로로 스크롤되는 필터 칩의 자연 폭도 유지한다. 이번 기록은 추가 페이지 수나 출시 완료율을 뜻하지 않는다.

## 적용 범위와 확인

소스 목록에서 해당 부품을 직접 참조하는 28개 화면 함수의 기록에 이 문서를 연결했다. 이는 파일 단위 참조 기록이며 각 상태의 실행 검증 결과가 아니다. 이전 작업표의 화면별 구현·검증 상태는 보존했다.

- 디자인 계약: 33개 경로의 공통 헤더/탭/로고 규칙 통과.
- 문자열·기존 자산·공백 검사 통과.
- 누적 로컬 변경 Kotlin 62개 파일 문법 파싱 통과. Android 타입 검사나 컴파일 결과가 아니다.
- 이번 색상 조합의 수치 계산: 공통 버튼 양 끝의 흰 글자 대비 8.09:1 / 5.29:1, 흰 빛이 가장 밝게 겹칠 때 최소 4.65:1. 상태 배지의 계산상 최소 대비는 밝은 테마 4.70:1, 어두운 테마 6.22:1. 선택 필터 칩은 각각 6.00:1 / 5.35:1. 지정한 색상 조합의 계산이며 앱 전체 접근성 인증이나 실제 화면 판정은 아니다.

실제 기기의 작은 화면·큰 글자·테마 전환·줄바꿈·스크롤·버튼 활성/비활성 확인은 아직 남는다. Android 도구가 없는 현재 환경에서는 새 네이티브 캡처를 만들지 않았다. 기존 미지원 착장/포즈, 부위별 캐릭터 합성, 지도/GPS·인증·서버 보상 등 출시 기능의 잔여 과제도 그대로 남아 있다.
